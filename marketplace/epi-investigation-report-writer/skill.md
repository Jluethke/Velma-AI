# Epi Investigation Report Writer

Compile the outbreak investigation into a report documenting the investigation steps, findings, and outcomes.

## Inputs

- `study-results`: Analytical study results
- `control-recommendations`: Recommended and implemented control measures
- `epidemic-curve`: Epidemic curve with intervention timing annotated

## Outputs

- `investigation-report`: Complete outbreak investigation report
- `lessons-learned`: What worked, what to improve, and recommendations for prevention

## Process

1. Structure the report: background, methods, results (descriptive and analytical), discussion, recommendations
2. Include the epidemic curve, attack rate tables, and analytical results
3. Document the control measures taken and their effect
4. Write lessons learned and recommendations for preventing future events
