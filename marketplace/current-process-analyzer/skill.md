# Current Process Analyzer

Analyze the current process to identify root causes.

## Inputs

- `quality-problem`: The quality issue
- `baseline-data`: Current performance data

## Outputs

- `process-map`: Visual map of the current workflow
- `root-causes`: Identified root causes of the quality gap

## Process

1. Map the current process with a flowchart or value stream map.
2. Conduct root cause analysis (fishbone diagram, 5 Whys).
3. Identify the highest-impact root causes to target.
