# Move Out Protection Plan

Protect yourself at move-out: inspection documentation, deposit return timeline, and dispute process.

## Inputs

- `lease_end_date`: When lease ends
- `deposit_amount`: Security deposit paid
- `property_condition`: Current condition of unit

## Outputs

- `move_out_checklist`: Step-by-step move-out protection
- `documentation_plan`: How to document condition at move-out
- `deposit_dispute_prep`: What to do if deposit wrongly withheld

## Process

1. Give proper written notice per lease terms
2. Document unit condition before move-out (photos, video)
3. Request walk-through inspection
4. Get forwarding address on file for deposit return
5. Know state deposit return deadline and dispute process
