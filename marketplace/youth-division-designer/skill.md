# Youth Division Designer

Design age-appropriate divisions with modified rules for youth play.

## Inputs

- `sport-type`: The sport being organized for youth
- `age-range`: The age range of participants in the program

## Outputs

- `youth-divisions`: Division structure with age groups and modified rules for each
- `safety-guidelines`: Safety rules and equipment requirements by age group

## Process

1. Define age group cutoffs (typically 2-year bands).
2. Modify game rules for each age group (field size, game length, scoring, substitution rules).
3. Set equipment requirements and safety guidelines for each division.
4. Document the division structure.
