# Dark Web Objectives Definer

Define the monitoring objectives, keywords, and collection targets for dark web surveillance.

## Inputs

- `organization-profile`: Brand names, domains, key personnel, and product names to monitor
- `threat-profile`: Known threat actors, industry-specific risks, and prior incidents

## Outputs

- `monitoring-requirements`: Keywords, entities, and patterns to watch for
- `collection-targets`: Forums, marketplaces, paste sites, and channels to monitor

## Process

1. Identify all brand names, domain variations, and personnel names to monitor
2. Define credential leak patterns (email domains, internal systems)
3. List threat actor groups known to target the industry
4. Prioritize monitoring targets by likelihood and impact
