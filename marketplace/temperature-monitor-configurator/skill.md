# Temperature Monitor Configurator

Configure monitoring devices and temperature alerts.

## Inputs

- `packaging-specifications`: Selected packaging and refrigerant per product
- `temperature-profiles`: Required temperature range and tolerance per product

## Outputs

- `monitor-configuration`: Configured monitoring devices with alert thresholds
- `alert-rules`: Alert rules and escalation procedures for excursions

## Process

1. Select the monitoring device (data logger, real-time IoT sensor)
2. Configure alert thresholds based on the temperature profiles
3. Set up escalation procedures for temperature excursions
4. Test the monitoring configuration before shipment
