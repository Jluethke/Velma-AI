# Slo Document Compiler

Compile the complete SLO document with all definitions, targets, budgets, and policies.

## Inputs

- `slo-targets`: The SLO targets
- `budget-policy`: Error budget policies

## Outputs

- `slo-document`: Complete SLO document for the service
- `stakeholder-summary`: One-page summary for stakeholders

## Process

1. Compile all SLI definitions, SLO targets, and error budgets
2. Include the error budget policy and escalation procedures
3. Write the stakeholder summary for non-technical audiences
4. Obtain sign-off from engineering and product stakeholders
