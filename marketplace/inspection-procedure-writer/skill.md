# Inspection Procedure Writer

Write the inspection procedures and set up the inspection area.

## Inputs

- `sampling-plans`: Sampling plans
- `inspection-criteria`: Criteria per material

## Outputs

- `inspection-procedures`: Step-by-step inspection instructions per material
- `equipment-list`: Required inspection tools and gages

## Process

1. Write step-by-step procedures for each material type
2. Specify the inspection equipment and calibration requirements
3. Design the inspection record forms
4. Set up the inspection area with adequate lighting, tools, and reference samples
