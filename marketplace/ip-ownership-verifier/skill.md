# Ip Ownership Verifier

Verify ownership and chain of title for each IP asset.

## Inputs

- `ip-inventory`: IP asset inventory
- `target-name`: Target entity name

## Outputs

- `ownership-report`: Verified ownership status for each asset
- `title-issues`: Any gaps or defects in chain of title

## Process

1. Trace assignment chain from inventor or creator to current owner
2. Check employee and contractor IP assignment agreements
3. Identify any co-ownership or joint development situations
