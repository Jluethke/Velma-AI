# Competency Definer

Define the competencies to assess for the role.

## Inputs

- `role-description`: Description of the role and its requirements
- `team-values`: Team and organizational values to assess

## Outputs

- `competency-list`: Prioritized list of competencies to evaluate
- `competency-definitions`: Clear definitions and behavioral indicators for each competency

## Process

1. Analyze the role requirements to identify core competencies
2. Define each competency with observable behavioral indicators
3. Prioritize by importance to the role
4. Validate with the hiring manager
