# Trademark Publication Monitor

Monitor the application through publication and opposition period to registration.

## Inputs

- `serial-number`: Application serial number
- `application-status`: Application status

## Outputs

- `registration-certificate`: Trademark registration certificate or status
- `trademark-file`: Complete trademark registration file

## Process

1. Monitor for publication in the Official Gazette
2. Watch for any opposition filings during the 30-day window
3. Receive the registration certificate or file the statement of use
