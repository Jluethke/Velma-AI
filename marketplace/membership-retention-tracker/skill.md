# Membership Retention Tracker

Track membership metrics and manage retention.

## Inputs

- `member-content-calendar`: The planned exclusive content
- `engagement-activities`: The planned community activities

## Outputs

- `membership-metrics`: Active members, MRR, churn rate, engagement by tier
- `membership-program-plan`: The complete membership program plan with performance data

## Process

1. Track the key metrics monthly: new members, churned members, MRR, engagement rate.
2. Identify the reasons for churn (survey, behavior analysis, cancellation feedback).
3. Test retention interventions (win-back campaigns, loyalty rewards, content adjustments).
4. Produce the program report with metrics and planned adjustments.
