# Voice Usability Tester

Test the voice prototype with users and produce findings.

## Inputs

- `voice-prototype`: Interactive prototype to test
- `test-scenarios`: Scenarios to walk users through

## Outputs

- `usability-findings`: Issues found, severity, and frequency across testers
- `voice-ux-report`: Complete report with persona, flows, test results, and recommended changes

## Process

1. Run the test scenarios with representative users.
2. Record where users got confused, abandoned, or needed to repeat themselves.
3. Classify issues by severity and frequency.
4. Compile the report with the persona, flows, test results, and prioritized fixes.
