# Tabletop Complexity Scaler

Scale the selected scenarios from basic to advanced complexity across the exercise series.

## Inputs

- `scenario-shortlist`: Selected scenarios for the year
- `past-incident-history`: Team's experience level

## Outputs

- `complexity-schedule`: Scenarios ordered by complexity with difficulty rating
- `learning-objectives-per-exercise`: Specific skills each exercise builds on the previous one

## Process

1. Rate each scenario by complexity (number of decision points, time pressure, ambiguity)
2. Order from simplest to most complex across the annual calendar
3. Define learning objectives that build progressively (basic triage, then coordination, then crisis communication)
4. Ensure later exercises assume skills practiced in earlier ones
