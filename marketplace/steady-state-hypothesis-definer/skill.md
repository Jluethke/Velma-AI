# Steady State Hypothesis Definer

Define the steady state hypothesis by identifying normal system behavior metrics and their expected ranges.

## Inputs

- `target-system`: The system or service to experiment on
- `observability-config`: Monitoring and metrics access for the system

## Outputs

- `steady-state-hypothesis`: Defined normal behavior metrics and thresholds
- `measurement-plan`: How to measure the hypothesis during the experiment

## Process

1. Identify the key metrics that define normal system behavior
2. Record current baseline values for each metric
3. Define the acceptable range for each metric during the experiment
4. Document how each metric will be measured in real time
