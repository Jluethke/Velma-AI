# Lesson Categorizer

Categorize lessons by theme for pattern analysis.

## Inputs

- `capture-protocol`: How lessons are captured
- `lesson-template`: Template for recording lessons

## Outputs

- `category-taxonomy`: Lesson categories (process, technical, communication, estimation, tooling)
- `tagging-rules`: How to assign categories to each lesson

## Process

1. Define the top-level categories: process, technical, communication, estimation, tooling, people.
2. Add subcategories where needed.
3. Write the tagging rules (one primary category, up to two secondary).
4. Produce the taxonomy and tagging rules.
