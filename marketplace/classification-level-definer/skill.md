# Classification Level Definer

Define classification levels and their criteria (public, internal, confidential, restricted).

## Inputs

- `regulatory-landscape`: Applicable regulations that drive classification requirements
- `organization-profile`: Organization context, industry, and data types

## Outputs

- `classification-scheme`: Defined levels with criteria for each
- `decision-tree`: Decision tree for classifying data assets

## Process

1. Define each classification level with clear boundaries
2. Establish criteria for assigning data to each level
3. Build a decision tree for consistent classification
4. Align levels with regulatory requirements
