# Punch Walk Documenter

Walk the site with the architect or owner and document each deficiency.

## Inputs

- `project-name`: Name of the construction project
- `walk-participants`: Names and roles of walk participants

## Outputs

- `deficiency-list`: List of deficiencies with location, description, and photo
- `walk-summary`: Summary of the punch walk findings

## Process

1. Walk each area of the project systematically.
2. Photograph and describe each deficiency with its exact location.
3. Categorize each item by severity (cosmetic, functional, code).
4. Number each item for tracking.
