# Territory Quota Setter

Set quotas for each territory based on potential and historical performance.

## Inputs

- `balanced-territories`: Final territory assignments
- `historical-performance`: Past attainment by territory or rep

## Outputs

- `territory-quotas`: Quota for each territory
- `quota-rationale`: How each quota was derived

## Process

1. Start from the territory's market potential.
2. Adjust for historical conversion rates in similar territories.
3. Factor in rep experience and ramp status.
4. Document the derivation for each territory.
