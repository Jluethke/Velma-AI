# Practice Session Protocol

Define the exact protocol for each practice session: warm-up, focused reps, cool-down review.

## Inputs

- `isolation-drill`: The drill
- `feedback-mechanism`: How you get feedback

## Outputs

- `session-protocol`: Step-by-step instructions for running one practice session (30-60 minutes)
- `session-frequency`: How many sessions per week and when, scheduled into the calendar

## Process

1. Warm-up (5 minutes): do 3-5 reps at an easier difficulty to activate the sub-skill without fatigue.
2. Focused practice (20-40 minutes): do reps at the calibrated difficulty. After each rep, score it immediately. After every 5 reps, review what went wrong on the failures and adjust your approach for the next 5.
3. Cool-down review (5-10 minutes): log the session data (total reps, success rate, difficulty level). Write one sentence about the most common failure pattern. Write one sentence about what you will try differently next session.
4. Schedule 3-5 sessions per week. Deliberate practice is mentally taxing, so sessions beyond 60 minutes produce diminishing returns.
