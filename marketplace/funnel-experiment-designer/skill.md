# Funnel Experiment Designer

Design experiments to test the drop-off hypotheses and improve conversion.

## Inputs

- `hypotheses`: Ranked hypotheses
- `drop-off-rates`: Baseline metrics

## Outputs

- `experiment-plan`: Experiments with control, variant, sample size, and duration
- `success-metrics`: Primary and secondary metrics for each experiment

## Process

1. Design an experiment for each top hypothesis
2. Calculate the required sample size
3. Define the success metrics and minimum detectable effect
