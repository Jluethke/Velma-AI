# Nonconformance Handler

Set up the process for handling nonconforming incoming material.

## Inputs

- `inspection-procedures`: Inspection instructions
- `risk-classification`: Material risk levels

## Outputs

- `ncr-process`: Nonconformance reporting and disposition process
- `quarantine-procedure`: Quarantine, return, rework, or use-as-is decision flow

## Process

1. Define the nonconformance report (NCR) form and workflow
2. Set disposition options: return to supplier, rework, use-as-is with concession, scrap
3. Define approval authority for each disposition (quality engineer, customer)
4. Set up the quarantine area and labeling system
