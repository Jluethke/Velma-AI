# Depth Learning Plan

Plan the deep work in the core area toward the depth target.

## Inputs

- `time-allocation`: How learning time is split across depth and breadth
- `core-area`: The one area worth most of your learning time

## Outputs

- `depth-plan`: A sequenced plan for the core area
- `depth-milestones`: Milestones toward the depth target

## Process

1. Sequence the core topics from foundation to frontier.
2. Set milestones that mark progress toward the depth target.
3. Build in deliberate practice for the hardest core sub-skills.
4. Plan how you will test real depth, not just exposure.
