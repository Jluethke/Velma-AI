# Electrode Performance Report

Compile all electrochemical data into a performance report for the electrode.

## Inputs

- `redox-characterization`: CV results
- `surface-area`: Electroactive surface area
- `equivalent-circuit`: EIS fit results
- `stability-data`: Long-term stability data

## Outputs

- `electrode-report`: Complete electrode characterization report with figures, tables, and performance summary
- `performance-metrics`: Key metrics: sensitivity, linear range, detection limit, response time, stability

## Process

1. Assemble the CV, EIS, and stability figures with consistent formatting
2. Tabulate the key performance metrics and compare against literature benchmarks
3. Identify the limiting factors for electrode performance
4. Write the report covering preparation, characterization, results, and recommendations
