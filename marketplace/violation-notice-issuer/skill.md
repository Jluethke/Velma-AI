# Violation Notice Issuer

Issue the notice of violation and set the compliance deadline.

## Inputs

- `violation-documentation`: Documented violation details
- `inspection-report`: The inspection report

## Outputs

- `violation-notice`: The official notice of violation sent to the property owner
- `compliance-deadline`: Deadline for the owner to correct the violation

## Process

1. Prepare the notice of violation citing the specific code sections.
2. Set the compliance deadline based on violation severity.
3. Deliver the notice to the property owner via the required method.
4. Log the notice in the enforcement tracking system.
