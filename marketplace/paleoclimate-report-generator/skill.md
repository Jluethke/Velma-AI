# Paleoclimate Report Generator

Compile the calibration, validation, and reconstruction into a final paleoclimate report.

## Inputs

- `climate-reconstruction`: Reconstructed climate with uncertainty envelope
- `validation-results`: Transfer function validation statistics
- `uncertainty-decomposition`: Sources and magnitudes of uncertainty

## Outputs

- `paleoclimate-report`: Final report with reconstruction plot, validation summary, and interpretation
- `reconstruction-data`: Tabulated reconstruction values with uncertainties for archival

## Process

1. Plot the reconstruction time series with confidence bands and modern climate overlay
2. Summarize transfer function calibration and validation statistics
3. Interpret the reconstruction in the context of known climate events
4. Package the reconstruction data and transfer function for archival
