# Review Report Deliverer

Deliver the 360 feedback report to each participant with context and guidance.

## Inputs

- `anonymized-reports`: Individual reports with aggregated scores and anonymized comments
- `aggregate-patterns`: Organization-wide benchmarks

## Outputs

- `delivered-reports`: Confirmation of report delivery to each participant
- `review-summary`: 360 review program summary with completion rates, patterns, and recommendations

## Process

1. Schedule a 1-on-1 debrief between each participant and their manager or a coach.
2. Deliver the report with context on how to read it (score interpretation, benchmark comparison).
3. Include a development planning template for the participant to set 2 to 3 focus areas.
4. Produce the program summary with completion rates, organization-wide patterns, and process improvements.
