# Quality Program Identification

Identify the applicable quality reporting programs and measures for the practice.

## Inputs

- `practice-profile`: Practice type, specialty, payer mix, and provider count
- `reporting-year`: The calendar year for which quality measures are being reported

## Outputs

- `applicable-programs`: List of programs the practice must or should report to (MIPS, HEDIS, state programs)
- `selected-measures`: Specific measures selected for reporting, with definitions and data requirements

## Process

1. Identify mandatory programs based on practice size and payer participation (MIPS for Medicare, HEDIS for commercial).
2. Select the measures that align with the practice's specialty and patient population.
3. Review each measure's specifications (numerator, denominator, exclusions, data source).
4. Create the reporting timeline with submission deadlines.
