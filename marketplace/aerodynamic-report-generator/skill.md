# Aerodynamic Report Generator

Compile all wind tunnel analysis into a final aerodynamic test report.

## Inputs

- `aerodynamic-plots`: Drag polar, lift curve, and moment plots
- `discrepancy-analysis`: Experimental vs CFD comparison
- `flow-features`: Identified flow features and their evidence

## Outputs

- `aerodynamic-report`: Final report with polars, comparison tables, and flow feature analysis
- `data-package`: All corrected coefficients and raw data in tabular format

## Process

1. Assemble the polars, comparison overlays, and flow visualization figures
2. Build the coefficient summary table at key angles of attack
3. Write the analysis section covering flow features and CFD agreement
4. Package all processed data for archival and future reference
