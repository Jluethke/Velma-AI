# Creative Approval Gate

Run the stakeholder approval process for the produced deliverables.

## Inputs

- `production-deliverables`: The deliverables to approve
- `approved-brief`: The original brief for alignment check

## Outputs

- `approval-status`: Approved, approved with changes, or rejected with reasons
- `final-change-list`: Any remaining changes required before delivery

## Process

1. Present the deliverables to stakeholders alongside the original brief.
2. Collect approval decisions and any required changes.
3. If rejected, identify the specific misalignment and route back for revision.
4. Produce the approval status and final change list.
