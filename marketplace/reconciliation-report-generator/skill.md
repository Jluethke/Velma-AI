# Reconciliation Report Generator

Produce the reconciliation report with summary statistics, discrepancy detail, and recommended actions.

## Inputs

- `investigation-results`: Causes and resolutions for discrepancies
- `correction-actions`: Corrections to apply in each system

## Outputs

- `reconciliation-report`: Summary of matched records, discrepancies found, causes, corrections applied, and remaining open items
- `process-improvements`: Recommendations to prevent recurring discrepancies

## Process

1. Summarize the reconciliation: total records, matched count, discrepancy count by category.
2. List each discrepancy with its cause and resolution status.
3. Identify patterns in the discrepancies that suggest a systemic issue.
4. Recommend process or system changes to reduce future discrepancies.
