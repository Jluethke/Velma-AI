# Seasonal Weatherization Check

Check and improve home weatherization for the coming season: insulation, sealing, windows, and doors.

## Inputs

- `home_type`: House, apartment, etc.
- `upcoming_season`: Which season to prepare for
- `climate_zone`: Geographic climate type

## Outputs

- `weatherization_checklist`: Items to check and fix
- `diy_fixes`: What can be done without a pro
- `cost_estimates`: Estimated costs for improvements

## Process

1. Inspect weather stripping on doors and windows
2. Check insulation in attic and crawlspace
3. Seal visible air leaks
4. Assess window condition
5. Estimate costs for needed improvements
