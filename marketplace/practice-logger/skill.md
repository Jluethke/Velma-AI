# Practice Logger

Run the sessions and log performance against the standard for each repetition.

## Inputs

- `session-plan`: A plan for one focused practice session
- `success-standard`: The standard that marks a repetition as correct

## Outputs

- `practice-log`: A record of results across sessions
- `error-patterns`: The specific errors that recur across repetitions

## Process

1. Record the result of each repetition against the success standard.
2. Note the specific errors that recur across repetitions.
3. Track the success rate across sessions over time.
4. Mark the point where performance plateaus or improves.
