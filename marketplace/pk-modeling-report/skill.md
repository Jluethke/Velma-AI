# Pk Modeling Report

Compile the pharmacokinetics analysis into a report with data summary, model development, diagnostics, simulations, and dosing recommendations.

## Inputs

- `gof-plots`: Goodness-of-fit diagnostics
- `dosing-comparison-table`: Regimen comparison results
- `fitted-parameters`: Final parameter estimates

## Outputs

- `pk-report`: Complete pharmacokinetic modeling report
- `model-code-archive`: Model code, datasets, and output files for reproducibility

## Process

1. Summarize the study data: number of subjects, samples, dose levels, and sampling scheme.
2. Present the model development: structural model, covariate analysis (if population), and final parameters.
3. Include all diagnostic plots and discuss model adequacy.
4. Present dosing simulations and make recommendations based on the target therapeutic window.
