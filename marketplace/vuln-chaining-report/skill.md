# Vuln Chaining Report

Produce the vulnerability chaining exercise report.

## Inputs

- `chain-pocs`: Proof-of-concept chains
- `risk-comparison`: Individual vs chained risk
- `adjusted-ratings`: Severity adjustments

## Outputs

- `chaining-report`: Complete vulnerability chaining report
- `prioritized-fixes`: Which individual fixes break the most chains

## Process

1. Document each attack chain with diagrams and step descriptions
2. Present the risk comparison clearly for non-technical readers
3. Identify which individual fixes would break the most chains
4. Recommend a fix sequence that maximizes risk reduction per effort
