# Breach Notification Reviewer

Review breach notification procedures against GDPR 72-hour requirements.

## Inputs

- `organization-profile`: Organization incident response context
- `processing-register`: Processing activities for breach scenario scoping

## Outputs

- `notification-assessment`: Assessment of breach notification readiness
- `gdpr-compliance-report`: Final GDPR compliance review report

## Process

1. Review the breach detection and classification process
2. Verify the 72-hour supervisory authority notification capability
3. Check the process for notifying affected data subjects
4. Compile all findings into the GDPR compliance report
