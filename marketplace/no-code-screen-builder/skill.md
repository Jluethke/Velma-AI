# No Code Screen Builder

Build the screens, navigation, and interactive elements.

## Inputs

- `data-model`: The app's data structure
- `user-flows`: The user paths to implement

## Outputs

- `built-prototype`: The working prototype with all screens and navigation
- `prototype-url`: URL to access the prototype

## Process

1. Build each screen following the user flow sequence.
2. Connect screens to the data model (forms write, lists read).
3. Add navigation between screens.
4. Test each flow end to end with the sample data.
