# Review Cycle Summarizer

Produce the summary report for the completed review cycle.

## Inputs

- `calibrated-ratings`: Final ratings
- `completion-rate`: Completion rates
- `next-period-goals`: Goals set for next period

## Outputs

- `cycle-summary-report`: Summary of the review cycle outcomes
- `cycle-improvements`: Suggested improvements for the next cycle

## Process

1. Summarize the rating distribution and trends
2. Report completion rates and timeline adherence
3. Identify systemic themes from the calibration discussions
4. Recommend process improvements for the next cycle
