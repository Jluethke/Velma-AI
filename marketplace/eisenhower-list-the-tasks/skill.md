# Eisenhower List The Tasks

Gather the tasks and commitments competing for your time in the window you are planning.

## Inputs

- `task-inbox`: The tasks and commitments pulling on your time.
- `time-window`: The period you are planning for.

## Outputs

- `task-list`: Every task and commitment, each with what it is for.
- `task-notes`: Where each task came from.

## Process

1. List every task and commitment pulling on your time.
2. Write one line on what each task is for.
3. Note where each task came from.
