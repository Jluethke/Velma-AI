# Failure Data Analyzer

Analyze failure data to improve the maintenance program.

## Inputs

- `maintenance-metrics`: KPI data
- `equipment-uptime-report`: Uptime data

## Outputs

- `failure-analysis`: Pareto of failure modes and root causes
- `pm-program-document`: Complete preventive maintenance program document

## Process

1. Run Pareto analysis on equipment failures by frequency and cost
2. Identify chronic failures for root cause analysis
3. Adjust PM intervals based on actual failure data
4. Compile the full PM program document with procedures, schedules, and metrics
