# Marketplace Submission Reviewer

Review and submit the listing, then handle the review process.

## Inputs

- `listing-content`: Marketplace listing materials
- `setup-documentation`: User-facing setup guide

## Outputs

- `submission-status`: Status of the marketplace review and any feedback to address
- `marketplace-listing-doc`: Complete record of the listing: what was submitted, where it is listed, how to update it

## Process

1. Review the complete submission against the marketplace checklist.
2. Submit the listing and track the review status.
3. Address any review feedback and resubmit if needed.
4. Once approved, document the listing URL, update process, and support responsibilities.
