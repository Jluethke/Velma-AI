# Disagreement Discussion Facilitator

Facilitate the discussion by focusing only on disagreements with the recommendation. Agreement does not need airtime. Silence is agreement.

## Inputs

- `decision-statement`: The decision on the table
- `options-list`: The options and trade-offs

## Outputs

- `disagreement-log`: Each disagreement stated, the person who raised it, and whether it was resolved in the meeting
- `new-information`: Any new information surfaced during discussion that changes the trade-offs

## Process

1. Ask: 'Who disagrees with the recommendation, and why?' Go around the room or ask for hands.
2. For each disagreement, clarify: is this new information that changes the trade-offs, or a difference in values or priorities?
3. New information is resolved with data. Value differences are resolved by the decision-maker weighing the trade-offs.
4. If a disagreement cannot be resolved in the meeting, note what would resolve it (data, analysis, external input) and assign an owner.
