# Curriculum Assessment Planner

Design the assessment plan with formative and summative assessments for each outcome.

## Inputs

- `learning-outcomes-list`: List of measurable learning outcomes
- `course-sequence`: Ordered list of courses and modules

## Outputs

- `assessment-plan`: Formative and summative assessments per module
- `assessment-calendar`: Timeline of all assessments

## Process

1. Design formative assessments (quizzes, reflections, peer review) for each module
2. Design summative assessments (exams, projects, portfolios) for each course
3. Schedule assessments across the program timeline
4. Produce the assessment plan and calendar
