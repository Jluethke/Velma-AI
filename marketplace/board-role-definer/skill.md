# Board Role Definer

Define board roles, responsibilities, and expectations.

## Inputs

- `organization-bylaws`: Current bylaws and articles of incorporation
- `board-size-target`: Target number of board members

## Outputs

- `role-descriptions`: Written descriptions for each board position
- `expectations-document`: Board member agreement covering duties and time commitment

## Process

1. Define fiduciary duties (duty of care, loyalty, obedience)
2. Write role descriptions for officers and at-large members
3. Set expectations for attendance, giving, and committee service
4. Draft the board member agreement for signature
