# Topology Reporter

Write the network analysis report: graph statistics, community structure, key nodes, structural properties, and implications for the research question.

## Inputs

- `graph-summary`: Basic statistics
- `community-assignments`: Community structure
- `bridge-nodes`: Bridges and hubs
- `property-test-results`: Structural properties

## Outputs

- `network-report`: Structured analysis report
- `implications`: What the network structure means for the research question

## Process

1. Summarize the graph's basic topology: size, density, degree distribution.
2. Describe the community structure and the roles of key nodes.
3. Report which structural properties hold and what they imply (e.g., vulnerability to targeted attack if scale-free).
4. Connect the findings to the original research question.
