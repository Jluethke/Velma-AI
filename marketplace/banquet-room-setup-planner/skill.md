# Banquet Room Setup Planner

Plan the room setup including layout, AV, and decor.

## Inputs

- `operational-requirements`: Setup requirements
- `venue-specifications`: Room specs

## Outputs

- `setup-diagram`: Room layout diagram with table placement and AV
- `setup-checklist`: Checklist of all items to set up

## Process

1. Design the room layout to meet the event order.
2. Specify table, chair, linen, and place setting counts.
3. Map AV equipment placement and power needs.
4. Create the setup checklist with responsible parties.
