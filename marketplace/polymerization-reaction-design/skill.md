# Polymerization Reaction Design

Design the polymerization reaction: mechanism, initiator, solvent, temperature profile, and target conversion.

## Inputs

- `monomer-candidates`: Selected monomers with purity and reactivity data
- `copolymer-ratios`: Comonomer feed ratios if applicable

## Outputs

- `reaction-protocol`: Step-by-step synthesis protocol with reagent quantities, conditions, and safety notes
- `conversion-targets`: Target conversion, molecular weight, and dispersity

## Process

1. Select polymerization mechanism (free radical, ATRP, RAFT, ring-opening, condensation) based on monomer chemistry
2. Choose initiator, catalyst, and solvent system with rationale
3. Design the temperature and feed profile to control molecular weight and dispersity
4. Write the bench-scale synthesis protocol with safety data sheet references
