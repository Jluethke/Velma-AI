# Primary Fractionation

Separate the crude extract into primary fractions by polarity or size.

## Inputs

- `crude-extract`: Active crude extract to fractionate
- `fractionation-decision`: Recommended method: liquid-liquid partition, flash chromatography, or size exclusion

## Outputs

- `primary-fractions`: Set of fractions with solvent, mass, and fraction ID
- `fractionation-log`: Column conditions, solvent gradient, and fraction collection windows

## Process

1. Set up the fractionation system (column packing, solvent preparation, gradient program)
2. Load the crude extract and collect fractions at defined intervals or polarity steps
3. Evaporate each fraction to dryness and record the recovered mass
4. Label and store fractions for bioassay testing
