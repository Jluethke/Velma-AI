# Species Identification Protocol

Identify and record marine species encountered along transects using visual ID, photography, and taxonomic keys.

## Inputs

- `transect-map`: Planned transect layout with habitat zones
- `target-taxa`: Taxonomic groups of interest (fish, invertebrates, algae, corals)
- `identification-resources`: Field guides, taxonomic keys, and reference photo libraries

## Outputs

- `species-list`: Complete species inventory with abundance counts per transect segment
- `photo-vouchers`: Georeferenced photographs of each identified species for verification
- `unidentified-specimens`: Specimens or photos requiring expert consultation or molecular ID

## Process

1. Swim each transect at constant speed, recording all observed organisms within the survey belt
2. Photograph each species with a scale reference and habitat context
3. Assign field identifications using taxonomic keys and note confidence level for each
4. Collect voucher specimens of uncertain identifications following permit requirements
5. Compile species counts per transect segment with GPS position and depth
