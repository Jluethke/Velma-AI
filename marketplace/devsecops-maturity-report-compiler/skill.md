# Devsecops Maturity Report Compiler

Compile the maturity assessment into a scored report with improvement roadmap.

## Inputs

- `sla-compliance-report`: SLA compliance data
- `champion-program-findings`: Champion program findings
- `training-metrics`: Training completion and effectiveness data
- `integration-gaps`: SDLC integration gaps

## Outputs

- `devsecops-maturity-report`: Full DevSecOps maturity assessment report
- `improvement-roadmap`: Phased improvement plan with quick wins and long-term items

## Process

1. Score each maturity dimension on a scale (initial, managed, defined, measured, optimized)
2. Compare against industry benchmarks if available
3. Build a phased improvement roadmap prioritized by risk reduction per effort
4. Produce the final report with maturity spider chart and narrative
