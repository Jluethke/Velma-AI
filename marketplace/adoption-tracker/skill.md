# Adoption Tracker

Track whether lessons are adopted and measure improvement.

## Inputs

- `action-plan`: Actionable lessons with owners
- `category-taxonomy`: Lesson categories

## Outputs

- `adoption-metrics`: Completion rate and recurrence rate for actioned lessons
- `lessons-learned-report`: Complete lessons learned report

## Process

1. Track action completion status (done, in progress, overdue, dropped).
2. Measure whether the same lesson recurs (recurrence = adoption failure).
3. Aggregate by category to find systemic gaps.
4. Produce the complete lessons learned report.
