# Daily Report Compiler

Compile all field data into the final daily field report.

## Inputs

- `weather-record`: Weather conditions log
- `crew-log`: Crew counts and hours by trade
- `work-description`: Work completed by area
- `delay-log`: Delays with cause and duration

## Outputs

- `daily-field-report`: Complete daily field report
- `report-distribution-list`: Recipients for the daily report

## Process

1. Assemble weather, crew, equipment, work, delay, and safety sections into the report template.
2. Add photos from the day to the appropriate sections.
3. Review the report for completeness and accuracy.
4. Distribute to the project team and file in the project records.
