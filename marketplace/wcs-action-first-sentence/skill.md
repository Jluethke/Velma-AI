# Wcs Action First Sentence

Write the first sentence so it states the action needed and from whom. Readers decide in the first line whether to act, skim, or defer. A message that buries the ask under context gets filed, not done. Confirm the message carries one topic, not three.

## Inputs

- `message-purpose`: What you need to happen as a result of this message
- `recipient`: Who receives it and what they are able to decide or do

## Outputs

- `action-sentence`: A first sentence naming the action, the owner, and the deadline
- `single-topic-check`: A confirmation that the message holds one topic, with any extra topics split into separate messages

## Process

1. Write the first sentence as the action: 'Please approve the attached budget by Thursday' or 'No action needed, sharing for your awareness.'
2. Name who acts and by when inside that first sentence. A deadline that arrives three paragraphs later is a deadline most readers never reach.
3. If the message asks for two unrelated things, split it. One message, one topic, so the reader can act and archive in one pass.
4. If there is genuinely no action, say so in the first line, so the reader can file it with confidence instead of scanning for a hidden ask.
