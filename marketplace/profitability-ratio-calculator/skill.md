# Profitability Ratio Calculator

Calculate profitability ratios: gross margin, net margin, ROE, and ROA.

## Inputs

- `income-statement`: Income statement data
- `balance-sheet`: Balance sheet data for asset and equity bases

## Outputs

- `profitability-ratios`: Margin and return ratios with interpretation
- `dupont-decomposition`: DuPont analysis breaking ROE into components

## Process

1. Calculate gross margin, operating margin, and net profit margin.
2. Calculate return on assets (ROA) and return on equity (ROE).
3. Perform DuPont decomposition (margin times turnover times leverage).
4. Compare to prior periods to identify trends.
