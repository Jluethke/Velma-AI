# Battle Card Builder

Build competitive battle cards for each major competitor.

## Inputs

- `competitor-list`: Competitors to cover
- `talk-tracks`: Existing talk tracks for context

## Outputs

- `battle-cards`: One-page competitive comparison per competitor
- `trap-questions`: Questions that expose competitor weaknesses

## Process

1. Profile each competitor's offering, pricing, and positioning.
2. Identify strengths and weaknesses relative to your offering.
3. Write the trap questions that highlight competitor gaps.
4. Create the one-page battle card per competitor.
