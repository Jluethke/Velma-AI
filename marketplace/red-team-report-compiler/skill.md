# Red Team Report Compiler

Compile the final red team exercise report with findings, evidence, and recommendations.

## Inputs

- `findings-list`: Vulnerabilities and weaknesses exploited
- `debrief-notes`: Joint debrief notes
- `improvement-recommendations`: Agreed improvements

## Outputs

- `red-team-report`: Complete red team exercise report with executive summary
- `remediation-tracker`: Tracking table for each finding with owner and deadline

## Process

1. Write the executive summary with key findings and overall risk assessment
2. Detail each finding with evidence, impact, and recommended remediation
3. Include the attack narrative from initial access through objectives
4. Build the remediation tracker with severity, owner, and target date for each item
