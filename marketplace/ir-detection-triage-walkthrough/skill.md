# Ir Detection Triage Walkthrough

Walk through how the incident would be detected and initially triaged given current tooling and procedures.

## Inputs

- `scenario-document`: The incident scenario
- `organization-context`: Current detection tools and monitoring capabilities

## Outputs

- `detection-assessment`: Assessment of whether and how quickly the incident would be detected
- `triage-walkthrough`: Step-by-step record of triage decisions and their rationale

## Process

1. Identify which monitoring tools or alert rules would fire for this attack
2. Estimate time to detection based on current coverage
3. Walk through initial triage steps: severity classification, scope assessment, evidence preservation
4. Document decisions made and information gaps encountered
