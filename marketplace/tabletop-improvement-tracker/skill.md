# Tabletop Improvement Tracker

Track improvements and action items across exercises to measure program effectiveness.

## Inputs

- `scenario-packages`: Exercise designs with expected outcomes
- `learning-objectives-per-exercise`: Skills each exercise targets

## Outputs

- `improvement-tracker`: Action items from each exercise with owner, status, and completion date
- `capability-trend`: How the team's performance improves across exercises (decision speed, communication quality, procedure adherence)

## Process

1. After each exercise: debrief, collect observations, and list action items
2. Assign each action item an owner and deadline
3. Track completion before the next exercise
4. Score each exercise on key dimensions and plot the trend
