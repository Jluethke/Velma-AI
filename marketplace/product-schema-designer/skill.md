# Product Schema Designer

Define the product data schema including SKU format, attributes, images, and pricing fields.

## Inputs

- `product-categories`: List of product categories to support
- `business-requirements`: Business rules for catalog structure

## Outputs

- `product-schema`: Finalized product data schema
- `sku-format`: SKU naming convention and format rules

## Process

1. Define the core product fields (title, description, price, weight, dimensions).
2. Design the SKU format with category, variant, and sequence components.
3. Specify image requirements (sizes, formats, alt text rules).
4. Document the pricing fields (base price, sale price, MAP, cost).
