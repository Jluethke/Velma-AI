# App Listing Preparer

Prepare the app store listing: title, description, keywords, screenshots, and icon.

## Inputs

- `app-name`: The app's name
- `app-description`: What the app does

## Outputs

- `listing-package`: Title, subtitle, description, keywords, screenshots, and icon
- `keyword-strategy`: Selected keywords and their rationale

## Process

1. Write the app title and subtitle within character limits.
2. Write the description with the key features in the first three lines.
3. Research and select keywords based on search volume and competition.
4. Prepare screenshots showing the main features and icon in required sizes.
