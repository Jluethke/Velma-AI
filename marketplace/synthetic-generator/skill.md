# Synthetic Generator

Generate the synthetic dataset using the selected method.

## Inputs

- `method-config`: Generation configuration
- `data-schema`: Schema and constraints

## Outputs

- `synthetic-dataset`: Generated synthetic data
- `generation-log`: Generation parameters and statistics

## Process

1. Run the generation process with the configuration.
2. Apply all constraints and business rules.
3. Validate the output schema matches the specification.
4. Log the generation parameters for reproducibility.
