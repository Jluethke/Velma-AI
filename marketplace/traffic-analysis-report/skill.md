# Traffic Analysis Report

Produce the network traffic security analysis report.

## Inputs

- `cleartext-findings`: Unencrypted sensitive data findings
- `covert-channel-findings`: Covert channel detections
- `lateral-movement-findings`: Lateral movement indicators
- `unauthorized-services`: Shadow IT findings

## Outputs

- `traffic-report`: Complete network traffic security analysis report
- `remediation-priorities`: Prioritized remediation actions

## Process

1. Compile all findings organized by category and severity
2. Include network diagrams showing problem areas
3. Write remediation recommendations for each finding category
4. Prioritize by risk and implementation effort
