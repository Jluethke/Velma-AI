# Program Effectiveness Measurer

Measure program effectiveness over time using detection rates, response times, and vulnerability trends.

## Inputs

- `success-metrics`: Defined metrics from the charter
- `remediation-workflow`: Where remediation data is tracked

## Outputs

- `effectiveness-report`: Quarterly effectiveness report with trend lines for key metrics
- `program-improvement-actions`: Specific changes to improve the program based on data

## Process

1. Compute detection rate: percentage of red team actions detected by blue team
2. Measure mean time to detect and mean time to respond across exercises
3. Track vulnerability remediation time and recurrence rate
4. Compare metrics quarter-over-quarter to show improvement or regression
