# Growth Program Scaler

Scale the winning growth tactics into an ongoing program.

## Inputs

- `experiment-results`: What each growth experiment produced
- `winning-tactics`: Which tactics worked

## Outputs

- `growth-program`: The ongoing growth program with tactics, cadence, and targets
- `audience-growth-report`: Report on audience growth with projections

## Process

1. For each winning tactic, define the ongoing execution cadence and resources needed.
2. Set growth targets for the next quarter based on experiment results.
3. Build the growth activities into the regular content operations workflow.
4. Set up a monthly review cadence to track progress and adjust.
