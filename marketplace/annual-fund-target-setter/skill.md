# Annual Fund Target Setter

Set the annual fund target based on budget needs and donor capacity.

## Inputs

- `operating-budget`: Organization's annual operating budget
- `donor-history`: Past giving data and donor retention rates

## Outputs

- `fund-target`: Dollar goal with breakdown by segment
- `retention-upgrade-goals`: Targets for donor retention and upgrade rates

## Process

1. Calculate the gap between budget and other revenue sources
2. Set the overall dollar target
3. Break the target down by donor segment (renew, upgrade, acquire, recapture)
4. Set retention and upgrade rate goals
