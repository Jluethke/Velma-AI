# Mechanic Selection Guide

Find and vet a trustworthy mechanic: certifications, reviews, pricing transparency, and test visit.

## Inputs

- `location`: Home or work zip code
- `vehicle_info`: Vehicle type for specialty matching
- `priorities`: Price, convenience, expertise, etc.

## Outputs

- `mechanic_shortlist`: Top candidates with details
- `evaluation_checklist`: What to check on first visit
- `red_flags`: Warning signs of a bad shop

## Process

1. Search for ASE-certified shops nearby
2. Check online reviews and BBB rating
3. Call for price quotes on a standard service
4. Evaluate shop on first visit using checklist
5. Compare to dealer pricing
