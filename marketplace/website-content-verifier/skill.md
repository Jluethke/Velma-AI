# Website Content Verifier

Verify all website content is final, proofread, and correctly formatted.

## Inputs

- `site-url`: The staging or preview URL of the site
- `content-list`: List of pages and content items to check

## Outputs

- `content-issues`: Any content problems found (typos, placeholder text, broken images)
- `content-signoff`: Confirmation that content is ready for launch

## Process

1. Review every page for placeholder text, lorem ipsum, or draft content.
2. Check all images for alt text, correct sizing, and proper loading.
3. Verify all internal links work and external links open correctly.
4. Proofread headings, body text, and microcopy for errors.
