# Processing Activity Describer

Describe the data processing activity including purpose, data types, and data flows.

## Inputs

- `processing-description`: Description of the planned or existing processing activity
- `system-inventory`: Systems involved in the processing

## Outputs

- `processing-record`: Structured description of the processing activity
- `data-flow-diagram`: Diagram showing how data moves through the activity

## Process

1. Document the purpose and necessity of the processing
2. Identify all personal data types and data subjects involved
3. Map the data flow from collection through storage to deletion
4. Identify all processors and sub-processors
