# Processing Activity Inventory

Inventory all processing activities that involve personal data.

## Inputs

- `organization-description`: Description of the organization, departments, and business activities
- `existing-documentation`: Any existing data inventories, privacy policies, or data flow diagrams

## Outputs

- `processing-activities`: List of all processing activities with description, department, and data subjects involved
- `system-inventory`: List of all systems (applications, databases, SaaS tools) that process personal data

## Process

1. Interview each department or review existing documentation to identify processing activities.
2. For each activity, record the description, responsible department, and categories of data subjects.
3. Inventory the systems used for each activity (applications, databases, cloud services, spreadsheets).
4. Note any processing performed by third-party processors on behalf of the organization.
