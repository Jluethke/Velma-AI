# Cross Level Action Tracker

Track action items across all review levels and produce the cadence framework.

## Inputs

- `review-levels`: The review levels
- `escalation-rules`: Escalation rules
- `agendas`: Agendas for each level

## Outputs

- `action-tracking-system`: How actions are tracked across levels (single backlog, linked registers)
- `review-cadence-framework`: Complete operational review cadence framework

## Process

1. Design the action tracking system (one backlog with level tags, or linked registers per level).
2. Set the review-of-reviews mechanism (quarterly review assesses whether the cadence itself works).
3. Assign facilitators for each level.
4. Produce the complete review cadence framework.
