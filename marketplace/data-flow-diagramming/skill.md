# Data Flow Diagramming

Map the data flows between systems, departments, and third parties.

## Inputs

- `data-catalog`: The data element catalog
- `third-party-recipients`: Third parties receiving data

## Outputs

- `data-flow-diagram`: Visual and textual representation of how personal data moves through the organization
- `cross-border-transfers`: List of data transfers outside the jurisdiction with the legal mechanism used

## Process

1. Draw the data flows from collection point through internal systems to storage and deletion.
2. Mark all transfers to third parties and cross-border transfers.
3. Identify the security measures applied at each stage (encryption in transit, at rest, access controls).
4. Flag any flows that lack a documented legal basis or security measure.
