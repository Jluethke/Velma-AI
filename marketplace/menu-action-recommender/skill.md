# Menu Action Recommender

Recommend actions for each menu item (promote, reprice, reformulate, or remove).

## Inputs

- `item-classification`: Item classifications
- `contribution-margins`: Margins per item

## Outputs

- `action-plan`: Recommended action for each item
- `projected-impact`: Projected revenue and margin impact of changes

## Process

1. Stars: maintain quality, keep prominent placement.
2. Plow horses: increase price carefully or reduce cost.
3. Puzzles: reposition on menu, add descriptions, or rebrand.
4. Dogs: remove, replace, or reformulate.
