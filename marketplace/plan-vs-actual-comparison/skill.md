# Plan Vs Actual Comparison

Document what was supposed to happen (the plan) and what actually happened (the outcome), side by side.

## Inputs

- `event-description`: The project, event, campaign, or period being reviewed
- `original-plan`: The plan as it was stated before execution began

## Outputs

- `plan-column`: What was supposed to happen, broken into specific milestones and metrics
- `actual-column`: What actually happened, using the same milestones and metrics
- `delta-list`: Every point where the actual diverged from the plan, whether positive or negative

## Process

1. Retrieve the original plan. Use the actual documented plan, not a reconstructed memory of what the plan was. Memory rewrites the plan to match the outcome.
2. Break the plan into specific, measurable milestones. 'Launch on time' becomes 'Ship version 1.0 by March 15.'
3. For each milestone, record the actual outcome using the same metric. 'Shipped version 1.0 on April 2 (18 days late).'
4. List every delta, positive and negative. Include things that went better than planned (these are as instructive as failures) and things that were not in the plan at all (unplanned events that affected the outcome).
