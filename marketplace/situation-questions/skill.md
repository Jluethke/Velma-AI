# Situation Questions

Open with situation questions to learn the current state before you touch any problem.

## Inputs

- `prep-brief`: The short brief on account and person
- `question-bank`: The grouped questions

## Outputs

- `situation-notes`: What the buyer told you about their current state
- `current-state-map`: A map of how things work for them today

## Process

1. Ask open questions about how things work today, and let the buyer talk without steering.
2. Keep situation questions brief, since too many make the buyer feel interrogated rather than heard.
3. Note the facts in the buyer's own words, since you will mirror them back later.
4. Build a quick map of the current state you can refer to when problems surface.
