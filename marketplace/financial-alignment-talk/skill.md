# Financial Alignment Talk

Align on finances before marriage: debt disclosure, spending styles, accounts, and financial goals.

## Inputs

- `individual_finances`: Each person's financial situation
- `financial_goals`: Shared and individual financial goals
- `money_attitudes`: Each person's relationship with money

## Outputs

- `financial_plan`: Agreed approach to shared finances
- `debt_disclosure`: Full debt picture for both
- `account_structure`: Joint vs separate account plan

## Process

1. Full financial disclosure (income, debt, savings, credit)
2. Discuss money attitudes and family money patterns
3. Agree on joint vs separate account structure
4. Set shared financial goals with timelines
5. Plan for financial disagreement resolution
