# Message Sequence Architect

Arrange the full message in the order the audience can receive it: bridge first, then supporting evidence, then the ask. Most messages fail because they put the ask before the bridge.

## Inputs

- `bridge-sentence`: The sentence connecting their frame to yours
- `supporting-points`: Points reinforcing the bridge
- `knowledge-gaps`: What they need to learn for the message to work

## Outputs

- `message-sequence`: The full message in delivery order: bridge, evidence, gap-fill, ask
- `delivery-notes`: Notes on tone, medium, and timing for delivery

## Process

1. Open with the bridge sentence. This is the first thing the audience hears or reads.
2. Follow with the supporting points, ordered by what matters most to them (not to you).
3. Fill knowledge gaps only where needed to support the ask. Do not educate for its own sake.
4. Place the ask last. By this point, the ask should feel like the logical conclusion of everything before it.
5. Add delivery notes: what medium suits this message (email, in-person, phone), what tone, and when to send it (timing relative to the audience's decision cycle).
