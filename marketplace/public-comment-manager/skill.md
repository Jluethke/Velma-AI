# Public Comment Manager

Publish the proposed rule for public comment and manage the comment period.

## Inputs

- `proposed-rule-text`: Proposed rule for publication
- `regulatory-impact-analysis`: Analysis to publish with the rule

## Outputs

- `public-comments`: All comments received, categorized by issue and commenter type
- `comment-summary`: Summary of comment themes, frequencies, and notable submissions

## Process

1. Publish the proposed rule in the Federal Register with the comment period and submission instructions.
2. Collect comments through the designated channels (regulations.gov, mail, email).
3. Categorize comments by issue, for/against, and commenter type (industry, public, other agency).
4. Summarize the comment themes and identify issues requiring response.
