# Job Description Writer

Write a job description that defines the role, responsibilities, qualifications, and compensation range.

## Inputs

- `role-title`: Title of the open role
- `team-context`: Team size, reporting structure, and mission
- `requirements-notes`: Key skills and experience needed

## Outputs

- `job-description`: Finalized job description
- `role-scorecard`: Key outcomes the hire must deliver in the first year

## Process

1. Define the role purpose and key outcomes
2. List responsibilities ranked by importance
3. Specify required and preferred qualifications
4. Set the compensation range and benefits summary
