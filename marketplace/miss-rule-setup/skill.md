# Miss Rule Setup

Set the never miss twice rule and define exactly what counts as a miss, so the rule is unambiguous under pressure.

## Inputs

- `defined-streak-habit`: The habit carrying the streak
- `streak-baseline`: The current run and gap pattern

## Outputs

- `never-miss-twice-rule`: The written rule that one miss is allowed but a second consecutive miss is not
- `miss-definition`: A precise definition of what counts as a miss and what counts as a completed day

## Process

1. Write the rule plainly: one missed day is acceptable, but you will never miss two days in a row. The second miss is where a streak turns into a lapse.
2. Define a miss precisely. Decide the minimum that counts as a completed day, so you are never arguing with yourself about whether a partial day counts.
3. Frame a single miss as data, not failure. One miss tells you something about your week. Treating it as failure is what triggers the spiral into a second and third.
4. Separate the streak from perfection. The goal is to never let the gap reach two, not to achieve an unbroken record, because perfectionism ends streaks the fastest.
