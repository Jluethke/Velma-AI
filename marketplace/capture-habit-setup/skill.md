# Capture Habit Setup

Set up a reliable way to capture ideas the moment they occur.

## Inputs

- `knowledge-sources`: Where your ideas and inputs come from
- `tooling-constraints`: The tools and limits you will work within

## Outputs

- `capture-workflow`: A fast way to capture every new idea
- `inbox-location`: The single place new ideas first land

## Process

1. Choose a single inbox where every new idea first lands.
2. Define quick capture methods for each place ideas occur.
3. Set a rule that capture is fast and raw, not polished.
4. Confirm the capture step takes only a few seconds.
