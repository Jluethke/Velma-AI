# Known Target Testing

Run each tool against known vulnerability targets to measure detection accuracy.

## Inputs

- `deployed-tools`: Running tool instances
- `test-plan`: Tests to execute

## Outputs

- `detection-results`: What each tool detected and missed
- `false-positive-log`: False positives generated by each tool

## Process

1. Deploy known vulnerable targets: DVWA, WebGoat, Metasploitable, or equivalent
2. Run each tool against the targets and collect results
3. Record true positives, false positives, and false negatives for each tool
