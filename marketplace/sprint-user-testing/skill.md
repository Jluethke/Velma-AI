# Sprint User Testing

Test the prototype with users and produce the sprint report (day 5).

## Inputs

- `prototype`: The prototype to test
- `test-script`: The interview script and tasks

## Outputs

- `test-findings`: What worked, what did not, and patterns across test sessions
- `sprint-report`: Complete sprint report with challenge, solution, test results, and recommendations

## Process

1. Run 5 test sessions with target users using the test script.
2. Note what works, what confuses, and where users struggle.
3. Identify patterns across sessions (3+ users with the same reaction = a pattern).
4. Compile the sprint report: challenge, process, solution, test results, and next steps.
5. Produce the test findings and sprint report.
