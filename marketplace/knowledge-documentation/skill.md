# Knowledge Documentation

Document the extracted knowledge in a format that can be studied and practiced by the learner.

## Inputs

- `cue-catalog`: The cues the expert uses
- `heuristic-library`: The expert's rules of thumb

## Outputs

- `expertise-document`: A structured document containing: the cue catalog, the heuristic library, and 3-5 annotated cases showing the heuristics in action
- `practice-scenarios`: 5 new scenarios (not from the interview) where the learner can practice applying the heuristics and check their answers against the expert's likely decision

## Process

1. Organize the cue catalog by frequency: the cues that appeared in the most cases go first. These are the most important things to learn to notice.
2. State each heuristic as a decision rule: 'When [specific cue pattern], then [specific action], because [reasoning].' Include the reasoning so the learner can adapt the heuristic to new situations.
3. Annotate 3 of the original cases with margin notes showing which cue triggered which heuristic at each decision point. This shows the expertise in action.
4. Create 5 new practice scenarios that require applying the heuristics. Include the 'expert answer' for each, verified with the expert if possible.
