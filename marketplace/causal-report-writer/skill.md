# Causal Report Writer

Write the causal analysis report with the DAG, assumptions, estimate, sensitivity, and limitations clearly stated.

## Inputs

- `causal-dag`: the causal diagram
- `causal-estimate`: the treatment effect
- `sensitivity-results`: robustness findings

## Outputs

- `causal-analysis-report`: complete report with DAG figure, methods, results, sensitivity, and limitations
- `assumption-table`: table of each assumption, its testable implications, and the test result

## Process

1. Present the DAG and the reasoning behind each edge
2. State the identifying assumptions and which are testable vs untestable
3. Report the causal estimate, confidence interval, and sensitivity analysis
4. Discuss limitations, especially the plausibility of unmeasured confounding
