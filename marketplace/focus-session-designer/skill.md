# Focus Session Designer

Design the focus session format and duration.

## Inputs

- `work-type`: Type of work to do during focus sessions (writing, coding, analysis)
- `available-time`: Maximum session length available

## Outputs

- `session-format`: Session structure (pomodoro, 90-minute deep work, custom)
- `session-rules`: Rules for the session (no phone, no notifications, single task)

## Process

1. Select the session format based on work type and attention span.
2. Set the work and break durations.
3. Write the session rules (what is allowed and what is not).
