# Tool Eval Report

Produce the security tool evaluation report with a recommendation.

## Inputs

- `comparison-matrix`: Tool comparison data
- `weighted-scores`: Overall scores
- `compatibility-notes`: Integration issues

## Outputs

- `evaluation-report`: Complete security tool evaluation report
- `recommendation`: Recommended tool with justification

## Process

1. Present the comparison matrix with clear visual scoring
2. Discuss trade-offs between the top candidates
3. Make a specific recommendation with supporting evidence
4. Include deployment roadmap for the recommended tool
