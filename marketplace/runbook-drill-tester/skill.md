# Runbook Drill Tester

Test each runbook during a drill to verify the procedures work and the documentation is clear.

## Inputs

- `runbooks-with-escalation`: Complete runbooks with escalation criteria
- `test-environment`: Environment for testing the runbook procedures

## Outputs

- `drill-results`: Results of testing each runbook
- `runbook-corrections`: Corrections needed based on drill findings

## Process

1. Schedule drills to walk through each runbook with a responder
2. Have the responder follow the runbook exactly as written
3. Note any steps that are unclear, missing, or incorrect
4. Record the time to complete each runbook
