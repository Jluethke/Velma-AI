# Bill Progress Tracker

Track the progress of each bill through the legislative process.

## Inputs

- `tracked-bills`: Bills being monitored
- `priority-classification`: Priority levels for alerting

## Outputs

- `status-updates`: Latest action on each bill (committee hearing, markup, floor vote, conference)
- `amendment-tracker`: Amendments filed, adopted, or rejected that affect the organization's interests

## Process

1. Check each tracked bill for new actions (committee schedules, votes, amendments).
2. Record the latest status and any changes to the bill text.
3. Flag amendments that change the bill's impact on the organization.
