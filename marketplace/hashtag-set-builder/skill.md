# Hashtag Set Builder

Select and organize hashtag sets for each content type.

## Inputs

- `hashtag-candidates`: The researched candidate hashtags
- `volume-data`: Volume and competition data

## Outputs

- `hashtag-sets`: Curated hashtag sets for each content type (product posts, educational, behind-the-scenes, promotional)
- `usage-guidelines`: Guidelines on how many hashtags to use per platform and content type

## Process

1. Select the best hashtags from each category based on volume, competition, and relevance.
2. Group them into sets by content type (e.g., product launch set, educational set, engagement set).
3. Set the hashtag count per platform (e.g., 3 to 5 for Twitter/X, 10 to 20 for Instagram).
4. Write the usage guidelines for the team.
