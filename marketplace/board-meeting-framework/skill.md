# Board Meeting Framework

Set the meeting cadence, agenda framework, and decision-making process.

## Inputs

- `committee-charters`: Committee structure and schedules
- `expectations-document`: Board member time commitments

## Outputs

- `meeting-calendar`: Annual calendar of board and committee meetings
- `agenda-template`: Standard board meeting agenda format

## Process

1. Set the board meeting frequency (monthly, bimonthly, quarterly)
2. Design the standard agenda (consent agenda, committee reports, discussion items, action items)
3. Define the decision-making process (quorum, voting, consent agenda)
4. Build the annual calendar with all board and committee meetings
