# Pulse Cadence Designer

Define the pulse survey cadence and question rotation strategy.

## Inputs

- `engagement-dimensions`: The dimensions to measure (engagement, manager, workload, culture, growth)
- `org-structure`: Teams, departments, and reporting hierarchy for result segmentation

## Outputs

- `pulse-cadence`: Survey frequency (weekly, biweekly, monthly) with question rotation plan
- `question-bank`: Pool of questions organized by dimension with rotation schedule

## Process

1. Select the survey cadence based on organization size and survey fatigue tolerance.
2. Build the question bank with 3 to 5 questions per dimension.
3. Design the rotation so each pulse includes 5 to 8 questions from different dimensions.
4. Include 1 to 2 anchor questions that repeat every cycle for trend tracking.
