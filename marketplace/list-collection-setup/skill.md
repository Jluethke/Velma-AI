# List Collection Setup

Design and deploy email collection points across owned channels.

## Inputs

- `business-context`: The business and what it offers
- `target-audience`: Who should be on the list

## Outputs

- `collection-points`: List of configured collection points (website forms, landing pages, checkout, in-app)
- `opt-in-flow`: The double opt-in confirmation flow

## Process

1. Identify every touchpoint where a visitor can subscribe (website header, footer, pop-up, checkout, blog sidebar, in-app).
2. Design each form with the minimum required fields (email, first name) plus any segmentation fields.
3. Set up the double opt-in confirmation email and landing page.
4. Configure the welcome email triggered on confirmation.
