# Beneficiary Alignment Check

Verify all account beneficiaries match estate plan intentions and fix any mismatches.

## Inputs

- `beneficiary_audit`: Current beneficiaries per account
- `will_decisions`: Intended distributions from will

## Outputs

- `mismatches`: Accounts where beneficiary differs from intent
- `action_items`: Specific changes to make
- `completion_checklist`: Checklist to verify all updates made

## Process

1. Compare each account beneficiary to will intent
2. Flag mismatches and outdated designations
3. Prioritize by account value
4. Generate change forms needed
5. Create follow-up checklist
