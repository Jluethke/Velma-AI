# Feedback Loop Builder

Build an immediate feedback source so each repetition is scored against a standard.

## Inputs

- `practice-task`: A task stripped down to the single sub-skill
- `repetition-plan`: How many focused repetitions fit one session

## Outputs

- `feedback-source`: The source that scores each repetition immediately
- `success-standard`: The standard that marks a repetition as correct

## Process

1. Define the standard that marks a repetition as correct.
2. Choose a feedback source that is immediate, such as a recording, a tool, a coach, or a checklist.
3. Decide how you will capture the result of each repetition.
4. Test that the feedback arrives fast enough to guide the next attempt.
