# Lesson Capture Protocol

Define when and how lessons are captured.

## Inputs

- `project-lifecycle`: Stages of the project lifecycle
- `team-structure`: Who participates in lessons learned sessions

## Outputs

- `capture-protocol`: Rules for when to capture lessons (milestones, project close, incidents)
- `lesson-template`: Template for recording a lesson (what happened, what was learned, action)

## Process

1. Define the capture points: project milestones, project close, post-incident, quarterly review.
2. Design the lesson template (context, what happened, what was learned, recommended action, owner).
3. Assign facilitators for each capture point.
4. Document the capture protocol.
