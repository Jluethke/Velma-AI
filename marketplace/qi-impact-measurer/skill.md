# Qi Impact Measurer

Measure the impact of the change.

## Inputs

- `cycle-results`: PDSA cycle data
- `baseline-data`: Pre-intervention performance

## Outputs

- `impact-analysis`: Statistical comparison of pre and post performance
- `run-chart`: Time-series chart showing performance trend

## Process

1. Compare post-intervention data to baseline.
2. Plot a run chart to visualize the trend.
3. Determine if the change produced a statistically meaningful improvement.
