# Initial Foothold Establishment

Establish the initial foothold from the authorized access vector.

## Inputs

- `initial-access-method`: The access vector used to gain the initial foothold
- `red-team-scope`: Rules of engagement and authorized persistence techniques

## Outputs

- `foothold-documentation`: Initial access details, timestamps, and host information
- `host-reconnaissance`: Local enumeration results from the compromised host

## Process

1. Establish access on the initial host and document the entry vector
2. Perform local enumeration (users, groups, processes, installed software, AV/EDR)
3. Identify the endpoint security products in use and their versions
4. Assess the initial host's network position and connectivity
