# Plain Explanation Writer

Explain the concept in plain language as if teaching a twelve-year-old.

## Inputs

- `concept-scope`: The concept framed as a clear question to answer
- `prior-knowledge-notes`: What you can state about it from memory

## Outputs

- `plain-explanation`: An explanation written in everyday words
- `analogy-list`: Analogies and examples that carry the idea

## Process

1. Write the explanation using only everyday words.
2. Replace technical terms with simple analogies and examples.
3. Keep each sentence focused on one idea.
4. Read it aloud to check a beginner could follow it.
