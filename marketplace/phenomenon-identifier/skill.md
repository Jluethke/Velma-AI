# Phenomenon Identifier

Identify and scope the physical phenomenon to investigate, state the governing theory, and define what measurement would confirm or refute the prediction.

## Inputs

- `research-question`: The physical question or effect to investigate
- `theoretical-context`: Relevant equations, models, or predicted values

## Outputs

- `phenomenon-scope`: Defined effect with parameter ranges and predicted magnitude
- `measurable-quantities`: What to measure, expected values, and required precision
- `governing-equations`: Equations linking measured quantities to the phenomenon

## Process

1. State the physical effect and the theory that predicts it
2. Identify which quantities to measure and to what precision
3. Estimate the expected signal magnitude and noise floor
4. Define the criterion for a positive detection vs null result
