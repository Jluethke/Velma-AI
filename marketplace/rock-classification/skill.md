# Rock Classification

Classify the rock using the mineral assemblage, texture, and appropriate classification scheme.

## Inputs

- `confirmed-minerals`: Identified minerals and proportions
- `texture-description`: Texture data from PPL examination
- `sample-context`: Geological setting for context

## Outputs

- `rock-name`: Formal rock name using the IUGS or appropriate classification scheme
- `classification-rationale`: The classification diagram or criteria used and where the sample plots

## Process

1. Determine if the rock is igneous, metamorphic, or sedimentary based on texture and mineralogy
2. Apply the appropriate classification: QAPF for plutonic, TAS for volcanic, metamorphic facies, or sedimentary
3. Plot the modal composition on the relevant diagram to assign the rock name
4. Note any prefix modifiers (e.g., biotite granite, garnet-bearing amphibolite)
