# Independent Follower Test

Have a different person, not the doer, follow the draft and perform the task while recording every point they get stuck. The author cannot find the gaps because the author already knows the answers.

## Inputs

- `draft-procedure`: The first written procedure
- `assumed-knowledge`: The draft's assumed context

## Outputs

- `stuck-points`: Every place the follower could not proceed from the document alone
- `follower-feedback`: What the follower needed that the document did not provide

## Process

1. Give the draft to someone who does not already know the task.
2. Have them attempt the task using only the document, without asking the doer.
3. Record every point where they stall, guess, or have to ask a question.
4. Capture what information would have unblocked each stuck point.
