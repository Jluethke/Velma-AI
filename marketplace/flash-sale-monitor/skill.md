# Flash Sale Monitor

Monitor real-time performance and manage post-sale fulfillment.

## Inputs

- `inventory-reserves`: Reserved inventory levels
- `marketing-assets`: Active marketing campaigns

## Outputs

- `sale-performance`: Real-time sales, revenue, and inventory data
- `flash-sale-report`: Post-sale performance report

## Process

1. Monitor sales velocity, inventory levels, and site performance in real time.
2. Adjust inventory reserves or extend the sale window if needed.
3. Process the surge in orders through fulfillment.
4. Produce the post-sale report (revenue, units sold, margin, new customers).
