# Eis Documentation And Review

Compile the Environmental Impact Statement, manage public and agency review, and prepare responses to comments.

## Inputs

- `impact-assessment`: Completed impact assessments for all topics
- `mitigation-measures`: Designed mitigation and monitoring program

## Outputs

- `environmental-impact-statement`: Complete EIS document with non-technical summary, ready for submission
- `comment-responses`: Responses to public and agency comments with any assessment revisions

## Process

1. Structure the EIS. Non-Technical Summary (NTS): plain language, illustrated, standalone document that the public can understand. Main document chapters: Introduction (project need, alternatives considered), Project Description, Assessment Methodology, Baseline Conditions, Assessment of Effects (one chapter per topic), Mitigation and Monitoring, Cumulative Effects, Summary of Residual Effects. Technical appendices: survey reports, modeling data, consultation records.
2. Write clearly. Each topic chapter: describe baseline, describe impact pathways, state predicted impact magnitude, state receptor sensitivity, derive significance. Use consistent terminology (the significance matrix). Present results in summary tables (receptor, impact, magnitude, sensitivity, significance before mitigation, mitigation measure, residual significance). Be honest about uncertainty: state confidence level in predictions, identify assumptions.
3. Alternatives analysis. NEPA requires analysis of alternatives including no-action. Present alternatives genuinely considered: route alternatives, technology alternatives, timing alternatives. Explain why each was selected or rejected based on environmental, technical, and economic factors. The preferred alternative should emerge from the comparison, not be predetermined.
4. Submit for review. Public notice of availability (Federal Register for NEPA, local newspapers). Review period: minimum 45 days for EIS (NEPA), 30 days for EA. Public hearing if required or requested. Agency review: cooperating agencies (USFWS for endangered species, USACE for wetlands, SHPO for cultural resources).
5. Respond to comments. Categorize comments by topic. Prepare substantive responses to each unique comment. If comments identify new information or errors: revise the assessment, prepare supplemental EIS if changes are significant. Compile responses into a final EIS or Record of Decision (ROD). The ROD states the decision, identifies the selected alternative, and commits to the mitigation measures.
