# Wearable Data Type Definer

Define the data types to collect from wearable devices.

## Inputs

- `wearable-devices`: The wearable devices to integrate (fitness bands, smartwatches, medical devices)
- `data-use-case`: How the wearable data will be used (wellness programs, clinical monitoring, research)

## Outputs

- `data-types`: List of data types to collect (steps, heart rate, sleep, SpO2, location)
- `privacy-requirements`: Privacy and consent requirements for the collected data

## Process

1. List each wearable device and the data types it produces.
2. Select the data types needed for the use case.
3. Document the privacy and consent requirements (opt-in, anonymization, retention limits).
