# Decisionjournal State Expected Outcome

State the outcome you expect and how confident you are, as a percentage.

## Inputs

- `alternatives-considered`: The real options you weighed.
- `rejected-reasons`: Why you rejected each alternative.

## Outputs

- `expected-outcome`: The result you expect from the decision.
- `confidence-level`: A confidence percentage on the expected result.

## Process

1. Write the result you expect from the decision.
2. Assign a confidence percentage to that expected result.
3. Set the date by which the outcome should be clear.
