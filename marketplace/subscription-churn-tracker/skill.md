# Subscription Churn Tracker

Set up churn tracking and retention programs.

## Inputs

- `fulfillment-plan`: Fulfillment workflow
- `pricing-model`: Pricing and billing details

## Outputs

- `churn-metrics`: Churn rate tracking and cohort analysis setup
- `subscription-box-plan`: Complete subscription box plan

## Process

1. Define churn metrics (monthly churn rate, LTV, payback period).
2. Set up cohort tracking by sign-up month.
3. Design retention interventions (skip option, gift, survey before cancel).
4. Produce the complete subscription box plan.
