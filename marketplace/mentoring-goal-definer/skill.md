# Mentoring Goal Definer

Define the goals and expectations for the research mentoring program.

## Inputs

- `program-context`: Department or institution context for the mentoring program
- `participant-pool`: Description of potential mentors and mentees

## Outputs

- `mentoring-goals`: Defined goals for the mentoring program
- `mentoring-expectations`: Expectations document for mentors and mentees

## Process

1. Define program goals (research skill development, publication, grant writing)
2. Set expectations for meeting frequency and duration
3. Define mentor responsibilities (feedback, networking, career guidance)
4. Define mentee responsibilities (preparation, follow-through, communication)
