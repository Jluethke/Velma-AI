# Audience Targeting Builder

Build audience targeting for each platform.

## Inputs

- `platform-plan`: Selected platforms
- `audience-requirements`: Targeting requirements

## Outputs

- `targeting-config`: Audience definitions per platform
- `exclusion-lists`: Audiences to exclude

## Process

1. Define the target audience demographics and interests per platform
2. Set up lookalike or similar audiences where available
3. Define exclusion lists to avoid wasted spend
