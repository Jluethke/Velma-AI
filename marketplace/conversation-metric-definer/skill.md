# Conversation Metric Definer

Define the metrics that measure conversational AI performance.

## Inputs

- `conversational-channels`: Channels to measure (voice, chat, email, social)
- `business-goals`: What success looks like (resolution rate, containment, satisfaction, cost per contact)

## Outputs

- `metric-catalog`: Defined metrics with formulas, data sources, and targets
- `data-collection-plan`: What data to capture from each channel and how

## Process

1. Define the core metrics (containment rate, escalation rate, resolution rate, average handle time, CSAT).
2. Add the intent-level metrics (recognition accuracy, slot fill rate, task completion rate per intent).
3. Map each metric to its data source and collection method.
