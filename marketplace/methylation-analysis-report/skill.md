# Methylation Analysis Report

Compile the DNA methylation analysis into a report with QC, methods, DMR results, annotations, and biological interpretation.

## Inputs

- `qc-summary`: Quality control results
- `dmr-statistics`: DMR detection results
- `pathway-analysis-results`: Biological significance findings
- `biological-interpretation`: Summary interpretation

## Outputs

- `methylation-report`: Complete epigenomics analysis report
- `supplementary-tables`: Full DMR list, annotations, and pathway results for download

## Process

1. Present QC metrics, alignment statistics, and conversion rates.
2. Show genome-wide methylation patterns and DMR summary statistics.
3. Include volcano plots, heatmaps of top DMRs, and genomic distribution plots.
4. Discuss biological significance, pathway enrichment, and study limitations.
