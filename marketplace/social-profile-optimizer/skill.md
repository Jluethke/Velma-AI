# Social Profile Optimizer

Create or optimize profiles on each platform.

## Inputs

- `account-inventory`: The current account inventory
- `gap-list`: Platforms needing new accounts

## Outputs

- `optimized-profiles`: Profile details for each platform (bio, profile image, cover image, links, CTA)
- `brand-consistency-checklist`: Checklist confirming visual and messaging consistency across platforms

## Process

1. Create accounts on platforms in the gap list.
2. Write the bio for each platform, adapted to its character limit and tone.
3. Set the profile image, cover image, and brand colors consistently.
4. Add the website link, contact information, and call-to-action on each.
