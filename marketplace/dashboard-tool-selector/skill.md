# Dashboard Tool Selector

Choose the visualization tool and set the refresh cadence.

## Inputs

- `layout-wireframe`: Dashboard layout design
- `visual-type-map`: Chart types needed

## Outputs

- `tool-selection`: Chosen visualization platform with rationale
- `refresh-schedule`: How often each data source refreshes

## Process

1. Evaluate available tools against the visual types and data sources needed.
2. Select the tool and document the rationale.
3. Set the refresh cadence for each data source (real-time, hourly, daily).
