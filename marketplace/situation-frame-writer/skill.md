# Situation Frame Writer

Write the Situation: the context the audience already knows. This grounds the story in shared reality. If the audience does not recognize the situation, your complication will not register.

## Inputs

- `decision-statement`: The decision the data supports
- `audience-and-decision`: Who the audience is

## Outputs

- `situation-statement`: 1-3 sentences establishing the context the audience already agrees on
- `shared-assumptions`: The assumptions embedded in the situation that the audience accepts without evidence

## Process

1. Write the situation in the audience's own language. 'We launched product X in Q1 targeting mid-market buyers.'
2. Include only facts the audience already accepts. The situation is not where you argue. It is where you establish common ground.
3. Test: would every person in the audience nod at every sentence? If anyone would push back, move that sentence to the complication.
