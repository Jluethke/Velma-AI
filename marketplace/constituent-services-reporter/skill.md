# Constituent Services Reporter

Report on constituent service metrics and trends.

## Inputs

- `resolution-record`: Resolved request records
- `constituent-response`: Responses delivered

## Outputs

- `service-metrics`: Metrics on request volume, resolution time, and satisfaction
- `constituent-services-report`: Summary report on constituent services performance

## Process

1. Aggregate request data by category, department, and time period.
2. Calculate resolution time, first-contact resolution rate, and backlog.
3. Identify the top issue categories and any emerging trends.
4. Produce the constituent services performance report.
