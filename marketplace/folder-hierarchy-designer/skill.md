# Folder Hierarchy Designer

Define the target folder hierarchy, naming convention, and organizational rules.

## Inputs

- `folder-inventory`: Current folder tree from the audit
- `naming-issues`: Naming problems identified in the audit

## Outputs

- `folder-hierarchy`: Target folder tree with descriptions of what goes where
- `naming-convention`: Naming rules for files and folders (format, date handling, versioning)

## Process

1. Group the existing folders by function (projects, departments, shared resources, archive).
2. Design the target hierarchy with no more than four levels of nesting.
3. Define the naming convention: lowercase or title case, date format, version suffix, separator character.
4. Document where each category of file belongs in the new structure.
