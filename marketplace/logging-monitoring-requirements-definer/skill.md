# Logging Monitoring Requirements Definer

Establish security logging and monitoring requirements for detection, investigation, and compliance.

## Inputs

- `threat-requirements`: Security requirements derived from threats
- `applicable-regulations`: List of regulations that apply

## Outputs

- `logging-requirements`: What events to log, log format, integrity, and retention requirements
- `security-requirements-document`: Complete security requirements document covering all categories

## Process

1. Define which security events must be logged (authentication, authorization, data access, changes).
2. Specify log format, integrity protection, and retention periods per regulation.
3. Compile all requirement categories into the final security requirements document.
