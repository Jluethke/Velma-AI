# Mobile Usability Auditor

Audit mobile usability: viewport, tap targets, font sizes, and responsive layout.

## Inputs

- `speed-report`: Speed test results
- `site-url`: The site URL

## Outputs

- `mobile-findings`: Mobile usability issues found
- `mobile-fixes`: Fixes prioritized by impact on mobile users

## Process

1. Check viewport meta tag configuration.
2. Test tap target sizes and spacing.
3. Verify font sizes are readable without zooming.
4. Test layout on multiple phone screen sizes.
