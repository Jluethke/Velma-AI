# Practice Adjuster

Review the log and adjust the target, difficulty, or feedback for the next cycle.

## Inputs

- `practice-log`: A record of results across sessions
- `error-patterns`: The specific errors that recur across repetitions

## Outputs

- `practice-adjustments`: Changes to make for the next cycle
- `next-cycle-plan`: The plan for the next practice cycle

## Process

1. Read the error patterns to find the next limiting sub-skill.
2. Raise difficulty when success is reliable, or lower it when progress stalls.
3. Adjust the feedback source if it is not catching the real errors.
4. Write the plan for the next practice cycle.
