# Outcome Variance Definer

Define expected outcomes and variance tracking criteria.

## Inputs

- `pathway-map`: Care activities by timeline
- `evidence-summary`: Evidence-based benchmarks

## Outputs

- `outcome-measures`: Expected outcomes with target values
- `variance-criteria`: Conditions that constitute a variance from the pathway

## Process

1. Define the primary outcome measures (length of stay, readmission, complication rate).
2. Set target values based on evidence and benchmarks.
3. Define what constitutes a variance and how to document it.
