# Life Area Definer

Define the life areas to set goals for.

## Inputs

- `life-areas`: Areas of life to consider (career, health, relationships, finances, learning)
- `current-situation`: Brief description of where things stand now

## Outputs

- `focus-areas`: Selected areas to set goals for
- `area-assessments`: Current state assessment for each area

## Process

1. Rate satisfaction in each life area on a 1-10 scale.
2. Select 2-4 areas with the largest gap between current and desired state.
3. Write a one-sentence assessment of each selected area.
