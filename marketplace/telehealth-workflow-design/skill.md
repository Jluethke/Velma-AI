# Telehealth Workflow Design

Design the virtual visit workflow from scheduling through follow-up.

## Inputs

- `platform-selection`: Selected telehealth platform
- `practice-requirements`: Practice workflows and visit types

## Outputs

- `telehealth-workflow`: Step-by-step workflow for virtual visits (scheduling, intake, consent, visit, documentation, follow-up)
- `consent-forms`: Telehealth-specific consent forms for patient signature

## Process

1. Map the virtual visit workflow (scheduling, pre-visit tech check, intake, consent, video visit, post-visit).
2. Design the patient-facing process (how to join, what to prepare, technical requirements).
3. Create the telehealth consent form covering risks, limitations, and privacy.
4. Define the documentation requirements for telehealth visits.
