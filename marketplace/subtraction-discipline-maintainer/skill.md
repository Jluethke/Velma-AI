# Subtraction Discipline Maintainer

Set up the discipline to prevent claim creep. Without maintenance, messaging accumulates claims over time and returns to the blurry state.

## Inputs

- `rebuilt-messaging`: New messaging framework
- `removable-claims`: The do-not-say list

## Outputs

- `messaging-governance-rules`: Rules for adding new claims: any new claim must survive the subtraction test and not contradict the core
- `quarterly-audit-checklist`: Checklist for re-running the subtraction exercise quarterly to catch claim creep

## Process

1. Rule: any new claim proposed for marketing materials must pass the subtraction test before it is added. If removing it would not change the right customer's decision, it does not go in.
2. Rule: the core statement does not change unless the business fundamentally changes. It is the anchor, not a rotating tagline.
3. Set a quarterly audit: re-collect all messaging, re-count the claims, and re-run the subtraction test. If the claim count has crept above the post-subtraction baseline, cut back.
