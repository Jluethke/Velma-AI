# Inversion List Failure Paths

Enumerate every way the effort could fail, holding back no path as too unlikely.

## Inputs

- `failure-question`: The goal rewritten as a question about causing failure.
- `failure-frame`: The failure stated as something you are trying to produce.

## Outputs

- `failure-paths`: Every action or condition that would move toward failure.
- `failure-ranked`: The failure paths ordered by how easily each could happen.

## Process

1. Brainstorm every action or condition that would move toward failure.
2. Include slow failures and sudden ones, inside causes and outside causes.
3. Rank the failure paths by how easily each could happen.
