# Seasonal Crop Plan Compiler

Compile the final seasonal crop plan document.

## Inputs

- `planting-schedule`: Planting calendar
- `input-list`: All input requirements
- `irrigation-plan`: Irrigation schedule

## Outputs

- `seasonal-crop-plan`: Complete plan for the growing season
- `milestone-checklist`: Key dates and action items through the season

## Process

1. Consolidate the planting schedule, input plan, and irrigation plan.
2. Create a milestone checklist with critical dates.
3. Review the plan for conflicts or gaps.
4. Produce the final seasonal crop plan document.
