# Keyword Gap Analyzer

Assess current keyword rankings and identify gaps against competitors.

## Inputs

- `site-url`: Site being audited
- `on-page-issues`: On-page data for context

## Outputs

- `keyword-rankings`: Current rankings by keyword and page
- `keyword-gaps`: Keywords competitors rank for that the site does not

## Process

1. Pull current keyword rankings
2. Identify competitor keywords the site does not rank for
3. Estimate traffic opportunity for each gap keyword
