# Compounding Content Refresher

Set up the refresh cycle. Compounding content decays into inaccuracy if not maintained. The refresh is what keeps it compounding.

## Inputs

- `production-calendar`: Content production plan
- `content-classification`: Existing compounding pieces that need refresh

## Outputs

- `refresh-schedule`: Each compounding piece mapped to its refresh cadence (6 or 12 months) based on how fast the topic changes
- `refresh-checklist`: What to check on each refresh: factual accuracy, links still working, new information to add, outdated sections to remove, search ranking position

## Process

1. For each compounding piece, set the refresh cadence based on topic volatility. Fast-moving topics (technology, pricing): every 6 months. Stable topics (principles, processes): every 12 months.
2. On each refresh: check facts, update numbers, add new information that has emerged since the last version, remove anything that is no longer accurate, and re-optimize the title and structure based on current search patterns.
3. After each refresh, track the impact: did traffic increase? Did the piece regain or improve its search ranking? If yes, the refresh worked. If no, the topic may have shifted and the piece needs a rewrite, not a refresh.
