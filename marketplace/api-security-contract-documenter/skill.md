# Api Security Contract Documenter

Document the API security contract: the full set of security guarantees, requirements, and usage constraints.

## Inputs

- `authn-design`: Authentication design
- `rate-limit-rules`: Rate limits per endpoint

## Outputs

- `api-security-contract`: Security contract document covering authentication, authorization, validation, rate limiting, and error handling
- `secure-api-design-document`: Complete secure API design document for the development team

## Process

1. Compile all security design decisions into the API security contract.
2. Write the developer-facing documentation with examples of correct and incorrect usage.
3. Produce the final secure API design document.
