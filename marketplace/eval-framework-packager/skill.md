# Eval Framework Packager

Package the evaluation framework with documentation.

## Inputs

- `eval-pipeline`: Automated evaluation code
- `human-eval-protocol`: Human evaluation protocol

## Outputs

- `eval-framework`: Complete evaluation framework package
- `framework-report`: Documentation of all metrics, datasets, and protocols

## Process

1. Combine automated and human evaluation into one framework.
2. Write the usage documentation.
3. Define the evaluation cadence and triggers.
4. Package for integration with the CI/CD pipeline.
