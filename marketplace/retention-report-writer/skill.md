# Retention Report Writer

Produce the retention analysis report with findings and action plan.

## Inputs

- `churn-metrics`: Retention and churn data
- `churn-reasons`: Root causes
- `intervention-playbook`: Designed interventions

## Outputs

- `retention-report`: Analysis report with findings and recommendations
- `tracking-plan`: Metrics and cadence to track intervention effectiveness

## Process

1. Summarize churn trends and their financial impact.
2. Present the top churn drivers with supporting data.
3. Document each intervention and its expected impact.
4. Define the tracking metrics and review cadence.
