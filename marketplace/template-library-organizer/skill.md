# Template Library Organizer

Organize the templates into a library with categories, versioning, and an approval process.

## Inputs

- `template-files`: The template files
- `usage-instructions`: How to use each template

## Outputs

- `library-structure`: The organized template library with categories, naming, and version numbers
- `template-library-document`: Complete guide to the template library: what is available, how to find it, and how to request changes

## Process

1. Organize templates into categories (sales, operations, finance, HR, legal, marketing).
2. Set the naming convention: [Category]-[Document Type]-v[Version] (e.g., Sales-Proposal-v1.0).
3. Define the versioning and approval process: who can edit a template, how changes are reviewed, and how new versions are published.
4. Compile the template library document with a table of contents, usage instructions, and the change request process.
