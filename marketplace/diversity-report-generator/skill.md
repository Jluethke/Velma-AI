# Diversity Report Generator

Compile all diversity analysis results into a structured ecology report.

## Inputs

- `alpha-diversity-table`: Within-site diversity indices
- `permanova-results`: Between-group composition test results
- `rarefaction-curves`: Rarefaction and richness estimation results

## Outputs

- `diversity-report`: Final report with diversity tables, ordination plots, and rarefaction curves
- `analysis-archive`: All matrices, statistics, and computed indices for reproducibility

## Process

1. Assemble diversity summary tables and ordination figures
2. Present PERMANOVA and dispersion test results with ecological interpretation
3. Include rarefaction curves showing sampling adequacy
4. Package all computed data for archival and reproducibility
