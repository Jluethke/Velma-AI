# Email Dashboard Designer

Design the dashboard layout and visualizations.

## Inputs

- `kpi-definitions`: The KPIs to display
- `data-model`: The data model powering the dashboard

## Outputs

- `dashboard-layout`: The dashboard layout with sections (overview, campaign detail, segment comparison, health metrics)
- `visualization-specs`: Specifications for each chart (type, metric, dimensions, filters)

## Process

1. Design the overview section: headline metrics with period-over-period trend arrows.
2. Design the campaign detail section: table of recent campaigns with sortable performance columns.
3. Design the segment comparison section: side-by-side performance by segment.
4. Design the health section: bounce rate, complaint rate, and list growth trend lines.
