# Automation Tester

Test each automation and scene to verify correct operation.

## Inputs

- `automation-rules`: The automation rules
- `access-config`: Remote access configuration

## Outputs

- `test-results`: Pass/fail results for each automation and scene
- `automation-plan`: The complete smart home automation plan

## Process

1. Trigger each automation manually and verify the expected devices respond.
2. Activate each scene and confirm all devices reach the correct state.
3. Test remote access from outside the home network.
4. Document any failures and their fixes in the final automation plan.
