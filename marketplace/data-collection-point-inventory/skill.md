# Data Collection Point Inventory

Inventory all points where personal data is collected from individuals.

## Inputs

- `organization-context`: Description of the organization and its data collection activities
- `digital-properties`: List of websites, apps, and other digital properties

## Outputs

- `collection-point-inventory`: Complete list of data collection points (web forms, app screens, phone, in-person, third-party)
- `data-purposes`: The purposes for which data is collected at each point

## Process

1. List all digital properties (websites, mobile apps, web apps) and their data collection forms.
2. Identify offline collection points (phone, in-person, paper forms, events).
3. Document the data types collected and the stated purpose at each point.
4. Note any third-party collection (analytics scripts, advertising pixels, embedded content).
