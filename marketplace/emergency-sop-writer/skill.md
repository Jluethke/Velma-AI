# Emergency Sop Writer

Write the standard operating procedures for each priority hazard.

## Inputs

- `eoc-org-chart`: EOC organization
- `role-assignments`: Role definitions

## Outputs

- `emergency-sops`: Standard operating procedures for each priority hazard
- `notification-procedures`: Public notification and evacuation procedures

## Process

1. Write the response procedures for each priority hazard.
2. Define the public notification methods (sirens, mass notifications, media).
3. Document the evacuation routes, shelter locations, and special needs procedures.
4. Include mutual aid agreements and resource request procedures.
