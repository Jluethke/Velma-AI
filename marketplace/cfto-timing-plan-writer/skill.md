# Cfto Timing Plan Writer

Write the cash timing plan.

## Inputs

- `float-value`: The value gained from better timing
- `smoothed-balance-curve`: The improved balance curve

## Outputs

- `cash-timing-plan`: Each shift and acceleration with its new date
- `action-checklist`: The dated list of moves to make

## Process

1. Document each shift and acceleration with its new date.
2. State the float value gained and the valleys removed.
3. Produce the dated action checklist.
