# Own Reservation Price Setter

Set your reservation price based on your BATNA analysis.

## Inputs

- `batna`: Your best alternative to a negotiated agreement
- `negotiation-issues`: All the issues on the table (price, terms, timing, scope)

## Outputs

- `own-reservation-price`: The worst terms you should accept on each issue
- `own-target`: The best realistic outcome you aim for on each issue

## Process

1. For each issue, set the reservation price: the point at which you are indifferent between this deal and your BATNA.
2. Set your target: the best outcome you can realistically justify. Research comparable deals, market rates, or precedents to support the target.
3. The reservation price is private. The target is what you argue for. Never reveal the reservation price.
4. For multi-issue negotiations: set reservation prices on each issue independently, but consider trade-offs across issues.
