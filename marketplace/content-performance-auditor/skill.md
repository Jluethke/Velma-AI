# Content Performance Auditor

Audit existing content for performance, gaps, and redundancy.

## Inputs

- `content-inventory`: List of existing content assets
- `analytics-access`: Access to traffic and engagement data

## Outputs

- `content-audit-results`: Performance data per asset (traffic, engagement, conversions)
- `content-gaps-found`: Topics with audience demand but no existing content

## Process

1. Pull traffic and engagement data for each content asset
2. Score each asset by performance tier
3. Identify gaps by comparing against audience questions and search demand
