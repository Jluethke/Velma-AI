# Additional Testing Recommender

Determine if additional testing is needed.

## Inputs

- `clinical-correlation`: Contextualized findings
- `trending-data`: Historical comparison

## Outputs

- `recommended-tests`: Suggested follow-up tests with rationale
- `action-plan`: Clinical actions based on the results

## Process

1. Evaluate whether results warrant confirmatory or follow-up testing.
2. Recommend additional tests based on clinical guidelines.
3. Define the timeline for repeat testing.
