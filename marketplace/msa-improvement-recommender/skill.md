# Msa Improvement Recommender

Recommend improvements if the measurement system is not acceptable.

## Inputs

- `acceptability-decision`: Accept/marginal/unacceptable
- `grr-results`: GRR breakdown

## Outputs

- `improvement-recommendations`: Actions to improve repeatability or reproducibility
- `msa-report`: Complete measurement system analysis report

## Process

1. If repeatability dominates: investigate gage condition, fixturing, measurement technique
2. If reproducibility dominates: investigate operator training, procedure clarity, environmental factors
3. Recommend specific actions and plan a follow-up study after implementation
4. Compile the complete MSA report with data, charts, and conclusions
