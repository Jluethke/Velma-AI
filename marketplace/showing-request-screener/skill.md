# Showing Request Screener

Screen incoming showing requests and schedule appointments.

## Inputs

- `active-listings`: Published listings
- `listing-analytics`: View and inquiry data

## Outputs

- `showing-schedule`: Scheduled showing appointments
- `prospect-profiles`: Basic information on each prospective tenant

## Process

1. Collect prospect inquiries from all platforms.
2. Pre-screen prospects for basic eligibility (income, move-in date, pets).
3. Schedule showings in time blocks to maximize efficiency.
