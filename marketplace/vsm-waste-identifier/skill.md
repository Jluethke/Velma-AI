# Vsm Waste Identifier

Identify waste and improvement opportunities in the current state.

## Inputs

- `current-state-map`: Current state VSM
- `timeline`: Lead time and VA time

## Outputs

- `waste-catalog`: Identified wastes categorized by type
- `improvement-opportunities`: Specific changes that would reduce waste

## Process

1. Walk through each step and inventory point looking for the 8 wastes
2. Categorize: overproduction, waiting, transport, overprocessing, inventory, motion, defects, unused talent
3. Quantify the cost or time impact of each waste
4. List improvement opportunities at each point
