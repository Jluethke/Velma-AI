# Frc Runway Report Writer

Write the runway report.

## Inputs

- `stress-scenarios`: The stressed runway results
- `burn-levers`: The levers that extend the runway

## Outputs

- `runway-report`: The base runway, end date, and stress results
- `runway-action-plan`: The levers with the months each one buys

## Process

1. State the base runway and the end date.
2. Summarize the stress scenarios and the worst case.
3. List the levers with the months each one buys.
