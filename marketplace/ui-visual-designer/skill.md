# Ui Visual Designer

Design the visual UI with components, layout, and interaction states.

## Inputs

- `wireframes`: Approved wireframe layouts
- `brand-guidelines`: Visual brand rules to apply

## Outputs

- `ui-designs`: High-fidelity screen designs with all states
- `component-library`: Reusable UI component designs

## Process

1. Apply the visual style to wireframe layouts
2. Design all component variants (buttons, inputs, cards, modals)
3. Create hover, active, disabled, and error states for each component
4. Design responsive breakpoints if applicable
