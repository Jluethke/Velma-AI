# Instructional Activity Planner

Plan the core instructional activities: direct instruction, guided practice, and independent work.

## Inputs

- `lesson-objectives`: Specific, measurable objectives for this lesson
- `opening-activity`: Description of the hook and prior knowledge activation

## Outputs

- `activity-sequence`: Ordered list of instructional activities with timing
- `activity-materials`: Materials and resources for each activity

## Process

1. Plan the direct instruction segment (explanation, modeling)
2. Design guided practice with scaffolding
3. Design independent practice or application activity
4. Assign time estimates to each segment
