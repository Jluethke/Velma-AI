# Scoring Platform Setup

Set up the scoring platform with flag submission, point tracking, and leaderboard.

## Inputs

- `flag-inventory`: All flags and point values
- `challenge-environments`: Running challenges

## Outputs

- `scoring-platform`: Configured scoring system ready for the event
- `admin-guide`: Guide for event administrators

## Process

1. Deploy the scoring platform (CTFd, FBCTF, or equivalent)
2. Configure challenges, flags, point values, and hint costs
3. Set up team registration, leaderboard, and event timing
