# Resolution Recommendation Writer

Write the Resolution: what the data means for the decision. The resolution is not 'here is more data.' The resolution is 'therefore, we should do X.'

## Inputs

- `complication-finding`: The disrupting data point
- `decision-statement`: The decision this data must inform

## Outputs

- `resolution-statement`: 1-2 sentences stating what the data means for the decision and what action it supports
- `confidence-level`: How confident you are in the recommendation, with what would increase or decrease confidence

## Process

1. Write the resolution as: 'Given [complication], we should [action] because [reason].'
2. State your confidence level honestly. 'High confidence: three quarters of data show the same trend.' Or 'Moderate confidence: one quarter of data, but the signal is strong.'
3. Name what would change the recommendation. 'If Q4 shows recovery, we should revisit.' This builds credibility.
4. Do not hedge the recommendation with 'perhaps' or 'we might consider.' State it. The audience can disagree.
