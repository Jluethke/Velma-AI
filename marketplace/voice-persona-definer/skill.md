# Voice Persona Definer

Define the voice agent's persona including tone, vocabulary, speaking style, and personality traits.

## Inputs

- `agent-purpose`: What the voice agent is for (support, sales, scheduling, information)
- `target-audience`: Who will interact with the agent

## Outputs

- `voice-persona`: Documented persona including name, tone, vocabulary level, personality traits, and speaking style
- `voice-constraints`: Things the agent must not say or do

## Process

1. Define the agent's name and role in one sentence.
2. Set the tone (formal, friendly, professional, casual) based on the audience.
3. Define the vocabulary level and any domain-specific terms the agent should use or avoid.
4. List the personality traits (patient, direct, warm, efficient) and how they show up in responses.
5. Document the constraints: topics to refuse, escalation triggers, and things never to promise.
