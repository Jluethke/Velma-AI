# Kpi Definition Workshop

Define KPIs aligned to business objectives.

## Inputs

- `business-objectives`: The organization's strategic goals
- `current-metrics`: Metrics already being tracked

## Outputs

- `kpi-list`: Defined KPIs with formulas, owners, and update frequency
- `objective-alignment-map`: Map of each KPI to the objective it measures

## Process

1. For each business objective, identify one to three KPIs that measure progress.
2. Define each KPI: name, formula, data source, owner, update frequency.
3. Map each KPI to its parent objective.
4. Produce the KPI list and alignment map.
