# Stakeholder Map Review

Review the stakeholder map when the context changes. Stakeholders move between quadrants as power and interest shift.

## Inputs

- `communication-plan`: The current communication plan
- `power-interest-grid`: The current grid placement

## Outputs

- `updated-grid`: The revised stakeholder grid with any movements noted
- `plan-adjustments`: Changes to the communication plan based on stakeholder movements

## Process

1. At each major milestone or context change, re-rate each stakeholder's power and interest. Has anyone gained or lost influence? Has anyone become more or less interested?
2. Move stakeholders between quadrants as needed. A previously low-interest executive who is now being asked to fund the next phase moves to high-interest.
3. Adjust the communication plan to match the new grid. A stakeholder who moved to manage-closely needs more frequent, more detailed communication immediately.
4. Look for new stakeholders who emerged since the last review. Add them to the grid and the plan.
