# Activation Milestone Definer

Define the activation milestone: the specific action that indicates the user has experienced the core value.

## Inputs

- `product-or-service`: What the user signed up for
- `core-value`: The primary value the user expects to receive

## Outputs

- `activation-milestone`: The single measurable action that best indicates the user experienced core value (e.g., sent their first message, completed their first workout, made their first sale)
- `activation-steps`: Every step between sign-up and the activation milestone, with the required action at each step

## Process

1. Define the core value: what is the one thing the user came for? For a communication tool: sending and receiving messages. For a fitness app: completing a workout. For a marketplace: making a sale.
2. Define the activation milestone: the first time the user experiences that core value. It must be a measurable, specific action.
3. Map every step between sign-up and the milestone: account creation, profile setup, onboarding flow, first feature interaction, and the milestone itself.
4. Each step must be necessary. If a step is not needed to reach the milestone, remove it from the path.
