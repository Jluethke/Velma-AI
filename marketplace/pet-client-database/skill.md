# Pet Client Database

Manage the client and pet database with grooming history, temperament notes, and health alerts.

## Inputs

- `grooming-menu`: Services offered for reference in pet profiles
- `time-estimates`: Duration estimates for scheduling

## Outputs

- `client-pet-records`: Client and pet database with contact info, pet profiles, and grooming history
- `pet-intake-form`: New pet intake form covering breed, temperament, vaccinations, and health conditions

## Process

1. Create the pet profile template (name, breed, weight, age, temperament, vaccination status).
2. Record health alerts and behavioral notes (anxiety triggers, aggression, mobility issues).
3. Track grooming history with photos, services performed, and groomer notes.
4. Set up automated appointment reminders based on grooming frequency.
