# Isolation Drill Designer

Design a drill that isolates the weakest sub-skill so you can practice it without the other sub-skills masking or compensating.

## Inputs

- `sub-skill-map`: All sub-skills of the target skill
- `sub-skill-scores`: Current performance in each sub-skill

## Outputs

- `isolation-drill`: A specific exercise that targets the weakest sub-skill in isolation
- `difficulty-calibration`: How to set the drill difficulty so it is at the edge of your ability (not too easy, not too hard)

## Process

1. Take the weakest sub-skill and design an exercise that requires only that sub-skill. Remove or simplify everything else. If the sub-skill is 'transition between ideas in writing,' the drill is writing only transitions, not full essays.
2. Set the difficulty at the point where you succeed about 60-80% of the time. Below 60% is frustrating. Above 80% is too easy. Adjust by changing speed, complexity, or constraints.
3. Define what 'one rep' looks like. Each rep should take 1-5 minutes so you get many reps per session.
4. Define what success and failure look like for each rep. This must be objective enough that you can score yourself immediately.
