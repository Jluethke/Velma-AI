# Closeout Package Compiler

Compile all closeout documents into the final package for the owner.

## Inputs

- `as-built-drawings`: As-built drawing set
- `warranty-package`: Warranties and guarantees
- `om-manuals`: Operation and maintenance manuals
- `test-reports`: Test and inspection reports

## Outputs

- `closeout-package`: Complete closeout package for the owner
- `closeout-transmittal`: Transmittal letter documenting the delivery

## Process

1. Organize all documents into the closeout package format per the contract.
2. Include the punch list sign-off and certificate of substantial completion.
3. Prepare the transmittal letter listing all delivered documents.
4. Deliver the package to the owner and file a copy in the project records.
