# Repurposing Performance Analyzer

Track derivative performance and refine the repurposing system.

## Inputs

- `derivative-content-batch`: The published derivatives
- `batch-manifest`: What was posted where and when

## Outputs

- `derivative-performance`: Metrics for each derivative versus its source pillar content
- `repurposing-system-doc`: The documented repurposing system with performance data and improvements

## Process

1. Pull analytics for each derivative after the reporting window.
2. Compare derivative performance to the original pillar content.
3. Identify which formats and platforms produce the best returns.
4. Update the repurposing system document with findings and adjustments.
