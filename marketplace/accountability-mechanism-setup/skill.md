# Accountability Mechanism Setup

Identify and set up accountability mechanisms.

## Inputs

- `priority-habits`: Habits being tracked
- `review-schedule`: Review cadence

## Outputs

- `accountability-plan`: Accountability partners or systems in place
- `habit-tracking-plan`: Complete habit tracking plan

## Process

1. Identify an accountability partner or group.
2. Set up the reporting mechanism (check-in message, shared tracker).
3. Define consequences for missed streaks and rewards for milestones.
4. Compile the full habit tracking plan.
