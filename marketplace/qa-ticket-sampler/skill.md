# Qa Ticket Sampler

Sample tickets for QA review using stratified sampling.

## Inputs

- `qa-scorecard`: Finalized scorecard
- `ticket-pool`: Resolved tickets available for review

## Outputs

- `review-sample`: Tickets selected for QA review
- `sampling-report`: Sampling methodology and coverage statistics

## Process

1. Define the sampling rate per agent and channel.
2. Stratify by ticket category and complexity.
3. Select the review sample.
4. Document the sampling methodology.
