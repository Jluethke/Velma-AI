# Print Ready Artwork Preparation

Prepare the print-ready artwork from the selected concept.

## Inputs

- `selected-concept`: The approved packaging concept
- `mandatory-elements`: Required text and symbols to include

## Outputs

- `print-ready-files`: Production-ready artwork files (correct color mode, bleeds, dieline, separations)
- `preflight-report`: Preflight check results (fonts, images, colors, bleeds)

## Process

1. Build the final artwork on the die line template in the correct color mode (CMYK or spot).
2. Place all mandatory elements (text, barcodes, symbols) in the required positions.
3. Run the preflight check (resolution, fonts, bleeds, color separations).
4. Produce the print-ready files and preflight report.
