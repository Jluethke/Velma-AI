# Nosql Injection Report

Produce the NoSQL injection assessment report with findings, proof of concept, and remediation.

## Inputs

- `exfil-scope`: Data exfiltration scope
- `data-sensitivity-rating`: Data sensitivity ratings

## Outputs

- `nosql-report`: Complete NoSQL injection assessment report
- `remediation-plan`: Prioritized remediation plan

## Process

1. Compile all findings with injection payloads and response evidence
2. Rate each finding by severity and exploitability
3. Recommend input validation, parameterized queries, and ORM usage
