# Sdlc Security Integration Review

Evaluate how security is integrated into each phase of the software development lifecycle.

## Inputs

- `sdlc-documentation`: SDLC process documentation and pipeline definitions
- `team-structure`: Development and security team structure and responsibilities

## Outputs

- `integration-gaps`: Phases where security activities are missing or insufficient
- `sdlc-security-map`: Map of security activities at each SDLC phase

## Process

1. Review requirements, design, coding, testing, deployment, and operations phases
2. Check for threat modeling at design, code review at development, and security testing at QA
3. Identify gaps where security activities are absent or manual-only
4. Compare against a maturity model (OWASP SAMM, BSIMM, or DSOMM)
