# Qa Scorecard Designer

Design the quality scorecard for support interactions.

## Inputs

- `quality-standards`: Standards for support quality (accuracy, tone, process)
- `channel-types`: Support channels to score (email, chat, phone)

## Outputs

- `qa-scorecard`: Scorecard with criteria, weights, and rating scale
- `scoring-guidelines`: Detailed guidance for each criterion

## Process

1. Define the scoring criteria (accuracy, tone, resolution, process adherence).
2. Weight each criterion by importance.
3. Write scoring guidelines with examples of each rating level.
4. Customize the scorecard per channel if needed.
