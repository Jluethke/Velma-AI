# Wireframe Mockup Designer

Design wireframes and visual mockups for key page templates.

## Inputs

- `site-architecture`: The new site structure
- `redesign-goals`: Goals to design toward

## Outputs

- `wireframes`: Wireframes for each page template
- `visual-mockups`: High-fidelity mockups showing the final visual design

## Process

1. Wireframe the key page templates (homepage, landing, product/service, about, contact).
2. Apply the visual design (brand colors, typography, imagery style).
3. Design for mobile-first, then adapt to larger viewports.
4. Review mockups against the redesign goals and user feedback.
