# Payer Enrollment Submission

Submit credentialing applications to each insurance payer.

## Inputs

- `caqh-profile`: Completed CAQH profile
- `provider-info`: Provider and practice information

## Outputs

- `enrollment-tracker`: Tracker with submission dates, payer contacts, and status for each application
- `enrollment-issues`: Any rejections or requests for additional information

## Process

1. Submit the enrollment application to each target payer (portal, fax, or CAQH delegation).
2. Record the submission date and expected turnaround for each payer.
3. Follow up on applications at 30 and 60 days if no response.
4. Respond to payer requests for additional information within 48 hours.
