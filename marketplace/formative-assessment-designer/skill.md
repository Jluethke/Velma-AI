# Formative Assessment Designer

Design the formative assessment to check understanding during or at the end of the lesson.

## Inputs

- `lesson-objectives`: Specific, measurable objectives for this lesson
- `success-criteria`: Observable criteria indicating the objectives are met

## Outputs

- `formative-assessment`: Assessment task (exit ticket, quiz, demonstration)
- `assessment-key`: Answer key or scoring guide

## Process

1. Select an assessment format aligned to the objectives (exit ticket, quick quiz, think-pair-share)
2. Write the assessment items or prompts
3. Create the answer key or scoring guide
4. Plan how to use results for next-lesson adjustments
