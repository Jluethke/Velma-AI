# Formulation Matrix Design

Design a formulation matrix varying key ingredients across a structured experimental space to optimize taste, texture, and stability.

## Inputs

- `ingredient-list`: Sourced ingredients with specifications
- `product-concept`: Target sensory and nutritional profile

## Outputs

- `formulation-matrix`: Table of trial formulations with ingredient percentages and processing parameters
- `bench-samples`: Prepared prototype samples for evaluation

## Process

1. Identify the key variables (sugar level, fat content, hydrocolloid type, pH) and their feasible ranges
2. Design the trial matrix using mixture design or factorial layout
3. Prepare bench-top prototypes at lab scale following standardized mixing and processing protocols
4. Record observations on appearance, viscosity, and immediate taste for each formulation
