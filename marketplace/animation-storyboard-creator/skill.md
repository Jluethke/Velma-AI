# Animation Storyboard Creator

Develop the concept and draw the storyboard.

## Inputs

- `animation-brief`: Purpose, audience, and style direction
- `script-or-narration`: Script or narration text to visualize

## Outputs

- `storyboard-panels`: Storyboard with frame descriptions and camera notes
- `style-guide`: Visual style references and color direction

## Process

1. Break the script into scenes and key moments
2. Sketch each panel with character poses and camera angles
3. Annotate with timing, transitions, and action notes
4. Establish the visual style with reference images and color palette
