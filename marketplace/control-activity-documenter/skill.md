# Control Activity Documenter

Document the control activities: authorization, reconciliation, segregation of duties, and physical controls.

## Inputs

- `high-risk-processes`: Processes to document controls for
- `existing-documentation`: Any existing process documentation or flowcharts

## Outputs

- `control-matrix`: Matrix of controls mapped to risks and assertions
- `process-narratives`: Written narratives or flowcharts for each process

## Process

1. Walk through each process with the process owner to understand the steps.
2. Identify the control activities at each step (approvals, reviews, reconciliations).
3. Document who performs each control and how frequently.
4. Map each control to the specific risk it mitigates.
