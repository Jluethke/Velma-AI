# Program Data Collector

Collect quantitative program data: enrollment, retention, graduation, and employment rates.

## Inputs

- `program-name`: Name and level of the academic program under review
- `review-period`: Time range for the review (e.g., past 5 years)

## Outputs

- `program-metrics`: Quantitative metrics over the review period
- `trend-analysis`: Trend analysis of key metrics over time

## Process

1. Pull enrollment, retention, and graduation data from the registrar
2. Collect employment and further education data from alumni surveys
3. Calculate year-over-year trends for each metric
4. Produce the metrics summary and trend analysis
