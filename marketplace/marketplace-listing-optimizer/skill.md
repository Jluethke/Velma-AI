# Marketplace Listing Optimizer

Create and optimize product listings for each marketplace.

## Inputs

- `product-catalog`: Products to list
- `active-accounts`: Active marketplace accounts

## Outputs

- `optimized-listings`: Listings optimized for each channel
- `listing-metrics-baseline`: Baseline listing quality scores

## Process

1. Adapt product titles to each marketplace's search algorithm.
2. Optimize images per channel requirements (white background, lifestyle).
3. Write bullet points and descriptions using marketplace keyword data.
4. Set pricing per channel accounting for fees and competitive position.
