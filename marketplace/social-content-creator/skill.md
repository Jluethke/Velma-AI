# Social Content Creator

Create the content (copy, images, and video) for each post.

## Inputs

- `content-calendar`: Calendar with post topics
- `creative-briefs`: Briefs for each post

## Outputs

- `ready-to-publish-posts`: Completed posts with copy and visuals
- `content-inventory`: Inventory of all created assets

## Process

1. Write the copy for each post optimized for its platform
2. Design or source the visual for each post
3. Create short-form video content where specified
4. Review all content for brand consistency and quality
