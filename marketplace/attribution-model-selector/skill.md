# Attribution Model Selector

Select and implement the attribution model.

## Inputs

- `path-data`: Conversion paths
- `path-statistics`: Path length and timing statistics

## Outputs

- `model-config`: Selected model with parameters
- `attribution-results`: Credit assigned to each channel and touchpoint

## Process

1. Evaluate model options (first-touch, last-touch, linear, time-decay, data-driven)
2. Select the model based on path characteristics and business goals
3. Run the model on the path data
