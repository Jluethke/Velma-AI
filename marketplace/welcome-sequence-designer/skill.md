# Welcome Sequence Designer

Design the welcome email sequence for new subscribers.

## Inputs

- `subscriber-source`: Where new subscribers come from (signup form, lead magnet, purchase, event)
- `brand-voice`: The brand voice and tone guidelines

## Outputs

- `welcome-sequence`: The welcome email sequence (timing, subject, content outline for each email)
- `welcome-goals`: The goals for the welcome sequence (activation, engagement, conversion)

## Process

1. Define the number of emails in the welcome sequence (typically 3 to 5).
2. Write the content outline for each email (introduction, value delivery, engagement prompt, conversion offer).
3. Set the timing between emails (typically 1, 3, 5, 7 days after signup).
4. Define the success metrics for the welcome sequence.
