# Change Order Creation

Write the formal change order for client approval.

## Inputs

- `impact-analysis`: Impact assessment details
- `options-list`: Options for the client

## Outputs

- `change-order`: The change order document specifying the change, cost, timeline adjustment, and terms
- `revised-schedule`: Updated project schedule reflecting the change

## Process

1. Write the change order with a clear description of what changes, the cost adjustment, and the new timeline.
2. Reference the original contract and the specific sections being amended.
3. Include a signature line for client approval.
4. Attach the revised schedule showing the impact on milestones.
