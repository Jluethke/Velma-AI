# Fmea Scope Definer

Define the FMEA scope and assemble the team.

## Inputs

- `design-or-process`: The design or process to analyze
- `boundary-diagram`: System boundaries and interfaces

## Outputs

- `fmea-scope`: Defined scope, type (design or process), and team roster
- `function-list`: Functions and requirements of each item or step

## Process

1. Decide the FMEA type: design (DFMEA) or process (PFMEA)
2. Define the scope boundaries and what is included
3. Assemble the cross-functional team (design, manufacturing, quality, service)
4. List all functions and requirements of the item or process steps
