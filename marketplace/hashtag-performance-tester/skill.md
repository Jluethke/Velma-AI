# Hashtag Performance Tester

Test hashtag performance and refine the strategy.

## Inputs

- `hashtag-sets`: The curated hashtag sets
- `usage-guidelines`: The usage guidelines

## Outputs

- `test-results`: Performance data for each hashtag set over the trial period (reach, impressions, engagement)
- `hashtag-strategy-document`: The final hashtag strategy with recommended sets, usage rules, and review cadence

## Process

1. Run each hashtag set on a sample of posts over a 2 to 4 week trial.
2. Track reach and engagement for posts using each set versus posts without.
3. Identify the top-performing and underperforming hashtags.
4. Finalize the hashtag strategy document with the proven sets and a quarterly review schedule.
