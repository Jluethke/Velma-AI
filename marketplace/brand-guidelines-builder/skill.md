# Brand Guidelines Builder

Create the brand guidelines document.

## Inputs

- `visual-identity`: Logo, colors, typography
- `brand-voice-guide`: Voice and tone guidelines

## Outputs

- `brand-guidelines`: Complete brand guidelines document
- `asset-library`: Logo files, color swatches, and font files

## Process

1. Document logo usage rules (clear space, minimum size, incorrect uses)
2. Specify color usage with accessible contrast ratios
3. Define typography hierarchy and usage rules
4. Compile the voice guide with do/don't writing examples
