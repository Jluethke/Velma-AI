# Call Quality Monitor Setup

Set up the quality monitoring program for call center agents.

## Inputs

- `agent-scripts`: Agent scripts for each call type
- `service-level-targets`: Service level targets

## Outputs

- `quality-scorecard`: Scorecard for evaluating call quality (greeting, resolution, compliance, tone)
- `monitoring-schedule`: Schedule for call monitoring: sample size, frequency, evaluator assignments

## Process

1. Define the quality scorecard dimensions: greeting, verification, resolution accuracy, compliance, tone.
2. Set the scoring scale and passing threshold.
3. Determine the sample size (calls per agent per month) and selection method.
4. Assign evaluators and set the calibration schedule.
