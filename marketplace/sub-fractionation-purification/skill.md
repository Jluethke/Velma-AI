# Sub Fractionation Purification

Sub-fractionate the active fraction to further purify the active compound.

## Inputs

- `active-fractions`: Primary fractions with confirmed activity
- `activity-map`: Activity profile guiding the sub-fractionation strategy

## Outputs

- `purified-compound`: Isolated compound at the highest achievable purity
- `purification-log`: HPLC or column conditions, retention times, and purity assessment

## Process

1. Select the chromatographic method for sub-fractionation (preparative HPLC, semi-prep)
2. Optimize the gradient to resolve the active peak from neighboring compounds
3. Collect the target peak and assess purity by analytical HPLC
4. Repeat if purity is below 95 percent or if activity splits between sub-fractions
