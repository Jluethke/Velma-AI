# Vendor Dpa Negotiation

Negotiate the data processing agreement with the vendor.

## Inputs

- `findings`: Assessment findings and gaps
- `data-sharing-scope`: Scope of data sharing

## Outputs

- `dpa-terms`: Agreed data processing agreement terms
- `remediation-requirements`: Conditions the vendor must meet before data sharing begins

## Process

1. Draft or review the data processing agreement covering processing scope, security measures, breach notification, audit rights, sub-processor controls, and data return/deletion.
2. Negotiate any terms where the vendor's standard agreement falls below requirements.
3. Define any remediation actions the vendor must complete before data sharing begins.
4. Obtain signatures from both parties.
