# Archival Scope Definer

Define what to archive, the preservation standards, and the access requirements.

## Inputs

- `content-sources`: Sources of content to archive (databases, file shares, email, websites, physical media)
- `preservation-goals`: Why the archive exists (legal, historical, regulatory, institutional memory)

## Outputs

- `archival-scope`: What is included and excluded from the archive with rationale
- `preservation-standard`: File formats, metadata requirements, and integrity checks for long-term preservation

## Process

1. Identify the content that must be preserved: contracts, financial records, project deliverables, correspondence, media.
2. Define the preservation standard: use open formats (PDF/A, TIFF, CSV, UTF-8 text) to avoid format obsolescence.
3. Set the metadata requirements: title, date, creator, description, retention period, and provenance.
4. Specify the integrity checks: checksums (SHA-256) for every archived file, periodic fixity checks.
