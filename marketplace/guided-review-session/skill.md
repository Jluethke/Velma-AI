# Guided Review Session

Plan a facilitated review session where developers work the exercises against the checklist.

## Inputs

- `hands-on-exercises`: Review exercises with learning goals and expected findings
- `code-review-checklist`: Ordered checks a reviewer runs against each change

## Outputs

- `session-plan`: Timed agenda pairing exercises with checklist practice
- `facilitation-guide`: Facilitator notes, prompts, and discussion points

## Process

1. Sequence exercises from warm-up to the hardest chained-flaw case
2. Pair each exercise with the checklist sections it should surface
3. Write facilitator prompts that steer discussion toward missed findings
4. Build in a debrief that compares participant findings to the answer key
