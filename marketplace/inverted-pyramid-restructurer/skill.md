# Inverted Pyramid Restructurer

Fourth pass: put the conclusion first. The reader should be able to act after the first paragraph. Everything after the first paragraph is supporting evidence for readers who need it.

## Inputs

- `concrete-draft`: The draft with concrete language
- `reader-action`: What the reader should do

## Outputs

- `final-draft`: The restructured message with conclusion first, evidence second, background last
- `one-paragraph-test-result`: Whether the first paragraph alone is sufficient for the reader to act

## Process

1. Move the conclusion and the ask to the first paragraph. 'I recommend we do X by Y date because Z.'
2. Follow with the evidence that supports the conclusion, ordered by strength.
3. Place background and context last. Most readers will not need it. Those who do will find it at the end.
4. Test: read only the first paragraph. Can you act? If yes, the structure is correct. If no, the first paragraph is missing the ask or a key fact.
