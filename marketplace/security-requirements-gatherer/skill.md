# Security Requirements Gatherer

Gather functional and security requirements from stakeholders, compliance mandates, and risk appetite.

## Inputs

- `system-description`: Functional description of the system being designed
- `compliance-requirements`: Applicable regulations and standards (PCI, HIPAA, SOC2, etc.)
- `risk-appetite`: Organization's tolerance for residual risk

## Outputs

- `security-requirements`: Prioritized list of security requirements
- `data-classification`: Classification of data types the system will handle

## Process

1. Interview stakeholders to understand functional requirements and threat concerns
2. Map compliance mandates to specific technical requirements
3. Classify data types by sensitivity (public, internal, confidential, restricted)
4. Prioritize requirements by compliance mandate and risk
