# Habit Inventory

Identify habits to build or break and rank them by impact.

## Inputs

- `current-habits`: Current daily routines and behaviors
- `goals`: Goals the habits should support

## Outputs

- `habit-list`: Ranked list of habits to build or break
- `priority-habits`: Top 3 habits to focus on first

## Process

1. List all current habits and categorize as build, break, or keep.
2. Score each by impact on stated goals.
3. Select the top 3 to focus on first.
4. Note triggers and barriers for each.
