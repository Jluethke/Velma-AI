# Chromatography Method Protocol

Compile the finalized method into a standard operating protocol.

## Inputs

- `column-selection`: Chosen column and stationary phase
- `mobile-phase-composition`: Finalized mobile phase
- `gradient-program`: Final gradient or isocratic conditions
- `validation-results`: Validation data and acceptance criteria

## Outputs

- `method-protocol`: Complete method protocol ready for routine use
- `troubleshooting-guide`: Common issues and corrective actions for the method

## Process

1. Write the step-by-step method with all instrument parameters
2. Include sample preparation, injection sequence, and data processing instructions
3. Attach the validation summary with acceptance criteria
4. Add a troubleshooting section for retention time drift, pressure changes, and peak shape degradation
