# Ir Gap Analysis

Identify gaps and improvement actions from the entire tabletop exercise.

## Inputs

- `detection-assessment`: Detection and triage assessment
- `escalation-findings`: Escalation and communication findings
- `containment-assessment`: Containment effectiveness assessment
- `recovery-assessment`: Recovery procedure assessment

## Outputs

- `gap-list`: Prioritized list of gaps identified across all response phases
- `improvement-actions`: Specific improvement actions with owners and timelines

## Process

1. Compile findings from each exercise phase into a unified gap list
2. Classify gaps by response phase and severity
3. Define specific improvement actions for each gap
4. Assign owners and target dates for each action
