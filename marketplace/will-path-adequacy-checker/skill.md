# Will Path Adequacy Checker

For a will problem, check whether the person was given clear expectations, direct feedback on the gap, and real consequences for not closing it. A will problem that never met a consequence has not actually been tested.

## Inputs

- `skill-path-finding`: Whether the skill path was adequate
- `skill-remedy-gaps`: Any missing skill-path element

## Outputs

- `will-path-finding`: Whether clear expectations, direct feedback, and real consequences were provided
- `will-remedy-gaps`: Any missing element of the will path that must be delivered before deciding

## Process

1. Confirm expectations were clear, so the person knew exactly what was required.
2. Confirm the gap was named directly in feedback, not hinted at or softened into invisibility.
3. Confirm a real consequence followed the continued gap, so the person understood it mattered.
4. Where feedback or consequence was missing, deliver it clearly and give a defined window to respond before deciding.
