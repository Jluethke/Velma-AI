# Security Investment Mapper

Map proposed security investments to the risk reduction they achieve.

## Inputs

- `capability-gap-list`: Gaps to close
- `risk-quantification`: Financial risk from each gap

## Outputs

- `investment-risk-map`: Each proposed investment linked to the risk it reduces and by how much
- `cost-estimates`: Estimated cost for each investment (tools, staffing, services)

## Process

1. For each gap, identify the investment needed to close it (tool, hire, service, process change)
2. Estimate the cost of each investment (license, salary, implementation)
3. Estimate the risk reduction: what fraction of the ALE each investment eliminates
4. Flag investments that address multiple gaps
