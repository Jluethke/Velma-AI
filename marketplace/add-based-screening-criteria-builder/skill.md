# Add Based Screening Criteria Builder

Convert the missing perspectives into screening criteria. The question shifts from whether a person is like us to whether they bring what we lack, which makes the decision evidence-based rather than a gut call.

## Inputs

- `culture-add-profile`: The perspectives the team lacks
- `blind-spot-examples`: The consequences of the gaps

## Outputs

- `add-criteria`: An observable criterion for each missing perspective
- `add-screening-questions`: A question for each criterion that candidates with the perspective answer differently

## Process

1. For each missing perspective, write an observable criterion, such as direct experience with a customer type the team does not understand.
2. For each criterion, write an interview question that a candidate with that perspective answers differently from one without it.
3. Confirm each question discriminates: if every candidate answers it the same way, rewrite it.
4. Keep the criteria tied to the profile, not to general likability.
