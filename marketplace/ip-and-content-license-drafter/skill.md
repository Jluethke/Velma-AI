# Ip And Content License Drafter

Specify IP ownership, user content licenses, and DMCA procedures.

## Inputs

- `service-scope`: Service scope
- `product-description`: Product description

## Outputs

- `ip-ownership-clause`: IP ownership and reservation of rights
- `user-content-license`: License granted by users for their content

## Process

1. State ownership of the service IP and trademarks
2. Define the license users grant for content they upload
3. Include DMCA or equivalent takedown procedures if applicable
