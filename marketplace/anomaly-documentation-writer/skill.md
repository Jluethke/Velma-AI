# Anomaly Documentation Writer

Write a structured finding report: what was observed, what was ruled out, what remains, and what should happen next.

## Inputs

- `anomaly-classification`: Final classification of the anomaly
- `classification-rationale`: Evidence chain supporting the classification

## Outputs

- `anomaly-report`: Structured finding report ready for the lab notebook or publication
- `next-steps`: Recommended follow-up experiments or analyses

## Process

1. Write the observation section: what, when, where, how large.
2. Write the investigation section: each check performed and its outcome.
3. Write the conclusion section: classification and confidence level.
4. Write the next-steps section: what additional data or experiments would resolve ambiguity.
