# Dashboard Usability Tester

Test with the actual audience. Can they answer their questions within the target time?

## Inputs

- `dashboard-layout`: The designed dashboard
- `information-requirements`: The questions it must answer

## Outputs

- `usability-results`: For each question: correctness, time to answer, confusion points
- `revised-dashboard`: The updated design incorporating findings

## Process

1. Show the dashboard to a target audience member. Ask them to answer each question out loud.
2. Measure: time to answer (summary under 10 seconds, diagnostic under 60 seconds), correctness, and confidence.
3. Note every confusion point: wrong chart, misread scale, unclear meaning.
4. Revise: fix confusion points, remove unused elements, enhance slow-to-read elements.
