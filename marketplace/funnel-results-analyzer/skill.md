# Funnel Results Analyzer

Analyze experiment results and produce the funnel analysis report.

## Inputs

- `experiment-plan`: Experiments run
- `drop-off-rates`: Baseline data for comparison

## Outputs

- `experiment-results`: Statistical results per experiment
- `funnel-analysis-report`: Complete funnel analysis with findings and recommendations

## Process

1. Collect results for each experiment
2. Run statistical significance tests
3. Produce the funnel analysis report with recommended changes
