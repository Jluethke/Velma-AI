# Data Collection Preserver

Collect and preserve data from the identified sources in a forensically sound manner.

## Inputs

- `scope-document`: The discovery scope
- `custodian-list`: Custodians and their data sources

## Outputs

- `collected-data-inventory`: Inventory of all collected data with chain of custody metadata
- `collection-log`: Log of collection actions, dates, and methods

## Process

1. Issue preservation instructions to IT and custodians.
2. Collect data from each source using forensically sound methods.
3. Record the chain of custody for each collection (who, when, what, how).
4. Verify the integrity of collected data with hash values.
