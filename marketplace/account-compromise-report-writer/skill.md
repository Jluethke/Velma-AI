# Account Compromise Report Writer

Produce the account compromise incident report.

## Inputs

- `attacker-activity-timeline`: Timeline of attacker actions
- `persistence-findings`: Persistence mechanisms found

## Outputs

- `account-compromise-report`: Complete account compromise incident report
- `prevention-recommendations`: Recommendations to prevent future account compromises

## Process

1. Compile the timeline from initial compromise through restoration
2. Summarize the impact (data accessed, actions taken by the attacker)
3. Document the root cause (phishing, credential stuffing, password reuse)
4. Recommend prevention measures (MFA enforcement, conditional access policies)
