# Format Adapter

Adapt the pyramid structure to the specific format: email, presentation, report, or conversation.

## Inputs

- `complete-message-structure`: The pyramid structure
- `communication-purpose`: The communication purpose
- `audience`: The audience

## Outputs

- `formatted-message`: The message adapted to the target format with the pyramid structure intact
- `format-notes`: Format-specific adaptations: email subject line = conclusion, slide title = argument, appendix = evidence

## Process

1. For email: subject line states the conclusion or action needed. First sentence restates it. Bullet points for arguments. Evidence in attachments or linked documents.
2. For presentations: slide title = argument. Slide body = evidence. First slide = conclusion. Last slide = conclusion restated with the ask.
3. For reports: executive summary = conclusion plus arguments. Body sections = one argument per section with evidence. Appendix = detailed data.
4. For conversations: state the conclusion first. Pause for reaction. If the listener agrees, stop. If they question, give the relevant argument and evidence.
