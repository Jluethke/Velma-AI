# Compliance Gap Report Compiler

Compile the full compliance gap analysis into a board-ready report.

## Inputs

- `control-mapping`: Control-to-framework mapping
- `risk-heat-map`: Risk heat map by domain
- `remediation-roadmap`: Phased remediation roadmap
- `effort-estimates`: Effort and cost estimates

## Outputs

- `compliance-gap-report`: Full compliance gap analysis report
- `executive-summary`: One-page executive summary for board presentation

## Process

1. Write the executive summary with overall compliance posture and top risks
2. Include the control mapping with coverage percentages by domain
3. Attach the remediation roadmap with ownership and timeline
4. Produce the final report with appendices for detailed evidence and gap descriptions
