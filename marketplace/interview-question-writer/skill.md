# Interview Question Writer

Write behavioral and situational questions for each competency.

## Inputs

- `competency-list`: Competencies to assess
- `competency-definitions`: Definitions and behavioral indicators

## Outputs

- `question-bank`: Questions mapped to competencies
- `follow-up-probes`: Follow-up questions to dig deeper on each topic

## Process

1. Write two to three behavioral questions per competency
2. Write one situational question per competency
3. Add follow-up probes for each question
4. Review for clarity and bias
