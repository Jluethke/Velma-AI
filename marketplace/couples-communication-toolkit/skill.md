# Couples Communication Toolkit

Build a shared communication toolkit with I-statements, active listening exercises, and repair attempts.

## Inputs

- `communication_style`: Each partner's natural style
- `conflict_patterns`: Known conflict patterns

## Outputs

- `communication_rules`: Agreed ground rules for hard conversations
- `repair_phrases`: Go-to repair attempt phrases
- `listening_exercises`: Practice exercises for active listening

## Process

1. Identify each partner's communication defaults
2. Draft ground rules for disagreements
3. Create personalized I-statement templates
4. Build a repair attempt phrase list
5. Design a weekly listening exercise
