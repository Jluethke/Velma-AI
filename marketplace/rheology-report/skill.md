# Rheology Report

Compile the rheological characterization into a report with flow curves, viscoelastic spectra, model fits, and material classification.

## Inputs

- `flow-curve-data`: Steady-shear flow curve
- `frequency-sweep-data`: Oscillatory frequency sweep data
- `fitted-model-parameters`: Constitutive model fit results

## Outputs

- `rheology-characterization-report`: Full rheology report with figures, tables, and material classification
- `rheology-data-package`: All raw data, processed curves, and model fits for archival

## Process

1. Generate publication-quality figures for flow curve, amplitude sweep, and frequency sweep
2. Tabulate the material parameters and model fit results
3. Compare to published data for similar materials if available
4. Write conclusions about material behavior relevant to the application
