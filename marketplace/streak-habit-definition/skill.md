# Streak Habit Definition

Define the habit you intend to sustain as a streak and record how consistent it is right now.

## Inputs

- `habit-to-sustain`: The habit you want to keep going without long breaks
- `current-consistency`: How often you currently manage it in a typical week

## Outputs

- `defined-streak-habit`: The habit stated as a single daily or near-daily action that can carry a streak
- `streak-baseline`: The current longest run and typical gap length for the habit

## Process

1. State the habit as one action that recurs often enough to form a streak, such as a daily walk or a daily page of writing.
2. Record the current baseline honestly: the longest run you have managed and how long the gaps between runs tend to be.
3. Confirm the habit is one you want daily or near daily. A habit meant to happen twice a week uses a different rule than a daily streak.
4. Note what a single rep of the habit normally costs in time and effort, because the recovery version will be a fraction of it.
