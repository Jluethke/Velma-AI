# Peer Program Comparer

Compare the program against peer and aspirant programs at other institutions.

## Inputs

- `program-metrics`: Quantitative metrics for this program
- `program-name`: Name of the program

## Outputs

- `peer-comparison`: Comparison of metrics and curriculum against peer programs
- `competitive-position`: Assessment of the program's competitive standing

## Process

1. Identify 5-8 peer programs at comparable institutions
2. Compare enrollment, graduation rates, and employment outcomes
3. Compare curriculum structure and specializations
4. Assess competitive position and differentiators
