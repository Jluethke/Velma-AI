# Subcontractor Project Onboard

Onboard the subcontractor to the project with context, tools, and expectations.

## Inputs

- `sub-agreement`: Signed agreement
- `onboarding-plan`: Onboarding steps

## Outputs

- `sub-workspace-access`: Tool access and communication channels set up for the subcontractor
- `deliverable-schedule`: Agreed schedule of deliverables with review points

## Process

1. Brief the subcontractor on the project context, client expectations, and their specific deliverables.
2. Grant access to the relevant project tools, files, and communication channels.
3. Set up the deliverable schedule with check-in points.
4. Clarify the review and feedback process.
5. Confirm the subcontractor has everything they need to start.
