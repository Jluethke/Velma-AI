# Awareness Program Report Writer

Compile the security awareness audit report with metrics, trends, and improvement recommendations.

## Inputs

- `content-review-findings`: Content review findings
- `phishing-trend-analysis`: Phishing simulation trends
- `reporting-culture-assessment`: Reporting culture assessment
- `role-training-findings`: Role-specific training findings

## Outputs

- `awareness-audit-report`: Complete security awareness program audit report
- `program-improvement-plan`: Prioritized plan for improving the awareness program

## Process

1. Consolidate all findings: content gaps, completion gaps, phishing trends, reporting culture, role training
2. Rate the overall program maturity (initial, developing, established, optimized)
3. Write specific improvement recommendations prioritized by impact
4. Produce the final report with executive summary, metrics dashboard, and improvement roadmap
