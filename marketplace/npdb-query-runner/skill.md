# Npdb Query Runner

Query the National Practitioner Data Bank.

## Inputs

- `applicant-name`: Provider name for the query
- `malpractice-history`: Self-reported and carrier-reported history

## Outputs

- `npdb-results`: NPDB query response with any reported actions
- `reconciliation-notes`: Comparison of NPDB data against application disclosures

## Process

1. Submit the NPDB query with the provider's identifying information.
2. Review the response for malpractice payments and adverse actions.
3. Reconcile NPDB findings with the provider's self-disclosure.
