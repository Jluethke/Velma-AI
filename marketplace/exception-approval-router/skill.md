# Exception Approval Router

Route the exception to the risk committee for approval with expiration date.

## Inputs

- `documented-request`: The exception request
- `compensating-controls`: Proposed compensating controls

## Outputs

- `approval-decision`: Approved, denied, or conditionally approved
- `exception-record`: Record with expiration date and conditions

## Process

1. Present the request, risk assessment, and compensating controls to the committee
2. Record the approval decision and any conditions
3. Set the expiration date (maximum one year)
4. Notify the requestor and relevant stakeholders
