# Landlord Violation Documenter

Document landlord violations with evidence: habitability issues, illegal entry, deposit problems.

## Inputs

- `violation_type`: Type of violation experienced
- `occurrence_dates`: When violations occurred
- `communication_history`: Prior communication about the issue

## Outputs

- `violation_log`: Dated log of violations with evidence
- `photo_video_guide`: How to document conditions
- `communication_record`: Organized communication history

## Process

1. Log each incident with date, time, and description
2. Photograph or video document conditions
3. Save all communications (texts, emails, letters)
4. Note any witnesses
5. Keep copies of everything off-premises
