# Visualization Standards Publisher

Compile and publish the visualization standards guide.

## Inputs

- `chart-type-guidelines`: Chart type rules
- `color-palette`: Color palettes
- `typography-rules`: Typography standards
- `anti-pattern-list`: Mistakes to avoid

## Outputs

- `visualization-standards-guide`: Complete standards document with examples
- `template-library`: Starter templates implementing the standards

## Process

1. Compile all rules, palettes, and examples into a single document.
2. Create starter templates in the most-used visualization tools.
3. Distribute to the organization and set a review cadence.
