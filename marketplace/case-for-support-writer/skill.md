# Case For Support Writer

Create the case for support that tells the story and makes the ask.

## Inputs

- `campaign-purpose`: What the campaign will fund
- `audience-segments`: Target donor segments

## Outputs

- `case-for-support`: Core narrative and talking points
- `message-variants`: Adapted messages per segment

## Process

1. Define the need with data and a human story
2. Describe the solution and the organization's track record
3. State the specific ask and what a gift will accomplish
4. Adapt the message for each segment
