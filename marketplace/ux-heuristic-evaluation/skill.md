# Ux Heuristic Evaluation

Walk through the key user flows and document usability issues.

## Inputs

- `audit-plan`: The scope and heuristics to evaluate against
- `product-to-audit`: The product to evaluate

## Outputs

- `issue-list`: All usability issues found with severity rating, heuristic violated, and screenshot
- `flow-annotations`: Annotated screenshots of each user flow showing the issues

## Process

1. Walk through each user flow as a first-time user and as a returning user.
2. At each step, evaluate against the selected heuristics.
3. Document each issue with a description, severity (critical, major, minor, cosmetic), the heuristic violated, and a screenshot.
4. Produce the issue list and annotated flow screenshots.
