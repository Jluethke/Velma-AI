# Translation And Adaptation

Translate and culturally adapt the content for each target locale.

## Inputs

- `content-inventory`: The strings and assets to translate
- `target-locales`: The locales to translate for

## Outputs

- `translated-content`: Translated strings and adapted assets for each locale
- `adaptation-notes`: Cultural adaptations made and their reasoning

## Process

1. Translate each string with context, not word-for-word.
2. Adapt cultural references, idioms, date/number formats, and imagery for each locale.
3. Flag items that cannot be directly translated and propose alternatives.
4. Produce the translated content and adaptation notes.
