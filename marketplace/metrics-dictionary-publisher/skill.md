# Metrics Dictionary Publisher

Publish the metrics dictionary and set the governance process.

## Inputs

- `metric-definitions`: All defined metrics
- `metric-targets`: Targets and thresholds

## Outputs

- `metrics-dictionary`: Published reference document of all business metrics
- `metrics-governance-plan`: Process for adding, changing, and retiring metrics

## Process

1. Compile all definitions into a searchable dictionary.
2. Define the governance process: how to propose, approve, and retire metrics.
3. Distribute the dictionary to the organization.
4. Set a quarterly review cadence.
