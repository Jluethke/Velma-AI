# Knowledge Integration Test

Periodically test whether spaced repetition is producing usable knowledge, not just card-passing ability.

## Inputs

- `retention-rate`: Current retention metrics
- `review-cards`: The full card set

## Outputs

- `integration-test-results`: Performance on an open-ended task that requires combining multiple knowledge items
- `system-adjustments`: Changes to make: add application cards, group related items, or retire well-known items

## Process

1. Design an open-ended test that requires combining multiple knowledge items to solve a problem. This tests whether you can USE the knowledge, not just recall isolated facts.
2. Take the test without looking at your cards. Score yourself honestly.
3. If you can recall individual cards but cannot combine them, add 'connection cards' that explicitly link related items (e.g., 'How does X relate to Y?').
4. Retire cards for items that have reached the 90-day interval and been passed three times at that level. They are in long-term memory.
