# Pricing Page Layout

Lay out the three tiers so the buyer's eye lands on the premium tier as the recommended choice.

## Inputs

- `decoy-tier`: The middle tier definition
- `feature-allocation`: Which features sit in each tier

## Outputs

- `page-layout`: The arrangement and labeling of the three tiers
- `visual-emphasis-plan`: How emphasis guides the eye toward premium

## Process

1. Order the tiers so the decoy sits between basic and premium, with premium shown as recommended.
2. Label features so the gap between decoy and premium is read at a glance, not studied.
3. Use emphasis, such as a highlight or a most-popular marker, to point at premium without hiding the others.
4. Keep the page honest and scannable, since a confusing page sends buyers to a sales rep or away.
