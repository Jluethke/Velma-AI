# Ugc Rights Manager

Establish the rights and permissions framework for using submitted content.

## Inputs

- `ugc-types`: The types of UGC being collected
- `collection-channels`: How UGC is being collected

## Outputs

- `rights-framework`: Terms of use, permission request templates, and consent tracking process
- `legal-guidelines`: Guidelines on attribution, usage scope, and duration of rights

## Process

1. Draft the terms of use that contributors agree to when submitting.
2. Create permission request templates for content found organically (not submitted directly).
3. Set up the consent tracking system (who granted what, when).
4. Document attribution requirements and usage scope.
