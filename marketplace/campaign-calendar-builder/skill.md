# Campaign Calendar Builder

Build the campaign calendar with touchpoints, deadlines, and milestones.

## Inputs

- `channel-plan`: Channels and message sequence
- `campaign-goal`: Dollar target and timeline

## Outputs

- `campaign-calendar`: Day-by-day schedule of activities
- `production-deadlines`: Deadlines for creative and print production

## Process

1. Plot the launch, mid-campaign push, and close dates
2. Schedule each touchpoint by channel
3. Set production deadlines working backward from send dates
4. Add milestone check-ins for progress review
