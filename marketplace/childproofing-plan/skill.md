# Childproofing Plan

Room-by-room childproofing assessment with product recommendations and installation timeline.

## Inputs

- `home_layout`: Number of rooms and floor plan description
- `child_age`: Current or expected age of child

## Outputs

- `room_assessments`: Hazard list per room
- `product_list`: Childproofing products needed
- `installation_timeline`: When to install what

## Process

1. Walk through each room and identify hazards
2. Categorize by severity and child development stage
3. Match products to each hazard
4. Build installation timeline by trimester or month
