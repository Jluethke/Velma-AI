# Outcome Recommender

Determine the outcome and recommend corrective actions.

## Inputs

- `factual-findings`: Findings of fact
- `company-policies`: Applicable policies

## Outputs

- `outcome-decision`: Substantiated, unsubstantiated, or inconclusive for each allegation
- `corrective-actions`: Recommended corrective actions

## Process

1. Determine if each allegation is substantiated by the evidence
2. Identify which policies were violated if substantiated
3. Recommend proportionate corrective actions
4. Consider any systemic issues that contributed to the situation
