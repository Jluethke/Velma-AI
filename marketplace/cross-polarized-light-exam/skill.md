# Cross Polarized Light Exam

Examine under cross-polarized light to record birefringence, extinction, and twinning for mineral identification.

## Inputs

- `thin-section`: Same thin section
- `ppl-observations`: PPL observations to correlate with XPL behavior

## Outputs

- `xpl-observations`: Birefringence colors, extinction angle and type, twinning, and interference figures for each phase
- `mineral-candidates`: Preliminary mineral identifications based on combined PPL and XPL properties

## Process

1. Record the maximum birefringence color for each mineral phase
2. Determine extinction type (parallel, inclined, symmetrical) and measure the angle where possible
3. Identify twinning patterns (simple, polysynthetic, cross-hatch) diagnostic of specific minerals
4. Obtain interference figures (uniaxial vs biaxial, optic sign) for ambiguous phases
