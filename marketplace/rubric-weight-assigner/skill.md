# Rubric Weight Assigner

Assign weights to each dimension based on its importance to the learning outcomes.

## Inputs

- `rubric-draft`: Draft rubric with all levels described
- `learning-outcomes`: The outcomes this assignment is designed to measure

## Outputs

- `weighted-rubric`: Rubric with dimension weights assigned
- `weight-rationale`: Justification for the weight distribution

## Process

1. Rank dimensions by importance to the learning outcomes
2. Assign percentage or point weights
3. Verify weights sum to 100% and reflect priorities
4. Document the rationale for weight choices
