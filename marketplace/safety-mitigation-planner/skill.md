# Safety Mitigation Planner

Recommend mitigations for each identified failure.

## Inputs

- `failure-analysis`: Failure patterns and root causes
- `safety-scores`: Scores by category

## Outputs

- `mitigation-plan`: Recommended mitigations per failure
- `safety-report`: Full safety evaluation report

## Process

1. Map each failure pattern to a mitigation strategy.
2. Prioritize mitigations by severity and feasibility.
3. Estimate the effort and risk for each mitigation.
4. Compile the full safety evaluation report.
