# Crisis Response Publisher

Publish the response and manage ongoing communication.

## Inputs

- `response-messages`: Approved response messages
- `response-team-assignments`: Team assignments

## Outputs

- `publication-log`: Log of all published responses with timestamps and channels
- `follow-up-plan`: Plan for ongoing updates and individual response handling

## Process

1. Publish the approved response on all affected channels.
2. Begin responding to individual comments and messages using the approved messaging.
3. Post updates as the situation develops.
4. Log every published response with timestamp and channel.
