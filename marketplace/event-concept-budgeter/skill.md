# Event Concept Budgeter

Define the event concept, format, and budget.

## Inputs

- `fundraising-goal`: Revenue target for the event
- `event-type-preference`: Gala, auction, walk-a-thon, or other format

## Outputs

- `event-concept`: Event format, theme, and date
- `event-budget`: Revenue and expense budget

## Process

1. Select the event format based on audience and fundraising goal
2. Set the date and define the theme
3. Build the expense budget (venue, catering, entertainment, printing, AV)
4. Set the revenue budget (tickets, sponsorships, auction, fund-a-need)
