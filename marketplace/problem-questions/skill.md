# Problem Questions

Surface the problems and the events that trigger them, letting the buyer name the pain.

## Inputs

- `situation-notes`: What the buyer said about their current state
- `current-state-map`: The map of how things work today

## Outputs

- `problem-list`: The problems the buyer named, in their words
- `problem-triggers`: The events that make each problem show up

## Process

1. Ask about the parts of the current state that cause difficulty, and wait through the silences.
2. Let the buyer name the problem, since a problem the buyer says out loud is one they own.
3. For each problem, learn what triggers it and how often it happens.
4. Resist pitching a fix here, since naming a solution too early stops the buyer from fully stating the pain.
