# Email Filter Rule Setup

Set up automatic filters and rules for recurring email.

## Inputs

- `folder-structure`: Folder hierarchy
- `processing-rules`: Processing decision tree

## Outputs

- `filter-rules`: Automatic filter rules configured
- `filter-list`: List of all filters with their actions

## Process

1. Create filters for newsletters (auto-label, skip inbox).
2. Create filters for recurring reports (auto-archive or auto-label).
3. Create filters for high-priority senders (star or flag automatically).
