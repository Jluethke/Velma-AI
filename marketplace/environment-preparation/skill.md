# Environment Preparation

Prepare the physical environment so the new habit requires zero setup when the trigger fires.

## Inputs

- `stack-formula`: The habit stack
- `target-habit`: What the new habit requires

## Outputs

- `environment-setup`: Physical changes that make the new habit frictionless: supplies laid out, space cleared, tools accessible
- `friction-removal`: Every obstacle between the trigger and the new habit, with a solution for each

## Process

1. The new habit must require zero decisions when the trigger fires. If the trigger is 'after I pour coffee' and the habit is 'journal for 5 minutes,' the journal and pen must be next to the coffee maker.
2. Remove every friction point: if the journal is in a drawer, you will skip it. If the pen is dead, you will skip it. If the table is cluttered, you will skip it. Make the habit the path of least resistance.
3. Add friction to competing behaviors: if the competing behavior is 'check phone after pouring coffee,' put the phone in another room during the morning routine.
4. Test the environment: run through the habit once. Time it. Note anything that slowed you down or required a decision. Eliminate those obstacles.
