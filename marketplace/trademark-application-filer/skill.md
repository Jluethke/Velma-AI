# Trademark Application Filer

File the application with the USPTO and record the serial number.

## Inputs

- `application-draft`: Prepared application
- `specimen-package`: Specimens of use

## Outputs

- `serial-number`: USPTO serial number assigned to the application
- `filing-receipt`: USPTO filing receipt

## Process

1. Submit the application through the TEAS electronic filing system
2. Pay the applicable filing fees
3. Record the serial number and filing date
