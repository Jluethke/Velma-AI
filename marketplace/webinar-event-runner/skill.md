# Webinar Event Runner

Run the live webinar event.

## Inputs

- `webinar-plan`: Event plan and speaker briefs
- `registration-metrics`: Registration data

## Outputs

- `event-recording`: Recording file and transcript
- `attendee-data`: Attendance, engagement, and poll responses

## Process

1. Run the tech check with speakers before the event
2. Host the live event and manage Q&A
3. Record the session and collect attendance data
