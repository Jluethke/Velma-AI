# Pedagogical Need Identifier

Identify the pedagogical need that technology could address.

## Inputs

- `teaching-challenge`: Description of the teaching or learning challenge
- `current-tools`: Technology tools currently in use

## Outputs

- `need-statement`: Clear statement of the pedagogical need
- `success-criteria`: Criteria for evaluating whether the technology addresses the need

## Process

1. Analyze the teaching challenge and its root cause
2. Determine if technology can address the root cause (vs. pedagogical redesign)
3. Write the need statement with measurable success criteria
4. Confirm alignment with institutional technology strategy
