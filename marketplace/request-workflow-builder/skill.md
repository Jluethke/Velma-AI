# Request Workflow Builder

Build the request fulfillment workflows for each service.

## Inputs

- `service-definitions`: Service definitions with scope and SLA

## Outputs

- `request-workflows`: Fulfillment workflows for each requestable service
- `approval-matrix`: Who approves each type of request

## Process

1. Map the fulfillment steps for each requestable service.
2. Define the approval requirements by cost and risk.
3. Build the request forms with required fields.
4. Test each workflow end to end.
