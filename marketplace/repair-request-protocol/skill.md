# Repair Request Protocol

Send proper repair requests that create a paper trail and trigger legal timelines.

## Inputs

- `repair_needed`: What needs fixing
- `urgency`: Emergency or routine
- `prior_requests`: Previous requests if any

## Outputs

- `request_letter`: Formal written repair request
- `legal_timeline`: State-required response deadlines
- `escalation_options`: Next steps if not addressed

## Process

1. Document the issue with photos
2. Send written request via method that proves receipt
3. Note state-required response timeline
4. Follow up in writing if no response
5. Know escalation options (code enforcement, rent withholding)
