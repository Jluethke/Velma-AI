# First Value Moment Optimization

Design the first value moment to be as obvious and satisfying as possible, so the user immediately understands why they signed up.

## Inputs

- `redesigned-flow`: The new onboarding flow
- `product-or-service`: What the product does

## Outputs

- `first-value-design`: The specific experience the user has at the first value moment: what they see, what they accomplish, and why it feels satisfying
- `value-confirmation`: How the product confirms that value was delivered (a success message, a result displayed, a problem solved)

## Process

1. Define the first value moment precisely: what does the user accomplish that they could not accomplish before signing up? This must be a real result, not a tutorial completion.
2. Design the experience around this moment. When the user gets their first result, make it visible and celebratory (without being annoying). Show them what they just accomplished.
3. Remove anything between the last essential step and the first value moment. No tutorials, no walkthroughs, no 'getting started' screens. Go straight from setup to value.
4. Test with 5 new users (who have never seen the product) and time them from landing to first value moment. Observe where they get stuck and iterate.
