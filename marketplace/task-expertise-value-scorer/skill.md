# Task Expertise Value Scorer

Score every recurring task on two axes: does it require your specific expertise, and is it among the highest-value uses of your time? Tasks low on both axes are delegation candidates.

## Inputs

- `task-inventory`: Every recurring task you personally perform
- `time-log`: How much time each task takes per week

## Outputs

- `scored-task-grid`: Each task placed on a two-by-two of expertise required against value of your time spent
- `delegation-candidates`: The low-expertise, low-value tasks that form the delegation pool

## Process

1. List every recurring task you personally do, with the hours each takes per week.
2. Score each task on expertise required, meaning only you can do it versus many could, and on the value of your time spent on it.
3. Place each task on a two-by-two grid.
4. The low-expertise, low-value quadrant is the delegation candidate pool; the high-expertise, high-value quadrant is what you keep.
