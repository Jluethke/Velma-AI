# Catering Event Executor

Execute the event with real-time coordination and issue handling.

## Inputs

- `event-timeline`: Event timeline and service sequence
- `prep-schedule`: Prep tasks and assignments

## Outputs

- `event-log`: Real-time log of the event with any deviations from plan
- `issue-register`: Issues that arose and how they were handled

## Process

1. Execute the kitchen prep and quality-check each dish before transport.
2. Set up the venue per the layout plan and verify equipment and supplies.
3. Run the service according to the timeline, adjusting for client or venue changes.
4. Handle issues (late guests, dietary surprises, equipment failures) on the spot.
