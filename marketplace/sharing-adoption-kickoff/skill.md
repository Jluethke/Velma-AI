# Sharing Adoption Kickoff

Roll out the sharing mechanisms. Start with one workflow, not all five. Demonstrate the value before expanding.

## Inputs

- `sharing-mechanisms`: Designed sharing artifacts and templates
- `definition-of-done-updates`: Updated definitions of done

## Outputs

- `pilot-workflow-results`: Results from the first workflow: adoption rate, artifact quality, and time cost per person
- `rollout-plan`: Plan for expanding to the remaining 4 workflows, with timing and success criteria for each

## Process

1. Start with the workflow that has the highest value and the lowest effort. This is usually incident case studies or project handoffs, because the value is immediately obvious to the team.
2. Run the pilot for 30 days. Track: how many artifacts were created, how many workflows completed without the artifact (compliance rate), and how much time each artifact took.
3. After 30 days, demonstrate the value: show a situation where someone benefited from a captured artifact. One concrete example is more persuasive than any policy argument.
4. Expand to the next workflow only when the first one has a compliance rate above 80 percent. Expanding too fast creates resentment. Expanding after demonstrated value creates buy-in.
