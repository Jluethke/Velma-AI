# Systematic Review Reporter

Write the systematic review report following PRISMA guidelines with all required sections and supplementary materials.

## Inputs

- `structured-question`: the review question
- `pooled-estimate`: summary effect size
- `bias-assessment-table`: bias summary
- `forest-plot`: forest plot figure

## Outputs

- `review-manuscript`: complete systematic review manuscript
- `prisma-checklist`: completed PRISMA checklist with page references
- `supplementary-materials`: search strings, extraction forms, excluded study list

## Process

1. Draft each PRISMA section: title, abstract, introduction, methods, results, discussion, funding
2. Embed the PRISMA flow diagram, forest plot, and bias summary figure
3. Complete the PRISMA checklist with page/section references
4. Compile supplementary materials (full search strings, extraction form, list of excluded studies with reasons)
