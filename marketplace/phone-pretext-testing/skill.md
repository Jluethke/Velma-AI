# Phone Pretext Testing

Execute phone-based pretexting calls to test employee resistance to social engineering over the phone.

## Inputs

- `pretext-scripts`: Phone pretext scripts
- `target-groups`: Employee groups for phone testing

## Outputs

- `phone-test-results`: Success/failure rate and information disclosed per call
- `call-transcripts`: Anonymized summaries of each test call

## Process

1. Place calls using approved pretext scenarios (IT help desk, vendor, executive request).
2. Record what information was disclosed (credentials, internal systems, org chart details).
3. Note which employees challenged the caller or escalated to security.
4. Document the elapsed time and number of attempts needed for each successful pretext.
