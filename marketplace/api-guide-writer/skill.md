# Api Guide Writer

Write the getting started guide and authentication walkthrough.

## Inputs

- `openapi-spec`: The API specification
- `code-snippets`: The code examples

## Outputs

- `getting-started-guide`: Step-by-step guide from account creation to first API call
- `auth-guide`: Authentication and authorization walkthrough

## Process

1. Write the prerequisites (account, API key, development environment).
2. Walk through authentication: how to get credentials, how to include them in requests.
3. Walk through making the first API call with a real example.
4. Cover pagination, rate limits, and error handling basics.
