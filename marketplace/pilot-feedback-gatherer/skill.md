# Pilot Feedback Gatherer

Run a pilot phase and gather feedback.

## Inputs

- `hybrid-policy`: The policy
- `transition-communications`: Communications sent

## Outputs

- `pilot-feedback`: Feedback from the pilot phase
- `adjustment-recommendations`: Recommended adjustments before full rollout

## Process

1. Select pilot teams representing different work patterns
2. Run the pilot for four to six weeks
3. Collect feedback through surveys and focus groups
4. Identify what is working and what needs adjustment
