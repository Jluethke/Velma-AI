# One On One Charter Setter

Set the charter for the one-on-one so both sides understand its purpose. The meeting belongs to the report, is not a status update, and exists to remove obstacles and develop the person.

## Inputs

- `manager-report-pair`: The manager and direct report who hold the meeting
- `current-practice`: How their one-on-ones run today, if at all

## Outputs

- `meeting-charter`: The written purpose: the report's meeting, for obstacles and growth, not a status review
- `cadence-decision`: The agreed frequency and the commitment to protect the slot from casual cancellation

## Process

1. State the purpose in writing: the report's meeting, for obstacles and growth, not a project status review.
2. Agree the cadence, weekly for most and biweekly for very experienced reports, and protect the slot from casual cancellation.
3. Agree that status reporting happens in another channel so this time is not consumed by updates.
4. Set the expectation that the report brings the agenda.
