# Sampling Strategy Planner

Design a sampling strategy with target population definition, sampling frame, sample size calculation, and recruitment plan.

## Inputs

- `target-population`: Population of interest with inclusion and exclusion criteria
- `study-design`: Cross-sectional, longitudinal, experimental, or quasi-experimental
- `effect-size-estimate`: Expected effect size from prior literature for power calculation

## Outputs

- `sampling-plan`: Sampling method (random, stratified, cluster, convenience) with justification
- `sample-size`: Required sample size with power analysis parameters and assumptions
- `recruitment-protocol`: Step-by-step recruitment procedure with timeline and contingency plans

## Process

1. Define the accessible sampling frame and identify stratification variables
2. Run power analysis using the expected effect size, alpha level, and desired power
3. Select the sampling method that balances internal validity with feasibility
4. Design the recruitment procedure with contact methods, incentives, and consent process
5. Plan for expected attrition and calculate the inflated sample size needed
