# Regional Comparison Assessor

Compare the site with regional sequences and contemporaneous sites to place it in broader context.

## Inputs

- `chronology-table`: Dated sequence of the site
- `type-frequency-table`: Artifact type frequencies by phase

## Outputs

- `regional-comparison`: How the site fits within the regional cultural sequence
- `significance-assessment`: The site's contribution to understanding regional history

## Process

1. Compare the artifact assemblage with published regional type series
2. Place each phase within the regional chronological framework
3. Identify parallels and divergences with contemporaneous sites
4. Assess the site's significance for regional questions
