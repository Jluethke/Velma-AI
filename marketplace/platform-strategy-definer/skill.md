# Platform Strategy Definer

Define the platform strategy: which platforms to use and how each one fits the content.

## Inputs

- `content-type`: The type of content being distributed (video, audio, text, image)
- `target-audience`: Who the content is for and where they spend time online

## Outputs

- `platform-plan`: Which platforms to use and the role each one plays
- `format-requirements`: The format specs for each platform (dimensions, length, captions, hashtags)

## Process

1. List the candidate platforms (YouTube, TikTok, Instagram, X, LinkedIn, newsletter, blog, podcast).
2. For each platform, define its role (primary, repurpose, promotion, community).
3. Document the format requirements for each (aspect ratio, max length, caption limits).
4. Prioritize platforms by where the target audience is most active.
