# List Segmentation Builder

Define and build segments for targeted sending.

## Inputs

- `collection-points`: How subscribers enter the list
- `target-audience`: Audience characteristics

## Outputs

- `segment-definitions`: Named segments with rules (demographics, behavior, engagement level, purchase history)
- `segment-map`: Map of which segments receive which content types

## Process

1. Define segments by demographics (location, role, industry) collected at sign-up.
2. Define segments by behavior (opened last 30 days, clicked last 7 days, purchased, abandoned cart).
3. Define engagement tiers (active, at-risk, dormant, churned) based on open and click recency.
4. Map each segment to the content types and frequency it should receive.
