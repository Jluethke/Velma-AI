# Photo Retoucher

Retouch images for skin, blemishes, and compositing.

## Inputs

- `developed-images`: Color-corrected images
- `shoot-brief`: Retouching level requested by client

## Outputs

- `retouched-images`: Fully retouched images ready for export
- `retouch-log`: Record of retouching applied to each image

## Process

1. Remove blemishes and temporary skin imperfections
2. Smooth skin texture while preserving natural detail
3. Clean up distracting background elements
4. Apply any compositing or object removal requested
