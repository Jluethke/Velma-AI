# Objection Preempt Messaging

Draft messaging that raises and answers each top objection before the buyer has to say it.

## Inputs

- `positioning-openings`: Openings created by the top themes
- `proof-requirements`: Proof each claim needs

## Outputs

- `preempt-messages`: Short messages that name the common objection and answer it with proof
- `placement-plan`: Where each message should appear across the buyer journey

## Process

1. For each opening, write a short message that names the objection in the buyer's words, then answers it with the proof you have.
2. Keep the tone honest, since a preempt that overclaims reads worse than staying silent.
3. Decide where each message does the most work, such as the pricing page, a sales call, or a comparison page.
4. Note which messages the sales team should say aloud versus which belong in written assets.
