# Dpa Role Identifier

Identify the controller and processor roles and the processing relationship.

## Inputs

- `business-relationship`: Description of the service and data processing
- `data-types`: Types of personal data being processed

## Outputs

- `role-assignment`: Controller and processor role designations
- `processing-scope`: Scope of processing including data types, subjects, and duration

## Process

1. Determine which party is the controller and which is the processor
2. Define the categories of data subjects and personal data types
3. Specify the duration and nature of the processing
