# Esg Narrative Writer

Write the narrative disclosures and compile the ESG report.

## Inputs

- `esg-metrics`: Calculated metrics mapped to framework requirements
- `performance-summary`: Performance summary against targets and prior year

## Outputs

- `esg-report-draft`: The draft ESG report with data tables and narrative disclosures
- `review-checklist`: Checklist of framework requirements with completion status

## Process

1. Write the narrative for each pillar: strategy, risks, opportunities, and management approach.
2. Insert the data tables and metrics into the appropriate disclosure sections.
3. Complete the framework index (GRI content index, SASB disclosure table, or TCFD recommendations map).
4. Produce the review checklist confirming every required disclosure is addressed.
