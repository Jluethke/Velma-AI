# Course Storyboarder

Storyboard the course modules, sequencing content and activities for each lesson.

## Inputs

- `course-objectives`: List of learning objectives
- `audience-analysis`: Analysis of learner characteristics

## Outputs

- `course-storyboard`: Module-by-module outline with content types and activities
- `media-plan`: List of media assets needed (videos, graphics, interactives)

## Process

1. Divide objectives into modules of manageable length
2. Outline each module with content segments and activities
3. Identify media types for each segment (video, reading, interactive, discussion)
4. Produce the storyboard and media production plan
