# Magnetic Interpretation Report

Compile magnetic survey results into an interpretation report with maps, depth sections, source models, and geological conclusions.

## Inputs

- `magnetic-model`: Final subsurface magnetic model
- `source-catalog`: Catalog of identified magnetic sources
- `model-fit-report`: Misfit analysis and model quality assessment

## Outputs

- `magnetics-report`: Interpretation report with maps, sections, and conclusions
- `magnetics-data-archive`: All data, models, and processing files packaged for reproducibility

## Process

1. Compile anomaly maps, derivative products, and depth estimates into coherent figure panels
2. Draw cross-sections through the magnetic model at key profiles
3. Write the geological interpretation linking magnetic results to the survey objectives
4. Package all data and processing workflows for archival
