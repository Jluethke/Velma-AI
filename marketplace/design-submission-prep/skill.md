# Design Submission Prep

Prepare and submit the design for review with context and review criteria.

## Inputs

- `design-files`: The design deliverables to review (mockups, prototypes, specifications)
- `design-context`: The brief, requirements, and constraints the design was built against

## Outputs

- `review-package`: The design files with context, review criteria, and reviewer assignments
- `review-schedule`: The review timeline with deadlines for each reviewer

## Process

1. Package the design files with the original brief and requirements for context.
2. Define the review criteria (brand alignment, usability, technical feasibility, accessibility).
3. Assign reviewers by expertise (design lead, product, engineering, legal if needed).
4. Set the review deadline and produce the review package.
