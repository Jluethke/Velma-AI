# Api Versioning Documenter

Produce the complete API versioning strategy document.

## Inputs

- `versioning-scheme`: Chosen approach and rules
- `migration-guide-template`: Migration process template
- `sunset-policy`: Deprecation and sunset rules

## Outputs

- `versioning-strategy-doc`: Complete versioning strategy for the engineering team
- `consumer-versioning-guide`: Consumer-facing guide explaining how versioning works

## Process

1. Compile the internal strategy document: scheme, rules, processes, responsibilities.
2. Write the consumer-facing guide: how versions work, how to check your version, how to migrate.
3. Set a review cadence for the strategy.
