# Analysis Delivery And Logging

Deliver the analysis and log the request for tracking.

## Inputs

- `assignment-rules`: How analysts are assigned
- `turnaround-slas`: Expected delivery times

## Outputs

- `delivery-protocol`: How finished analyses are delivered and presented
- `ad-hoc-analysis-framework-doc`: Complete framework document covering intake, triage, assignment, delivery, and logging

## Process

1. Define the delivery format (document, dashboard, presentation).
2. Set up a log to track all requests, assignments, delivery dates, and outcomes.
3. Compile the full framework into a document.
4. Review the log monthly for patterns that suggest a recurring report should replace ad-hoc requests.
