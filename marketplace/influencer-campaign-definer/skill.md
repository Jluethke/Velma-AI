# Influencer Campaign Definer

Define the campaign goals, audience, and influencer criteria.

## Inputs

- `campaign-goals`: What the campaign should achieve (awareness, traffic, conversions)
- `target-audience`: The audience the campaign should reach
- `campaign-budget`: The available budget for influencer partnerships

## Outputs

- `campaign-brief`: The campaign brief with goals, audience, timeline, and key messages
- `influencer-criteria`: Selection criteria (follower range, engagement rate, audience demographics, content style)

## Process

1. State the campaign goal in measurable terms (e.g., 10,000 impressions, 500 clicks, 50 conversions).
2. Define the target audience demographics and interests.
3. Set the influencer selection criteria (minimum engagement rate, audience overlap, content alignment).
4. Write the campaign brief with timeline and key messages.
