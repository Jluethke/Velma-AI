# Caqh Profile Management

Complete and maintain the provider's CAQH ProView profile.

## Inputs

- `provider-file`: Verified credentialing documents

## Outputs

- `caqh-profile`: Completed CAQH profile with attestation
- `caqh-id`: Provider's CAQH ID number

## Process

1. Create or update the CAQH ProView profile with all provider information.
2. Upload supporting documents (licenses, insurance, certifications).
3. Complete the attestation and authorize payer access.
4. Set the re-attestation reminder (every 120 days).
