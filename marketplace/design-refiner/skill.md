# Design Refiner

Refine the selected concept based on feedback.

## Inputs

- `design-concepts`: Presented concepts with client feedback
- `brand-guidelines`: Brand rules for compliance check

## Outputs

- `refined-design`: Polished design after revision rounds
- `revision-history`: Log of changes made in each round

## Process

1. Apply the client feedback to the selected concept
2. Refine typography, spacing, and color usage
3. Check alignment with brand guidelines
4. Present the refined version for approval
