# Territory Plan Documenter

Produce the territory plan with assignments, quotas, and strategies.

## Inputs

- `balanced-territories`: Territory assignments
- `territory-quotas`: Assigned quotas
- `segment-profiles`: Segment characteristics

## Outputs

- `territory-plan`: Full territory plan document
- `territory-strategies`: Specific go-to-market strategy per territory

## Process

1. Document each territory's accounts, quota, and rep assignment.
2. Write a one-paragraph strategy for each territory.
3. Include the balance metrics and fairness analysis.
4. Set the review cadence for territory adjustments.
