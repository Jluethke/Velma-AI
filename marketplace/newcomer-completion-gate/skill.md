# Newcomer Completion Gate

Confirm the document is done by having a fresh newcomer complete the task using only the revised procedure, with no help. The document is finished when it works in the hands of someone who has never done the task.

## Inputs

- `revised-procedure`: The repaired procedure
- `resolved-gaps`: What was fixed in the repair pass

## Outputs

- `validated-procedure`: The procedure proven in a newcomer's hands
- `completion-evidence`: Proof the newcomer finished using only the document

## Process

1. Give the revised procedure to a newcomer who has not seen the earlier rounds.
2. Have them complete the task using only the document and no outside help.
3. Treat any new stuck point as a failed gate and send the document back for repair.
4. Mark the procedure validated only when a newcomer finishes unaided, and record the evidence.
