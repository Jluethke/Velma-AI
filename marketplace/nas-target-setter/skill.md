# Nas Target Setter

Set the target and the walk-away point.

## Inputs

- `negotiation-context`: What is being negotiated and with whom
- `your-objective`: What a good result looks like for you

## Outputs

- `target-outcome`: The concrete number a good result lands on
- `walk-away-point`: The point below which no deal is better than a deal

## Process

1. State what a good result looks like in concrete numbers.
2. Set the walk-away point below which no deal is better.
3. Record the units the negotiation is measured in, such as salary, price, or rate.
