# Mentoring Program Architect

Establish the faculty mentoring program pairing experienced and new faculty.

## Inputs

- `faculty-roster`: List of faculty with roles and experience levels
- `priority-topics`: Ranked list of development topics

## Outputs

- `mentoring-plan`: Mentoring program structure, pairings, and expectations
- `mentoring-agreement`: Template agreement between mentor and mentee

## Process

1. Define eligibility and matching criteria
2. Create the mentoring agreement template
3. Schedule the program timeline (orientation, check-ins, wrap-up)
4. Plan the recognition and incentive structure
