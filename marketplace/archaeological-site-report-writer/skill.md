# Archaeological Site Report Writer

Compile the site analysis into a publication-quality report following disciplinary standards.

## Inputs

- `formation-narrative`: Site formation and occupation narrative
- `regional-comparison`: Regional context and significance
- `chronology-table`: Site chronology

## Outputs

- `site-report`: Complete archaeological site report with stratigraphy, finds, dating, and interpretation
- `archive-inventory`: Inventory of the physical and digital archive for deposition

## Process

1. Structure the report: introduction, methods, stratigraphy, finds, dating, spatial analysis, interpretation
2. Include the Harris matrix, plans, sections, photographs, and artifact illustrations
3. Write the interpretive synthesis connecting evidence to questions
4. Compile the archive inventory for repository deposition
