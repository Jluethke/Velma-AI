# Dendrochronology Report

Compile the dendrochronology analysis into a report with chronology plots, climate correlations, and the paleoclimate reconstruction.

## Inputs

- `climate-reconstruction`: Final paleoclimate reconstruction with uncertainty
- `verification-statistics`: Calibration and verification results
- `signal-strength-statistics`: EPS and Rbar over time

## Outputs

- `dendro-report`: Full analysis report with figures, statistics, and interpretation
- `dendro-data-archive`: Ring-width data, chronology, and reconstruction in standard formats

## Process

1. Assemble figures showing the chronology, climate correlations, and reconstruction
2. Write the methods section detailing each processing step and parameter choice
3. Interpret the reconstruction in the context of regional climate history
4. Format the data files in standard formats (ITRDB) for archival
