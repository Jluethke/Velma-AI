# Evaluation Findings Analyzer

Analyze the data and identify key findings.

## Inputs

- `collected-data`: Raw data
- `evaluation-questions`: Questions to answer

## Outputs

- `findings`: Key findings organized by evaluation question
- `data-visualizations`: Charts and tables supporting the findings

## Process

1. Analyze quantitative data (descriptive statistics, comparisons, trends)
2. Analyze qualitative data (coding, theme identification)
3. Triangulate findings across data sources
4. Create visualizations for key findings
