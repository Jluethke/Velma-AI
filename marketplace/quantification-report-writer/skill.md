# Quantification Report Writer

Produce the image quantification report with representative images, measurement distributions, group comparisons, and validation scores.

## Inputs

- `group-statistics`: Per-group summary statistics
- `validation-scores`: Automation validation metrics
- `measurement-distributions`: Feature histograms

## Outputs

- `quantification-report`: Complete image analysis report with figures and tables
- `quantification-figures`: Representative images, measurement plots, and comparison charts

## Process

1. Select representative images showing segmentation overlays.
2. Generate measurement distribution plots and group comparison charts.
3. Write the methods covering preprocessing, segmentation, and classification.
4. Compile the final report with all figures, tables, and validation summary.
