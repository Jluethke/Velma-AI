# Blue Ocean Value Curve Synthesis

Combine the four passes into a new value curve and define the uncontested space it opens. A strong new curve looks clearly different from the industry baseline, not like a slightly tuned copy.

## Inputs

- `eliminate-list`: Factors to remove entirely
- `reduce-list`: Factors to dial well below industry norm
- `raise-list`: Factors to push well above industry norm
- `create-list`: New factors the industry never offered

## Outputs

- `value-curve`: The new value curve after all four actions
- `uncontested-space-definition`: The market space the new curve claims and who it serves

## Process

1. Redraw the value curve applying all four actions: eliminate, reduce, raise, create.
2. Compare it to the industry baseline. A curve that tracks the baseline has not escaped the red ocean.
3. State the uncontested space the new curve claims and the customers, including former non-customers, it serves.
4. Confirm the lower-cost moves fund the higher-value moves so the position is sustainable.
