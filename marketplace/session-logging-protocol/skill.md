# Session Logging Protocol

Log what was accomplished in each session and compile the framework.

## Inputs

- `goal-template`: Session goal template
- `completion-criteria`: Completion criteria

## Outputs

- `session-log-template`: Template for logging session results
- `focus-session-framework`: Complete focus session protocol document

## Process

1. Design the log template: goal, actual outcome, time spent, interruptions, notes.
2. Set a brief reflection after each session (what worked, what to adjust).
3. Compile the full focus session framework.
