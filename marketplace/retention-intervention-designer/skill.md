# Retention Intervention Designer

Design interventions to address the top churn drivers.

## Inputs

- `churn-reasons`: Categorized churn drivers
- `leading-indicators`: Early warning signals

## Outputs

- `intervention-playbook`: Designed interventions for each churn driver
- `alert-rules`: Automated triggers based on leading indicators

## Process

1. Design an intervention for each of the top three churn reasons.
2. Define the trigger criteria for each intervention.
3. Set up automated alerts based on leading indicators.
4. Estimate the expected impact on retention.
