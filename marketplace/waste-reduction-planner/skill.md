# Waste Reduction Planner

Set reduction targets and plan the waste management improvements.

## Inputs

- `waste-baseline`: Baseline waste data by stream
- `contamination-findings`: Contamination issues identified

## Outputs

- `reduction-targets`: Waste reduction and diversion rate targets with timeline
- `improvement-plan`: Plan for infrastructure, signage, training, and procurement changes

## Process

1. Set diversion rate targets (e.g., from 30% to 60% within 18 months) based on the audit results.
2. Identify the highest-volume misrouted materials and design infrastructure to capture them.
3. Plan signage, bin placement, and color coding for each waste stream.
4. Identify upstream reduction opportunities (purchasing changes, reusable alternatives).
