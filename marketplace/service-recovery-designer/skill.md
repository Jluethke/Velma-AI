# Service Recovery Designer

Design recovery protocols for service failures.

## Inputs

- `service-standards`: Defined service standards
- `pain-points`: Known pain points

## Outputs

- `recovery-protocols`: Recovery protocol for each failure scenario
- `empowerment-guidelines`: What staff can do without manager approval

## Process

1. List the most common service failure scenarios.
2. Design a recovery response for each scenario.
3. Define the authority level for each recovery action.
4. Set the compensation guidelines (upgrade, comp, discount).
