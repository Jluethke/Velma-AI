# Dashboard Layout Builder

Build the dashboard layout and produce the KPI dashboard plan.

## Inputs

- `kpi-list`: Defined KPIs
- `targets-and-thresholds`: Targets and alert thresholds
- `alert-rules`: Alerting configuration

## Outputs

- `dashboard-layout`: Dashboard wireframe with KPI placement and visualization types
- `kpi-dashboard-plan`: Complete KPI dashboard plan

## Process

1. Group KPIs by objective or function.
2. Select the visualization type per KPI (gauge, time series, bar chart, number with trend arrow).
3. Lay out the dashboard (summary row, detail sections, drill-down links).
4. Produce the complete KPI dashboard plan.
