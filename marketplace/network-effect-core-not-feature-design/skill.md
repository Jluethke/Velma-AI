# Network Effect Core Not Feature Design

Make the value interaction the core of the product, not a side feature. Network effects fade when the interaction that drives them is buried behind features that give the same value without any other users.

## Inputs

- `core-interaction`: The single interaction that drives the network effect
- `value-mechanism`: How that interaction turns more users into more value per user

## Outputs

- `core-design`: The product reshaped around the core interaction
- `feature-demotions`: The features to demote or cut so they do not undercut the network

## Process

1. Redesign the main flow so the core interaction is the first and central thing a user does.
2. Identify features that deliver value without needing other users and may blunt the network effect.
3. Demote or cut those features so they do not compete with the network as the source of value.
4. Confirm a new user quickly reaches the core interaction rather than a single-user dead end.
