# Version Control Policy Writer

Write the version control policy covering check-in, check-out, and audit procedures.

## Inputs

- `naming-convention`: Naming and numbering rules
- `folder-structure`: Storage structure and permissions
- `access-matrix`: Access control rules

## Outputs

- `version-control-policy`: The complete version control policy document
- `quick-reference-guide`: One-page reference for daily use

## Process

1. Write the check-out and check-in procedures.
2. Define the review and approval workflow for version changes.
3. Specify the audit and compliance requirements.
4. Create the quick reference guide for end users.
