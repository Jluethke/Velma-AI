# Lesson Objective Writer

Identify and write the learning objectives for one lesson session.

## Inputs

- `topic`: The subject and topic for this lesson
- `prior-knowledge`: What learners already know coming into this lesson

## Outputs

- `lesson-objectives`: Specific, measurable objectives for this lesson
- `success-criteria`: Observable criteria indicating the objectives are met

## Process

1. Identify 2-4 learning objectives for the session
2. Write each objective with an action verb and measurable criterion
3. Define observable success criteria for each objective
