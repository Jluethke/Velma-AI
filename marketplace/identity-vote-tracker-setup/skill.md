# Identity Vote Tracker Setup

Set up a tally of votes so the identity has visible, accumulating evidence rather than a feeling that can be argued away.

## Inputs

- `vote-schedule`: The frequency and timing of the action
- `identity-statement`: The identity being built

## Outputs

- `vote-tracker`: A simple running tally where each completed action is one recorded vote
- `vote-tally-method`: The rule for what earns a mark and how the total is read as evidence

## Process

1. Pick a tracker you will actually use, such as a calendar mark or a single tally line. The record must be faster to update than to skip.
2. Define what earns a mark. Completing the smallest vote action earns one, regardless of how the day otherwise went.
3. Keep the running total visible. A growing chain of votes becomes evidence you can point to when the identity feels false.
4. Do not record quality grades. The tally counts votes, not performance, because the identity is built by frequency, not by any single strong day.
