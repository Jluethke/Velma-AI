# Naa Sample Preparation

Prepare and encapsulate samples and standards for reactor irradiation.

## Inputs

- `sample-material`: Description of the sample matrix and expected elements
- `analysis-goals`: Target elements and required detection limits

## Outputs

- `prepared-samples`: Weighed, encapsulated samples and certified reference materials ready for irradiation
- `irradiation-plan`: Reactor position, neutron flux, and irradiation duration for each sample set

## Process

1. Dry, homogenize, and weigh the samples into irradiation vials
2. Select and prepare certified reference materials that bracket the expected concentrations
3. Calculate the required irradiation time based on target sensitivity and expected activities
4. Seal and label all vials with sample IDs and positions in the irradiation container
