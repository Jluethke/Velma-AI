# Bounty Severity Reward Tier Designer

Design severity classifications and corresponding reward tiers.

## Inputs

- `program-scope`: Scope of the program
- `risk-tolerance`: Risk tolerance and budget constraints

## Outputs

- `severity-tiers`: Severity classification scheme with examples
- `reward-schedule`: Payment amounts for each severity level and asset type

## Process

1. Define severity levels (critical, high, medium, low, informational) with concrete examples
2. Set reward amounts for each severity level, scaled by asset criticality
3. Define bonus criteria (first report of a class, chain of bugs, exceptional write-up)
4. Document what does and does not qualify for a reward (duplicates, known issues, scanner output)
