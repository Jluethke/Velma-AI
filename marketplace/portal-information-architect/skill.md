# Portal Information Architect

Design the portal information architecture and navigation.

## Inputs

- `self-service-candidates`: Features and content for the portal
- `automation-potential`: Priority ranking of self-service features

## Outputs

- `portal-architecture`: Site map, navigation structure, and page hierarchy
- `content-requirements`: Content needed for each section

## Process

1. Group self-service features into logical categories.
2. Design the navigation hierarchy.
3. Define the content requirements for each page.
4. Plan the search and filtering experience.
