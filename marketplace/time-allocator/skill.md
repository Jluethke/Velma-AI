# Time Allocator

Split learning time so the vertical gets the majority and the horizontals share the rest.

## Inputs

- `depth-target`: What depth looks like for that area
- `literacy-targets`: What functional literacy means for each area

## Outputs

- `time-allocation`: How learning time is split across depth and breadth
- `weekly-rhythm`: A weekly rhythm that protects the core block

## Process

1. Assign the majority of learning time to the core area.
2. Spread the remaining time across the adjacent areas.
3. Set a weekly rhythm that protects the core block.
4. Confirm the split still moves the depth target forward.
