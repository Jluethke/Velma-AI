# Wearable Reporting Builder

Build the reporting layer for wearable data.

## Inputs

- `common-schema`: Normalized data schema
- `data-store-config`: Storage configuration

## Outputs

- `reports`: Reports and dashboards for the wearable data
- `integration-document`: Complete wearable data integration documentation

## Process

1. Build the individual user dashboard (daily activity, sleep trends, health metrics).
2. Build the aggregate reporting layer (population trends, program participation, anomalies).
3. Set up automated report generation on the chosen schedule.
4. Compile the complete integration documentation.
