# Cascade Verification

After 30 days with the keystone habit, check whether the downstream behaviors actually changed without additional effort.

## Inputs

- `adoption-plan`: The keystone habit plan that was executed
- `causal-map`: Expected downstream behaviors

## Outputs

- `cascade-results`: For each expected downstream behavior: did it actually improve, stay the same, or get worse?
- `next-action`: If the cascade is working, continue. If not, reassess whether the chosen habit is truly a keystone or whether the causal connections were wrong.

## Process

1. Track the downstream behaviors for the full 30-day period. Do not try to adopt them. The point of a keystone habit is that the downstream changes happen without additional willpower.
2. Compare: did the downstream behaviors actually change? If exercise was the keystone and you expected better sleep, did sleep actually improve?
3. If the cascade is working (2+ downstream behaviors improved), continue the keystone habit and let the cascade deepen over the next 60 days.
4. If the cascade did not materialize, one of two things happened: the keystone habit was not truly upstream (the causal map was wrong), or the keystone habit was not adopted firmly enough. Check which one.
