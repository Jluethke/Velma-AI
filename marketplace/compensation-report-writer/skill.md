# Compensation Report Writer

Produce the compensation benchmarking report for leadership.

## Inputs

- `comp-analysis`: Analysis results
- `adjustment-recommendations`: Proposed adjustments
- `cost-projection`: Cost projections

## Outputs

- `compensation-report`: Final benchmarking report
- `executive-summary`: One-page summary for leadership

## Process

1. Compile the analysis, findings, and recommendations
2. Create charts showing market position by job family
3. Write the executive summary with key findings and costs
4. Prepare the appendix with detailed data by role
