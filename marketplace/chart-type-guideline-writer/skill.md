# Chart Type Guideline Writer

Define which chart type to use for each data scenario.

## Inputs

- `audit-findings`: Current inconsistencies
- `pattern-catalog`: Observed patterns

## Outputs

- `chart-type-guidelines`: When to use each chart type (bar, line, pie, scatter, table, tile)
- `anti-pattern-list`: Common visualization mistakes to avoid

## Process

1. Define the data scenarios: comparison, trend, proportion, distribution, relationship.
2. Assign the correct chart type to each scenario with examples.
3. Document anti-patterns with before/after corrections.
