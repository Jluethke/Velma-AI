# Statistical Analysis Planner

Select appropriate statistical tests, define significance thresholds, plan for multiple comparisons, and specify the analysis pipeline before data are collected.

## Inputs

- `hypothesis-statement`: The hypothesis under test
- `raw-data-schema`: Structure of the data to be analyzed
- `sample-size-justification`: Expected sample size and power

## Outputs

- `analysis-plan`: Ordered list of tests, assumptions, corrections, and decision criteria
- `significance-thresholds`: Alpha levels, correction method, and effect size benchmarks

## Process

1. Match each prediction to a statistical test based on data type and design
2. State assumptions (normality, independence, equal variance) and how to check them
3. Define alpha level and correction for multiple comparisons
4. Specify the analysis code or software and version to be used
5. Document stopping rules and interim analysis criteria if applicable
