# Eisenhower Protect Q2

Guard the not-urgent-important quadrant, since that is where lasting value is built.

## Inputs

- `quadrant-map`: Each task placed in one of the four quadrants.
- `quadrant-counts`: How many tasks landed in each quadrant.

## Outputs

- `protected-time`: Time set aside for the not-urgent-important tasks.
- `q2-plan`: The plan that keeps the quadrant from being crowded out.

## Process

1. Set aside protected time for the not-urgent-important tasks.
2. Block that time before the urgent tasks fill the day.
3. Write the plan that keeps the quadrant from being crowded out.
