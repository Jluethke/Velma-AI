# Service Definition Writer

Write the service definition for each catalog entry.

## Inputs

- `service-categories`: Categorized service list
- `service-inventory`: Detailed service inventory

## Outputs

- `service-definitions`: Complete definition for each service (description, SLA, cost, owner)
- `sla-matrix`: SLA targets for each service

## Process

1. Write the description, scope, and eligibility for each service.
2. Define the SLA targets (availability, response time, resolution time).
3. Assign the service owner and support team.
4. Document the cost model if applicable.
