# Redesign Goals Definer

Define the redesign goals, success metrics, and constraints.

## Inputs

- `current-state-audit`: Audit of the current site
- `redesign-opportunities`: Improvement opportunities identified

## Outputs

- `redesign-goals`: Specific, measurable goals for the redesign
- `success-metrics`: How success will be measured post-launch

## Process

1. Set specific goals tied to the audit findings (increase conversion by X%, reduce bounce rate by Y%).
2. Define the success metrics and measurement timeline.
3. Identify constraints (budget, timeline, technical platform).
4. Get stakeholder alignment on goals before proceeding.
