# Disclosure Publisher

Publish the advisory and disclosure timeline.

## Inputs

- `security-advisory`: Public advisory text
- `cve-id`: CVE identifier
- `notification-log`: Record of notifications sent

## Outputs

- `published-advisory`: The advisory as published on the security page
- `disclosure-timeline`: Full timeline from report to publication

## Process

1. Publish the advisory on the product security page and mailing lists
2. Update the CVE record with final details
3. Publish the disclosure timeline including all key dates
4. Archive the complete case file for future reference
