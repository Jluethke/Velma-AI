# Banquet Kitchen Coordinator

Coordinate the menu execution with the kitchen for the banquet.

## Inputs

- `operational-requirements`: Menu and timing requirements
- `event-timeline`: Service timeline

## Outputs

- `kitchen-production-plan`: Course-by-course production plan with fire times
- `banquet-operations-record`: Final banquet operations record

## Process

1. Translate the menu into a production plan with quantities.
2. Set fire times for each course.
3. Coordinate with the service team on pacing.
4. Document the complete operations record.
