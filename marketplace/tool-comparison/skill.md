# Tool Comparison

Compare all tool candidates across all evaluation criteria.

## Inputs

- `accuracy-metrics`: Detection accuracy data
- `integration-scores`: Integration quality data
- `eval-criteria`: Weighted criteria

## Outputs

- `comparison-matrix`: Side-by-side comparison of all tools across all criteria
- `weighted-scores`: Overall weighted score for each tool

## Process

1. Score each tool against each weighted criterion
2. Calculate overall weighted scores
3. Identify clear winners and areas where each tool excels
