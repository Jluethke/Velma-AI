# Referral Invite Flow Designer

Design the invite flow: copy, channels, and sharing interface.

## Inputs

- `referral-flow`: Referral mechanics
- `incentive-structure`: Incentive to communicate

## Outputs

- `invite-copy`: Share messages for each channel
- `invite-ui-spec`: UI specifications for the invite interface

## Process

1. Write the share message for each channel (email, SMS, social)
2. Design the in-app invite interface
3. Specify the landing page for referred users
