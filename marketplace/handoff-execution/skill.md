# Handoff Execution

Conduct the on-call handoff between the outgoing and incoming responders.

## Inputs

- `handoff-checklist`: Checklist of items to cover
- `handoff-template`: Template for recording the handoff

## Outputs

- `handoff-record`: Completed handoff record with all items addressed
- `action-items`: Any follow-up actions for the incoming on-call

## Process

1. The outgoing on-call fills in the handoff template with current status for each item.
2. The incoming on-call reviews the template and asks clarifying questions.
3. Both confirm the handoff is complete and the incoming on-call is now primary.
4. Log the handoff record in the team's knowledge base.
