# Failure Mode Enumerator

List all potential failure modes for each function.

## Inputs

- `function-list`: Functions and requirements
- `fmea-scope`: FMEA scope

## Outputs

- `failure-modes`: All potential failure modes by function
- `effects-list`: Effects of each failure mode on the system and customer

## Process

1. For each function, brainstorm how it could fail (loss, degradation, intermittent, unintended)
2. Describe the local and end effects of each failure mode
3. Identify the potential causes or mechanisms for each failure mode
4. Reference historical data (warranty, scrap, complaints) for known failure modes
