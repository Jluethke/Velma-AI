# Investigation Report Writer

Produce the investigation report documenting the incident from detection through remediation.

## Inputs

- `containment-actions`: Immediate containment actions taken
- `remediation-plan`: Long-term remediation recommendations

## Outputs

- `investigation-report`: Complete incident investigation report
- `lessons-learned`: Lessons learned and improvements for future incident prevention and response

## Process

1. Write the executive summary: what happened, when, what was affected, and current status
2. Document the full technical analysis with timeline, TTPs, and evidence references
3. Include containment actions taken and remediation plan with owners and timelines
4. Capture lessons learned for process improvement
