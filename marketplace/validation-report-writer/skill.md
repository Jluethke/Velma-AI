# Validation Report Writer

Write the instrument validation report with construct definition, item development, psychometric properties, and recommendations.

## Inputs

- `construct-definition`: formal definition
- `reliability-metrics`: internal consistency and test-retest
- `validity-evidence`: convergent, discriminant, criterion
- `cfa-results`: factor structure and fit

## Outputs

- `validation-report`: complete psychometric validation report
- `final-instrument`: the validated instrument with scoring instructions

## Process

1. Summarize the construct definition and item development process
2. Present reliability (alpha, omega, test-retest) and item-level statistics
3. Present validity evidence (convergent, discriminant, criterion) with correlation tables
4. Report factor structure with fit indices and standardized loadings; provide the final instrument and scoring
