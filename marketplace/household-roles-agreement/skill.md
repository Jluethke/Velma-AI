# Household Roles Agreement

Agree on household role division: chores, cooking, finances, maintenance, and mental load.

## Inputs

- `current_habits`: How each person manages household tasks now
- `preferences`: Tasks each prefers or dislikes
- `work_schedules`: Work hours and flexibility

## Outputs

- `chore_division`: Agreed task assignments
- `review_process`: How to adjust when it is not working
- `mental_load_plan`: How to share planning and tracking

## Process

1. List all household tasks
2. Discuss preferences and dislikes
3. Divide tasks considering schedules and strengths
4. Address mental load (planning, scheduling, remembering)
5. Set quarterly review to adjust
