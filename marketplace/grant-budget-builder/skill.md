# Grant Budget Builder

Prepare the grant budget and budget narrative.

## Inputs

- `program-narrative`: Program description with staffing and activities
- `funder-profile`: Funder budget requirements and restrictions

## Outputs

- `grant-budget`: Line-item budget
- `budget-narrative`: Justification for each budget line

## Process

1. List all costs by category (personnel, fringe, travel, supplies, contractual, indirect)
2. Calculate each line item with supporting assumptions
3. Apply the funder's indirect cost rate or negotiate
4. Write the budget narrative explaining each line
