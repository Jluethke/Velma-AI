# Biosketch Preparer

Prepare NIH-format or NSF-format biosketches for each investigator with positions, contributions, and synergistic activities.

## Inputs

- `investigator-cvs`: Current CVs for PI and all co-investigators
- `format-requirements`: Funder-specific biosketch format (NIH, NSF, DOE, etc.)
- `project-relevance`: How each investigator's expertise connects to the proposed aims

## Outputs

- `biosketches`: Formatted biosketches for each investigator meeting funder requirements
- `contribution-statements`: Up to five contributions per investigator with citations
- `training-record`: Relevant training and mentoring record for each investigator

## Process

1. Extract relevant positions, education, and training from each CV
2. Select up to five contributions that demonstrate expertise relevant to the proposed work
3. Write personal statements connecting each investigator's background to their project role
4. List synergistic activities and broader impacts per funder format
5. Verify page limits and formatting against the most current funder template
