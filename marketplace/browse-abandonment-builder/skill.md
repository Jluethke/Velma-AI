# Browse Abandonment Builder

Set up browse abandonment flows for visitors who viewed but did not add to cart.

## Inputs

- `abandonment-segments`: Visitor behavior segments
- `email-sequence`: Cart recovery sequence to extend

## Outputs

- `browse-flows`: Browse abandonment email and retargeting flows
- `audience-rules`: Audience targeting rules for each flow

## Process

1. Define browse abandonment criteria (viewed product, no add to cart within 1 hour).
2. Design the browse abandonment email with product recommendations.
3. Set up retargeting audience rules for ad platforms.
4. Configure frequency caps to avoid over-messaging.
