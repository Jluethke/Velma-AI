# Finished Intel Producer

Produce finished intelligence products tailored to different stakeholder audiences.

## Inputs

- `relevance-assessment`: Relevance-scored intelligence items
- `priority-intel-items`: Items requiring immediate action

## Outputs

- `intel-products`: Finished reports, bulletins, and indicator lists for stakeholders
- `detection-indicators`: Machine-readable indicators formatted for ingestion into security tools

## Process

1. Write executive summaries for leadership highlighting strategic threats
2. Produce tactical bulletins for the SOC with indicators and detection guidance
3. Format machine-readable indicator lists for SIEM and EDR ingestion
4. Create technical deep-dives for incident responders on priority threats
