# Instructional Strategy Selector

Select instructional strategies and materials for each module based on learning outcomes and learner profile.

## Inputs

- `course-sequence`: Ordered list of courses and modules
- `learning-outcomes-list`: List of measurable learning outcomes

## Outputs

- `strategy-plan`: Instructional strategies mapped to each module
- `materials-list`: Required materials, textbooks, and resources per module

## Process

1. Match each outcome to an instructional method (lecture, lab, project, discussion)
2. Select primary and supplementary materials for each module
3. Identify technology and facility requirements
4. Produce the strategy plan and materials list
