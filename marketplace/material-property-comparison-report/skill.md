# Material Property Comparison Report

Compile all characterization results into a comparison report benchmarked against published data for similar materials.

## Inputs

- `mechanical-results`: Strength, hardness, and ductility data
- `thermal-results`: Thermal stability and transition data
- `xrd-results`: Crystal structure and phase composition

## Outputs

- `property-comparison-table`: Side-by-side comparison of measured vs published properties
- `characterization-summary`: One-page summary of the material's key properties and suitability
- `recommended-applications`: Applications where the material's properties are a good match

## Process

1. Tabulate all measured properties with uncertainties
2. Retrieve published data for comparable materials
3. Identify where the new material outperforms, matches, or falls short
4. Recommend applications based on the property profile
