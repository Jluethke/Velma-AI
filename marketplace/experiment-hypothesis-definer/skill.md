# Experiment Hypothesis Definer

Define the hypothesis, success metric, and guardrail metrics.

## Inputs

- `product-change`: The change being tested
- `business-goal`: The business outcome to improve

## Outputs

- `experiment-hypothesis`: Formal hypothesis with primary and guardrail metrics
- `metric-definitions`: Precise definitions for each metric

## Process

1. State the null and alternative hypotheses.
2. Define the primary success metric with its precise calculation.
3. Define guardrail metrics that must not degrade.
4. Set the minimum detectable effect size based on business value.
