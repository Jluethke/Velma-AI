# Rubric Outcome Identifier

Identify the learning outcomes and performance dimensions the rubric will assess.

## Inputs

- `assignment-description`: Description of the assignment or task being assessed
- `learning-outcomes`: The outcomes this assignment is designed to measure

## Outputs

- `performance-dimensions`: List of dimensions to evaluate
- `dimension-definitions`: Clear definition of each dimension

## Process

1. Analyze the assignment for distinct performance aspects
2. Map each aspect to one or more learning outcomes
3. Define each dimension clearly and without overlap
