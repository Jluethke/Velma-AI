# Note Rewriter

Rewrite each captured item as a self-contained note in your own words.

## Inputs

- `capture-workflow`: A fast way to capture every new idea
- `inbox-location`: The single place new ideas first land

## Outputs

- `atomic-notes`: Self-contained notes, one idea each
- `source-references`: The source recorded for each note

## Process

1. Restate each idea in your own words so it stands alone.
2. Keep one idea per note so it can be linked precisely.
3. Record the source reference for each note.
4. Give each note a title that states its idea.
