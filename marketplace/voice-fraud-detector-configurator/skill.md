# Voice Fraud Detector Configurator

Configure fraud detection for spoofing, replay, and synthetic voice attacks.

## Inputs

- `verification-config`: Verification thresholds and logic
- `security-policy`: Security requirements and retention rules

## Outputs

- `fraud-detection-rules`: Rules for detecting replay attacks, voice synthesis, and channel manipulation
- `voice-biometrics-document`: Complete setup document covering enrollment, verification, fraud detection, and policy

## Process

1. Configure replay detection (audio hash comparison, liveness checks).
2. Configure synthetic voice detection (spectral analysis, artifact detection).
3. Set up alerting for detected fraud attempts.
4. Compile the complete voice biometrics document.
