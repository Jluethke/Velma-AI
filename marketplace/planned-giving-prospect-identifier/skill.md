# Planned Giving Prospect Identifier

Identify and cultivate planned giving prospects from the donor base.

## Inputs

- `donor-database`: Current donor records with giving history
- `vehicle-menu`: Available planned giving options

## Outputs

- `prospect-list`: Ranked planned giving prospects
- `cultivation-plan`: Personalized outreach strategy per prospect

## Process

1. Screen the donor base for planned giving indicators (age, loyalty, giving level, engagement)
2. Rank prospects by likelihood and capacity
3. Design a cultivation strategy for each prospect tier
4. Schedule personal outreach for top prospects
