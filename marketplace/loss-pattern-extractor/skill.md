# Loss Pattern Extractor

Find the patterns across losses. The individual reasons are anecdotes. The patterns are your improvement roadmap.

## Inputs

- `real-reason-analysis`: Real reasons behind each loss
- `objection-map`: Actual objections ranked by frequency

## Outputs

- `loss-patterns`: The 3-5 recurring patterns that explain the majority of losses
- `pattern-stage-map`: Which patterns strike at which stages in the process

## Process

1. Group the real reasons into clusters. Name each cluster by the underlying failure: unclear value, wrong audience, weak follow-up, missing proof, or process friction.
2. For each cluster, count the losses. The largest cluster is your biggest leak.
3. Map each cluster to the stage where the loss typically occurs. A pattern that kills deals early is a positioning problem. A pattern that kills deals late is a trust or proof problem.
4. Rank the patterns by impact: number of losses times average deal value (or opportunity value). This is the roadmap priority order.
