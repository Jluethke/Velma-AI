# Conversation Script Writer

Write the conversation scripts for greetings, confirmations, errors, and closings.

## Inputs

- `dialog-flows`: Dialog flow diagrams
- `bot-persona`: Bot persona document

## Outputs

- `conversation-scripts`: Scripts for all dialog turns including greetings, confirmations, disambiguation, errors, and closings
- `multimodal-elements`: Design for buttons, cards, quick replies, and carousels where applicable

## Process

1. Write the greeting and disambiguation scripts in the persona's voice.
2. Write confirmation and error scripts (typo correction, ambiguity resolution, out-of-scope).
3. Design the multimodal elements (quick reply buttons, cards) for chat interfaces.
4. Write the closing scripts with next-step suggestions.
