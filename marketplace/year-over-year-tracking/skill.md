# Year Over Year Tracking

Set up year over year tracking of the baseline numbers so slow changes become visible before they become problems.

## Inputs

- `baseline-numbers`: The current baseline values
- `metric-tracking-sheet`: The sheet holding each measure by year

## Outputs

- `trend-tracker`: A view of each measure across years that shows direction, not just the latest value
- `change-alert-rules`: Rules for how much change in a measure should prompt attention or a clinician visit

## Process

1. Record each measure in the same way every year, so the comparison reflects real change rather than differences in how it was taken.
2. Read each measure as a direction across years, not a single reading. A value drifting steadily toward the edge of its range matters even while it is still in range.
3. Set alert rules for meaningful change, so a measure moving by a defined amount prompts a closer look rather than being noticed only once it is far out of range.
4. Keep the trend view simple enough to scan each year, since a record you cannot read quickly will not get read.
