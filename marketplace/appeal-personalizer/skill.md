# Appeal Personalizer

Personalize the appeal messaging by segment.

## Inputs

- `segmented-lists`: Donor segments
- `ask-amounts`: Suggested ask per donor

## Outputs

- `appeal-packages`: Personalized appeal content per segment
- `channel-assignments`: Delivery channel per donor (mail, email, phone, in-person)

## Process

1. Write the core appeal story
2. Adapt the message for each segment (first-time, renewal, upgrade, lapsed)
3. Personalize the ask amount and impact statement
4. Assign each donor to the most effective channel
