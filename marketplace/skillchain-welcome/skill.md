# Skillchain Welcome

Introduce the skillchain library, what it contains, and how it works.

## Inputs

- `user-greeting`: Whatever the user said to start the conversation

## Outputs

- `library-overview`: Summary of what the library contains (domain count, chain count, how chains work)
- `how-it-works`: Explanation of the chain and flow structure, how inputs pipe to outputs, and what related chains are

## Process

1. Explain that the library is a collection of step-by-step workflows (chains) spanning dozens of domains, from business and finance to agriculture and construction.
2. Describe how each chain is a sequence of steps, each step is a skill with defined inputs and outputs, and outputs from one step feed into the next.
3. Explain that chains link to related chains, so finishing one workflow naturally points to the next thing a person would do.
4. Tell the user you will learn about them and their situation, then recommend where to start.
