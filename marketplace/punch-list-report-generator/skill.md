# Punch List Report Generator

Produce the punch list report with status summary and metrics.

## Inputs

- `status-report`: Current status of all punch list items
- `overdue-items`: Items past their deadline

## Outputs

- `punch-list-report`: Final punch list report with status and metrics
- `sign-off-readiness`: Assessment of readiness for owner sign-off

## Process

1. Compile the status of all items into the report format.
2. Calculate metrics (total items, open, closed, overdue, percent complete).
3. Assess whether the project is ready for owner sign-off.
4. Distribute the report to the project team.
