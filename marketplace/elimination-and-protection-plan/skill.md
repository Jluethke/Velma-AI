# Elimination And Protection Plan

Protect the core from erosion and test-eliminate the bottom rather than cutting it outright. Many low-ratio activities exist for a reason that is invisible until they stop, so removal is a reversible trial.

## Inputs

- `core-activities`: The vital few to protect
- `elimination-candidates`: Low-ratio activities to test removing

## Outputs

- `protection-plan`: Actions that keep the core funded and defended
- `elimination-trial-plan`: Reversible trials to remove low-ratio activities

## Process

1. For each core activity, name what protects its time and resources from being eroded by low-ratio work.
2. For each elimination candidate, design a reversible trial that stops the activity for a set period.
3. Define what signal would prove the activity was actually needed, so a real dependency surfaces fast.
4. Set a restore path for any trial that turns out to have cut something load-bearing.
