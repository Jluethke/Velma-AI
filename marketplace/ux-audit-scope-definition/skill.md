# Ux Audit Scope Definition

Define the audit scope, select the heuristics, and set up the evaluation framework.

## Inputs

- `product-to-audit`: The product, app, or website to audit
- `audit-goals`: What the audit should focus on (onboarding, checkout, navigation, accessibility)

## Outputs

- `audit-plan`: The scope, heuristics, user flows to evaluate, and evaluation criteria
- `competitor-list`: Competitors to benchmark against

## Process

1. Define which parts of the product to audit based on the goals.
2. Select the evaluation heuristics (Nielsen's 10, WCAG, custom criteria).
3. Identify the key user flows to walk through.
4. Select two to three competitors for benchmarking.
5. Produce the audit plan and competitor list.
