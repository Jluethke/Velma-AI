# Executive Reporting Launcher

Launch the reporting cadence and set the review process.

## Inputs

- `report-designs`: Report formats and metrics
- `production-schedule`: Delivery schedule

## Outputs

- `reporting-cadence-doc`: Complete executive reporting plan
- `review-process`: How and when to review and update the reporting cadence

## Process

1. Produce the first cycle of each report.
2. Gather feedback from the executive audience.
3. Adjust formats and metrics based on feedback.
4. Document the cadence and set a quarterly review.
