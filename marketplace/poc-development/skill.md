# Poc Development

Develop proof-of-concept exploits for confirmed vulnerabilities.

## Inputs

- `dynamic-findings`: Confirmed vulnerabilities
- `protection-profile`: Active mitigations to bypass

## Outputs

- `poc-exploits`: Working proof-of-concept exploits
- `bypass-techniques`: Mitigation bypass methods used

## Process

1. Craft exploit payloads for each confirmed vulnerability
2. Develop mitigation bypass techniques where needed (ROP chains, heap shaping)
3. Test each PoC for reliability and document the steps
