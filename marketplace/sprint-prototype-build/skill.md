# Sprint Prototype Build

Build a realistic prototype of the solution (day 4).

## Inputs

- `storyboard`: The storyboard to turn into a prototype
- `sprint-target`: The target area for context on fidelity needed

## Outputs

- `prototype`: A realistic prototype ready for user testing
- `test-script`: The interview script and tasks for user testing

## Process

1. Assign prototype tasks to team members (screens, copy, data, assets).
2. Build the prototype at a fidelity level that users can react to (not pixel-perfect, but believable).
3. Write the test script with introduction, tasks, and follow-up questions.
4. Produce the prototype and test script.
