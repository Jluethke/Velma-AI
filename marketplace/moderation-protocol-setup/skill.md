# Moderation Protocol Setup

Set up the moderation protocol and tools.

## Inputs

- `moderation-rules`: The moderation rules from the guidelines
- `platform-choice`: The platform the community runs on

## Outputs

- `moderation-protocol`: Step-by-step protocol for handling violations
- `moderation-tools-config`: Configuration for bots, filters, and reporting workflows

## Process

1. Map each violation type to a specific response action.
2. Configure automated filters for spam, slurs, and prohibited content.
3. Set up the reporting workflow (how members report, how moderators triage).
4. Document the escalation path for edge cases.
