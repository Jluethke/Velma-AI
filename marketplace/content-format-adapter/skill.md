# Content Format Adapter

Adapt the source content for each target platform.

## Inputs

- `platform-plan`: The platforms and their roles
- `format-requirements`: The specs for each platform

## Outputs

- `adapted-content-set`: The content adapted for each platform (files, captions, hashtags)
- `adaptation-notes`: Notes on what was changed for each platform and why

## Process

1. Take the source content and create derivatives for each platform.
2. Adjust the format (crop, resize, trim, add captions or subtitles).
3. Write platform-specific captions and select hashtags.
4. Review each adaptation against the platform's best practices.
