# Ui Requirements Gatherer

Gather requirements and define user flows.

## Inputs

- `product-requirements`: Feature requirements and user stories
- `user-personas`: Target user descriptions and goals

## Outputs

- `user-flows`: Step-by-step flows for each key task
- `ui-requirements`: Screen inventory and functional requirements per screen

## Process

1. Map the primary user tasks from requirements
2. Draw user flow diagrams for each task
3. Identify all screens needed to support the flows
4. List functional requirements for each screen
