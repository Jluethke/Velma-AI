# Music Arrangement Writer

Write the song arrangement including chord structure, melody, and form.

## Inputs

- `song-concept`: Genre, mood, tempo, and lyrical theme
- `reference-tracks`: Reference songs for style and structure

## Outputs

- `arrangement-chart`: Song structure with chords, melody, and sections
- `instrument-plan`: List of instruments and parts for each section

## Process

1. Define the song structure (intro, verse, chorus, bridge, outro)
2. Write the chord progression for each section
3. Compose the melody and counter-melodies
4. Plan the instrumentation and dynamics for each section
