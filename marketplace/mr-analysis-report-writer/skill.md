# Mr Analysis Report Writer

Compile the magnetic resonance analysis into a report with methods, spectra or images, assignments, quantification, and conclusions.

## Inputs

- `quantification-results`: All quantified values
- `standards-comparison-table`: Reference comparisons
- `processing-log`: Record of processing steps

## Outputs

- `mr-analysis-report`: Complete report with annotated spectra/images and conclusions
- `raw-data-package`: Raw and processed data for archival

## Process

1. Write the methods section: instrument, field strength, pulse sequence, processing parameters.
2. Include annotated spectra or images with labeled peaks or regions.
3. Present quantification results and reference comparisons in tables.
4. State conclusions about molecular structure, purity, composition, or anatomical findings.
