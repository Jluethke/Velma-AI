# Workplace Investigation Report Writer

Produce the investigation report.

## Inputs

- `factual-findings`: Findings
- `outcome-decision`: Outcomes
- `corrective-actions`: Recommended actions

## Outputs

- `investigation-report`: Complete investigation report
- `closure-communications`: Communications to the complainant and respondent about the outcome

## Process

1. Write the report with scope, methodology, findings, and conclusions
2. Ensure the report is factual and free of opinion or bias
3. Prepare the closure communications for the parties
4. File the report per the records retention policy
