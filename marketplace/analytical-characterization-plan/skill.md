# Analytical Characterization Plan

Plan analytical characterization for each intermediate and the final product using NMR, mass spectrometry, IR, and chromatography.

## Inputs

- `selected-route`: Synthesis steps and expected intermediates
- `target-structure`: Expected final product structure

## Outputs

- `characterization-protocol`: Which techniques to run at each stage with expected diagnostic signals
- `expected-spectra`: Predicted NMR shifts, MS fragments, and IR bands for the target
- `purity-method`: HPLC or GC method for purity determination

## Process

1. List diagnostic signals (NMR chemical shifts, MS parent ion, IR bands) for the target
2. Assign characterization checkpoints at key intermediates
3. Define an HPLC or GC method for purity measurement
4. Specify acceptance criteria (purity threshold, spectral match tolerance)
