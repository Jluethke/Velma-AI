# Journaling Framework Compiler

Compile the full journaling framework document.

## Inputs

- `review-protocol`: Weekly review process
- `rotation-schedule`: Prompt rotation schedule

## Outputs

- `journaling-framework`: Complete journaling practice document
- `starter-kit`: First week's prompts and setup checklist

## Process

1. Assemble the format, schedule, prompts, and review process into one document.
2. Write the first week's daily prompts.
3. Create the setup checklist (materials, environment, calendar blocks).
