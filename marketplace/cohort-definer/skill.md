# Cohort Definer

Define the cohort criteria and analysis parameters.

## Inputs

- `analysis-question`: What question the cohort analysis should answer
- `available-data`: What data is available for cohort grouping

## Outputs

- `cohort-definition`: How users are grouped into cohorts (signup date, first purchase, plan tier)
- `analysis-parameters`: Time periods, metric to track (retention, conversion, revenue), granularity

## Process

1. State the question: are we retaining users better over time? Is a specific segment converting differently?
2. Define the cohort grouping: by week, month, acquisition channel, or plan tier.
3. Set the metric to track and the time granularity (weekly, monthly).
