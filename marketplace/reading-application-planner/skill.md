# Reading Application Planner

Decide what to apply from each reading and plan the application.

## Inputs

- `reading-notes`: Notes from completed readings
- `key-takeaways`: Top insights per item

## Outputs

- `application-plan`: Specific actions to take from each reading
- `reading-list-report`: Complete reading list with notes and status

## Process

1. Review the takeaways and select the ones worth acting on.
2. Write a specific action for each (what, when, how).
3. Add completed items to the reading log with notes and rating.
