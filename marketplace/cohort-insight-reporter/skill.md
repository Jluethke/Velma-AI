# Cohort Insight Reporter

Extract insights and produce the cohort analysis report.

## Inputs

- `cohort-table`: Visualized cohort data
- `pattern-observations`: Trends and outliers

## Outputs

- `cohort-insights`: Key findings from the analysis with supporting data
- `cohort-analysis-report`: Complete report with methodology, findings, and recommendations

## Process

1. State the key finding in one sentence.
2. Support it with specific cohort comparisons.
3. Recommend actions based on the findings.
4. Compile into the analysis report.
