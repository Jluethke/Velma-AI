# Booking Interface Setup

Set up the customer-facing booking page or widget where appointments are scheduled.

## Inputs

- `availability-rules`: Availability rules governing when slots appear
- `service-catalog`: Services available for booking

## Outputs

- `booking-page-config`: Configuration of the booking page (layout, fields, branding, embed code)
- `intake-form-fields`: Customer intake fields collected at booking time

## Process

1. Select the booking platform or embed method (standalone page, website widget, link in email).
2. Configure the booking flow: service selection, provider selection (if applicable), date/time picker, customer info form.
3. Define the intake fields to collect at booking (name, contact, reason for visit, insurance, special requests).
4. Apply branding (logo, colors, confirmation copy) and test the booking flow end to end.
