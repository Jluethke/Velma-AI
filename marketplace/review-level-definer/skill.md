# Review Level Definer

Define the review levels and their purposes.

## Inputs

- `organization-structure`: Teams, departments, and leadership structure
- `current-review-practices`: Existing meetings and review sessions

## Outputs

- `review-levels`: Defined levels (daily standup, weekly ops, monthly business, quarterly strategy)
- `level-purposes`: What each level is for and what it is not for

## Process

1. Define each review level: daily (execution), weekly (operations), monthly (business health), quarterly (strategy).
2. Set the purpose and non-purpose of each level.
3. Map existing meetings to the levels.
4. Produce the review level definitions.
