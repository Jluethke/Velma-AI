# Feedback Request Formulator

Make a specific, actionable request for change. 'Be more respectful' is not actionable. 'Let the presenter finish each slide before asking questions' is actionable.

## Inputs

- `impact-statement`: What the behavior caused
- `pattern-or-one-off`: Whether this is a pattern, which affects the weight of the request

## Outputs

- `change-request`: The specific behavior change you are requesting
- `success-measure`: How both of you will know the change has happened

## Process

1. State the behavior you want to see instead. Positive framing: 'Hold questions until the end of each section' not 'Stop interrupting.'
2. Make it measurable: both of you should be able to observe whether the change happened.
3. For a pattern, the request is stronger: 'I need this to change starting now.' For a one-off, lighter: 'Can you try X next time?'
4. One request per feedback session. Multiple requests dilute each other and feel like an attack.
