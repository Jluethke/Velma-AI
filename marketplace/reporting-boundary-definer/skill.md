# Reporting Boundary Definer

Define the organizational and operational boundaries for greenhouse gas reporting (Scope 1, 2, 3).

## Inputs

- `organization-structure`: Description of the organization's entities, facilities, and operations
- `reporting-period`: The time period covered by the report

## Outputs

- `reporting-boundary`: Defined boundary including which entities and scopes are in scope
- `data-collection-plan`: Plan listing the data sources and responsible parties for each scope

## Process

1. Identify all entities, facilities, and operations the organization controls or has equity in.
2. Select the consolidation approach (operational control, financial control, or equity share).
3. Define which Scope 1, 2, and 3 categories apply based on the organization's activities.
4. List the data sources and assign collection responsibilities for each category.
