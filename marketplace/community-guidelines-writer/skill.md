# Community Guidelines Writer

Draft community guidelines and moderation rules.

## Inputs

- `community-purpose`: The purpose and target audience of the community
- `platform-choice`: The platform for the community (Discord, Slack, Facebook Group, Reddit)

## Outputs

- `community-guidelines`: Published guidelines and code of conduct
- `moderation-rules`: Rules for content removal, warnings, and bans

## Process

1. Define the community's purpose and who it serves.
2. Write the behavior standards (what is welcome, what is not).
3. Set the enforcement ladder (warning, mute, temporary ban, permanent ban).
4. Format the guidelines for posting in the community's welcome channel or pinned post.
