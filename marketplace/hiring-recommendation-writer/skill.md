# Hiring Recommendation Writer

Produce the final hiring recommendation with supporting evidence.

## Inputs

- `interview-scores`: Scores from interviews
- `reference-results`: Reference check feedback
- `red-flags`: Any concerns identified

## Outputs

- `hiring-recommendation`: Recommended candidate with justification
- `offer-parameters`: Proposed compensation, start date, and terms

## Process

1. Rank the finalists by composite score
2. Weigh reference results and any red flags
3. Draft the recommendation with evidence from each stage
4. Propose the offer parameters
