# Social Ad Optimizer

Optimize the campaign based on performance data.

## Inputs

- `ab-test-results`: A/B test data
- `social-ad-brief`: KPIs for reference

## Outputs

- `optimization-actions`: Changes made to improve performance
- `social-ad-report`: Campaign performance report with results and learnings

## Process

1. Pause underperforming ads and scale winners
2. Adjust targeting or budget based on data
3. Produce the campaign report
