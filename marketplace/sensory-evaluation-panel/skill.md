# Sensory Evaluation Panel

Design and run a sensory evaluation panel: recruit panelists, train on attributes, and score samples using a structured ballot.

## Inputs

- `bench-samples`: Formulation prototypes for sensory testing
- `product-concept`: Target sensory profile guiding attribute selection

## Outputs

- `sensory-scores`: Panelist scores per attribute per sample with statistical analysis
- `preference-ranking`: Overall preference ranking with significant differences identified

## Process

1. Recruit a panel of 8-12 trained assessors or 60+ consumers depending on test type
2. For descriptive analysis, train panelists on reference standards for each attribute (sweetness, acidity, firmness, etc.)
3. Present samples in randomized order with three-digit codes using a balanced incomplete block or Williams design
4. Analyze scores with ANOVA and post-hoc tests, generate spider plots and preference maps
