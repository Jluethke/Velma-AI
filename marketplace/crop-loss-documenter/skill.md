# Crop Loss Documenter

Document the crop loss with cause, date, and extent.

## Inputs

- `loss-event`: Description of the loss event (drought, hail, flood, disease)
- `field-records`: Planting records, input records, and yield history

## Outputs

- `loss-documentation`: Written description with dates, cause, and affected acreage
- `photographic-evidence`: Dated photos of damage from multiple angles

## Process

1. Record the date and cause of loss as soon as possible.
2. Document the affected acreage and estimated damage percentage.
3. Photograph damage from multiple locations across the field.
4. Gather supporting records (planting dates, input applications, weather data).
