# Curriculum Alignment Mapper

Build the curriculum alignment matrix mapping outcomes to courses, strategies, and assessments.

## Inputs

- `learning-outcomes-list`: List of measurable learning outcomes
- `assessment-plan`: Formative and summative assessments per module
- `strategy-plan`: Instructional strategies mapped to each module

## Outputs

- `alignment-matrix`: Matrix showing outcome-course-assessment-strategy alignment
- `curriculum-document`: Final curriculum document ready for review

## Process

1. Cross-reference each outcome against courses, strategies, and assessments
2. Identify any outcomes without adequate assessment coverage
3. Fill gaps and finalize the alignment matrix
4. Compile the full curriculum document
