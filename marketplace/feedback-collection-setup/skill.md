# Feedback Collection Setup

Set up the feedback collection process for after each interview.

## Inputs

- `scoring-rubric`: The scoring rubric
- `panel-schedule`: Interview panel assignments

## Outputs

- `feedback-process`: Process for collecting and aggregating interviewer feedback
- `debrief-template`: Template for the post-interview debrief meeting

## Process

1. Design the feedback submission form using the rubric
2. Set the deadline for feedback submission (before debrief)
3. Create the debrief meeting agenda template
4. Define the decision criteria for advancing candidates
