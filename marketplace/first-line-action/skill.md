# First Line Action

Put the action or ask in the first line of the email body.

## Inputs

- `email-purpose`: The action needed
- `subject-line`: The subject

## Outputs

- `opening-line`: First sentence states exactly what you need
- `action-clarity`: The specific action, who does it, by when

## Process

1. First sentence = the ask. Everything else is context.
2. If multiple recipients with different actions, name them.
3. If FYI, the first line is the takeaway.
4. If responding to a question, the first line is the answer.
