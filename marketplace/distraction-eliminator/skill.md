# Distraction Eliminator

Identify and eliminate distractions before each session.

## Inputs

- `session-format`: Focus session structure
- `session-rules`: Session rules

## Outputs

- `distraction-checklist`: Pre-session checklist for eliminating distractions
- `environment-setup`: Physical and digital environment configuration

## Process

1. List the top distractions (phone, email, chat, noise, browser tabs).
2. Write the elimination step for each (phone in another room, close email, use site blocker).
3. Set up the physical environment (clean desk, headphones, water).
