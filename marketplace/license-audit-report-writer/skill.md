# License Audit Report Writer

Produce the license compliance audit report.

## Inputs

- `compliance-status`: Compliance status
- `remediation-plan`: Remediation plan
- `budget-estimate`: Budget estimate

## Outputs

- `audit-report`: License compliance audit report
- `executive-summary`: Executive summary for management

## Process

1. Summarize overall compliance posture
2. Detail findings with severity and exposure
3. Present the remediation plan and budget request
