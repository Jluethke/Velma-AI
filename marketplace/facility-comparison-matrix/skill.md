# Facility Comparison Matrix

Compare assisted living facilities on care quality, cost, location, amenities, and resident satisfaction.

## Inputs

- `care_level_needed`: Required level of care
- `geographic_preferences`: Preferred locations
- `budget_range`: Monthly budget range
- `must_haves`: Non-negotiable features

## Outputs

- `facility_shortlist`: Top facilities with comparison data
- `visit_checklist`: What to check during tours
- `question_list`: Questions to ask each facility

## Process

1. Research facilities meeting care level and location
2. Check state inspection reports and ratings
3. Compare monthly costs and what is included
4. Create tour checklist
5. Build standardized question list for each visit
