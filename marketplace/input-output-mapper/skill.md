# Input Output Mapper

List all inputs and measure the output each one produces. An input is anything you invest resources in (time, money, attention). An output is the result you care about (revenue, satisfaction, progress, health). The mapping must be specific: not 'marketing' but 'Google Ads, LinkedIn posts, email campaigns, trade shows, referral program.'

## Inputs

- `domain-description`: The area to analyze (business line, personal schedule, product portfolio, customer base, etc.)
- `output-metric`: The output you care about (revenue, time saved, satisfaction score, weight lost, etc.)

## Outputs

- `input-list`: Every distinct input, at the most granular level available
- `output-per-input`: The measured output each input produces, over the same time period

## Process

1. List every input at the most specific level you can. Break categories into their components. 'Customers' becomes each customer or customer segment. 'Activities' becomes each distinct activity.
2. For each input, measure the output it produces. Use the same time period for all inputs. If direct measurement is not possible, estimate and mark the estimate.
3. Record the total output across all inputs. You will use this to calculate percentages.
