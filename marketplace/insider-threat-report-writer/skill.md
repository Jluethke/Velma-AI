# Insider Threat Report Writer

Document the investigation findings with evidence for the insider threat report.

## Inputs

- `exfiltration-findings`: Evidence of insider activity
- `response-decision`: Decision on next steps

## Outputs

- `insider-threat-report`: Complete insider threat investigation report
- `prevention-controls`: Recommended controls to prevent similar incidents

## Process

1. Compile all evidence into a structured investigation report
2. Include the timeline, findings, and supporting evidence for each finding
3. Document the response decision and its rationale
4. Recommend controls to detect and prevent similar insider threats
