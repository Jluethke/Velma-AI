# Decision Framer

Define the decision, the alternatives being compared, and the evaluation criteria.

## Inputs

- `decision-description`: Description of the business decision to be made
- `alternatives-list`: List of alternatives to compare

## Outputs

- `decision-framework`: Structured framework with alternatives and criteria
- `evaluation-scope`: Time horizon, discount rate, and boundary conditions

## Process

1. State the decision clearly and identify all viable alternatives including status quo.
2. Define the evaluation criteria (financial and non-financial).
3. Set the time horizon for the analysis.
4. Determine the appropriate discount rate for NPV calculations.
