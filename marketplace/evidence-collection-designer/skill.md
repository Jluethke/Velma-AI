# Evidence Collection Designer

Design the evidence collection process for documenting competency attainment.

## Inputs

- `assessment-tasks`: Tasks aligned to each competency
- `competency-framework`: List of competencies

## Outputs

- `evidence-portfolio-template`: Template for the learner evidence portfolio
- `collection-procedures`: Procedures for collecting and storing evidence

## Process

1. Define acceptable evidence types per competency (artifacts, observations, reflections)
2. Create the portfolio template with sections for each competency
3. Design the submission and review workflow
4. Set policies for evidence quality and authenticity
