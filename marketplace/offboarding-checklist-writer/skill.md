# Offboarding Checklist Writer

Compile the complete offboarding record.

## Inputs

- `access-revocation-log`: Access revocation log
- `equipment-return-log`: Equipment return log
- `final-pay-record`: Final pay record

## Outputs

- `offboarding-record`: Complete offboarding record for HR files
- `offboarding-complete`: Confirmation that all steps are complete

## Process

1. Verify all checklist items are complete
2. Compile the access, equipment, pay, and knowledge transfer records
3. Get sign-off from HR, IT, and the manager
4. File the complete record
