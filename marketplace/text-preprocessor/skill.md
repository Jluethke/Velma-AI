# Text Preprocessor

Implement text preprocessing (tokenization, normalization, stop words).

## Inputs

- `prepared-corpus`: The cleaned text corpus
- `language`: Language of the text

## Outputs

- `preprocessed-corpus`: Tokenized and normalized text
- `preprocessing-config`: Preprocessing pipeline configuration

## Process

1. Tokenize the text (word-level, subword, or character depending on task).
2. Apply normalization (lowercasing, lemmatization or stemming).
3. Remove stop words (if appropriate for the task).
4. Handle special tokens, numbers, and domain-specific vocabulary.
