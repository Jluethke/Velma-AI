# Report Layout Formatter

Design the visual layout: page structure, branding, headers, and conditional formatting.

## Inputs

- `report-outline`: Sections and visual types
- `calculation-definitions`: Metrics and formulas

## Outputs

- `layout-template`: Visual layout with positioning, sizing, color coding, and conditional formatting rules
- `formatting-rules`: Conditional formatting and alerting rules (red if below target, green if above)

## Process

1. Arrange sections on the page in order of importance (key takeaways first).
2. Apply consistent formatting: fonts, colors, number formats, date formats.
3. Add conditional formatting for thresholds (red/yellow/green for KPIs).
4. Include headers, footers, timestamps, and data freshness indicators.
