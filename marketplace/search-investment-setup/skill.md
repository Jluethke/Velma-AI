# Search Investment Setup

Invest in search capability. Configure full-text search, tag filtering, date-range search, and saved searches for common retrieval patterns. The time you save on organizing goes into making search work.

## Inputs

- `metadata-schema`: The metadata fields applied to all items
- `tagging-discipline`: Tagging rules and tag management

## Outputs

- `search-configuration`: Working search configuration: full-text, tag filter, date range, project scope, and saved searches
- `search-over-organize-doc`: Complete system documentation: flat store, metadata, search, and the quarterly maintenance routine

## Process

1. Enable full-text search across all storage. Test it: can you find a document by a phrase you remember from inside it? If not, the search tool needs to be replaced or upgraded.
2. Set up filtered search: search within a project, search within a date range, search by tag. These filters narrow results when full-text returns too many matches.
3. Create saved searches for your 10 most common retrieval scenarios. A saved search should return the answer in one click.
4. Run the retrieval test again: time the same 10 scenarios from the audit. Every scenario should now complete in under 30 seconds. Any that do not reveal a metadata or search gap to fix.
