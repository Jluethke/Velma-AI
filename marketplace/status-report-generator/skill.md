# Status Report Generator

Generate the project status report.

## Inputs

- `tracking-dimensions`: What gets tracked
- `risk-criteria`: How at-risk items are flagged
- `escalation-protocol`: How blockers get escalated

## Outputs

- `report-template`: Template for the status report
- `project-status-report`: Complete project status report framework

## Process

1. Design the report layout (summary, per-workstream detail, blockers, actions).
2. Include risk flags and escalation status.
3. Set the distribution list and format.
4. Produce the report template and framework.
