# Referral Loop Mapper

Map the referral loop: how does a user invite another user, and what is the experience of the invited user?

## Inputs

- `product-or-service`: What the user is referring
- `current-referral-mechanism`: How users currently refer others (if any)

## Outputs

- `referral-loop-map`: The step-by-step loop: user action to invite, invitation delivery, invited user's experience, conversion of invited user, new user's action to invite
- `loop-friction-points`: Where the loop is difficult, slow, or unclear

## Process

1. Map each step: what does the existing user do to invite? (Share a link, send an email, tell someone, use an in-product invite feature.) How is the invitation delivered? What does the invited person see? What must they do to convert?
2. Identify the friction points: is the invite action easy to find? Is the invitation clear and persuasive? Is the conversion process simple?
3. If there is no referral mechanism, design one. The simplest: a shareable link with a clear benefit for both the referrer and the invitee.
4. Map the loop back to the beginning: once the new user is onboarded, how likely are they to invite someone? This closes the loop.
