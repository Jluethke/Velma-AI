# Baseline Gap Measurement

Measure the gap between the minimum dose and what you currently do, so the starting dose is set from reality rather than ambition.

## Inputs

- `minimum-dose-table`: The minimum dose for each target
- `current-activity-baseline`: What you currently do in a typical week

## Outputs

- `current-vs-minimum-gap`: For each target, how far current activity is from the minimum dose
- `starting-dose`: The dose to begin with, set close to current activity when the gap is large

## Process

1. Compare current activity to each minimum. Someone doing zero cardio has a full gap, while someone doing one hundred minutes has only a small one.
2. Where the gap is large, do not jump straight to the minimum. A jump from zero to one hundred fifty minutes collapses within weeks.
3. Set the starting dose a step above current activity, not at the final minimum. The first job is to establish the habit, then grow it to the floor.
4. Where current activity already meets or exceeds the minimum, set the starting dose at maintenance and move attention to another target.
