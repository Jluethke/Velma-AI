# Bottleneck Eliminator

Fix the bottlenecks in priority order. For each bottleneck, design a specific fix and implement it. The fix for access delays is pre-provisioning before the start date. The fix for knowledge gaps is documentation. The fix for direction gaps is a structured first-week plan. Do not try to fix everything at once. Fix the biggest bottleneck first, measure the result, then move to the next.

## Inputs

- `ranked-bottlenecks`: Bottlenecks ranked by delay caused
- `bottleneck-owners`: Who controls each bottleneck

## Outputs

- `fix-implementations`: For each of the top 3 bottlenecks: the specific fix implemented, who is responsible, and the expected reduction in delay
- `revised-onboarding-plan`: The updated onboarding process with the fixes incorporated

## Process

1. Take the top-ranked bottleneck. Design the fix. Common fixes: pre-provision all access and equipment before the start date (submit requests at offer acceptance, not on day one), write the missing documentation (the team should maintain a 'new hire survival guide'), create a structured first-week plan with daily objectives.
2. Implement the fix. This may require coordination with other teams (IT, facilities). Set a deadline.
3. Move to the second bottleneck. Repeat.
4. Update the onboarding plan to incorporate the fixes. The plan should specify what happens before day one, during week one, and during weeks two through four.
