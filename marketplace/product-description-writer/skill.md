# Product Description Writer

Write product descriptions following naming conventions and SEO guidelines.

## Inputs

- `product-schema`: Product data schema to follow
- `sku-format`: SKU naming convention

## Outputs

- `product-descriptions`: Written product descriptions
- `naming-standards`: Naming convention reference document

## Process

1. Establish title templates by category (brand, product type, key attribute, size).
2. Write descriptions with features, benefits, and specifications.
3. Apply SEO guidelines to titles and descriptions.
4. Validate descriptions against the schema.
