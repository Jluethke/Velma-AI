# Regulatory Change Implementer

Plan and implement changes to meet new regulatory requirements.

## Inputs

- `impact-assessment`: Impact assessment
- `gap-analysis`: Gap analysis

## Outputs

- `implementation-plan`: Plan with tasks, owners, and deadlines
- `change-evidence`: Evidence of implemented changes

## Process

1. Create the implementation plan with tasks, owners, and deadlines.
2. Execute the changes (policy updates, process changes, system modifications, training).
3. Collect evidence that each change was implemented.
4. Validate compliance through testing or review.
