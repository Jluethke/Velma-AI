# Moat Network Effect Assessment

Assess network effects: whether the product becomes more valuable to each user as more users join. Strong network effects make the leading product hard to displace because value, not just size, grows with scale.

## Inputs

- `business-profile`: A tight profile of the business model and customers
- `competitor-set`: The named set of real competitors

## Outputs

- `network-effect-score`: A 0 to 5 score for network effect strength
- `network-effect-evidence`: The user-to-user value that grows with scale

## Process

1. Ask whether one more user makes the product better for existing users, and how.
2. Name the interaction that creates the effect: more buyers draw more sellers, more users create more data, and so on.
3. Check whether the effect is local or global. Local effects can be beaten market by market.
4. Score 0 to 5 and write down the specific value that grows with user count.
