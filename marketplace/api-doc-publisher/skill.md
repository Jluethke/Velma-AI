# Api Doc Publisher

Publish the documentation and set up automated updates.

## Inputs

- `api-reference`: Complete documentation
- `getting-started-guide`: Quick start guide

## Outputs

- `published-docs`: URL and access details for the published documentation
- `doc-update-process`: How documentation updates when the API changes

## Process

1. Choose the hosting platform for the documentation.
2. Publish the reference and getting started guide.
3. Set up a process to update docs when endpoints change (CI hook or review checklist).
