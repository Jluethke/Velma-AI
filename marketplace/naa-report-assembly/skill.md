# Naa Report Assembly

Compile the NAA results into a final analytical report.

## Inputs

- `elemental-concentrations`: Quantified elements with uncertainties
- `quality-metrics`: Detection limits and reference material agreement
- `correction-factors`: All corrections applied during the analysis

## Outputs

- `naa-report`: Complete NAA report with methods, results tables, QA/QC, and interpretation
- `data-archive`: Archived spectra, peak fit files, and calculation spreadsheets

## Process

1. Organize results into tables by sample with element, concentration, uncertainty, and detection limit
2. Write the methods section covering irradiation, counting, and correction procedures
3. Include QA/QC results showing reference material agreement
4. Archive all raw spectra and intermediate calculations alongside the report
