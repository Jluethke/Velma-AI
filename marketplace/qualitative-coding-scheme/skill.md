# Qualitative Coding Scheme

Develop and apply a codebook for qualitative data analysis with deductive codes from theory and inductive codes from the data.

## Inputs

- `interview-transcripts`: Transcribed interview data ready for analysis
- `conceptual-model`: Theoretical framework guiding deductive code categories
- `coding-approach`: Thematic analysis, grounded theory, content analysis, or framework analysis

## Outputs

- `codebook`: Complete codebook with code names, definitions, inclusion criteria, and examples
- `coded-data`: Transcripts with applied codes and annotations
- `inter-rater-reliability`: Cohen kappa or percentage agreement between independent coders

## Process

1. Read through all transcripts to gain familiarity before coding
2. Create initial deductive codes from the conceptual model and research questions
3. Code a subset of transcripts independently with two coders and calculate agreement
4. Refine the codebook based on disagreements and emergent inductive codes
5. Apply the finalized codebook to all transcripts and compile frequency and co-occurrence tables
