# Store Comparison Planner

Compare store prices for regular purchases and build a multi-store strategy if savings justify the trips.

## Inputs

- `regular_items`: Frequently purchased items
- `nearby_stores`: Available grocery stores
- `time_value`: How much extra time is acceptable for savings

## Outputs

- `price_comparison`: Item prices across stores
- `store_strategy`: Which items to buy where
- `trip_consolidation`: How to minimize extra trips

## Process

1. List 20-30 most-purchased items
2. Compare prices across 3-4 stores
3. Calculate savings vs extra trip time
4. Build optimal store routing
5. Identify loss leaders worth chasing
