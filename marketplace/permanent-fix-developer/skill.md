# Permanent Fix Developer

Develop, test, and implement the permanent fix.

## Inputs

- `root-cause`: The identified root cause
- `problem-record`: The problem record

## Outputs

- `fix-implementation`: The implemented permanent fix
- `test-evidence`: Evidence that the fix resolves the problem

## Process

1. Design the permanent fix that addresses the root cause.
2. Test the fix in a non-production environment.
3. Submit the fix through the change management process.
4. Implement and verify in production.
