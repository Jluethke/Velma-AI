# Crypto Review Report

Compile cryptographic review findings into a prioritized report with a migration roadmap.

## Inputs

- `standards-findings`: Standards compliance findings
- `implementation-flaws`: Implementation flaw findings
- `certificate-findings`: Certificate management findings
- `agility-assessment`: Crypto agility assessment

## Outputs

- `crypto-review-report`: Complete cryptographic implementation review report
- `migration-roadmap`: Prioritized roadmap for cryptographic upgrades

## Process

1. Classify findings by severity and exploitability
2. Build a phased migration plan (immediate fixes, short-term upgrades, long-term transitions)
3. Map findings to compliance requirements where applicable
4. Produce the final report with risk ratings and technical recommendations
