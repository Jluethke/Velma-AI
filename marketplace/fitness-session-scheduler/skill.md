# Fitness Session Scheduler

Schedule training sessions and classes across trainers and time slots.

## Inputs

- `training-program`: Client programs with recommended frequency
- `trainer-capacity`: Trainer availability and specialties

## Outputs

- `training-calendar`: Weekly training calendar with all sessions, clients, and trainers
- `class-schedule`: Group class schedule with capacity limits and waitlists

## Process

1. Match clients to trainer availability and specialty fit.
2. Set recurring session times for consistency.
3. Manage group class scheduling with capacity limits.
4. Handle cancellations and makeup sessions within policy.
