# Current Friction Count

Count how many steps each behavior currently takes to start, because the step count is what willpower has to overcome every time.

## Inputs

- `defined-increase-target`: The increase behavior
- `defined-decrease-target`: The decrease behavior

## Outputs

- `increase-friction-points`: Every step between the current moment and starting the increase behavior
- `decrease-friction-points`: Every cue and step that currently makes the decrease behavior easy to start

## Process

1. Walk through starting the increase behavior and count each step. If a home workout needs finding clothes, clearing space, and locating a video, that is three friction points standing in the way.
2. Walk through the decrease behavior and count how few steps it takes. A behavior you can start in one tap has almost no friction protecting you from it.
3. Note the cue for each behavior. Most behaviors begin with something you see, so write down what you see right before each one starts.
4. Record the time of day each behavior tends to happen. Willpower is lowest late in the day, so late behaviors need environmental help the most.
