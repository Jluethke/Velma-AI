# App Requirements Definer

Define the app's purpose, target users, and core user flows.

## Inputs

- `app-idea`: Description of what the app should do
- `target-users`: Who will use the app

## Outputs

- `app-requirements`: List of features and user stories
- `user-flows`: The main paths a user takes through the app

## Process

1. Clarify the app's core purpose in one sentence.
2. List the must-have features for the first version.
3. Map the primary user flows from entry to completion.
4. Identify any data the app needs to store or retrieve.
