# Portfolio Builder Beginner

Build a simple portfolio using index funds or target-date funds aligned to the risk profile.

## Inputs

- `risk_profile`: Risk tolerance level
- `asset_allocation_target`: Target stock/bond split
- `account_plan`: Account types being used

## Outputs

- `portfolio`: Specific funds with allocation percentages
- `fund_rationale`: Why each fund was chosen
- `rebalancing_rules`: When and how to rebalance

## Process

1. Select core index funds for each asset class
2. Set allocation percentages matching target
3. Choose between target-date simplicity vs DIY
4. Define rebalancing triggers
5. Document the portfolio in writing
