# Family Discussion Guide

Guide productive family discussions with structured formats for different topic types.

## Inputs

- `agenda`: Meeting agenda
- `family_dynamics`: Known sensitivities or conflict areas
- `ages_present`: Ages of participants for age-appropriate inclusion

## Outputs

- `discussion_formats`: Format for each topic type
- `inclusion_strategies`: How to include quieter members
- `conflict_protocols`: What to do if discussion gets heated

## Process

1. Match discussion format to topic type
2. Plan how to include younger members
3. Prepare prompts for quieter voices
4. Set up conflict pause protocol
5. Build in appreciation round
