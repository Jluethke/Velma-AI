# Item Pool Generator

Generate an initial pool of candidate items covering every dimension of the content domain map.

## Inputs

- `construct-definition`: formal definition with dimensions
- `content-domain-map`: target coverage per dimension

## Outputs

- `item-pool`: candidate items with dimension tags, response format, and scoring direction
- `expert-review-plan`: plan for content validity review by subject matter experts

## Process

1. Write 3-5x more items than the target instrument length to allow attrition
2. Tag each item to its content domain dimension
3. Vary item difficulty, wording direction (positive/negative), and response format
4. Plan and conduct expert review for content validity (relevance, clarity, representativeness)
