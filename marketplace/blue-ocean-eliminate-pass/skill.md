# Blue Ocean Eliminate Pass

Decide which factors the industry takes for granted can be eliminated entirely. Removing a factor nobody truly values frees cost and often reveals that a long-assumed requirement was never needed.

## Inputs

- `competition-factors`: The factors the industry competes on
- `current-factor-levels`: Where today's offering sits on each factor

## Outputs

- `eliminate-list`: Factors to remove entirely
- `eliminate-rationale`: Why each one can go and what it frees

## Process

1. For each factor, ask whether the customer truly values it or the industry provides it out of habit.
2. Mark for elimination any factor that exists mainly because competitors all have it.
3. For each elimination, note the cost or complexity it removes.
4. Be willing to remove a factor the industry considers essential if customers do not value it.
