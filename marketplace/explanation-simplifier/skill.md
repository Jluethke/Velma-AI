# Explanation Simplifier

Rewrite the explanation, folding in the new understanding and cutting remaining jargon.

## Inputs

- `gap-research-notes`: Plain-language answers to each gap question
- `resolved-questions`: The questions you can now answer cleanly

## Outputs

- `simplified-explanation`: A clearer explanation with the gaps filled
- `refined-analogies`: Analogies improved by the new understanding

## Process

1. Rewrite the explanation using the resolved answers.
2. Replace any remaining jargon with a simpler phrasing or analogy.
3. Shorten sentences so each carries one idea.
4. Check the explanation now flows without a jump.
