# Dpa Subprocessor Terms Drafter

Draft the sub-processor approval and flow-down requirements.

## Inputs

- `processing-instructions`: Processing instructions
- `security-requirements`: Security requirements

## Outputs

- `subprocessor-clause`: Sub-processor notification and approval terms
- `current-subprocessor-list`: Current sub-processor list requirement

## Process

1. Define the process for adding or changing sub-processors
2. Require prior notification with an objection window
3. Specify flow-down of equivalent data protection obligations
