# Methods Replication Writer

Write the methods section with enough detail for another researcher to replicate the study.

## Inputs

- `study-protocol`: The actual procedures, materials, and instruments used
- `analysis-scripts`: Statistical or computational analysis code

## Outputs

- `methods-draft`: Methods section organized by study design, materials, procedures, and analysis
- `replication-checklist`: Checklist of details needed for replication (reagent catalog numbers, software versions, parameters)

## Process

1. Organize methods into subsections: study design, participants/samples, materials, procedures, and analysis.
2. Include specific quantities, catalog numbers, software versions, and parameter settings.
3. Describe the statistical analysis plan including tests, corrections, and significance threshold.
4. Check against the replication checklist to ensure nothing is omitted.
