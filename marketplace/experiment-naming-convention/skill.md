# Experiment Naming Convention

Define naming conventions and metadata standards for experiments.

## Inputs

- `platform-selection`: Selected tracking platform
- `team-requirements`: Team workflows

## Outputs

- `naming-conventions`: Standards for experiment, run, and artifact names
- `metadata-schema`: Required tags and metadata for every run

## Process

1. Define the experiment naming hierarchy (project, experiment, run).
2. Set the required metadata tags for every run.
3. Define the artifact naming and versioning scheme.
4. Document the conventions for the team.
