# Session Cadence Setup

Set up the recurring session cadence for a client.

## Inputs

- `client-profile`: The client's name, contact info, service type, and goals
- `provider-availability`: The provider's available time slots for recurring sessions

## Outputs

- `session-cadence`: The agreed cadence (weekly, biweekly, monthly), day, time, and duration
- `session-package`: The session package or subscription details (number of sessions, expiration, price)

## Process

1. Discuss the client's preferred frequency (weekly, biweekly, monthly) and time preferences.
2. Match against the provider's available recurring slots.
3. Confirm the cadence: day, time, duration, and modality (in-person, video, phone).
4. Set up the package or subscription: number of prepaid sessions, expiration date, cancellation terms.
