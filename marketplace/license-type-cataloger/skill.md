# License Type Cataloger

Catalog the license type and terms for each software product.

## Inputs

- `software-inventory`: Software inventory
- `scan-scope`: Audit scope

## Outputs

- `license-catalog`: License type and key terms for each product
- `open-source-list`: Open source components and their licenses

## Process

1. Classify each product as commercial, open source, or SaaS
2. Record license metrics (per-seat, per-core, enterprise, concurrent)
3. Catalog open source licenses and their obligations (GPL, MIT, Apache)
