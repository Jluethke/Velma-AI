# Internal Template Builder

Create the email templates for internal communications.

## Inputs

- `communication-calendar`: The planned calendar
- `cadence-rules`: Frequency rules

## Outputs

- `internal-templates`: Email templates for each communication type
- `approval-workflow`: Approval process for each communication type (who drafts, who reviews, who approves)

## Process

1. Design the templates for each communication type (all-hands, department, leadership, policy, event).
2. Define the approval workflow for each (author, reviewer, approver, send authority).
3. Set up the drafting and review timeline per template.
4. Document the template usage guidelines.
