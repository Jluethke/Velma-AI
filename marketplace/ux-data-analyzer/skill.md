# Ux Data Analyzer

Analyze the research data using affinity mapping and metrics.

## Inputs

- `session-recordings`: Session recordings to review
- `observer-notes`: Notes from each session

## Outputs

- `affinity-map`: Grouped observations and patterns
- `task-metrics`: Success rates, error rates, and time on task

## Process

1. Transcribe key observations onto individual notes
2. Group related observations into themes (affinity mapping)
3. Calculate task success rates and time on task metrics
4. Identify the most frequent pain points and workarounds
