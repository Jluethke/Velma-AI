# Progressive Distillation Layer

Apply progressive summarization to items inside project folders. Layer 1: bold the key passages. Layer 2: highlight the boldest. Layer 3: write a one-sentence summary. Each pass is done only when you revisit the item, not on a schedule.

## Inputs

- `project-folder-structure`: Organized project folders with captured items
- `inbox-processing-routine`: The routine for moving items from inbox to projects

## Outputs

- `distillation-protocol`: The layered distillation method with rules for when to apply each layer
- `retrieval-depth-guide`: Guide for accessing knowledge at different depths: summary, highlights, key passages, full original

## Process

1. Layer 1 (on first revisit): bold the passages that stand out. Do not summarize. The bolding itself is the work. Takes 2 to 5 minutes per item.
2. Layer 2 (on second revisit): highlight the most important bolded passages. You are compressing the already-compressed version. Takes 1 to 2 minutes.
3. Layer 3 (on third revisit): write one sentence that captures the core idea. This is the executive summary. Takes 30 seconds.
4. The key discipline: each layer is applied only when you naturally revisit the item for a project. Items you never revisit never get distilled, and that is correct. The system surfaces what is useful by your own usage patterns.
