# Credentialing Document Collection

Collect and verify the provider's credentialing documents.

## Inputs

- `provider-info`: Provider name, NPI, specialty, and practice affiliation
- `credentialing-checklist`: List of required documents by payer

## Outputs

- `provider-file`: Complete credentialing file with all required documents verified
- `document-gaps`: Any missing or expired documents that need to be obtained

## Process

1. Collect the provider's licenses, DEA certificate, board certifications, and malpractice insurance.
2. Verify education, training, and work history.
3. Obtain the malpractice claims history and any disciplinary actions.
4. Check the NPDB, OIG exclusion list, and state sanctions.
