# Pivot Pattern Analyzer

Identify patterns, trends, and outliers in the pivot results.

## Inputs

- `pivot-table`: The computed pivot table
- `derived-metrics`: Calculated metrics (percentages, ranks, cumulative)

## Outputs

- `pattern-findings`: Notable patterns, trends, and outliers with their significance
- `pivot-analysis-report`: Complete analysis report: question, methodology, pivot table, findings, and recommendations

## Process

1. Scan for the highest and lowest values in each dimension.
2. Look for trends across the column dimension (growth, decline, seasonality).
3. Identify outliers that deviate from the group pattern.
4. Write the findings as clear statements with supporting numbers.
5. Compile the analysis report with the question, method, table, and findings.
