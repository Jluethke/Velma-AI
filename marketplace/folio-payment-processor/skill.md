# Folio Payment Processor

Process payments and manage guest folios.

## Inputs

- `check-out-procedure`: Check-out procedure
- `request-handling-guide`: Standard request handling

## Outputs

- `payment-procedures`: Payment processing procedures by method
- `front-desk-operations-manual`: Complete front desk operations manual

## Process

1. Document the payment methods accepted and their processing steps.
2. Define the folio management rules (posting, adjustments, splits).
3. Set the end-of-shift balancing procedure.
4. Compile all procedures into the front desk operations manual.
