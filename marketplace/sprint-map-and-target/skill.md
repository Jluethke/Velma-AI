# Sprint Map And Target

Map the problem space and pick the target area for the sprint (day 1).

## Inputs

- `sprint-challenge`: The challenge statement
- `sprint-team`: The team members and their expertise

## Outputs

- `problem-map`: Visual map of the problem (user journey, actors, pain points)
- `sprint-target`: The specific part of the map the team will focus on

## Process

1. Have experts present what they know about the problem (customer data, business context, technical constraints).
2. Map the user journey from start to finish, noting pain points and opportunities.
3. Vote on which part of the map to target for the sprint.
4. Produce the problem map and selected target.
