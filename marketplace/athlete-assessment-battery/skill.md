# Athlete Assessment Battery

Assess athletes through fitness testing, injury history review, and goal setting.

## Inputs

- `athlete-roster`: Athletes to be assessed
- `sport-demands`: Physical demands and performance benchmarks for the sport

## Outputs

- `assessment-results`: Fitness test scores, injury history, and baseline measurements for each athlete
- `athlete-goals`: Individual goals for each athlete based on assessment and sport demands

## Process

1. Administer fitness tests (strength, speed, agility, endurance, flexibility).
2. Review each athlete's injury history and current limitations.
3. Set individual goals based on test results and sport-specific demands.
4. Produce the assessment report.
