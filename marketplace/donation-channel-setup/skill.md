# Donation Channel Setup

Set up the channels through which the organization receives donations: online, in-person, mail, and recurring.

## Inputs

- `organization-profile`: Name, tax status, and banking information
- `fund-list`: The designated funds that donors can give to (general, building, missions, benevolence)

## Outputs

- `channel-configuration`: Each donation channel with its setup details and processing method
- `fund-structure`: The funds, their purposes, and accounting codes

## Process

1. Set up online giving: payment processor, donation page, recurring gift option, fund selection.
2. Set up in-person giving: offering envelopes, kiosk or card reader, counting team procedures.
3. Set up mail giving: PO box or address, processing workflow, deposit procedure.
4. Define each fund with its purpose, restrictions, and accounting code.
