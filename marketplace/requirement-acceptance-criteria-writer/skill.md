# Requirement Acceptance Criteria Writer

Write acceptance criteria and verification methods that make each requirement objectively checkable.

## Inputs

- `security-requirements`: Testable requirements that counter the abuse cases
- `misuse-scenarios`: Step-by-step scenarios of abuse across boundaries

## Outputs

- `acceptance-criteria`: Pass or fail conditions for each requirement
- `verification-methods`: How each requirement will be tested or reviewed

## Process

1. Turn each requirement into observable pass or fail conditions
2. Choose a verification method of test, review, analysis, or demonstration
3. Reuse misuse scenarios as negative test conditions
4. Confirm each criterion is measurable without interpreting intent
