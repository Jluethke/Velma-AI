# User Rights Documenter

Document user rights and how to exercise them.

## Inputs

- `data-inventory`: Data inventory
- `consent-requirements`: Consent requirements

## Outputs

- `rights-section`: User rights description for the privacy policy
- `rights-process`: Internal process for handling rights requests

## Process

1. List applicable rights (access, rectification, deletion, portability, objection)
2. Describe how users can submit requests
3. Set the response timeline and verification process
