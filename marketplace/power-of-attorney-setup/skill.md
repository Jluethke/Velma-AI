# Power Of Attorney Setup

Establish financial and healthcare powers of attorney with agent selection and scope definition.

## Inputs

- `trusted_contacts`: People trusted to act on your behalf
- `state_of_residence`: State for legal requirements

## Outputs

- `financial_poa`: Financial POA agent and scope
- `healthcare_poa`: Healthcare POA agent and scope
- `poa_limitations`: Any specific limitations or instructions

## Process

1. Select financial POA agent and backup
2. Define scope of financial authority
3. Select healthcare POA agent and backup
4. Document specific healthcare wishes
5. Note state filing requirements
