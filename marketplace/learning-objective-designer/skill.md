# Learning Objective Designer

Define learning objectives for each role and topic.

## Inputs

- `training-needs`: Needs by role
- `priority-topics`: Prioritized topic list

## Outputs

- `learning-objectives`: Measurable objectives per role and topic
- `role-curriculum-map`: Map of roles to required training modules

## Process

1. Write measurable learning objectives for each topic
2. Assign objectives to roles based on exposure and access
3. Define specialist tracks (developers, admins, executives)
4. Map the curriculum structure
