# Mobile Forensics Report Writer

Produce the mobile forensics report with all findings and evidence references.

## Inputs

- `communication-analysis`: Call and message analysis findings
- `app-analysis`: Application data analysis findings
- `location-history`: Location history and movement analysis

## Outputs

- `mobile-forensics-report`: The complete mobile device forensics report
- `evidence-catalog`: Catalog of all evidence items with hash values

## Process

1. Organize findings by evidence type and chronological order
2. Write the analysis narrative answering the investigation questions
3. Reference specific evidence items for each conclusion
4. Compile the evidence catalog with integrity hashes
