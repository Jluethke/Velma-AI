# Ideal Customer Profile Builder

Define the ideal customer profile with demographic and firmographic attributes.

## Inputs

- `customer-data`: Historical customer data and attributes
- `product-description`: What the product does and who benefits

## Outputs

- `icp-attributes`: Ranked list of ICP attributes and values
- `icp-summary`: Narrative description of the ideal customer

## Process

1. Analyze closed-won deals for common attributes.
2. Rank attributes by correlation with conversion.
3. Define the must-have vs nice-to-have attributes.
4. Write the ICP summary.
