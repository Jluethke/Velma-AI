# Catering Post Event Review

Handle post-event cleanup, invoicing, feedback collection, and lessons learned.

## Inputs

- `event-log`: Event execution record
- `issue-register`: Issues and resolutions from the event

## Outputs

- `final-invoice`: Final invoice with adjustments for actual guest count and add-ons
- `catering-operations-record`: Complete event record with P&L, feedback, and improvement notes

## Process

1. Complete the venue breakdown and return rented equipment.
2. Reconcile the actual costs against the proposal (food waste, extra hours, rental overages).
3. Send the final invoice with any adjustments.
4. Collect client feedback and document lessons learned for future events.
