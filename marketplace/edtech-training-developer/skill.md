# Edtech Training Developer

Develop training materials and support resources for faculty adoption.

## Inputs

- `selected-tool`: The tool selected from the pilot
- `pilot-results`: Lessons learned from the pilot

## Outputs

- `training-materials`: Guides, videos, and reference materials for faculty
- `support-plan`: Ongoing support plan (help desk, office hours, peer support)

## Process

1. Create getting-started guides and video tutorials
2. Document common use cases and best practices from the pilot
3. Set up the help desk workflow and FAQ
4. Identify faculty champions for peer support
