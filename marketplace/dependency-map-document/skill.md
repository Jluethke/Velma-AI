# Dependency Map Document

Compile the complete dependency map and store it where it can be accessed during a crisis.

## Inputs

- `dependency-tree`: The complete dependency tree
- `revised-workaround-plans`: The tested workaround plans

## Outputs

- `dependency-map-document`: The complete dependency map: functions, dependencies, failure impacts, workarounds, test results, and review schedule
- `crisis-quick-reference`: A one-page summary: the top 5 fragile dependencies, the workaround for each, and who to contact

## Process

1. Compile the full document: critical functions, dependency trees, failure impact table, workaround plans, and test results.
2. Create the one-page quick reference for use during an actual crisis. It should be readable in under 2 minutes.
3. Store both documents in at least two locations: one digital (cloud storage with shared access), one physical (printed, in a known location).
4. Set the review cadence: re-map dependencies whenever a critical function changes, a key person leaves, or a vendor is added or removed.
