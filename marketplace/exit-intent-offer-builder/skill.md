# Exit Intent Offer Builder

Implement exit-intent offers to capture visitors before they leave.

## Inputs

- `trigger-analysis`: Abandonment triggers
- `incentive-rules`: Discount and incentive rules

## Outputs

- `exit-intent-config`: Exit-intent popup configuration
- `offer-variants`: Offer variants for testing

## Process

1. Design the exit-intent popup (timing, trigger, copy, offer).
2. Create variants for A/B testing (discount vs free shipping vs urgency).
3. Set display rules (once per session, exclude returning customers, exclude mobile).
4. Configure the email capture for anonymous visitors.
