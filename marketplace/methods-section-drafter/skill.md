# Methods Section Drafter

Draft the methods section: enough detail for replication, organized by procedure not by chronology, with all parameters specified.

## Inputs

- `experimental-results`: Raw data and analysis outputs for cross-reference
- `protocol-notes`: Lab notebook entries, SOPs, and analysis scripts used

## Outputs

- `methods-draft`: Complete methods section text
- `replication-checklist`: Every parameter, reagent, and setting needed to replicate

## Process

1. Organize by procedure type: participants/samples, materials, protocol, analysis.
2. For each procedure, specify every parameter (concentrations, temperatures, durations, software versions).
3. Reference established protocols by citation rather than re-describing them in full.
4. Check that every analysis mentioned in the results has its method described here.
