# Scope Constrainer

Constrain the project scope and timeline so it is finishable, not sprawling.

## Inputs

- `project-brief`: A short brief for the chosen project
- `required-skills-map`: Which parts of the project exercise which sub-skills

## Outputs

- `scoped-project`: The smallest version that still proves the skill
- `deadline-plan`: A deadline short enough to force progress

## Process

1. Cut the project to the smallest version that still proves the skill.
2. Set a deadline short enough to force progress.
3. Define what is explicitly out of scope for this version.
4. Confirm the scoped version still exercises the core sub-skills.
