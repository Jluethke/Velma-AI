# Annual Insurance Review

Set up an annual insurance review process to catch life changes, rate increases, and better options.

## Inputs

- `all_policies`: Complete policy inventory
- `renewal_dates`: When each policy renews

## Outputs

- `review_calendar`: Annual review schedule per policy
- `life_change_triggers`: Events that should trigger a review
- `review_checklist`: What to check at each review

## Process

1. Map all renewal dates to calendar
2. Set review reminders 60 days before renewal
3. List life events that trigger coverage changes
4. Create annual review checklist
5. Compare rates at each renewal
