# Problem Record Opener

Open a formal problem record and assign ownership.

## Inputs

- `problem-candidates`: Candidate problems to investigate
- `pattern-analysis`: Pattern data for each candidate

## Outputs

- `problem-record`: Formal problem record with assigned owner
- `investigation-scope`: Scope and timeline for the investigation

## Process

1. Select the highest-priority candidate.
2. Create the problem record with all linked incidents.
3. Assign the problem owner and investigation team.
4. Define the investigation scope and deadline.
