# Synthetic Journey Configurator

Set up synthetic user journey checks that simulate key user flows.

## Inputs

- `error-tracking-config`: Error monitoring in place
- `site-endpoints`: Key user flows to simulate

## Outputs

- `synthetic-checks`: Automated user journey checks configured
- `monitoring-setup-document`: Complete monitoring setup with all checks documented

## Process

1. Identify the critical user journeys (signup, login, checkout, search).
2. Build synthetic checks that simulate each journey end to end.
3. Set the run schedule and failure thresholds.
4. Document the full monitoring setup with escalation procedures.
