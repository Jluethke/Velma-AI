# Skill Path Adequacy Checker

For a skill problem, check whether the person was actually given a fair path: clear expectations, real training, and enough time to reach competence. If any of these was missing, the problem may be yours to fix before it is theirs to answer for.

## Inputs

- `problem-diagnosis`: The skill, will, or mixed diagnosis
- `supporting-evidence`: The evidence behind it

## Outputs

- `skill-path-finding`: Whether clear expectations, real training, and enough time were provided
- `skill-remedy-gaps`: Any missing element of the skill path that must be provided before the gap is treated as unfixable

## Process

1. Confirm expectations were stated clearly and specifically, not assumed.
2. Confirm real training or support was provided, not just a one-time explanation.
3. Confirm enough time was given to reach competence at this skill, by a realistic standard for its difficulty.
4. Where any element was missing, provide it and reset the clock before treating the gap as unfixable.
