# Workout Programming

Design and periodize workout programs based on client goals and assessment results.

## Inputs

- `client-fitness-profile`: Assessment results and goals
- `studio-format`: Training format (one-on-one, group) for program design

## Outputs

- `training-program`: Periodized program with exercises, sets, reps, rest, and progression plan
- `progress-checkpoints`: Scheduled reassessment dates and milestone targets

## Process

1. Select the training methodology based on the client's goals and experience level.
2. Design the program structure (days per week, split, progression scheme).
3. Write the workouts with exercise selection, volume, and intensity targets.
4. Schedule progress checkpoints for reassessment and program updates.
