# Coral Health Assessor

Assess coral colony health using bleaching indices, disease prevalence, tissue condition, and recruitment counts.

## Inputs

- `transect-map`: Survey transect layout covering reef areas
- `species-list`: Coral species identified along each transect
- `baseline-data`: Historical coral cover and health data for the site, if available

## Outputs

- `bleaching-assessment`: Bleaching severity and extent per colony using a standardized color reference card
- `disease-prevalence`: Proportion of colonies affected by each disease type per transect
- `recruitment-counts`: Juvenile coral counts per quadrat indicating reef recovery potential

## Process

1. Score each coral colony for bleaching severity using the Coral Watch color chart
2. Record disease signs (white band, black band, white plague, tissue loss) by colony
3. Count juvenile coral recruits in fixed quadrats along each transect
4. Photograph representative healthy, bleached, and diseased colonies with scale bars
5. Compare current health metrics to baseline data to detect trends
