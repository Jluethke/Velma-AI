# Nda Term Setter

Set the NDA term, survival period, and return/destruction obligations.

## Inputs

- `nda-type`: Type of NDA
- `ci-definition`: Confidential information definition

## Outputs

- `term-provisions`: Term length, survival period, and expiration terms
- `return-obligations`: Return or destruction requirements at termination

## Process

1. Set the initial term of the agreement
2. Define the survival period for confidentiality obligations after expiration
3. Specify return or destruction obligations for confidential materials
