# Trademark Class Selector

Select the appropriate international classes and draft the goods/services description.

## Inputs

- `goods-services`: Goods and services description
- `search-results`: Clearance search results

## Outputs

- `selected-classes`: International classes selected for the application
- `gs-description`: Goods and services description in USPTO format

## Process

1. Identify the correct international classes for the goods and services
2. Draft the goods and services description using acceptable identifications
3. Consider filing in additional classes for broader protection
