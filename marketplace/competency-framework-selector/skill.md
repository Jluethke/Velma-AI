# Competency Framework Selector

Define the competency framework and rating scale for the 360 review.

## Inputs

- `role-levels`: The roles and levels being reviewed (individual contributor, manager, director)
- `org-values`: The organization's core values and leadership expectations

## Outputs

- `competency-framework`: The competencies and behaviors to evaluate, organized by role level
- `rating-scale`: The rating scale with definitions for each level (1-5 or frequency-based)

## Process

1. Select or adapt a competency framework aligned with the organization's values and role expectations.
2. Define 5 to 8 competencies per role level with 3 to 5 observable behaviors each.
3. Choose the rating scale (1-5 proficiency, frequency-based, or comparison to expectations).
4. Write clear definitions for each scale level to reduce rater interpretation differences.
