# Construct Definition Builder

Define the theoretical construct the instrument intends to measure, its dimensions, and its boundaries with adjacent constructs.

## Inputs

- `target-construct`: name and informal description of what the instrument should measure
- `literature-review-notes`: existing definitions, instruments, and theoretical frameworks

## Outputs

- `construct-definition`: formal definition with dimensions and boundaries
- `content-domain-map`: map of sub-domains the items must cover

## Process

1. Review existing definitions and instruments measuring the same or related constructs
2. Identify the core dimensions and sub-dimensions of the construct
3. Specify the boundaries: what the construct includes and explicitly excludes
4. Produce a content domain map showing the proportional coverage each dimension needs
