# Icd Opportunity Cost Calculator

Price the opportunity cost of tied-up capital.

## Inputs

- `option-set`: The options under comparison
- `running-cost-with-time`: The running total to add opportunity cost onto

## Outputs

- `running-cost-with-opportunity`: The running total including opportunity cost
- `opportunity-cost-detail`: The capital tied and the return it would earn elsewhere

## Process

1. Identify the capital each option locks up.
2. Apply the return that capital would earn elsewhere.
3. Add the opportunity cost to the running total.
