# Schedule Update Report Generator

Produce the schedule update report for the project team.

## Inputs

- `impact-assessment`: Delay impact assessment
- `recovery-options`: Options to recover lost time

## Outputs

- `schedule-update-report`: Complete schedule update report with narrative and metrics
- `schedule-metrics`: Metrics on schedule performance (SPI, days ahead or behind)

## Process

1. Write the schedule narrative covering progress, delays, and recovery plan.
2. Calculate the schedule performance index (SPI).
3. Include a bar chart or Gantt view of the current schedule.
4. Distribute the report to the owner, architect, and project team.
