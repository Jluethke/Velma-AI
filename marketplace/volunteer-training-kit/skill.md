# Volunteer Training Kit

Create training materials and orientation plan for volunteers by role.

## Inputs

- `role_descriptions`: Volunteer roles
- `skill_requirements`: Skills needed per role
- `policies`: Organization policies volunteers must know

## Outputs

- `training_materials`: Role-specific training guides
- `orientation_agenda`: Orientation session plan
- `reference_cards`: Quick reference cards for day-of

## Process

1. Write role-specific instructions
2. Create orientation presentation
3. Build quick-reference cards for each role
4. Include emergency procedures
5. Set up communication channel for questions
