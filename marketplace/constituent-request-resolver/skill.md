# Constituent Request Resolver

Route and resolve the constituent's request.

## Inputs

- `categorized-request`: The categorized request
- `department-routing`: Responsible department assignment

## Outputs

- `resolution-record`: Record of what was done to resolve the request
- `constituent-response`: Response sent to the constituent with the outcome

## Process

1. Assign the request to the responsible staff member.
2. Track the resolution progress against the service level target.
3. Document the resolution actions taken.
4. Send the constituent the outcome and close the request.
