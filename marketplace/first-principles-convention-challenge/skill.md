# First Principles Convention Challenge

Challenge and discard the conventions. For each one, ask what the world would actually allow if the convention did not exist, and keep only the hard constraints that remain.

## Inputs

- `convention-list`: The assumptions that are only convention
- `classified-assumptions`: Each assumption tagged fundamental truth or convention

## Outputs

- `hard-constraints`: The real limits that survive scrutiny
- `discarded-conventions`: The conventions dropped, with what each one was costing

## Process

1. Take each convention and ask, if nobody did it this way, what would actually stop us.
2. If the honest answer is nothing but habit or industry norm, discard the convention.
3. Record what each discarded convention was costing in time, money, or options.
4. Combine the surviving fundamental truths into a clean list of hard constraints.
