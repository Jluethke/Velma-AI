# Management Strategy Selector

Select the management strategy: cultural, biological, or chemical.

## Inputs

- `identification-result`: Identified organism
- `severity-rating`: Severity and economic threshold data

## Outputs

- `management-plan`: Selected control methods with timing and application details
- `product-list`: Specific products, rates, and pre-harvest intervals

## Process

1. Evaluate cultural controls (crop rotation, resistant varieties, sanitation).
2. Assess biological options (beneficial insects, microbial agents).
3. Select chemical controls if threshold is exceeded, choosing lowest-impact options.
4. Set application timing, rates, and re-entry intervals.
