# Unlearning Target Identifier

Identify precisely the outdated skill or belief to unlearn.

## Inputs

- `outdated-pattern`: The skill or belief you suspect is outdated
- `trigger-context`: What prompted you to question it

## Outputs

- `unlearning-target`: The specific pattern to unlearn, stated narrowly
- `evidence-of-staleness`: The evidence that it is outdated

## Process

1. Name the specific skill or belief that no longer serves you.
2. Gather the evidence that it is outdated rather than merely uncomfortable.
3. State the target narrowly so it can be acted on.
4. Separate the pattern from any part still worth keeping.
