# Layer Two Highlight Pass

Layer 2: highlight the most important bolded passages. You are compressing the already-compressed version. Only the passages that capture the core ideas survive this pass.

## Inputs

- `layer-one-result`: Source with bolded passages
- `bold-passage-count`: Count and percentage of bolded text

## Outputs

- `layer-two-result`: Source text with highlighted passages within the bolded passages (the best of the best)
- `highlight-passage-count`: Number of highlighted passages, typically 3 to 10 percent of the original

## Process

1. Re-read only the bolded passages. From those, highlight the ones that capture the core ideas. If you had to explain this material in 60 seconds, which bolded passages would you reference?
2. Target: 3 to 10 percent of the original text should be highlighted. The highlighted passages should make sense on their own when read in sequence.
3. This pass is done only when you revisit the material for a specific project or purpose. It is not done on a schedule.
4. The gap between Layer 1 and Layer 2 reveals what seemed important on first read versus what matters when you actually need the material.
