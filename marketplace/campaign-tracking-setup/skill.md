# Campaign Tracking Setup

Set up tracking and reporting for campaign progress.

## Inputs

- `success-metrics`: KPIs for the campaign
- `campaign-calendar`: Schedule of activities

## Outputs

- `tracking-dashboard`: Dashboard configuration for real-time monitoring
- `campaign-plan`: Complete campaign plan document

## Process

1. Configure the CRM to track gifts by campaign code
2. Set up the reporting dashboard with KPIs
3. Define the reporting cadence (daily during active pushes, weekly otherwise)
4. Compile everything into the campaign plan document
