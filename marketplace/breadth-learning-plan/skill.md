# Breadth Learning Plan

Plan efficient breadth learning across the adjacent areas to reach literacy.

## Inputs

- `literacy-targets`: What functional literacy means for each area
- `time-allocation`: How learning time is split across depth and breadth

## Outputs

- `breadth-plan`: A plan for reaching literacy in each adjacent area
- `breadth-checkpoints`: Checkpoints confirming each area reached literacy

## Process

1. Choose fast routes to literacy for each adjacent area.
2. Schedule light, regular exposure rather than deep dives.
3. Set checkpoints to confirm each area reached functional literacy.
4. Stop each area once it hits its literacy target.
