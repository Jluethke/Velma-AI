# Competitor Messaging Mapper

Map each competitor's messaging, positioning, and value propositions.

## Inputs

- `competitor-list`: Competitors to analyze
- `competitor-profiles`: Basic profiles

## Outputs

- `messaging-map`: Messaging themes, taglines, and claims per competitor
- `positioning-matrix`: Competitors plotted on key dimensions

## Process

1. Review each competitor's website, ads, and marketing materials
2. Extract their key messages and value propositions
3. Plot competitors on a positioning matrix
