# Lms Configurator

Configure the selected LMS: branding, categories, roles, enrollment rules, and integrations.

## Inputs

- `platform-selection`: Selected LMS platform
- `lms-requirements`: Prioritized list of requirements

## Outputs

- `configured-lms`: LMS configured and ready for content
- `configuration-log`: Record of all configuration settings

## Process

1. Apply branding (logo, colors, terminology)
2. Set up user roles and permissions
3. Configure enrollment rules and course categories
4. Connect integrations (SSO, SIS, content libraries)
