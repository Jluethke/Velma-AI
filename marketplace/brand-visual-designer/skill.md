# Brand Visual Designer

Design the visual identity including logo, color palette, and typography.

## Inputs

- `brand-strategy`: Brand positioning and personality
- `market-analysis`: Competitive visual landscape

## Outputs

- `visual-identity`: Logo, color palette, typography, and iconography
- `design-rationale`: Explanation of design decisions and their connection to strategy

## Process

1. Explore logo concepts that express the brand personality
2. Define the primary and secondary color palette with hex values
3. Select typefaces for headings, body text, and accent use
4. Design supporting visual elements (patterns, icons, photography style)
