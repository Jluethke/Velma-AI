# Api Security Report

Produce the API security assessment report with findings, risk ratings, and remediation guidance.

## Inputs

- `authorization-findings`: Authorization bypass findings
- `input-validation-findings`: Input validation findings
- `disclosure-findings`: Information disclosure findings

## Outputs

- `api-security-report`: Complete API security assessment report
- `remediation-checklist`: Prioritized list of fixes with implementation guidance

## Process

1. Consolidate findings from all testing phases with severity ratings.
2. Map findings to OWASP API Security Top 10 categories.
3. Write remediation guidance specific to the API framework and architecture.
4. Produce an executive summary and a detailed technical appendix.
