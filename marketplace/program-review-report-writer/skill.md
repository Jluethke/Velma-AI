# Program Review Report Writer

Write the program review report synthesizing all findings into strengths, weaknesses, and recommendations.

## Inputs

- `program-metrics`: Quantitative metrics
- `relevance-assessment`: Curriculum relevance assessment
- `common-themes`: Recurring stakeholder themes

## Outputs

- `program-review-report`: Complete program review report
- `action-plan`: Prioritized action plan with owners and timelines

## Process

1. Synthesize quantitative and qualitative findings
2. Identify program strengths and areas for improvement
3. Develop specific, actionable recommendations
4. Create the action plan with responsible parties and deadlines
