# Creative Brief Drafting

Draft the creative brief from the intake summary.

## Inputs

- `intake-summary`: The structured intake information
- `brand-guidelines`: Brand voice, visual identity, and messaging guidelines

## Outputs

- `draft-brief`: The draft creative brief ready for stakeholder review
- `brief-assumptions`: Assumptions made during drafting that need validation

## Process

1. Write the brief sections: background, objective, target audience, key message, deliverables, timeline, and success metrics.
2. Reference the brand guidelines to set tone and visual direction.
3. Note any assumptions that need stakeholder validation.
4. Produce the draft brief and assumptions list.
