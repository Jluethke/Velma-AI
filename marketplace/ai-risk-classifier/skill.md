# Ai Risk Classifier

Classify each AI system by risk level.

## Inputs

- `ai-inventory`: Catalog of AI systems
- `risk-framework`: Risk classification criteria

## Outputs

- `risk-classification`: Each system assigned a risk tier
- `risk-rationale`: Justification for each classification

## Process

1. Define risk tiers (minimal, limited, high, unacceptable).
2. Assess each system against the criteria (impact, autonomy, data sensitivity).
3. Assign a risk tier to each system.
4. Document the rationale for each classification.
