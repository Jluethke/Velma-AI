# Knowledge Retention Assessor

Measure knowledge retention through assessments, code review metrics, and vulnerability recurrence tracking.

## Inputs

- `training-schedule`: Calendar of training sessions with topics and attendees
- `skill-assessment-results`: Baseline per-developer skill scores

## Outputs

- `retention-metrics`: Post-training scores compared to baseline, plus code quality delta
- `training-program-plan`: Final training program document with schedule, materials, labs, and measurement plan

## Process

1. Administer post-training assessments using the same instrument as the baseline.
2. Track code review findings for trained vulnerability classes over the following quarter.
3. Compile the full training program plan including schedule, materials, labs, and measurement methodology.
