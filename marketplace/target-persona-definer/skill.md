# Target Persona Definer

Define target personas and the questions they ask at each buying stage.

## Inputs

- `content-audit-results`: What content currently performs
- `analytics-access`: Audience data

## Outputs

- `persona-profiles`: Named personas with goals, pain points, and information needs
- `question-bank`: Questions each persona asks at each funnel stage

## Process

1. Analyze audience data to identify distinct segments
2. Build a profile for each persona
3. List the questions each persona asks at awareness, consideration, and decision stages
