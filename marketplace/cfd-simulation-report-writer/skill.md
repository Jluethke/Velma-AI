# Cfd Simulation Report Writer

Compile the CFD study into a report documenting the setup, results, validation, and conclusions.

## Inputs

- `validation-metrics`: Quantitative comparison against experiments
- `flow-visualizations`: Key figures from the simulation
- `convergence-history`: Solver convergence documentation

## Outputs

- `simulation-report`: Complete CFD study report
- `lessons-learned`: Notes on what worked, what to change, and recommended next steps

## Process

1. Structure the report: problem definition, mesh, model, boundary conditions, convergence, results, validation
2. Embed the key figures and validation plots
3. State the confidence in the results given the validation metrics
4. Document lessons learned and recommendations for follow-on studies
