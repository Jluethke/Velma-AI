# Weekly Priority Setter

Set the top priorities for the upcoming week.

## Inputs

- `week-review`: Review of the prior week
- `carryover-items`: Tasks carried forward

## Outputs

- `weekly-priorities`: Top 3-5 priorities for the week
- `task-list`: Full task list for the week

## Process

1. Review the calendar for fixed commitments.
2. Identify the 3-5 most important outcomes for the week.
3. Break each priority into specific tasks.
4. Flag any tasks that require preparation or coordination.
