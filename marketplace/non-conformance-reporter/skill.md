# Non Conformance Reporter

Issue non-conformance reports for failed inspections.

## Inputs

- `inspection-results`: Inspection results
- `finding-photos`: Photos of findings

## Outputs

- `non-conformance-reports`: NCRs issued for each failure
- `remediation-requirements`: Required corrective work for each NCR

## Process

1. Issue a non-conformance report for each failed inspection.
2. Describe the deficiency and reference the specification requirement.
3. Specify the required remediation work.
4. Set the deadline for correction and re-inspection.
