# Design Mood Board Builder

Research visual references and create mood boards.

## Inputs

- `clarified-brief`: Detailed project brief
- `brand-guidelines`: Brand visual rules

## Outputs

- `mood-boards`: Visual reference boards showing style directions
- `style-notes`: Notes on visual approach and rationale

## Process

1. Collect visual references matching the brief's tone
2. Organize references into 2 to 3 distinct style directions
3. Annotate each direction with its strengths and trade-offs
4. Present mood boards for direction approval
