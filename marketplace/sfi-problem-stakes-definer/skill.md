# Sfi Problem Stakes Definer

Define the problem the protagonist faces and the stakes if it goes unsolved. The problem is the engine of the story, and the stakes are why anyone keeps listening. A problem with no real stakes produces a story with no tension, which the audience forgets as fast as a plain fact.

## Inputs

- `protagonist`: The central figure who faces the problem
- `core-message`: The idea the problem must set up

## Outputs

- `problem-statement`: The concrete problem the protagonist faces, framed to set up the core message
- `stakes`: What the protagonist stands to lose if the problem is not solved

## Process

1. State the problem concretely, as the protagonist would feel it, not as an abstract issue.
2. Name the stakes: what breaks, what is lost, what changes for the worse if the problem wins.
3. Tie the problem to the core message. The way the protagonist escapes this problem is what proves your point.
4. Keep the stakes real and proportionate. Overstated stakes read as manipulation and cost you the audience's trust.
