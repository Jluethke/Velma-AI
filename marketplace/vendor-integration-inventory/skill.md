# Vendor Integration Inventory

Inventory all third-party vendor connections and data sharing agreements.

## Inputs

- `vendor-list`: List of third-party vendors and service providers
- `contract-repository`: Vendor contracts and data processing agreements
- `assessment-scope`: Which vendors and integrations to assess

## Outputs

- `integration-inventory`: All vendor connections with data types shared, protocols, and access methods
- `data-sharing-matrix`: Matrix of which data goes to which vendor and why

## Process

1. Catalog every vendor integration including APIs, file transfers, and shared databases
2. Document the data types shared with each vendor and the legal basis
3. Identify which vendors have access to production environments
4. Map the authentication and authorization methods for each integration
