# Baseline Metrics Record

Record your baseline health numbers now, so future changes can be measured against a known starting point.

## Inputs

- `risk-profile`: The combined risk profile
- `screening-schedule`: The screening and checkup schedule

## Outputs

- `baseline-numbers`: The current values of your key health measures
- `metric-tracking-sheet`: A sheet that holds each measure with room for yearly values

## Process

1. Record the measures that matter for your profile, such as blood pressure, resting heart rate, key blood values, weight, and anything tied to a risk flag.
2. Capture the current value and the date for each. A number without a date cannot be compared cleanly against next year.
3. Build a tracking sheet with one row per measure and a column per year, so the record grows into a trend rather than a scatter of readings.
4. Note the healthy range for each measure beside its value, so a reading can be read in context rather than in isolation.
