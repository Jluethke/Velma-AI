# Website Functional Tester

Test all forms, interactive elements, and user flows.

## Inputs

- `content-signoff`: Content is verified and ready
- `site-url`: The site URL

## Outputs

- `functional-issues`: Any broken forms, buttons, or interactive elements
- `functional-signoff`: Confirmation that all interactive elements work

## Process

1. Submit every form with valid and invalid data to test validation.
2. Test navigation, dropdowns, modals, and interactive components.
3. Verify email notifications, confirmations, and thank-you pages.
4. Test on multiple browsers (Chrome, Firefox, Safari, Edge).
