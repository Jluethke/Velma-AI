# Pre Day One Prep

Prepare equipment, system access, and workspace before the new hire's first day.

## Inputs

- `hire-details`: Name, role, start date, team, and manager
- `access-requirements`: Systems and tools the role needs

## Outputs

- `prep-checklist`: Completed pre-arrival checklist
- `welcome-package`: Welcome email draft and day-one schedule

## Process

1. Order and configure equipment (laptop, monitors, peripherals)
2. Provision system accounts and access permissions
3. Set up the physical or remote workspace
4. Draft the welcome email with first-day logistics
