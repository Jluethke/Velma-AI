# Cost Of Inaction Questions

Quantify what each problem costs if nothing changes, so urgency comes from the buyer, not from you.

## Inputs

- `problem-list`: The problems the buyer named
- `problem-triggers`: The events that trigger each problem

## Outputs

- `cost-estimates`: The cost of each problem in time, money, and risk if nothing changes
- `urgency-signals`: Which problems the buyer feels enough to act on now

## Process

1. For each problem, ask what it costs today and what it will cost if it continues for another year.
2. Help the buyer put numbers on it, since a cost the buyer quantifies is a cost they will act on.
3. Note which problems carry real urgency and which the buyer can live with.
4. Let the buyer conclude that doing nothing is expensive, rather than telling them so.
