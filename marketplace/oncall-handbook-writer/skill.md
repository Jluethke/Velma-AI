# Oncall Handbook Writer

Write the on-call handbook covering responsibilities, common procedures, and where to find information.

## Inputs

- `escalation-policies`: The configured escalation chains
- `alerting-channels`: Configured notification channels

## Outputs

- `oncall-handbook`: The completed on-call handbook document
- `quick-reference-card`: One-page reference for on-call responders

## Process

1. Document the on-call responder responsibilities
2. List common alert types and their initial triage steps
3. Include links to runbooks, dashboards, and escalation contacts
4. Write the quick-reference card for fast lookups
