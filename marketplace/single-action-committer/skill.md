# Single Action Committer

Commit to a single action that addresses the root cause. One action, one owner, one deadline. Not a list of five improvements that no one owns.

## Inputs

- `root-cause-analysis`: The root cause and the systemic issue
- `team-members`: The team and their capacity

## Outputs

- `committed-action`: The single action: what will change (a process, a tool, a habit), who owns the change, and the deadline for implementation
- `success-criterion`: How to know the action worked: a measurable outcome that will be checked at the next retrospective

## Process

1. Design the action that addresses the root cause. It should be a systemic change: a process step added or removed, a tool introduced, a communication pattern changed, a policy updated.
2. Assign a single owner. The owner is responsible for implementing the change, not the entire team. 'The team will do better' is not an action. 'Maria will add a test plan review step to the sprint planning template by next Friday' is an action.
3. Set the deadline: the action must be implemented before the next retrospective. If it cannot be done in one sprint, break it into a smaller first step that can.
4. Define the success criterion: at the next retrospective, how will you know this worked? The criterion must be measurable: 'Reduce unplanned testing extensions from 3 per sprint to 0.'
