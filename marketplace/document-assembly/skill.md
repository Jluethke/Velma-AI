# Document Assembly

Assemble the final document: conclusion, supporting arguments with evidence, counter-arguments, and clear ask.

## Inputs

- `conclusion-statement`: The conclusion
- `argument-structure`: Supporting arguments
- `evidence-map`: Evidence
- `preemptive-responses`: Objections addressed

## Outputs

- `finished-document`: The complete document: conclusion first, arguments with evidence, objections addressed, specific ask at the end
- `executive-summary`: A 3-sentence version: conclusion, strongest evidence, ask

## Process

1. Assemble: First sentence is the conclusion. Next 2-4 sections are arguments with evidence. Then objections. End with a specific ask.
2. Write an executive summary: 3 sentences that give the reader everything if they read nothing else.
3. Cut ruthlessly. Every sentence must support the conclusion or address an objection.
4. The document should be readable in under 5 minutes. If longer, shorten it.
