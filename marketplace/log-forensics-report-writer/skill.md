# Log Forensics Report Writer

Produce the log forensics report with the attack narrative and supporting evidence.

## Inputs

- `attack-timeline`: The attack timeline with confidence ratings
- `compromise-assessment`: Initial compromise and lateral movement analysis
- `correlation-gaps`: Documented gaps in log coverage

## Outputs

- `log-forensics-report`: The complete log forensics investigation report
- `detection-recommendations`: Recommendations for improved logging and detection

## Process

1. Write the attack narrative from initial access through impact
2. Include evidence references for each claim
3. Document limitations from log gaps
4. Recommend logging and detection improvements
