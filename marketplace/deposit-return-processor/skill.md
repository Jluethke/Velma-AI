# Deposit Return Processor

Process the security deposit return and prepare the unit for turnover.

## Inputs

- `damage-report`: Itemized damage report
- `deposit-deduction-worksheet`: Deductions with amounts

## Outputs

- `deposit-return-record`: Record of deposit returned with itemized deductions
- `move-out-record`: Complete move-out file with all supporting documents

## Process

1. Calculate the net deposit return amount.
2. Send the itemized statement and deposit return within the statutory deadline.
3. Schedule turnover work: cleaning, painting, and repairs.
4. Close the tenant file and produce the move-out record.
