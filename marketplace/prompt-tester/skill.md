# Prompt Tester

Test the prompt against a sample set and score the outputs.

## Inputs

- `draft-prompt`: Prompt to test
- `evaluation-rubric`: Scoring rubric

## Outputs

- `test-results`: Scored results for each test case
- `failure-cases`: Cases that did not meet criteria

## Process

1. Run the prompt against each test input.
2. Score each output against the rubric.
3. Identify failure patterns and edge cases.
4. Calculate the overall pass rate.
