# Icd Cost Report Writer

Write the true-cost finding.

## Inputs

- `cost-ranking`: The options ranked by true cost
- `sticker-gap-table`: The gaps between sticker and true cost

## Outputs

- `invisible-cost-report`: Sticker price next to true cost for each option
- `cheapest-true-option`: The cheapest option once every cost is counted

## Process

1. Present the sticker price next to the true cost for each option.
2. Call out the options whose true cost is far above the sticker.
3. Name the cheapest option once all costs are counted.
