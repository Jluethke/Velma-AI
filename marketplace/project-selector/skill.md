# Project Selector

Choose a concrete project that cannot be completed without using the skill.

## Inputs

- `skill-definition`: The skill stated in terms of what you can do
- `proof-criteria`: The evidence that would prove you have the skill

## Outputs

- `project-brief`: A short brief for the chosen project
- `required-skills-map`: Which parts of the project exercise which sub-skills

## Process

1. Brainstorm projects that force use of the target skill.
2. Pick one that is useful or interesting enough to finish.
3. Map which parts of the project exercise which sub-skills.
4. Check the project cannot be finished by avoiding the skill.
