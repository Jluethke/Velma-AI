# Network Effect Interaction Capture

Capture the product and the ways users could interact with each other. A network effect lives in a user-to-user interaction, so the first job is to find the candidate interactions worth examining.

## Inputs

- `product-description`: What the product does and for whom
- `user-types`: The kinds of users the product serves
- `current-value-source`: Where the product's value comes from today

## Outputs

- `product-profile`: A profile of the product and its users
- `interaction-candidates`: The user-to-user interactions that could create value

## Process

1. Describe the product and the kinds of users it serves.
2. List the ways users could interact: sharing, transacting, contributing, matching, communicating.
3. Note whether today's value comes from the product itself or from other users.
4. Collect the interaction candidates without judging them yet.
