# Engagement Rules Template Writer

Define the rules of engagement template used for each exercise.

## Inputs

- `program-charter`: Overarching authority and boundaries
- `exercise-calendar`: Types of exercises planned

## Outputs

- `roe-template`: Rules of engagement template covering scope, constraints, deconfliction, and emergency stop procedures
- `deconfliction-process`: How to distinguish red team activity from real attacks

## Process

1. Define the scope section: in-scope systems, IP ranges, and user accounts
2. Define constraints: no denial of service, no data destruction, no production impact without approval
3. Establish deconfliction: how the red team signals its activity to SOC leadership
4. Define the emergency stop procedure (safe word, phone call, email)
