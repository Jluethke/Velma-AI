# Questionnaire Package Compiler

Compile the completed questionnaire with attachments for submission.

## Inputs

- `approved-responses`: All approved responses
- `evidence-attachments`: Evidence files to include

## Outputs

- `completed-questionnaire`: Final questionnaire ready for submission
- `submission-record`: Record of what was submitted and when

## Process

1. Assemble all responses into the required questionnaire format
2. Attach evidence files and verify they are complete
3. Perform a final completeness check
4. Package for submission and archive a copy
