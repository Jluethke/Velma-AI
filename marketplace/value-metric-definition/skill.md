# Value Metric Definition

Define the single value metric buyers actually compare tiers on, since the decoy works along that axis.

## Inputs

- `tier-map`: The map of current tiers
- `value-gaps`: Where tier jumps confuse buyers

## Outputs

- `value-metric`: The metric buyers use to judge whether a tier is worth it
- `willingness-to-pay-notes`: What the market will pay at each point on that metric

## Process

1. Identify the one thing buyers point to when they say a tier is or is not worth the price.
2. Confirm the metric scales with value the buyer feels, not just with a feature count.
3. Gather what you know about willingness to pay along that metric from quotes, losses, and discounts.
4. State the metric in one sentence so every later pricing choice can be checked against it.
