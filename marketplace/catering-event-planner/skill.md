# Catering Event Planner

Plan the event logistics including prep schedule, transport, setup, and service timeline.

## Inputs

- `catering-proposal`: Approved proposal with menu and staffing
- `event-contract`: Signed contract with confirmed details

## Outputs

- `event-timeline`: Minute-by-minute event timeline from kitchen prep through breakdown
- `prep-schedule`: Kitchen prep schedule with task assignments and deadlines

## Process

1. Build the kitchen prep schedule working backward from the service time.
2. Plan the loading, transport, and venue setup sequence.
3. Create the minute-by-minute service timeline (cocktail hour, first course, etc.).
4. Assign staff roles and brief the team on the event flow.
