# Edge Hardware Selector

Select the edge hardware based on the requirements.

## Inputs

- `edge-requirements`: Processing and storage requirements
- `edge-vs-cloud-analysis`: Edge vs cloud task split

## Outputs

- `hardware-selection`: The selected edge hardware with specifications
- `deployment-plan`: How and where to deploy the edge nodes

## Process

1. Match the requirements to available hardware options (industrial gateways, single-board computers, edge servers).
2. Evaluate the options on compute power, environmental rating, connectivity, and cost.
3. Select the hardware and plan the physical deployment locations.
