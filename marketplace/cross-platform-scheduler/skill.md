# Cross Platform Scheduler

Schedule the adapted content across all platforms.

## Inputs

- `adapted-content-set`: The content ready for each platform
- `platform-plan`: The posting strategy for each platform

## Outputs

- `publish-schedule`: The scheduled post times for each platform
- `cross-promo-plan`: How each platform will reference the others to drive traffic

## Process

1. Determine the optimal posting time for each platform based on audience activity.
2. Stagger the posts so the primary platform publishes first.
3. Add cross-promotion elements (links, mentions, CTAs pointing to other platforms).
4. Load the content into the scheduling tool or publish queue.
