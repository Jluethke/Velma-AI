# Custodian Identifier

Identify all custodians and data sources subject to the hold.

## Inputs

- `hold-scope`: Hold scope
- `relevant-topics`: Relevant topics and data types

## Outputs

- `custodian-list`: List of all custodians with their data sources
- `system-list`: IT systems and repositories subject to the hold

## Process

1. Identify individuals with relevant knowledge or documents
2. Map each custodian to their data sources (email, files, chat, devices)
3. Identify shared systems (databases, file shares, cloud storage) in scope
