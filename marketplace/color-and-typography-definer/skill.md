# Color And Typography Definer

Set the color palette and typography rules for data visualizations.

## Inputs

- `chart-type-guidelines`: Chart type rules
- `brand-guidelines`: Existing brand colors and fonts

## Outputs

- `color-palette`: Sequential, diverging, and categorical color palettes for data
- `typography-rules`: Font sizes and weights for titles, labels, annotations, and values

## Process

1. Define a categorical palette (6 to 8 distinct colors) aligned with the brand.
2. Define sequential and diverging palettes for quantitative data.
3. Set typography rules: title size, axis label size, annotation size, value display.
