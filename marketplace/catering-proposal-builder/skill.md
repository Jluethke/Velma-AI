# Catering Proposal Builder

Create a detailed catering proposal with menu, staffing, equipment, and pricing.

## Inputs

- `qualified-inquiry`: Event details and feasibility assessment
- `site-visit-plan`: Site assessment results

## Outputs

- `catering-proposal`: Detailed proposal with menu, per-head pricing, staffing plan, and equipment list
- `event-contract`: Contract with payment schedule, cancellation terms, and liability details

## Process

1. Design the menu based on event type, guest preferences, and dietary needs.
2. Calculate the staffing requirements (chefs, servers, bartenders, cleanup crew).
3. List the equipment and rental needs (tables, linens, chafing dishes, bar setup).
4. Build the cost breakdown and present the per-head and total pricing.
