# Master Template Creator

Create the master email templates for each use case.

## Inputs

- `email-brand-spec`: Email-specific brand guidelines
- `template-requirements`: Requirements per email type

## Outputs

- `template-set`: The master templates for newsletter, transactional, promotional, and event emails
- `template-documentation`: Usage guide for each template including editable sections and content rules

## Process

1. Build the newsletter template with header, content sections, sidebar, and footer.
2. Build the transactional template with minimal design and clear action focus.
3. Build the promotional template with hero image, offer section, and CTA.
4. Build the event template with date, location, agenda, and registration CTA.
5. Document the editable sections and content rules for each.
