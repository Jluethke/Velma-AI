# Seed Bank Accession

Process and deposit seed from selected entries into a seed bank with full passport data and viability testing.

## Inputs

- `selection-recommendations`: Entries selected for advancement or conservation
- `yield-data`: Harvest data including seed lot origin

## Outputs

- `accession-records`: Seed bank accession numbers with passport data (origin, pedigree, traits)
- `viability-test`: Germination test results for each deposited lot

## Process

1. Clean and dry seed lots to target moisture content for long-term storage
2. Run a standard germination test (ISTA rules) and record percent germination
3. Package seed in moisture-barrier containers and deposit at the designated storage temperature
4. Enter passport data (accession number, species, pedigree, collection site, trait summary) into the genebank database
