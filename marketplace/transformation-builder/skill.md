# Transformation Builder

Implement the data transformations: cleaning, normalization, and enrichment.

## Inputs

- `schema-mapping`: Source-to-target mapping with rules
- `extraction-plan`: How data is extracted from each source

## Outputs

- `transformation-logic`: Implemented transformation code or configuration
- `transformation-tests`: Test cases validating each transformation

## Process

1. Implement data cleaning rules (nulls, duplicates, format standardization).
2. Build normalization steps (unit conversion, encoding, date formatting).
3. Add enrichment logic (lookups, derived fields, aggregations).
4. Write test cases for each transformation covering edge cases.
