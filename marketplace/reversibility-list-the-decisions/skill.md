# Reversibility List The Decisions

Gather the decisions waiting to be made so each can be filtered by how reversible it is.

## Inputs

- `decision-backlog`: The decisions currently waiting to be made.
- `decision-owner`: Who is accountable for the decisions.

## Outputs

- `pending-decisions`: The listed decisions with what each commits you to.
- `decision-notes`: Which decisions are blocking other work.

## Process

1. List every decision currently waiting to be made.
2. Write one line on what each decision commits you to.
3. Note which decisions are blocking other work.
