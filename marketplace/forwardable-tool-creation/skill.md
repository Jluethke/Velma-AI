# Forwardable Tool Creation

Create something the customer can forward without effort, so the referral costs them almost nothing.

## Inputs

- `referral-ask`: The specific ask
- `ask-timing`: When and how to deliver it

## Outputs

- `forwardable-asset`: A ready-to-send asset the customer can pass along as is
- `intro-template`: A short template that makes the introduction easy to write

## Process

1. Build an asset the customer can forward directly, such as a short note, a guide, or an invite.
2. Write a template the customer can paste and send, since drafting an intro is the friction that kills referrals.
3. Make the asset useful to the person receiving it on its own, so forwarding it feels like a favor, not an ad.
4. Keep it short, since a long asset is less likely to be sent.
