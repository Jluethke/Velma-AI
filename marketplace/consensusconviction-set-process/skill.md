# Consensusconviction Set Process

Define the decision process that matches the chosen mode and name the roles in it.

## Inputs

- `chosen-mode`: Consensus or conviction for this decision.
- `mode-rationale`: Why the mode fits the three scores.

## Outputs

- `decision-process`: The process that matches the chosen mode.
- `process-roles`: The roles and timeline for the process.

## Process

1. For consensus, set how input is gathered and how agreement is reached.
2. For conviction, name the single decider and what input they will hear first.
3. Write the roles and the timeline for the chosen process.
