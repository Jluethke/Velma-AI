# Conversation Component Builder

Build the reusable conversation components (intents, entities, dialog modules).

## Inputs

- `pattern-catalog`: The conversation patterns
- `anti-patterns`: Patterns to avoid

## Outputs

- `component-library`: Library of reusable conversation components (common intents, shared entities, dialog modules)
- `usage-guide`: Guide for using and extending the component library

## Process

1. Build the shared intent library (greetings, farewells, help requests, escalation requests, yes/no, corrections).
2. Build the shared entity library (dates, times, phone numbers, addresses, names, account numbers).
3. Build the reusable dialog modules (authentication, address collection, date/time scheduling, payment).
4. Write the usage guide for each component.
