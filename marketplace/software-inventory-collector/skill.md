# Software Inventory Collector

Inventory all software in use across the organization.

## Inputs

- `scan-scope`: Systems and departments to include in the audit
- `discovery-tools`: Available asset discovery and inventory tools

## Outputs

- `software-inventory`: Complete list of installed and SaaS software
- `usage-metrics`: User counts and usage frequency per application

## Process

1. Run automated discovery across endpoints, servers, and cloud
2. Catalog SaaS subscriptions from procurement and expense records
3. Record user counts and deployment locations for each product
