# Case Study Design Production

Design the visual presentation of the case study.

## Inputs

- `case-study-draft`: Written content
- `metrics-summary`: Quantified results

## Outputs

- `case-study-final`: The designed case study ready for publication
- `case-study-assets`: Images, screenshots, charts, and pull quotes for promotion

## Process

1. Design the layout with sections for challenge, approach, solution, and results.
2. Add visuals: before/after screenshots, process diagrams, or data charts.
3. Highlight the key metric in a pull-out stat block.
4. Include a client testimonial if available.
5. Produce social-friendly image assets for promotion.
