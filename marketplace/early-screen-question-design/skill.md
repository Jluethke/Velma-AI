# Early Screen Question Design

Turn the disqualifiers into screening questions for the first call, with a rubric to score the answers.

## Inputs

- `worst-fit-profile`: The named worst-fit composite
- `disqualifier-list`: Observable disqualifiers

## Outputs

- `screening-questions`: Questions that surface disqualifiers without sounding like an interrogation
- `scoring-rubric`: How to score answers into pursue, probe further, or disqualify

## Process

1. For each disqualifier, write a question that a good-fit buyer answers comfortably and a bad-fit buyer stumbles on.
2. Phrase questions as help, not as a gate, so the call stays a conversation.
3. Build a rubric that maps answer patterns to pursue, probe further, or disqualify.
4. Set a rule for how many disqualifiers trigger a polite exit, so reps are not left guessing.
