# Review Collection Setup

Set up automated review collection from customers.

## Inputs

- `product-catalog`: Products to collect reviews for
- `customer-touchpoints`: Available channels for review requests

## Outputs

- `collection-flows`: Automated review collection flows
- `collection-schedule`: Timing rules for review requests

## Process

1. Design the post-purchase review request email (timing, copy, incentive).
2. Set up in-app or on-site review prompts.
3. Configure review syndication across channels.
4. Set frequency caps to avoid over-requesting.
