# Analysis Assignment Router

Assign requests to analysts and set expectations.

## Inputs

- `intake-form`: Standardized request form
- `triage-criteria`: Urgency and complexity classification

## Outputs

- `assignment-rules`: How requests are matched to analysts based on skill and availability
- `turnaround-slas`: Expected turnaround time by request type

## Process

1. Match request types to analyst skills.
2. Set turnaround expectations by triage level.
3. Define the handoff protocol between requestor and analyst.
