# Newsletter Design Assembler

Assemble the newsletter in the email template and prepare for send.

## Inputs

- `newsletter-draft`: The written content
- `subject-line-candidates`: Subject lines for testing
- `preview-text`: The preview text

## Outputs

- `assembled-email`: The newsletter assembled in the email template, tested across clients
- `send-configuration`: Send settings (segment, send time, A/B test setup for subject lines)

## Process

1. Place the content into the newsletter template.
2. Add images, formatting, and links. Verify all links work.
3. Test rendering across email clients (Gmail, Outlook, Apple Mail, mobile).
4. Configure the send: select the segment, set the send time, configure subject line A/B test.
