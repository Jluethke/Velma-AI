# Qa Report Generator

Produce the QA report with trends and coaching recommendations.

## Inputs

- `scored-interactions`: All scored interactions
- `calibration-notes`: Calibration session outcomes

## Outputs

- `qa-report`: QA report with scores, trends, and agent breakdowns
- `coaching-plan`: Agent-level coaching recommendations

## Process

1. Calculate scores by agent, team, and criterion.
2. Identify trends over time.
3. Highlight top performers and agents needing coaching.
4. Produce the QA report and coaching plan.
