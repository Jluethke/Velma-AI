# Update Cadence Setter

Set the update cadence and collection method.

## Inputs

- `tracking-dimensions`: What gets tracked
- `project-list`: Active projects

## Outputs

- `update-cadence`: How often updates are collected and from whom
- `collection-method`: How updates are gathered (form, meeting, async, automated)

## Process

1. Set the update frequency by project criticality (daily for critical, weekly for standard).
2. Choose the collection method (async form, standup, status meeting, automated from tools).
3. Assign update owners per workstream.
4. Produce the cadence and collection plan.
