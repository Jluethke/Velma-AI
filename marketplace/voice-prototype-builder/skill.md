# Voice Prototype Builder

Build a testable prototype of the voice experience.

## Inputs

- `dialog-flows`: Complete dialog trees
- `voice-style-guide`: Tone and language guidelines

## Outputs

- `voice-prototype`: Interactive prototype or script that walks through the dialog flows
- `test-scenarios`: Scenarios covering happy paths, errors, edge cases, and adversarial inputs

## Process

1. Implement the dialog flows in a prototyping tool or script.
2. Record or synthesize audio for each system prompt.
3. Write the test scenarios covering normal use, errors, and edge cases.
