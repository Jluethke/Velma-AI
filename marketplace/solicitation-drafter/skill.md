# Solicitation Drafter

Draft the procurement solicitation document (RFP, RFQ, or IFB).

## Inputs

- `procurement-need`: Description of what is being procured (goods, services, or construction)
- `procurement-method`: The solicitation type (RFP, RFQ, IFB) and applicable procurement rules

## Outputs

- `solicitation-document`: The draft solicitation with scope, requirements, evaluation criteria, and terms
- `evaluation-criteria`: Scoring criteria and weights for bid evaluation

## Process

1. Define the scope of work or specifications.
2. Set the evaluation criteria and their weights.
3. Include the required terms, conditions, and certifications.
4. Set the submission deadline and question period.
