# Sensitive Area Access Test

Attempt access to sensitive areas including server rooms, executive offices, and network closets.

## Inputs

- `badge-clone-results`: Cloned credentials for access attempts
- `tailgate-results`: Tailgating access for deeper penetration
- `door-bypass-findings`: Bypass techniques for locked sensitive areas

## Outputs

- `sensitive-area-findings`: Access results for sensitive areas
- `data-exposure-observations`: Sensitive information observed in accessed areas

## Process

1. Attempt server room access using each available technique
2. Test network closet locks and check for unsecured switch ports
3. Check executive office access and document visible sensitive information
4. Note any unattended workstations, unlocked cabinets, or visible credentials
