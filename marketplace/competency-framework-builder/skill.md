# Competency Framework Builder

Define the competencies and performance indicators for the program or role.

## Inputs

- `program-scope`: Program, role, or profession being assessed
- `standards-reference`: Professional or accreditation standards to align with

## Outputs

- `competency-framework`: List of competencies with performance indicators
- `proficiency-levels`: Defined levels of proficiency for each competency

## Process

1. Identify the core competencies required for the program or role
2. Write 3-5 performance indicators per competency
3. Define proficiency levels (novice, developing, proficient, expert)
4. Align competencies to external standards where applicable
