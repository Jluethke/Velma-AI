# Core Sampling Protocol

Design and execute a core sampling program: drill locations, core diameter, depth targets, preservation, and logging procedures.

## Inputs

- `sampling-targets`: Where and what to core
- `site-list`: Approved sites with access details

## Outputs

- `core-log`: Lithologic description, depth intervals, contacts, and features for each core
- `sample-inventory`: Labeled samples with depth, formation, and intended analysis
- `core-photos`: Annotated core photographs with scale bars

## Process

1. Position drill holes to intersect target formations
2. Core at specified diameter and depth with continuous recovery logging
3. Log lithology, color, grain size, fossils, and structural features per interval
4. Photograph cores with scale and orientation marks
5. Package and label samples for transport to the lab
