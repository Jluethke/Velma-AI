# Challenge Design Builder

Design challenges across categories: web, crypto, forensics, reverse engineering, network.

## Inputs

- `learning-objectives`: Skills to teach or test
- `difficulty-tiers`: Difficulty level definitions

## Outputs

- `challenge-specs`: Detailed specification for each challenge
- `flag-inventory`: All flags with their challenge assignments

## Process

1. Design web challenges: SQL injection, XSS, SSRF, auth bypass
2. Design crypto challenges: weak algorithms, implementation flaws, key management
3. Design forensics challenges: disk images, memory dumps, network captures, log analysis
4. Design reverse engineering and network challenges appropriate to each tier
