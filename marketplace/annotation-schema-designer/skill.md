# Annotation Schema Designer

Define the annotation schema and labeling guidelines.

## Inputs

- `data-samples`: Representative data samples to annotate
- `task-requirements`: What the annotations will be used for

## Outputs

- `annotation-schema`: Label taxonomy with definitions and examples
- `annotation-guidelines`: Step-by-step instructions for annotators

## Process

1. Define the label taxonomy with clear boundaries.
2. Write the annotation guidelines with positive and negative examples.
3. Handle ambiguous cases with decision rules.
4. Pilot the guidelines on a small sample to check clarity.
