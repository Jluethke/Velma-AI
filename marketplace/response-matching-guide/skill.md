# Response Matching Guide

Build a single guide that routes each kind of stress to the right tool, so the response is matched rather than random.

## Inputs

- `acute-reset-tools`: The physiological reset tools
- `chronic-source-plan`: The structural change plan
- `defusion-protocol`: The anticipatory defusion steps

## Outputs

- `stress-response-matcher`: A guide mapping each stress type to its matched response
- `quick-reference-card`: A short card you can reach for in the moment to pick the right tool fast

## Process

1. Write the matching rule: acute goes to a physiological reset, chronic goes to a structural change, anticipatory goes to defusion and a scheduled time.
2. Put the rule on a short reference card. In a stressed moment you need a quick route to the right tool, not a long document to read.
3. Flag the common mismatch: using a reset tool on chronic stress. It feels productive but leaves the source untouched, so the card should prompt you to check the type first.
4. Keep the card where stress tends to hit, so the matched response is close at hand rather than remembered only after the episode has passed.
