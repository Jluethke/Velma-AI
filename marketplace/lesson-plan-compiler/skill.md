# Lesson Plan Compiler

Compile all components into the final lesson plan document with timing and transitions.

## Inputs

- `opening-activity`: Description of the hook and prior knowledge activation
- `activity-sequence`: Ordered list of instructional activities with timing
- `formative-assessment`: Assessment task

## Outputs

- `lesson-plan`: Complete lesson plan document
- `lesson-timeline`: Minute-by-minute timeline of the lesson

## Process

1. Assemble all sections into the lesson plan template
2. Add transitions between activities
3. Finalize the minute-by-minute timeline
4. Review for alignment between objectives, activities, and assessment
