# Evaluation Question Definer

Define the evaluation questions and scope.

## Inputs

- `program-description`: Description of the program to evaluate
- `evaluation-purpose`: Why the evaluation is being conducted (funder requirement, improvement, accountability)

## Outputs

- `evaluation-questions`: Specific questions the evaluation will answer
- `evaluation-scope`: Boundaries and focus areas

## Process

1. Identify stakeholders and their information needs
2. Draft evaluation questions tied to program goals
3. Define the scope (which sites, time period, components)
4. Prioritize questions by importance and feasibility
