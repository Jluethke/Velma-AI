# Practice Session Planner

Plan a short, high-focus practice session with full attention and rest.

## Inputs

- `practice-task`: A task stripped down to the single sub-skill
- `feedback-source`: The source that scores each repetition immediately

## Outputs

- `session-plan`: A plan for one focused practice session
- `focus-rules`: Rules that remove distraction during the session

## Process

1. Set a session length short enough to sustain full concentration.
2. Schedule the session when your attention is highest.
3. Define rules that remove distraction during the session.
4. Plan short rest breaks between blocks of repetitions.
