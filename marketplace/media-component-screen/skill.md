# Media Component Screen

Screen media components to identify which carbon, nitrogen, and mineral sources most affect the target product.

## Inputs

- `baseline-conditions`: Starting media composition
- `optimization-objectives`: What to measure

## Outputs

- `significant-components`: Media components with the largest effect on the target product
- `screening-data`: Titer and growth data from the screening experiment

## Process

1. Design a Plackett-Burman or fractional factorial screening experiment covering 8-12 media components.
2. Run the screening fermentations (small scale, typically shake flasks).
3. Measure the target product titer and biomass for each condition.
4. Analyze main effects to identify the 3-5 most significant components for further optimization.
