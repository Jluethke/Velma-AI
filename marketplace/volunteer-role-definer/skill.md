# Volunteer Role Definer

Define the volunteer roles, requirements, and scheduling needs for recurring services or events.

## Inputs

- `service-schedule`: The recurring events or services that need volunteers (weekly worship, monthly food bank)
- `role-list`: The volunteer positions to fill for each event type

## Outputs

- `role-definitions`: Each role with its description, requirements, training needed, and time commitment
- `staffing-requirements`: Minimum and target headcount for each role per event

## Process

1. List every volunteer role by event type: greeters, ushers, musicians, sound tech, nursery, food prep, setup, cleanup.
2. For each role, define the requirements: minimum age, training, background check, physical ability.
3. Set the time commitment: arrival time, duration, frequency (weekly, monthly, quarterly).
4. Set the minimum and target number of volunteers per role per event.
