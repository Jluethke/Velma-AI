# Request Statement Writer

Write the request: the specific behavior change or decision you need. A request without specifics is a complaint. 'I need you to submit the draft by Wednesday at 5pm' not 'I need you to be more responsible.'

## Inputs

- `conversation-goal`: What you need from this conversation
- `impact-statement`: What the behavior caused

## Outputs

- `request-statement`: The specific, actionable request
- `measurable-check`: How both parties will know whether the request has been met

## Process

1. State the specific behavior change or decision you need. Use a verb, a deadline, and a deliverable.
2. Make the request about behavior, not character. You can change behavior. You cannot change character in a conversation.
3. Define how both of you will know whether the request has been met. If you cannot measure it, the request is too vague.
4. Keep the request to one sentence. Multiple requests dilute each other.
