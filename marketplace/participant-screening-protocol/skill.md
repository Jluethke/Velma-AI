# Participant Screening Protocol

Design the participant screening: inclusion and exclusion criteria, informed consent, MRI safety screening, and demographic data collection.

## Inputs

- `acquisition-protocol`: Imaging modality determines safety screening requirements
- `refined-hypothesis`: Population of interest

## Outputs

- `screening-form`: Inclusion/exclusion criteria, MRI safety questionnaire, and demographic survey
- `consent-template`: Informed consent document with study description, risks, and data handling
- `target-sample-size`: Required N with power analysis justification

## Process

1. Define inclusion criteria (age, handedness, vision, language)
2. Set exclusion criteria (MRI contraindications, neurological history, medications)
3. Write informed consent covering procedures, risks, and data storage
4. Calculate target sample size from expected effect size and desired power
