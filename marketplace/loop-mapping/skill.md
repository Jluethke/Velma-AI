# Loop Mapping

Map the current loop from the moment an action is taken to the moment you learn whether it worked. Most teams have never drawn this loop and are surprised how many stages sit between doing and knowing.

## Inputs

- `process-to-improve`: The process whose feedback loop is being tightened
- `current-review-cadence`: How often results are currently reviewed

## Outputs

- `loop-map`: The path from action taken to learning the result
- `loop-stages`: The ordered stages the signal passes through

## Process

1. Mark the moment an action is taken as the start of the loop.
2. Mark the moment someone learns whether it worked as the end of the loop.
3. List every stage the signal passes through between those two points.
4. Confirm the map reflects what actually happens, not the process as it is supposed to run.
