# Time Block Review Protocol

Review and adjust the time blocking system weekly.

## Inputs

- `calendar-blocks`: Current time blocks
- `protection-rules`: Deep work protection rules

## Outputs

- `review-protocol`: Weekly review steps for the time blocking system
- `time-blocking-template`: Complete time blocking system document

## Process

1. Set a weekly review to compare planned vs actual time usage.
2. Note which blocks held and which were interrupted.
3. Adjust the template based on what worked.
4. Compile the full time blocking system document.
