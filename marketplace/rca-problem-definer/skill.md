# Rca Problem Definer

Define the problem in measurable, specific terms.

## Inputs

- `problem-report`: Initial report of the issue
- `impact-data`: Data on the scope and severity of the problem

## Outputs

- `problem-definition`: Specific, measurable problem statement (is/is-not)
- `containment-actions`: Immediate actions to contain the problem

## Process

1. Write the problem statement: what, where, when, how much
2. Construct the is/is-not analysis to bound the problem
3. Implement immediate containment actions to protect the customer
4. Define the timeline and team for the investigation
