# Perimeter Entry Surveyor

Survey the facility perimeter and all entry points for physical weaknesses.

## Inputs

- `facility-description`: Description and floor plans of the facility
- `access-control-policies`: Current physical access control policies

## Outputs

- `entry-point-inventory`: Inventory of all entry points with their access control type
- `perimeter-weaknesses`: Physical weaknesses found in the perimeter

## Process

1. Walk the full perimeter and document every entry point (doors, loading docks, windows, roof access)
2. Classify each entry point by access control type (badge, key, biometric, unlocked)
3. Identify weak points: propped doors, damaged locks, blind spots, accessible windows
4. Photograph and document each finding with location
