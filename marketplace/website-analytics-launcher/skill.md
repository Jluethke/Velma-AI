# Website Analytics Launcher

Set up analytics, search console, and submit the sitemap, then launch.

## Inputs

- `security-config`: Security configuration complete
- `site-url`: The site URL

## Outputs

- `analytics-config`: Analytics and search console configured
- `launch-checklist`: Complete launch checklist with all items signed off

## Process

1. Install and verify analytics tracking on all pages.
2. Register the site with search console and submit the sitemap.
3. Set up uptime monitoring and error alerting.
4. Switch DNS or remove the maintenance page to go live.
