# Email Brand Guidelines Definer

Define the brand guidelines specific to email design.

## Inputs

- `brand-guidelines`: The existing brand guidelines (colors, fonts, logo)
- `email-use-cases`: The types of emails to be sent (newsletter, promotional, transactional, event)

## Outputs

- `email-brand-spec`: Email-specific brand guidelines covering colors, fonts, layout rules, and logo placement
- `template-requirements`: Requirements for each email type (sections, CTAs, footer, legal requirements)

## Process

1. Adapt the brand colors for email (web-safe colors, dark mode considerations).
2. Select the email-safe fonts (system fonts and web fonts with fallbacks).
3. Define the layout grid and spacing rules for email.
4. Define the logo placement, CTA button styles, and footer requirements.
5. Document the legal requirements per email type (unsubscribe link, physical address, privacy link).
