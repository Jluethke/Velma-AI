# Podcast Show Notes Writer

Write show notes, timestamps, and transcript.

## Inputs

- `mixed-episode`: Final mixed episode audio
- `episode-outline`: Episode structure for reference

## Outputs

- `show-notes`: Episode description with timestamps and links
- `transcript`: Full text transcript of the episode

## Process

1. Generate or write the transcript from the audio
2. Write the episode summary and key takeaways
3. Add timestamps for each segment and topic
4. Include links to resources mentioned in the episode
