# Naming Convention Definer

Define the document naming convention and version numbering scheme.

## Inputs

- `document-types`: Types of documents to be version-controlled
- `organizational-standards`: Any existing naming or numbering standards

## Outputs

- `naming-convention`: The naming convention with examples for each document type
- `version-numbering-scheme`: Major, minor, and draft version numbering rules

## Process

1. Define the naming pattern (project code, document type, date, version).
2. Set the version numbering rules (when to increment major vs minor, draft conventions).
3. Provide examples for each document type.
4. Document exceptions and edge cases.
