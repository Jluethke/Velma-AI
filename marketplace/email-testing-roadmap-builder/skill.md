# Email Testing Roadmap Builder

Define the testing roadmap covering what to test and in what order.

## Inputs

- `email-performance-data`: Current email performance metrics (open rates, click rates, conversion rates)
- `testing-goals`: What the testing program aims to improve

## Outputs

- `testing-roadmap`: Ordered list of tests to run (subject lines, send times, content, CTAs, design)
- `testing-priorities`: Tests ranked by expected impact and ease of execution

## Process

1. Identify the biggest performance gaps (low open rate means test subjects, low click rate means test content and CTAs).
2. List all testable elements: subject lines, preheaders, send times, send days, from names, content length, CTA placement, CTA copy, design layout, personalization.
3. Rank by expected impact and ease of execution.
4. Schedule the tests across upcoming sends.
