# Sharing Requirements Analyzer

Define the file sharing requirements: who shares what with whom, and the security constraints.

## Inputs

- `sharing-scenarios`: Common file sharing scenarios (internal team, external client, one-time delivery, ongoing collaboration)
- `security-requirements`: Data sensitivity levels and compliance requirements (encryption, retention, access logging)

## Outputs

- `sharing-matrix`: Who shares what type of files with whom, via what method, with what controls
- `compliance-constraints`: Regulatory or policy requirements that affect how files can be shared

## Process

1. List the common sharing scenarios: internal team collaboration, external client delivery, vendor exchange, public distribution.
2. For each scenario, identify the file types, sensitivity level, and recipient type.
3. Map the compliance constraints: encryption requirements, geographic restrictions, retention rules, audit obligations.
4. Produce the sharing matrix and compliance constraints.
