# Review Mining Refresh Schedule

Set the cadence for re-mining. Markets shift, competitors respond, and new complaints surface. This is not a one-time exercise.

## Inputs

- `derived-marketing-copy`: Current copy derived from reviews
- `feature-opportunity-list`: Current product opportunities from reviews

## Outputs

- `refresh-schedule`: When and how to re-run the mining process (quarterly recommended), with triggers for ad-hoc runs
- `monitoring-setup`: Ongoing review monitoring alerts for new complaints that match known gap patterns or reveal new ones

## Process

1. Set a quarterly cadence: re-run the collection and analysis every 3 months. Markets move; new complaints surface as competitors ship changes.
2. Set ad-hoc triggers: if a competitor launches a major update, re-mine within 2 weeks to see the reaction. If you launch a feature that fills a gap, monitor competitor reviews to see if customers notice.
3. Set up alerts (Google Alerts, review platform notifications) for your competitors' brand names plus negative sentiment keywords.
