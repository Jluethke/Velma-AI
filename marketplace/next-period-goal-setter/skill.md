# Next Period Goal Setter

Set goals for the next review period based on review outcomes.

## Inputs

- `calibrated-ratings`: Final ratings
- `delivered-reviews`: Review conversation outcomes

## Outputs

- `next-period-goals`: Goals for each employee for the next period
- `development-plans`: Development plans for growth areas

## Process

1. Identify the key objectives for the next period
2. Set measurable goals aligned to team and company priorities
3. Create development plans for growth areas identified in the review
4. Agree on check-in cadence to track progress
