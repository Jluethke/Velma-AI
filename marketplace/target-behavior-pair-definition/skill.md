# Target Behavior Pair Definition

Name one behavior to increase and one to decrease, each stated as an observable action rather than a feeling or outcome.

## Inputs

- `behavior-to-increase`: Something you want to do more often but keep skipping
- `behavior-to-decrease`: Something you want to do less often but keep returning to

## Outputs

- `defined-increase-target`: The increase behavior stated as an action with a weekly minimum
- `defined-decrease-target`: The decrease behavior stated as an action with a weekly maximum

## Process

1. State the increase behavior as something a camera could record, such as read ten pages before bed, and attach a weekly minimum.
2. State the decrease behavior the same way, such as open the delivery app, and attach a weekly maximum rather than zero. Absolute bans create one failure that ends the effort.
3. Confirm both are single behaviors. Pairing a vague cluster like eat better with a single action makes the design impossible to aim.
4. Write why each matters in one sentence so the design has a reason to survive the first hard week.
