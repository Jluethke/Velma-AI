# Control Chart Type Selector

Choose the appropriate control chart type for each characteristic.

## Inputs

- `critical-characteristics`: CTQ characteristics to monitor
- `measurement-methods`: How each characteristic is measured

## Outputs

- `chart-assignments`: Control chart type assigned to each characteristic
- `sampling-plan`: Sample size, frequency, and subgroup rationale

## Process

1. Classify each characteristic as variable or attribute data
2. Select chart type: X-bar R, X-bar S, I-MR for variables; p, np, c, u for attributes
3. Define subgroup size and sampling frequency
4. Document the rationale for each selection
