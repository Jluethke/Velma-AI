# Msa Data Collector

Collect the measurements following the study design.

## Inputs

- `study-design`: Study parameters
- `data-collection-form`: Measurement form

## Outputs

- `measurement-data`: All measurements by operator, part, and replicate
- `collection-notes`: Any deviations from the study plan

## Process

1. Ensure the gage is calibrated before the study
2. Have each operator measure each part in random order without seeing previous results
3. Record all measurements on the data collection form
4. Note any anomalies or deviations from the study plan
