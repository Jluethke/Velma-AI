# Parent Communication Coordinator

Manage communications with parents including schedules, updates, weather cancellations, and feedback.

## Inputs

- `equipment-ledger`: Distribution status for parent reference
- `return-status`: Return reminders for parent communication

## Outputs

- `communication-log`: Record of all communications sent to parents
- `parent-feedback-summary`: Compiled parent feedback and satisfaction data

## Process

1. Set up the communication channel (email list, team app, text group).
2. Send regular updates (schedule changes, weather cancellations, picture day, events).
3. Collect parent feedback through a mid-season and end-of-season survey.
4. Compile feedback and produce the communication log.
