# Requirement Rewriter From Behavior

Rewrite the role requirements around the validated pattern. Replace guessed credentials with the behaviors and skills the best people actually use, and delete the requirements that predict nothing.

## Inputs

- `validated-pattern`: The behaviors and skills confirmed across performers
- `pattern-confidence`: How strong the evidence is for each

## Outputs

- `evidence-based-requirements`: The rewritten requirements, each stated in observable terms drawn from the validated pattern
- `removed-requirements`: The credential-noise requirements removed, with the reason each was cut

## Process

1. For each item in the validated pattern, write a requirement in observable terms, naming the behavior rather than a personality label.
2. Remove the credential-noise items, and state that you removed them and why, so the change is defensible.
3. Keep the requirement list short: the validated pattern, not a wish list.
4. Note that the new requirements will attract different applicants than the old ones, which is the intended result.
