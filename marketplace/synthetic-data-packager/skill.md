# Synthetic Data Packager

Package the synthetic data with documentation for downstream use.

## Inputs

- `synthetic-dataset`: Validated synthetic data
- `fidelity-report`: Fidelity and privacy audit results

## Outputs

- `data-package`: Synthetic data with metadata and documentation
- `usage-guidelines`: Guidelines for using the synthetic data

## Process

1. Format the dataset for the target consumption platform.
2. Write the data card with schema, lineage, and limitations.
3. Document the approved use cases and restrictions.
4. Package with the fidelity report and generation log.
