# Grant Proposal Compiler

Compile all sections and attachments into the final grant proposal.

## Inputs

- `needs-statement`: Problem statement
- `program-narrative`: Program description
- `evaluation-plan`: Evaluation methodology
- `grant-budget`: Line-item budget

## Outputs

- `grant-proposal`: Complete proposal ready for submission
- `submission-checklist`: Verified list of all required components

## Process

1. Assemble sections in the funder's required order
2. Write the executive summary and cover letter
3. Compile required attachments (board list, financials, letters of support)
4. Review for compliance with page limits, formatting, and submission instructions
