# Ingredient Quantity Calculator

Calculate ingredient quantities based on the menu and guest count.

## Inputs

- `proposed-menu`: Approved menu
- `event-requirements`: Guest count and service details

## Outputs

- `ingredient-list`: Itemized ingredient quantities needed
- `procurement-timeline`: When each ingredient must be ordered and delivered

## Process

1. Scale each recipe to the guest count with waste factor.
2. List all ingredients with quantities and units.
3. Identify items needing advance ordering.
4. Build the procurement timeline.
