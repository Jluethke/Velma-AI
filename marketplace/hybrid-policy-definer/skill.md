# Hybrid Policy Definer

Define the hybrid work policy based on business needs and employee input.

## Inputs

- `preference-data`: Employee preferences
- `business-requirements`: Business collaboration needs

## Outputs

- `hybrid-policy`: The hybrid work policy (days, eligibility, flexibility)
- `eligibility-criteria`: Criteria for which roles can be hybrid vs in-office

## Process

1. Balance business requirements with employee preferences
2. Define the minimum in-office days by role category
3. Set the eligibility criteria for remote and hybrid arrangements
4. Define the exception process for individual accommodations
