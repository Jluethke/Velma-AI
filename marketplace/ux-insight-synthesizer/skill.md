# Ux Insight Synthesizer

Synthesize findings into actionable design recommendations.

## Inputs

- `affinity-map`: Grouped research patterns
- `task-metrics`: Quantitative usability metrics

## Outputs

- `ux-research-report`: Findings, insights, and recommendations
- `design-recommendations`: Prioritized list of design changes

## Process

1. Translate each theme into a finding with supporting evidence
2. Derive design implications from each finding
3. Prioritize recommendations by severity and frequency
4. Write the report with executive summary and detailed findings
