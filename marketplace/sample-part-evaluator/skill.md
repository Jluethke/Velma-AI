# Sample Part Evaluator

Evaluate sample parts from the candidate supplier.

## Inputs

- `material-requirements`: Specifications
- `audit-findings`: Audit observations

## Outputs

- `sample-evaluation`: Test results and dimensional data from sample parts
- `ppap-package`: Production Part Approval Process documentation if applicable

## Process

1. Request sample parts produced on production tooling and processes
2. Inspect and test against all specification requirements
3. Evaluate dimensional data, material certifications, and functional test results
4. Review the PPAP or equivalent first article package
