# Donor Segmentation Builder

Segment donors by giving level, recency, frequency, and engagement for targeted communications.

## Inputs

- `clean-donor-database`: Validated donor records
- `organization-profile`: Description of the nonprofit and its programs

## Outputs

- `segment-definitions`: Named segments with criteria
- `segment-assignments`: Each donor assigned to segments

## Process

1. Define giving level tiers (major, mid-level, annual, first-time, lapsed)
2. Apply RFM analysis (recency, frequency, monetary value)
3. Create engagement segments (event attendees, volunteers, board members)
4. Assign every donor to at least one segment
