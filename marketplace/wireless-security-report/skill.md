# Wireless Security Report

Produce the wireless network security assessment report with findings, risk ratings, and hardening recommendations.

## Inputs

- `encryption-findings`: Encryption weaknesses
- `rogue-ap-findings`: Rogue access point detections
- `guest-segmentation-findings`: Guest network segmentation issues

## Outputs

- `wireless-security-report`: Complete wireless security assessment report
- `wireless-hardening-guide`: Wireless network hardening recommendations

## Process

1. Consolidate all findings with severity and affected SSIDs/BSSIDs.
2. Write the executive summary with the overall wireless risk posture.
3. Document each finding with evidence, impact, and specific configuration fixes.
4. Produce a wireless hardening guide covering encryption, authentication, segmentation, and monitoring.
