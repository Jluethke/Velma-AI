# Permit Completeness Verifier

Verify the application is complete and ready for technical review.

## Inputs

- `application-record`: The logged application
- `completeness-checklist`: Document checklist with submission status

## Outputs

- `verified-application`: Application confirmed complete and ready for review
- `review-routing`: Assigned reviewer and review type based on permit category

## Process

1. Confirm all required documents are present and legible.
2. Verify fees have been paid or payment is pending.
3. Route the application to the appropriate technical reviewer based on permit type.
4. Set the review deadline per the jurisdiction's processing timeline.
