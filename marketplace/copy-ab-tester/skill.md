# Copy Ab Tester

A/B test key copy elements and finalize the campaign copy.

## Inputs

- `reviewed-copy`: Brand-approved copy drafts
- `campaign-objectives`: Metrics to optimize (CTR, conversion)

## Outputs

- `winning-copy`: Final copy with winning variants selected
- `test-results`: A/B test results with statistical significance

## Process

1. Select the elements to test (headlines, CTAs, subject lines)
2. Set up A/B tests with proper sample sizes
3. Run the tests and collect performance data
4. Select the winning variants and finalize the campaign copy deck
