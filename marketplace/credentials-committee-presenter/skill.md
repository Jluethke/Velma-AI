# Credentials Committee Presenter

Present the verified file to the credentials committee.

## Inputs

- `npdb-results`: NPDB query results
- `education-verification`: Verified education and training

## Outputs

- `committee-decision`: Approved, approved with conditions, deferred, or denied
- `credentialing-file`: Complete credentialing file with all verifications

## Process

1. Compile the complete credentialing file with all verifications.
2. Present the file to the credentials committee with a summary.
3. Record the committee's decision and any conditions.
