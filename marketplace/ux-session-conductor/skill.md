# Ux Session Conductor

Conduct the research sessions.

## Inputs

- `research-plan`: Methodology and session protocol
- `participant-roster`: Scheduled participants

## Outputs

- `session-recordings`: Video or audio recordings of each session
- `observer-notes`: Real-time observations from each session

## Process

1. Set up the session environment (lab, remote tool, prototype)
2. Run each session following the protocol
3. Take notes on participant behavior and quotes
4. Debrief after each session on initial patterns
