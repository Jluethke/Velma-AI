# Reallocation Plan

Shift the capacity freed by trimming and by optimizing the middle back into the core, and project the output gain. The point of the audit is not to do less but to move effort to where it produces the most.

## Inputs

- `optimization-targets`: Middle activities to improve
- `protection-plan`: How the core is protected
- `elimination-trial-plan`: Trials freeing capacity

## Outputs

- `reallocation-plan`: Where freed capacity goes and in what order
- `expected-output-gain`: The projected result from moving effort to the core

## Process

1. Estimate the capacity freed by the elimination trials and by streamlining the optimization targets.
2. Direct that freed capacity toward the core activities with the highest ratios.
3. Project the output gain from the reallocation using the same metric as the ranking.
4. Order the moves so the core is strengthened before any freed capacity is spent elsewhere.
