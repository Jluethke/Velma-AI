# Email Brand Standards Definer

Define the brand standards for email design.

## Inputs

- `brand-guidelines`: The brand's visual identity guidelines (colors, fonts, logo)
- `email-types`: Types of emails to design for (newsletter, transactional, promotional, lifecycle)

## Outputs

- `email-brand-spec`: Email-specific brand standards (colors as hex, web-safe font stack, logo sizing, spacing rules)
- `accessibility-rules`: Accessibility requirements (contrast ratios, alt text rules, font sizes, link styling)

## Process

1. Translate the brand colors to hex values and define background, text, link, button, and accent colors.
2. Select the web-safe font stack (primary + fallback) since custom fonts render inconsistently in email.
3. Set the logo placement, size, and alt text for email headers.
4. Define the accessibility rules: minimum 14px body text, 4.5:1 contrast ratio, alt text on every image.
