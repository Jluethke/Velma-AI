# Report Template Designer

Design the automated report template and schedule delivery.

## Inputs

- `data-pipeline-spec`: How the data is extracted and transformed
- `pipeline-validation`: Confirmed data accuracy

## Outputs

- `report-template`: The report template with placeholders for automated data
- `delivery-schedule`: When and how each report is generated and distributed

## Process

1. Design the report template matching the current format.
2. Connect the template to the data pipeline.
3. Set the generation schedule and distribution list.
4. Test end-to-end: trigger, generate, deliver.
