# Processing Description

Describe the planned data processing for the new product or feature.

## Inputs

- `feature-description`: Description of the new product, feature, or system
- `technical-design`: Technical design documents or architecture diagrams

## Outputs

- `processing-summary`: Summary of all personal data processing involved (what data, why, how, where, how long)
- `data-subjects`: Categories of individuals whose data will be processed

## Process

1. Describe the feature and its purpose in plain language.
2. List all personal data that will be collected, generated, or inferred.
3. Document how the data flows through the system (collection, processing, storage, sharing, deletion).
4. Identify the categories of data subjects affected (users, employees, partners, minors).
