# Toolkit Effectiveness Review

Review the toolkit against the stress log to see which responses worked and refine the weak ones.

## Inputs

- `stress-response-matcher`: The matching guide
- `stress-log`: The ongoing record of stress episodes

## Outputs

- `effectiveness-review`: A summary of which matched responses reduced stress and which did not
- `toolkit-refinement`: Changes to tools, cues, or the structural plan where the response fell short

## Process

1. Compare recent episodes to earlier ones. A working toolkit shows acute spikes resolving faster and chronic load easing as sources are reduced.
2. For each type, judge whether the matched response actually helped. An acute reset that never gets used in time points to a cue problem, not a tool problem.
3. If chronic stress has not eased, check whether the structural change was actually made. Chronic load does not fall until the source changes, no matter how good the acute tools are.
4. Refine the weakest part. Usually it is a missing cue, a reset not yet practiced, or a structural change that was planned but never executed.
