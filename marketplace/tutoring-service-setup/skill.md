# Tutoring Service Setup

Define the tutoring or coaching service offerings, formats, and pricing.

## Inputs

- `subject-areas`: Subjects or skill areas offered
- `delivery-formats`: Delivery options (in-person, online, hybrid, group, one-on-one)

## Outputs

- `service-offerings`: Service catalog with subjects, formats, session lengths, and pricing
- `session-policies`: Policies for cancellations, makeup sessions, and refunds

## Process

1. List the subjects or skills offered and the qualification level for each.
2. Define session formats (one-on-one, small group, workshop) and durations.
3. Set pricing per format (per session, package, monthly subscription).
4. Write the cancellation, no-show, and refund policies.
