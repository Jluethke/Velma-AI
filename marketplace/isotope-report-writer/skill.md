# Isotope Report Writer

Produce the isotope analysis report with data tables, comparison plots, precision summary, and methods.

## Inputs

- `interpretation`: Contextual interpretation narrative
- `precision-report`: Precision and uncertainty assessment
- `accuracy-check`: Reference material accuracy check

## Outputs

- `isotope-report`: Complete isotope ratio analysis report
- `isotope-figures`: Delta value plots, comparison charts, and uncertainty diagrams

## Process

1. Build the data table with sample ID, delta values, and uncertainties.
2. Generate comparison plots and uncertainty diagrams.
3. Write the methods section covering preparation, measurement, and correction.
4. Compile the final report.
