# Tamper Evident Storage Manager

Store evidence in tamper-evident containers with access logging.

## Inputs

- `current-custodian`: Current custodian and storage requirements
- `integrity-status`: Current integrity status of evidence items

## Outputs

- `storage-records`: Records of evidence storage locations and access controls
- `access-log`: Log of all access to stored evidence

## Process

1. Store digital media in sealed, tamper-evident evidence bags
2. Place in a locked evidence room with access logging
3. For digital-only evidence, store in write-once media or sealed archives
4. Enable access logging for all storage locations
