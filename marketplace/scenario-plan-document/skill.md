# Scenario Plan Document

Compile the scenario plan into a document and set the review cadence.

## Inputs

- `scenario-responses`: The strategic responses for each scenario
- `signal-monitoring-plan`: The signal monitoring setup

## Outputs

- `scenario-plan-document`: The complete scenario plan: uncertainties, matrix, narratives, signals, responses, common actions, and review schedule
- `immediate-action-list`: The no-regret and option actions to execute now, before any scenario materializes

## Process

1. Compile the full document: the two uncertainties, the 2x2 matrix, the four narratives, the signal map, the four strategic responses, the common actions, and the review schedule.
2. Extract the immediate action list: no-regret moves plus options to acquire. These are your current to-do items.
3. Set the review cadence: quarterly, check the signals and update the scenario probabilities. Annually, re-assess whether the two uncertainties are still the right axes.
4. The scenario plan is not a prediction. It is a preparation. The value is in the thinking, not in being right about which quadrant materializes.
