# Loan Application Receiver

Receive and log the loan application with borrower details.

## Inputs

- `borrower-information`: Applicant name, address, SSN, employment, and income
- `loan-request`: Requested loan amount, purpose, and term

## Outputs

- `application-record`: Logged application with unique ID and timestamp
- `document-checklist`: List of required supporting documents

## Process

1. Record the borrower details and loan request into the application system.
2. Assign an application ID and timestamp.
3. Generate the document checklist based on loan type and borrower profile.
