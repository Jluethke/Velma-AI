# Pkm Tool Selector

Select the knowledge management tool and method.

## Inputs

- `note-taking-style`: How you currently take notes (digital, paper, mixed)
- `knowledge-goals`: What you want the system to do (remember, connect ideas, write from notes)

## Outputs

- `pkm-method`: Selected method (Zettelkasten, digital garden, wiki, folder system)
- `pkm-tool`: Selected tool and configuration

## Process

1. Match goals to method: connection maps to Zettelkasten, publishing to digital garden, reference to wiki.
2. Select the tool that supports the method (Obsidian, Notion, LogSeq, plain files).
3. Configure the tool with the initial folder or tag structure.
