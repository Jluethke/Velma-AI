# Thirty Sixty Ninety Goal Setter

Set 30, 60, and 90-day goals for the new hire with their manager.

## Inputs

- `hire-details`: Role and expectations
- `orientation-completion`: Orientation status

## Outputs

- `milestone-goals`: Goals for 30, 60, and 90 days
- `success-criteria`: Measurable criteria for each milestone

## Process

1. Define learning goals for the first 30 days
2. Define contribution goals for days 31 to 60
3. Define ownership goals for days 61 to 90
4. Agree on success criteria with the manager
