# Reinsurance Structure Designer

Design the reinsurance program structure.

## Inputs

- `risk-analysis`: Portfolio risk analysis and peak exposures
- `reinsurance-needs`: Identified reinsurance needs by type

## Outputs

- `program-structure`: Designed reinsurance program with layers, attachments, limits, and type (quota share, surplus, per-risk XOL, catastrophe XOL)
- `estimated-cost`: Estimated reinsurance cost by layer

## Process

1. Design the program layers with attachment points and limits.
2. Select the reinsurance type for each layer based on objectives.
3. Estimate the cost for each layer using market benchmarks.
4. Optimize the structure to balance cost and protection.
