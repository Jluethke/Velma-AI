# Personal Data Inventory

Inventory all personal data collected and processed by the organization.

## Inputs

- `product-description`: Description of products and services
- `data-systems`: Systems and third parties that handle personal data

## Outputs

- `data-inventory`: Inventory of personal data types and collection points
- `processing-map`: Map of how data flows through the organization

## Process

1. Catalog all personal data types collected (name, email, location, behavioral)
2. Map each collection point (website, app, customer service, partners)
3. Trace data flows from collection through storage and processing
