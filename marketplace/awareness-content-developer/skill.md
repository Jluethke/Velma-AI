# Awareness Content Developer

Develop training modules and assessment items that meet the learning objectives for each audience segment.

## Inputs

- `learning-objectives`: The measurable objectives to meet.
- `topic-outline`: The ordered topics to cover.

## Outputs

- `training-modules`: Short lessons with examples and scenarios keyed to each objective.
- `assessment-items`: Quiz and exercise items that test each objective against its passing standard.

## Process

1. Build a short lesson for each topic with a real-world example or scenario.
2. Key each lesson to the objective it serves so coverage is traceable.
3. Write assessment items that test each objective at its passing standard.
4. Keep the length and reading level suited to each segment.
