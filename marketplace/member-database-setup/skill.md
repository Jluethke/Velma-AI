# Member Database Setup

Set up the member database with fields for contact info, join date, membership status, groups, and roles.

## Inputs

- `organization-profile`: Name, type, and size of the organization
- `membership-categories`: Types of membership offered (full, associate, youth, honorary)

## Outputs

- `database-schema`: Field definitions and data types for the member database
- `category-definitions`: Membership categories with rights, dues, and requirements for each

## Process

1. Define the core member fields: name, contact info, join date, status (active, inactive, pending), and household grouping.
2. Add group and role fields: committees, ministry teams, volunteer roles, and leadership positions.
3. Define each membership category with its requirements, dues amount, and voting or participation rights.
4. Set up the data entry forms and import process for existing members.
