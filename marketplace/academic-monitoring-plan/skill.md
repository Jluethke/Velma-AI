# Academic Monitoring Plan

Monitor academic performance without micromanaging: check-in cadence, intervention triggers, and support resources.

## Inputs

- `current_grades`: Current academic standing
- `learning_style`: Known strengths and challenges
- `school_resources`: Available tutoring, counseling, etc.

## Outputs

- `monitoring_cadence`: When and how to check in
- `intervention_triggers`: When to step in vs let them handle it
- `support_resources`: Tutoring, study groups, school counselor

## Process

1. Set up grade monitoring access
2. Define check-in frequency by performance level
3. Identify intervention thresholds
4. Map available support resources
5. Build study skill toolkit
