# Field Progress Collector

Collect progress data from the field for schedule update.

## Inputs

- `project-name`: Name of the construction project
- `update-period`: Date range for the schedule update

## Outputs

- `progress-data`: Percent complete and actual dates for each activity
- `field-notes`: Notes on conditions affecting progress

## Process

1. Walk the site and assess percent complete for each active activity.
2. Record actual start and finish dates for completed activities.
3. Note any conditions affecting progress (weather, access, labor, material).
4. Collect input from subcontractor superintendents.
