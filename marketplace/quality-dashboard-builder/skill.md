# Quality Dashboard Builder

Build the data quality dashboard for visibility.

## Inputs

- `check-implementation`: Quality checks and their results
- `baseline-profile`: Baseline statistics for trend comparison

## Outputs

- `quality-dashboard`: Data quality dashboard with trends
- `quality-scorecard`: Summary score per dataset and dimension

## Process

1. Build summary views showing pass/fail rates per dataset.
2. Add trend charts for each quality dimension over time.
3. Include drill-down to individual rule results.
4. Create the quality scorecard with color-coded health indicators.
