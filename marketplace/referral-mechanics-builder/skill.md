# Referral Mechanics Builder

Set the referral mechanics: link, code, or in-app sharing.

## Inputs

- `incentive-structure`: Incentive design
- `product-economics`: Product context

## Outputs

- `referral-flow`: Step-by-step referral flow for the user
- `tracking-requirements`: Events and attribution to track

## Process

1. Choose the referral method (unique link, code, in-app invite)
2. Design the user flow from share to conversion
3. Define the tracking events for attribution
