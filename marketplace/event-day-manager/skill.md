# Event Day Manager

Manage event logistics on the day of the event.

## Inputs

- `venue-contract`: Venue details
- `vendor-contracts`: Vendor arrangements
- `ticket-sales-report`: Attendee list

## Outputs

- `event-execution-log`: Timeline of the event as executed
- `donation-collections`: Donations collected during the event

## Process

1. Run the setup with vendors per the timeline
2. Manage registration and guest check-in
3. Execute the program (speeches, auction, fund-a-need)
4. Collect donations and process payments on site
