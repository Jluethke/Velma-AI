# Fermentation Monitored Run

Run the designed fermentations with continuous monitoring of growth, pH, dissolved oxygen, and product titer.

## Inputs

- `experimental-design`: Run list with factor levels
- `organism-strain`: Production organism to inoculate

## Outputs

- `fermentation-time-courses`: OD, pH, DO, substrate, and product concentrations over time for each run
- `final-responses`: End-point titer, yield, and productivity for each design point

## Process

1. Prepare media according to each design point's composition.
2. Inoculate from a standardized seed culture and run fermentations under controlled conditions.
3. Sample at regular intervals for OD, pH, substrate consumption, and product titer.
4. Record dissolved oxygen and any pH or temperature excursions.
