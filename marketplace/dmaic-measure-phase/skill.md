# Dmaic Measure Phase

Measure the current process performance.

## Inputs

- `project-charter`: Project charter
- `ctq-tree`: CTQ characteristics

## Outputs

- `baseline-performance`: Current Cpk, sigma level, defect rate
- `measurement-plan`: Data collection plan and validated measurement system

## Process

1. Define the data collection plan (what, where, when, who, how)
2. Validate the measurement system (Gage R&R)
3. Collect baseline data
4. Calculate process capability (Cpk) and sigma level
