# Clinical Statistical Analysis Plan

Write the statistical analysis plan: analysis populations, primary analysis method, sensitivity analyses, subgroup analyses, and missing data handling.

## Inputs

- `endpoint-definitions`: All endpoints and their measurement properties
- `randomization-scheme`: Treatment arms and stratification
- `sample-size-report`: Expected N and power

## Outputs

- `sap-document`: Full statistical analysis plan with analysis populations, methods, and decision rules
- `mock-tables`: Shell tables and figures showing the planned layout of results
- `missing-data-strategy`: Approach to missing data (multiple imputation, mixed models, sensitivity analyses)

## Process

1. Define analysis populations (ITT, per-protocol, safety)
2. Specify the primary analysis model and its assumptions
3. Plan sensitivity analyses for departures from assumptions
4. Define subgroup analyses with multiplicity adjustment
5. Describe the missing data handling strategy and its justification
