# Calibration Cycle Improver

After each calibration cycle, improve the process. Track: how many ratings were adjusted (should decrease over time as managers learn), how long the session took, and whether managers found it valuable. If adjustments are not decreasing, the coaching is not working.

## Inputs

- `bias-pattern-report`: Documented bias patterns
- `coaching-recommendations`: Coaching points for each manager

## Outputs

- `cycle-metrics`: Adjustment rate, session duration, and manager feedback for this calibration cycle
- `process-improvements`: Changes to make for the next cycle based on what worked and what did not

## Process

1. Calculate the adjustment rate: what percentage of ratings changed during calibration? Track this across cycles. A healthy trend is 20-30% in the first cycle, declining to under 10% by the fourth cycle.
2. Collect manager feedback: Was the calibration session useful? Did it change how you will rate next time?
3. Identify process improvements: Was the session too long? (Cap at 3 hours.) Were there too many employees per session? (Cap at 20.) Did the facilitator allow discussion to become personal? (Add ground rules.)
4. Implement the improvements for the next cycle.
