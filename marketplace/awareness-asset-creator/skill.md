# Awareness Asset Creator

Create the campaign assets for each channel.

## Inputs

- `channel-plan`: Channels and formats
- `key-message`: Message to communicate

## Outputs

- `campaign-assets`: Creative assets per channel
- `asset-specs`: Specifications and file formats per asset

## Process

1. Design visual and written assets for each channel
2. Adapt the key message to each format
3. Produce final files to specification
