# Seo Fix Prioritizer

Prioritize SEO fixes by estimated traffic impact and implementation effort.

## Inputs

- `technical-issues`: Technical problems
- `on-page-issues`: On-page problems
- `keyword-gaps`: Keyword opportunities

## Outputs

- `prioritized-fixes`: Ranked list of fixes with impact and effort scores
- `seo-audit-report`: Complete SEO audit report

## Process

1. Score each issue by estimated traffic impact
2. Score each issue by implementation effort
3. Rank the fixes and produce the audit report
