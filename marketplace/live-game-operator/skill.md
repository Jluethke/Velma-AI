# Live Game Operator

Run the game operations: scoring, timekeeping, substitutions, and in-game management.

## Inputs

- `briefing-record`: Pre-game procedures confirmed
- `game-roster-sheets`: Active rosters for each team

## Outputs

- `game-result`: Final score, period scores, and key events
- `game-log`: Play-by-play or event log (goals, fouls, substitutions, injuries, ejections)

## Process

1. Manage warmups and the start-of-game procedures.
2. Operate the scoreboard and clock, recording scoring plays and penalties.
3. Track substitutions, timeouts, and any stoppages.
4. Record the final result and any incidents.
