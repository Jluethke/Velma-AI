# Influencer Performance Tracker

Track campaign performance and produce the report.

## Inputs

- `publication-schedule`: The schedule of published posts
- `campaign-brief`: The campaign goals for comparison

## Outputs

- `performance-data`: Performance data per influencer (reach, engagement, clicks, conversions)
- `influencer-campaign-report`: The complete campaign report with ROI analysis and lessons learned

## Process

1. Collect performance data for each published post (reach, impressions, engagement, clicks, conversions).
2. Calculate the cost per engagement and cost per conversion for each influencer.
3. Compare results against the campaign goals set in the brief.
4. Compile the campaign report with ROI analysis and recommendations for future campaigns.
