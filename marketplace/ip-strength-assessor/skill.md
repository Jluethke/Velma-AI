# Ip Strength Assessor

Assess the strength and scope of protection for key IP assets.

## Inputs

- `ip-inventory`: IP inventory
- `encumbrance-list`: Encumbrances on IP

## Outputs

- `strength-assessment`: Strength rating for each key IP asset
- `vulnerability-notes`: Identified weaknesses in IP protection

## Process

1. Assess patent claim scope and prosecution history
2. Evaluate trademark distinctiveness and geographic coverage
3. Review trade secret protection measures and documentation
