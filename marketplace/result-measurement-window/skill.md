# Result Measurement Window

Hold the dose steady for a measurement window and record the metric, so changes to the dose are driven by results rather than impatience.

## Inputs

- `weekly-dose-schedule`: The scheduled starting dose
- `target-metrics`: The measure for each target

## Outputs

- `result-measurements`: The metric for each target recorded across the window at the held dose
- `below-target-flag`: A flag for each target showing whether the result is at, above, or below the target

## Process

1. Hold the dose constant for a window long enough for the body to respond, usually four to six weeks, before judging anything.
2. Record the metric at the start and end of the window. Changing the dose weekly makes it impossible to tell what caused any change.
3. Compare the end metric to the target and flag each as at, above, or below. The flag, not a feeling, drives the next step.
4. Note how sustainable the dose felt. A dose that hit the target but could not be sustained is still a failed dose for the long run.
