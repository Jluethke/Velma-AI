# Supporting Argument Structure

Organize 2-4 supporting arguments under the conclusion, each answering 'why?' or 'how?'

## Inputs

- `conclusion-statement`: The main conclusion
- `reader-question`: What the reader needs to know

## Outputs

- `argument-structure`: 2-4 supporting arguments, each stated as a single sentence that directly supports the conclusion
- `argument-order`: Arguments ordered by importance or logical dependency

## Process

1. Each supporting argument answers 'why?' or 'how?' about the conclusion.
2. Limit to 2-4 arguments. More than 4 dilutes the strength of each.
3. Group arguments by type: inductive (evidence pointing the same direction) or deductive (if A and B then C).
4. Order matters: strongest first if reader might stop reading, logical order if arguments are dependent.
