# Rubric Pilot Tester

Pilot the rubric on sample student work to identify ambiguities and scoring issues.

## Inputs

- `weighted-rubric`: Rubric with dimension weights assigned
- `assignment-description`: Description of the assignment or task being assessed

## Outputs

- `pilot-results`: Scores and notes from pilot testing
- `ambiguity-log`: List of unclear or problematic descriptors

## Process

1. Select 5-10 sample student submissions spanning quality levels
2. Score each sample using the rubric
3. Note any descriptors that are ambiguous or hard to apply
4. Record the scoring results and issues found
