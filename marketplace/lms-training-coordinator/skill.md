# Lms Training Coordinator

Train administrators and instructors on using the new LMS.

## Inputs

- `configured-lms`: LMS configured and ready
- `migration-report`: Report of migrated items

## Outputs

- `training-materials`: User guides and training resources
- `lms-documentation`: Complete LMS setup and operations documentation

## Process

1. Create user guides for each role (admin, instructor, learner)
2. Conduct training sessions for administrators and instructors
3. Set up a sandbox environment for practice
4. Produce the final LMS documentation package
