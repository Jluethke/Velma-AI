# Rating Algorithm Developer

Develop the rating algorithm and rate tables for the product.

## Inputs

- `coverage-specification`: The coverage terms to be rated
- `product-requirements`: Pricing targets and competitive benchmarks

## Outputs

- `rating-algorithm`: The rating algorithm with base rates, class codes, territory factors, and modification rules
- `rate-filing-support`: Actuarial support for the rate filing including loss cost analysis and expense loading

## Process

1. Analyze loss data to develop base rates by class and territory.
2. Build the rating algorithm with factors for exposure, risk characteristics, and modifiers.
3. Load expenses, profit margin, and contingency into the rates.
4. Validate the rates against target loss ratios and competitive benchmarks.
