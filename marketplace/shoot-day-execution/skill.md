# Shoot Day Execution

Manage the photo shoot day from setup through wrap.

## Inputs

- `shoot-schedule`: The planned schedule for the day
- `shot-list`: The shots to capture

## Outputs

- `raw-captures`: All captured images from the shoot
- `shoot-day-notes`: Notes on what went as planned, what changed, and any issues

## Process

1. Set up the location, lighting, and props per the creative direction.
2. Work through the shot list, checking each shot against the brief.
3. Adapt to on-set changes (weather, timing, talent availability).
4. Wrap the set and produce the raw captures and shoot day notes.
