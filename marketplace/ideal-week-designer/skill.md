# Ideal Week Designer

Design the ideal weekly template based on the time audit.

## Inputs

- `time-log`: Audited time log
- `time-categories`: Time by category

## Outputs

- `weekly-template`: Ideal weekly time block template
- `deep-work-windows`: Protected deep work blocks

## Process

1. Allocate time to each category based on priorities, not current habits.
2. Place deep work in the highest-energy hours.
3. Group meetings into specific days or time bands.
4. Leave buffer blocks for overflow and transitions.
