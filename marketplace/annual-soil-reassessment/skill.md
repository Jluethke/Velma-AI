# Annual Soil Reassessment

Resample and compare to baseline to measure progress.

## Inputs

- `baseline-results`: Original baseline soil data
- `implementation-record`: Practices applied since baseline

## Outputs

- `progress-report`: Year-over-year comparison of soil health indicators
- `updated-plan`: Adjusted practices based on results

## Process

1. Resample fields using the same protocol as the baseline.
2. Compare new results to baseline values for each indicator.
3. Calculate the rate of change and time to target.
4. Adjust the practice plan based on what is working and what is not.
