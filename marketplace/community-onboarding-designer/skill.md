# Community Onboarding Designer

Design the onboarding flow for new community members.

## Inputs

- `community-guidelines`: The published guidelines
- `platform-choice`: The platform the community runs on

## Outputs

- `onboarding-flow`: Step-by-step flow a new member goes through on joining
- `welcome-content`: Welcome message, introduction prompts, and resource links

## Process

1. Map the new member journey from join to first interaction.
2. Write the welcome message and introduction prompt.
3. List the key channels or sections to direct new members to.
4. Set up any role assignment or verification steps.
