# Firing Decision Gate

Pass the case through the decision gate. If the person was given the full path for their problem type and the gap still persists, the decision is made for you. If the path had holes, the gate sends you back to fill them first.

## Inputs

- `will-path-finding`: Whether the will path was adequate
- `will-remedy-gaps`: Any missing will-path element

## Outputs

- `decision-determination`: Whether to separate now or to close a path gap and reassess
- `decision-record`: The path provided and the evidence of the persistent gap, recorded for fairness and defensibility

## Process

1. Check that the adequate path for the diagnosed problem type was fully provided: training and time for skill, feedback and consequence for will.
2. If any element was missing, do not decide to separate yet; close the gap and reassess after a defined period.
3. If the full path was provided and the gap persists at the agreed standard, the determination is to separate.
4. Record the determination with the path provided and the evidence of the persistent gap, which is fair to the person and sound if later questioned.
