# Model Library Expansion

Expand your model library beyond the core 10 by adding domain-specific models and retiring models that do not fit.

## Inputs

- `model-rankings`: Rankings showing which models work and which do not
- `combination-patterns`: Model combinations that work in your domain

## Outputs

- `expanded-library`: Your personalized model library (10-15 models) with definitions, trigger conditions, and personal examples for each
- `maintenance-plan`: How to keep the library current: add new models when encountered, retire models that stop producing insight, and review quarterly

## Process

1. Retire any model that produced zero insight after two full cycles. Replace it with a domain-specific model: theory of constraints (operations), Bayesian updating (data analysis), comparative advantage (career), network effects (technology), loss aversion (sales and negotiation).
2. For each new model, go through the same process: define it, find 3 personal examples, apply it for one week, and score its usefulness.
3. Cap the library at 15 models. A library too large is unused. The constraint forces you to keep only the models that actually change your decisions.
4. Review the library quarterly. Remove any model you have not applied in 3 months. Add any model you found yourself needing but did not have.
