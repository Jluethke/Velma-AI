# Donor Acknowledgment Workflow

Set up automated acknowledgment and receipting workflows for gifts.

## Inputs

- `segment-definitions`: Named donor segments
- `crm-recommendation`: Selected CRM platform

## Outputs

- `acknowledgment-templates`: Templates for thank-you letters and tax receipts by segment
- `acknowledgment-plan`: Workflow rules for timing and channel of acknowledgments

## Process

1. Define acknowledgment timing targets (48 hours for gifts, same day for major gifts)
2. Create templates by segment (personal letter for major donors, email for online gifts)
3. Set up tax receipt generation with required IRS language
4. Configure the automated workflow in the CRM
