# Failure Analysis Report Writer

Compile the failure analysis into a report with visual evidence, test results, root cause, and corrective recommendations.

## Inputs

- `root-cause`: Determined root cause and causal chain
- `fractographic-record`: Fracture surface images and annotations
- `material-test-results`: Material property data and compliance status

## Outputs

- `failure-analysis-report`: Complete failure analysis report
- `corrective-actions`: Recommended design, material, or process changes to prevent recurrence

## Process

1. Structure the report: background, visual examination, fractography, material testing, analysis, root cause, recommendations
2. Include all images, test certificates, and data tables as evidence
3. State the root cause and contributing factors clearly
4. Recommend corrective actions and prioritize by effectiveness
