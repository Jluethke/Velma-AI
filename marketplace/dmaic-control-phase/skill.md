# Dmaic Control Phase

Establish controls to sustain the improvement.

## Inputs

- `implemented-solutions`: Implemented solutions
- `improved-performance`: Post-improvement capability

## Outputs

- `control-plan`: Monitoring plan with control charts and response rules
- `dmaic-project-report`: Complete DMAIC project report with before and after data

## Process

1. Develop the control plan (what to monitor, how, who, response rules)
2. Implement control charts at the process
3. Update standard work and training materials
4. Compile the DMAIC project report and hand off to process owners
