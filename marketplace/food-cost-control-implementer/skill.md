# Food Cost Control Implementer

Implement controls to reduce food cost variance.

## Inputs

- `root-causes`: Identified variance causes
- `control-recommendations`: Recommended controls

## Outputs

- `control-plan`: Controls implemented with responsible parties
- `food-cost-report`: Final food cost report with variance, causes, and controls

## Process

1. Deploy standardized recipes with portioning tools.
2. Set up regular inventory counts.
3. Implement purchase order approval controls.
4. Schedule weekly food cost reviews.
