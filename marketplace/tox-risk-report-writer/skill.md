# Tox Risk Report Writer

Compile the full risk assessment into a structured report following regulatory formatting conventions.

## Inputs

- `risk-characterization`: Risk metrics and classification
- `uncertainty-narrative`: Description of key uncertainties
- `confidence-rating`: Overall confidence in the estimate

## Outputs

- `risk-assessment-report`: The complete risk assessment document
- `executive-summary`: One-page summary of hazard, exposure, risk, and confidence

## Process

1. Structure the report: executive summary, hazard identification, dose-response, exposure, risk characterization, uncertainty
2. Write each section referencing the supporting data
3. Include the executive summary with the bottom-line risk conclusion
4. Format tables and figures for the regulatory audience
