# Paleo Excavation Grid

Design the excavation grid, assign quadrants, and define stratigraphic logging protocols for a fossil locality.

## Inputs

- `candidate-sites`: Selected site with GPS coordinates and formation data
- `target-taxa`: Taxa or morphological targets guiding excavation depth and extent

## Outputs

- `excavation-plan`: Grid layout with quadrant IDs, datum point, and dig sequence
- `strat-log-template`: Standardized stratigraphic logging sheet with lithology codes
- `collection-protocol`: Specimen numbering, GPS tagging, and field photography standards

## Process

1. Establish a permanent datum point and orient the grid to true north
2. Divide the exposure into 1-meter quadrants and assign unique IDs
3. Define vertical excavation intervals tied to lithologic changes
4. Set field numbering, photography, and GPS tagging standards for every specimen removed
