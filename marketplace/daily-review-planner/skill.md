# Daily Review Planner

Plan a short daily review session that fits the due prompts into a fixed time box.

## Inputs

- `review-schedule`: The first review date for each prompt
- `interval-ladder`: The expanding ladder of review intervals

## Outputs

- `daily-session-plan`: A plan for the short daily review
- `due-queue-rules`: Rules for building each day's queue

## Process

1. Set a fixed daily time box of about fifteen minutes.
2. Define how due prompts are pulled into each day's queue.
3. Decide what happens when the queue is larger than the time box.
4. Pick a consistent time of day for the session.
