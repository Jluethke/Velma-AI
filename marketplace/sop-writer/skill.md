# Sop Writer

Write standard operating procedures for core lab methods with step-by-step instructions, quality criteria, and troubleshooting guides.

## Inputs

- `core-methods`: List of the primary analytical and experimental methods the lab will use
- `instrument-manuals`: Manufacturer documentation for key instruments
- `quality-standards`: Precision, accuracy, and reproducibility targets for each method

## Outputs

- `sop-collection`: Complete set of SOPs for each core method with version control
- `quality-criteria`: Acceptance criteria for each SOP including control chart limits
- `troubleshooting-guides`: Decision trees for common problems encountered in each method

## Process

1. Draft each SOP with purpose, scope, materials, procedure, and quality criteria sections
2. Include instrument startup, calibration, and shutdown in each relevant SOP
3. Write troubleshooting decision trees based on known failure modes
4. Have a second person test-run each SOP and incorporate their feedback
5. Establish version control and review schedule for each SOP
