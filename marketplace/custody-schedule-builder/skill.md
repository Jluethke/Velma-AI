# Custody Schedule Builder

Design a custody schedule considering school, activities, work schedules, and child preferences.

## Inputs

- `children_ages`: Ages of children
- `parent_work_schedules`: Both parents' work schedules
- `school_schedule`: School calendar and activities
- `geographic_distance`: Distance between homes

## Outputs

- `proposed_schedule`: Weekly and holiday custody schedule
- `transition_plan`: Pickup/dropoff logistics
- `flexibility_rules`: How to handle schedule changes

## Process

1. Map school calendar and activities
2. Overlay both parents' work schedules
3. Design base weekly schedule
4. Plan holiday and summer rotation
5. Define schedule change request process
