# Consent Category Definition

Define the consent categories and their legal basis.

## Inputs

- `collection-point-inventory`: The inventory of data collection points
- `data-purposes`: The purposes for data collection

## Outputs

- `consent-categories`: Defined consent categories (necessary, preferences, analytics, marketing) with descriptions
- `legal-basis-mapping`: Mapping of each data processing activity to its legal basis

## Process

1. Group data processing activities into consent categories (strictly necessary, functional preferences, analytics and performance, marketing and advertising).
2. Determine the legal basis for each category (consent, legitimate interest, contractual necessity, legal obligation).
3. Write the user-facing descriptions for each category in plain language.
4. Define which categories require opt-in versus opt-out under the applicable regulations.
