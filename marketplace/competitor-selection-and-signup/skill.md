# Competitor Selection And Signup

Select the competitor to tear down and sign up as a real customer using a real use case.

## Inputs

- `competitor-to-analyze`: The competitor and their product
- `use-case`: A real use case you or a test user will execute with their product

## Outputs

- `signup-experience`: Detailed notes on the signup process: time to complete, friction points, first impressions, initial value delivered
- `teardown-plan`: The 30-day plan: which features to test each week, which use cases to run, what to measure

## Process

1. Sign up as a real customer, not a demo or trial (if possible). Use a real email, provide real information, and go through the same process any customer would.
2. Document the entire signup experience second by second: how long did it take, what information was required, how quickly did you reach value, what confused you, what delighted you.
3. Plan the 30-day teardown: Week 1 = core features and primary use case. Week 2 = secondary features and edge cases. Week 3 = integrations, customization, and support experience. Week 4 = billing, upgrade/downgrade, and cancellation.
4. Set up a structured note-taking system: for each session, record the task attempted, the steps taken, friction encountered, and your emotional reaction (frustrated, confused, delighted, neutral).
