# Dashboard Layout Designer

Design the dashboard layout including grouping, visual types, and hierarchy.

## Inputs

- `selected-metrics`: Metrics with definitions
- `metric-hierarchy`: Primary, secondary, supporting grouping

## Outputs

- `layout-wireframe`: Dashboard layout showing placement of each metric and visual type
- `visual-type-map`: Which chart or visual type to use for each metric

## Process

1. Group metrics by theme or business area.
2. Assign a visual type to each metric (number tile, line chart, bar chart, table).
3. Arrange groups on the layout with primary metrics at the top.
4. Add filters, date selectors, and drill-down paths.
