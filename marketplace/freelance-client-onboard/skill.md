# Freelance Client Onboard

Onboard the client after contract signing: set up communication, access, and project tools.

## Inputs

- `signed-contract`: The executed contract
- `payment-schedule`: Agreed payment schedule

## Outputs

- `onboarding-checklist`: Completed checklist of onboarding steps
- `project-workspace`: Links and access details for the shared project workspace

## Process

1. Send the welcome email with the project timeline, key contacts, and what you need from the client.
2. Set up the shared workspace (project management tool, file sharing, communication channel).
3. Schedule the kickoff meeting and recurring check-ins.
4. Collect any materials, credentials, or assets needed from the client.
5. Confirm the client has access to all shared tools and understands the communication protocol.
