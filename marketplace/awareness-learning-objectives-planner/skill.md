# Awareness Learning Objectives Planner

Set measurable learning objectives and a topic outline for each audience segment based on its risk exposure.

## Inputs

- `audience-segments`: The staff groups to train.
- `role-risk-map`: The security risks mapped to each segment.

## Outputs

- `learning-objectives`: Measurable objectives per segment stating what staff should be able to recognize or do.
- `topic-outline`: Ordered list of topics and sub-topics that cover the objectives for each segment.

## Process

1. Turn each mapped risk into a measurable objective for the segment it affects.
2. State what staff should be able to recognize, avoid, or report after the training.
3. Order the topics so that foundational ideas come before segment-specific ones.
4. Set the minimum passing standard for each objective.
