# Career Transition Network Builder

Build a network in the target field through informational interviews, communities, and portfolio projects.

## Inputs

- `target_career`: Target field
- `current_network`: Existing contacts in or near the field
- `online_presence`: Current LinkedIn and portfolio status

## Outputs

- `networking_plan`: Weekly networking activities
- `informational_interview_list`: People to request conversations with
- `portfolio_plan`: Projects to build credibility

## Process

1. Identify communities and groups in target field
2. List potential informational interview targets
3. Update LinkedIn for career change narrative
4. Plan portfolio or sample projects
5. Set weekly networking activity targets
