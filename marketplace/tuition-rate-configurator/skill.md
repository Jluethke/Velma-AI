# Tuition Rate Configurator

Set up the tuition rates and fee schedule for the childcare program.

## Inputs

- `program-list`: List of programs offered with age groups and schedules (full-time, part-time, drop-in)
- `cost-analysis`: Operating cost per child by program type

## Outputs

- `rate-schedule`: Published tuition rates by program, schedule, and any sibling or multi-day discounts
- `fee-policy`: Late payment fees, registration fees, supply fees, and other charges

## Process

1. Calculate the break-even tuition per child by program type based on operating costs.
2. Set the tuition rates with margin targets for each program.
3. Define the discount structure (sibling discounts, multi-child, prepayment).
4. Document the fee schedule (registration, late pickup, late payment, returned check).
5. Publish the rate schedule and fee policy.
