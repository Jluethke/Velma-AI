# Design Production Exporter

Produce the final design files in all required formats.

## Inputs

- `refined-design`: Approved final design
- `clarified-brief`: Delivery specifications

## Outputs

- `design-deliverables`: Final files in all required formats (print, web, social)
- `production-specs`: Print specifications or digital asset dimensions

## Process

1. Export print-ready files with bleed, crop marks, and color profiles
2. Export digital formats at correct resolutions and color spaces
3. Prepare an asset inventory listing all files and specifications
4. Deliver the package to the client with usage notes
