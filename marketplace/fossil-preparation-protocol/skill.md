# Fossil Preparation Protocol

Stabilize, clean, and prepare fossil specimens for study using mechanical and chemical techniques appropriate to matrix type.

## Inputs

- `excavation-plan`: Grid and collection data for recovered specimens
- `matrix-type`: Lithology of enclosing sediment (sandstone, limestone, shale, etc.)

## Outputs

- `prepared-specimens`: Catalog of cleaned, stabilized specimens with preparation notes
- `preparation-log`: Methods, consolidants, and tools used per specimen

## Process

1. Assess each specimen for fragility, consolidant needs, and matrix hardness
2. Apply mechanical preparation (air scribe, pin vise) or chemical preparation (acetic acid, formic acid) as matrix dictates
3. Stabilize with appropriate consolidant (Paraloid B-72, cyanoacrylate) and document every application
4. Photograph each specimen at standard angles before and after preparation
