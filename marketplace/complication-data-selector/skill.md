# Complication Data Selector

Select the single data point or finding that disrupts the situation. The complication is the reason this data matters. Without a complication, data is a status report, not a story.

## Inputs

- `situation-statement`: The shared context
- `data-relevance-filter`: Which data matters for the decision

## Outputs

- `complication-finding`: The single data point that disrupts the status quo
- `complication-chart`: Specification for the one chart that shows the complication, with title as the conclusion

## Process

1. Find the data point that breaks the audience's expectation. The complication is the gap between what they expected and what the data shows.
2. If multiple data points complicate the story, pick the one with the largest gap from expectation. One complication per story.
3. Specify the chart: the title is the conclusion ('Retention dropped 22% after pricing change'), not a description ('Q3 Retention Rates').
4. Annotate the chart to guide the eye: highlight the data point, add a reference line for the expectation, label the gap.
