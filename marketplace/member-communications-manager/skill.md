# Member Communications Manager

Manage ongoing member communications including newsletters, announcements, and the member directory.

## Inputs

- `registration-workflow`: How members are registered and categorized
- `onboarding-checklist`: New member onboarding items

## Outputs

- `communication-plan`: What is sent, to whom, how often, and through which channels
- `directory-policy`: What member info is shared in the directory and who can access it

## Process

1. Define the communication types: weekly newsletter, event announcements, leadership updates, prayer requests or support needs.
2. Set the channels and frequency for each type: email, text, bulletin board, app notification.
3. Create the member directory with opt-in fields (phone, email, address, photo) and access controls.
4. Set up segmented lists so communications reach the right groups (all members, committee members, youth families).
