# Internal Audience Segmenter

Identify the internal audience segments and their communication needs.

## Inputs

- `organization-structure`: The organizational structure (departments, teams, levels, locations)
- `communication-goals`: What the internal communications program aims to achieve

## Outputs

- `audience-segments`: Defined internal audience segments with size and communication needs
- `communication-types`: Types of internal communications needed (all-hands update, department news, leadership message, policy update, event notice)

## Process

1. Map the organization into audience segments (all employees, department, leadership, location, project team).
2. Identify the communication types each segment needs.
3. Set the priority and frequency for each communication type.
4. Document the distribution channels for each segment.
