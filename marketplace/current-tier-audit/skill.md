# Current Tier Audit

Document the current tiers, prices, and what each one includes, so the decoy is built on facts.

## Inputs

- `pricing-data`: Current tiers, prices, and conversion by tier
- `feature-list`: The full list of features and which tier holds each

## Outputs

- `tier-map`: A clear map of tiers, prices, and included value
- `value-gaps`: Where the jump between tiers is confusing or poorly justified

## Process

1. Lay out each tier with its price and the value a buyer gets at that price.
2. Record the share of buyers who pick each tier today, since that is the baseline you will move.
3. Mark where the gap between two tiers is hard for a buyer to reason about.
4. Note any tier that almost nobody chooses, since it may already be acting as an accidental decoy.
