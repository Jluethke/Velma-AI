# Engagement Report Writer

Produce the final engagement survey report.

## Inputs

- `results-analysis`: Analysis
- `action-plan`: Action plan
- `response-rate`: Response rates

## Outputs

- `engagement-report`: Final survey report for the record
- `lessons-learned`: Process improvements for the next survey cycle

## Process

1. Compile the full report with methodology, results, and actions
2. Document the response rate and participation trends
3. Record lessons learned for improving the next cycle
4. File the report for year-over-year tracking
