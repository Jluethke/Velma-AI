# Pilot Data Collector

Administer the item pool to a pilot sample and collect response data for psychometric analysis.

## Inputs

- `item-pool`: candidate items after expert review
- `target-population`: characteristics of the population the instrument serves

## Outputs

- `pilot-response-data`: item-level response matrix from the pilot sample
- `sample-demographics`: demographic description of the pilot sample

## Process

1. Determine the required sample size (at least 5-10 respondents per item for factor analysis)
2. Recruit a pilot sample representative of the target population
3. Administer the item pool and collect responses
4. Screen for careless responding (response time, invariance, attention checks)
