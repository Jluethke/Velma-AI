# Mutual Commitment Recorder

End each meeting with one commitment from each side. A single concrete commitment each turns the conversation into action and makes the next meeting's follow-up obvious.

## Inputs

- `obstacle-list`: The open obstacles
- `manager-action-items`: The manager's actions

## Outputs

- `commitment-pair`: One concrete commitment from the report and one from the manager before the next meeting
- `commitment-log`: Both commitments recorded where both sides can see them

## Process

1. Before closing, agree one commitment the report will make and one the manager will make before the next meeting.
2. Keep each to a single concrete action, not a list, so it actually gets done.
3. Record both commitments where both sides can see them.
4. Make the commitments specific enough that at the next meeting it is clear whether each happened.
