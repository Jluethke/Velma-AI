# Report Led Agenda Builder

Give the report a simple way to build the agenda before each meeting. When the report prepares, the meeting is about what they need; when they do not, it drifts back to a manager monologue.

## Inputs

- `meeting-charter`: The meeting's purpose
- `cadence-decision`: The agreed frequency

## Outputs

- `agenda-template`: A short shared agenda the report fills in before each meeting
- `prep-prompts`: Prompts that cue the report toward priorities, blockers, and growth

## Process

1. Provide a short shared agenda the report fills in before each meeting.
2. Include prompts: what do you want to prioritize, what is blocking you, where do you want to grow.
3. Ask the report to add items as they come up during the week, so nothing waits for memory.
4. Let the manager add at most one or two items, clearly marked, so the meeting stays the report's.
