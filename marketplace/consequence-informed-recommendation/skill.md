# Consequence Informed Recommendation

Produce the recommendation based on the full consequence tree. State which option you recommend, why, and specifically which second-order effects changed the analysis. Include the monitoring plan for third-order tail risks.

## Inputs

- `consequence-comparison`: The comparison across all levels
- `ranking-shifts`: Where rankings changed at deeper levels

## Outputs

- `recommendation`: The recommended option with the specific second-order reasoning that led to it
- `monitoring-plan`: What to watch for as the decision plays out: early signals of second and third-order effects materializing

## Process

1. State the recommendation and the single most important second-order effect that drove it.
2. If the recommendation differs from the first-order obvious choice, explain why in one sentence.
3. For the recommended option, list the second-order effects to monitor as the decision plays out.
4. Set review dates to check whether the predicted second-order effects are materializing or not.
