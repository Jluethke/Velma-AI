# Service Catalog Publisher

Publish the catalog and establish the review cadence.

## Inputs

- `service-definitions`: All service definitions
- `request-workflows`: Request fulfillment workflows
- `category-hierarchy`: Category structure

## Outputs

- `published-catalog`: The published service catalog
- `review-schedule`: Quarterly review and update schedule

## Process

1. Assemble all definitions, categories, and workflows into the catalog format.
2. Publish to the self-service portal.
3. Announce the catalog to all users with instructions.
4. Schedule the first quarterly review.
