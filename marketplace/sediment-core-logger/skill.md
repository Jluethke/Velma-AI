# Sediment Core Logger

Log the sediment core with visual description, photography, and non-destructive measurements.

## Inputs

- `core-sections`: Split core halves with depth markings
- `site-metadata`: Coring location, water depth, and collection method

## Outputs

- `core-log`: Visual description, color (Munsell), texture, and boundaries at each depth
- `core-photos`: High-resolution photographs of each section

## Process

1. Photograph each section under consistent lighting with a color card and ruler.
2. Describe sediment color using Munsell charts, texture, visible structures, and fossil content.
3. Mark lithological boundaries and note any disturbance from coring.
4. Run non-destructive scans (magnetic susceptibility, XRF core scanning) if available.
