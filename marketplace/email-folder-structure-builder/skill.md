# Email Folder Structure Builder

Set up folders or labels for organized email.

## Inputs

- `processing-rules`: Processing rules per email type
- `email-types`: Types of email received

## Outputs

- `folder-structure`: Folder or label hierarchy
- `archive-policy`: What gets archived and what gets deleted

## Process

1. Create folders aligned with the processing rules (action, waiting, reference, archive).
2. Keep the folder count under 10 to avoid decision fatigue.
3. Define the archive vs delete policy.
