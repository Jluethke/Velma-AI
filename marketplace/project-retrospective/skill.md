# Project Retrospective

Review the finished project against the proof criteria and plan the next build.

## Inputs

- `research-log`: A log of what you researched and learned
- `proof-criteria`: The evidence that would prove you have the skill

## Outputs

- `skill-evidence`: The evidence the project produced
- `next-project-ideas`: Next projects that stretch the weak sub-skills

## Process

1. Check the finished project against the proof criteria.
2. Note which sub-skills are solid and which are still weak.
3. Choose a next project that stretches the weak sub-skills.
4. Record what you would do differently next time.
