# Root Cause Investigator

Investigate the root cause of the problem.

## Inputs

- `problem-record`: The problem record
- `investigation-scope`: What to investigate and by when

## Outputs

- `root-cause`: Identified root cause with evidence
- `workaround`: Interim workaround if available

## Process

1. Collect logs, metrics, and configuration data from the affected systems.
2. Apply root cause analysis techniques (5 Why, fault tree, timeline analysis).
3. Identify and document the root cause with supporting evidence.
4. Define an interim workaround if the permanent fix will take time.
