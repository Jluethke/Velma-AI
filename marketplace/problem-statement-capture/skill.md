# Problem Statement Capture

State the problem you are trying to solve in positive terms, then invert it.

## Inputs

- `problem-description`: The problem or goal stated normally (e.g., 'How do we increase customer retention?')
- `context`: The situation and constraints around the problem

## Outputs

- `positive-statement`: The goal stated positively: 'We want to achieve X'
- `inverted-statement`: The goal inverted: 'How would we guarantee the opposite of X? How would we make sure we LOSE customers?'

## Process

1. Write the goal in one sentence, positively: 'We want to [achieve something specific].'
2. Invert it: 'How would we guarantee the opposite? How would we make absolutely certain that we fail at this?'
3. The inversion should feel slightly absurd. 'How would we guarantee that every customer leaves?' That absurdity makes it easier to think of answers because failure modes are more vivid than success factors.
4. Write the inverted question on a whiteboard or at the top of a document. This is now the question everyone will answer.
