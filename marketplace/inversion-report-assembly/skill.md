# Inversion Report Assembly

Produce the final inversion report: the original goal, the inverted question, the failure paths (especially non-obvious ones), the avoidance rules, the strategy, current failure behaviors, and immediate corrections. This document becomes the reference for ongoing strategy checks.

## Inputs

- `inversion-strategy`: The inversion-derived strategy
- `current-failure-behaviors`: Failure behaviors already in progress
- `immediate-corrections`: Changes to make this week
- `forward-gap-analysis`: Blind spots forward thinking missed

## Outputs

- `inversion-report`: Complete inversion analysis: goal, failure paths, avoidance rules, strategy, current gaps, and corrections
- `review-schedule`: When to revisit the inversion analysis (quarterly recommended) and what to check

## Process

1. Compile all sections into a single document: goal, inverted question, failure paths, avoidance rules, strategy, current failures, corrections.
2. Highlight the non-obvious failure paths and the forward-gap findings. These are the unique value of the inversion approach.
3. Set a quarterly review date to re-run the inversion against current reality.
4. At each review, ask: have new failure paths emerged? Are any avoidance rules being violated?
