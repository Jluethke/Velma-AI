# Ir Scenario Definition

Define the incident scenario including attack vector, scope, and injects for the tabletop exercise.

## Inputs

- `organization-context`: Description of the organization's infrastructure and threat landscape
- `exercise-objectives`: What the exercise aims to test (detection, escalation, recovery, communication)

## Outputs

- `scenario-document`: Written scenario with timeline, injects, and expected discussion points
- `participant-guide`: Guide for participants including roles and ground rules

## Process

1. Select the incident type based on the organization's threat profile (ransomware, data breach, insider threat, DDoS)
2. Write the scenario narrative with a realistic attack chain
3. Prepare injects (new information revealed at timed intervals during the exercise)
4. Define success criteria for each phase of the response
