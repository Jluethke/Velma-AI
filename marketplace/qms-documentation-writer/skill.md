# Qms Documentation Writer

Write procedures, work instructions, and forms.

## Inputs

- `process-map`: Process interaction diagram
- `process-owners`: Process owners

## Outputs

- `documented-procedures`: Required procedures and work instructions
- `forms-and-records`: Record templates for each process

## Process

1. Write mandatory documented information required by ISO 9001
2. Write procedures for each core process in a consistent format
3. Create work instructions for critical operations
4. Design forms and record templates for objective evidence
