# Coding Scheme Definer

Define the coding scheme: codes, definitions, inclusion and exclusion criteria for each code, and anchor examples.

## Inputs

- `research-question`: What the coding is meant to capture
- `sample-data`: A representative sample of the data to be coded

## Outputs

- `codebook-draft`: Complete codebook with codes, definitions, criteria, and examples
- `ambiguity-notes`: Known edge cases and how they should be handled

## Process

1. Read the sample data and identify the constructs to be coded.
2. Write a definition for each code with clear inclusion and exclusion boundaries.
3. Select anchor examples that illustrate clear cases and borderline cases.
4. Document known ambiguities and the decision rule for each.
