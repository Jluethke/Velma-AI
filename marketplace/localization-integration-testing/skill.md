# Localization Integration Testing

Integrate the localized content and test it in context.

## Inputs

- `reviewed-content`: The reviewed and corrected translations
- `source-content`: The original content for comparison

## Outputs

- `integrated-content`: The localized content integrated into the product or platform
- `localization-record`: Complete localization record (scope, translations, reviews, testing)

## Process

1. Import the translated strings into the product or CMS.
2. Test each locale for text overflow, truncation, layout breaks, and encoding issues.
3. Verify links, images, and dynamic content in each locale.
4. Produce the integrated content and localization record.
