# File Upload Security Report

Produce the file upload security test report with all findings and remediation steps.

## Inputs

- `storage-security-findings`: Storage security findings
- `access-control-gaps`: Access control gaps

## Outputs

- `upload-report`: Complete file upload security report
- `remediation-plan`: Prioritized remediation plan

## Process

1. Compile all findings with upload examples and evidence
2. Rate each finding by severity and exploitability
3. Recommend content-type validation, storage isolation, and execution prevention
