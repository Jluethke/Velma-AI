# Campaign Summary Report

Synthesize all campaign datasets into a summary report documenting key findings, data quality, and recommendations for follow-up.

## Inputs

- `model-evaluation`: Model performance against observations
- `source-attribution`: Source region analysis results
- `boundary-layer-heights`: BL structure and turbulence findings

## Outputs

- `campaign-report`: Integrated campaign summary with key findings, data inventory, and quality flags
- `data-archive-manifest`: File inventory, formats, and metadata for archival in a public repository

## Process

1. Summarize the meteorological context of the campaign period relative to climatology
2. Highlight the key scientific findings supported by the observational and modeling evidence
3. Document data quality, known issues, and recommended corrections for each instrument
4. Prepare the data archive with standardized file formats, metadata, and DOI registration
