# Load Test Scenario Definer

Define the load test scenarios including target metrics, user journeys, and acceptance criteria.

## Inputs

- `application-endpoints`: List of endpoints and user journeys to test
- `performance-requirements`: Target throughput, latency, and error rate thresholds

## Outputs

- `test-scenarios`: Defined load test scenarios with parameters
- `acceptance-criteria`: Pass/fail criteria for each scenario

## Process

1. Identify the critical user journeys to simulate
2. Define the target load levels (concurrent users, requests per second)
3. Set latency and error rate thresholds for each endpoint
4. Document the acceptance criteria for the campaign
