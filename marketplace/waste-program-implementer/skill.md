# Waste Program Implementer

Implement the waste management improvements and train staff.

## Inputs

- `reduction-targets`: Targets and timeline
- `improvement-plan`: Infrastructure and training plan

## Outputs

- `implementation-record`: Record of changes made (bins, signage, contracts, training)
- `training-materials`: Training materials for employees on proper sorting

## Process

1. Install or reconfigure bins, compactors, and collection points per the plan.
2. Update waste hauler contracts to add or modify streams (organics, e-waste, textiles).
3. Train employees on proper sorting with hands-on demonstrations.
4. Set up the monthly tracking process for tonnage and diversion rate.
