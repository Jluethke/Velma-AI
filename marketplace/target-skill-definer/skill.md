# Target Skill Definer

Define the skill to learn and the evidence that would prove you have it.

## Inputs

- `skill-to-learn`: The skill you want to build
- `motivation-context`: Why you want it and how you will use it

## Outputs

- `skill-definition`: The skill stated in terms of what you can do
- `proof-criteria`: The evidence that would prove you have the skill

## Process

1. State the skill in terms of what you want to be able to do.
2. Define the observable evidence that would prove you can do it.
3. List the core sub-skills the project should exercise.
4. Confirm the proof criteria are checkable by someone else.
