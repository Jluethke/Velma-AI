# Phenotype Scoring Protocol

Score phenotypic traits at defined growth stages using standardized scales for morphology, disease resistance, and agronomic performance.

## Inputs

- `selected-entries`: Entries being evaluated with their target traits
- `randomization-plan`: Plot map for systematic scoring order

## Outputs

- `phenotype-data`: Scored trait values per plot per scoring date
- `scoring-notes`: Observer notes on off-types, lodging, bird damage, or border effects

## Process

1. Define the trait list, scoring scale, and growth stage for each observation
2. Train scorers on the scale with reference photographs and calibration plots
3. Score plots in serpentine order within each replicate to minimize environmental trend bias
4. Enter data same-day and run range checks to catch transcription errors
