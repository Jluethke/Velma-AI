# Rag Corpus Curator

Select and prepare the document corpus for retrieval.

## Inputs

- `use-case`: What questions the RAG system must answer
- `source-documents`: Available document sources

## Outputs

- `curated-corpus`: Selected and cleaned document collection
- `corpus-metadata`: Statistics on corpus size, types, and coverage

## Process

1. Inventory the available document sources.
2. Select documents relevant to the use case.
3. Clean and normalize the document formats.
4. Catalog the corpus with metadata.
