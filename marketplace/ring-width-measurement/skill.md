# Ring Width Measurement

Measure ring widths from prepared core or cross-section samples under a stereomicroscope with a measuring stage.

## Inputs

- `prepared-samples`: Sanded tree cores or cross-sections mounted for measurement
- `measurement-setup`: Stage calibration, software, and measurement protocol

## Outputs

- `raw-ring-widths`: Annual ring-width measurements for each sample in standard format (Tucson decadal)
- `sample-metadata`: Species, site, core ID, and measurement notes for each sample

## Process

1. Verify sample surface preparation is adequate for ring boundary visibility
2. Calibrate the measuring stage and set the resolution
3. Measure each ring from pith to bark, recording widths in the standard Tucson decadal format
4. Flag any problematic rings (false rings, missing rings, compression wood) for crossdating attention
