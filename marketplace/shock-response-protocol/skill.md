# Shock Response Protocol

Write the response protocol for each shock category so that decisions are made before the crisis, not during it.

## Inputs

- `reserve-targets`: The reserve amounts and access instructions
- `fragility-fixes`: The redundancies in place

## Outputs

- `shock-response-playbooks`: For each shock category: the first 72-hour actions, the 30-day stabilization plan, and the 90-day recovery plan
- `decision-authorities`: Who can authorize reserve drawdowns, contract terminations, and emergency spending, and the thresholds for each

## Process

1. For each shock category, write the first 72 hours: who is contacted, what is activated (insurance, reserves, backup systems), and what is paused (non-essential spending, discretionary commitments).
2. Write the 30-day stabilization plan: how to reduce obligations to match the new reality, how to activate the redundancies, and how to communicate to stakeholders.
3. Write the 90-day recovery plan: how to rebuild from the reduced state, what to invest in, and what to let go permanently.
4. Store the playbooks where they can be found by someone other than you. A playbook locked in your own head fails if you are the one incapacitated.
