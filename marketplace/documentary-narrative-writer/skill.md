# Documentary Narrative Writer

Write the narrative structure and paper edit.

## Inputs

- `transcripts`: Interview transcripts with tags
- `thesis-statement`: Central argument of the film

## Outputs

- `paper-edit`: Written narrative sequence with selected quotes and b-roll notes
- `narration-script`: Voiceover narration script if needed

## Process

1. Arrange the strongest quotes and scenes into a narrative arc
2. Write transitions and narration to connect the sections
3. Verify the narrative supports the thesis
4. Finalize the paper edit as the blueprint for editing
