# Evaluation Report Writer

Write the evaluation report with recommendations.

## Inputs

- `findings`: Key findings
- `data-visualizations`: Supporting charts and tables

## Outputs

- `evaluation-report`: Complete evaluation report
- `action-recommendations`: Prioritized recommendations for program improvement

## Process

1. Write the executive summary with headline findings
2. Present findings by evaluation question with supporting evidence
3. Develop actionable recommendations prioritized by impact and feasibility
4. Include a section on limitations and suggestions for future evaluation
