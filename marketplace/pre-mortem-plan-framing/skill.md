# Pre Mortem Plan Framing

Frame the plan or decision for a pre-mortem: state the plan in one sentence, define what success looks like, define what failure looks like, and set the time horizon. A clear frame prevents vague failure stories.

## Inputs

- `plan-description`: The plan, project, or decision to pre-mortem
- `success-criteria`: What a successful outcome looks like in concrete terms
- `time-horizon`: When the plan would be evaluated (3 months, 1 year, etc.)

## Outputs

- `framed-plan`: One-sentence plan statement with success and failure definitions
- `failure-definition`: Concrete description of what failure looks like at the time horizon

## Process

1. Compress the plan into one sentence that a stranger could understand.
2. State the success criteria in measurable terms (a number, a state, a deliverable).
3. State the failure criteria in equally measurable terms.
4. Set the evaluation date. Vague time horizons produce vague failure stories.
