# Eval Criteria Definition

Define evaluation criteria and use cases for the security tool.

## Inputs

- `tool-candidates`: Security tools to evaluate
- `use-case-requirements`: What the tool needs to do in the environment

## Outputs

- `eval-criteria`: Weighted evaluation criteria
- `test-plan`: Specific tests to run against each criterion

## Process

1. Define detection accuracy criteria: true positive rate, false positive rate
2. Define operational criteria: performance impact, integration ease, alert quality
3. Weight criteria by importance to the specific deployment context
