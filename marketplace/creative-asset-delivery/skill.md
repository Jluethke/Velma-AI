# Creative Asset Delivery

Deliver the final creative assets and close out the project.

## Inputs

- `production-deliverables`: The approved deliverables
- `final-change-list`: Any last changes to apply

## Outputs

- `delivered-assets`: The final assets in all required formats and sizes
- `creative-project-record`: Complete project record (brief, concepts, revisions, approvals, final assets)

## Process

1. Apply any remaining changes from the final change list.
2. Export the assets in all required formats, sizes, and specifications.
3. Deliver the assets to the requestor with usage notes.
4. Archive the project record.
5. Produce the delivered assets and project record.
