# Communication Platform Selector

Select and configure the communication platform for parent-center communication.

## Inputs

- `center-size`: Number of enrolled families and classrooms
- `communication-needs`: Required communication types (daily reports, billing, announcements, emergencies, messaging)

## Outputs

- `platform-selection`: Selected communication platform with the setup configuration
- `channel-structure`: Communication channels defined (center-wide, classroom-specific, individual family, emergency)

## Process

1. Evaluate communication platforms against the center's needs (daily reporting, photo sharing, billing, messaging).
2. Select the platform that covers the required features within the budget.
3. Define the channel structure (center-wide announcements, per-classroom updates, individual family messaging, emergency broadcast).
4. Configure the platform with the center's branding and settings.
