# Case Study Project Selection

Select a project for the case study and get client permission.

## Inputs

- `completed-projects`: List of completed projects with outcomes
- `portfolio-gaps`: What your current portfolio is missing (industries, services, outcomes)

## Outputs

- `selected-project`: The project selected for the case study with rationale
- `client-permission`: Written permission from the client to use the project in your portfolio

## Process

1. Review completed projects and rank by strength of results, relevance to target clients, and visual appeal.
2. Identify which project fills the biggest gap in your current portfolio.
3. Contact the client and request permission to feature the project, specifying what you will share.
4. If the client declines naming, agree on an anonymized version (industry and results without the company name).
