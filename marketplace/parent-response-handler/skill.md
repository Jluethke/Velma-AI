# Parent Response Handler

Handle parent responses and questions about the daily report.

## Inputs

- `daily-reports`: The sent daily reports
- `distribution-confirmation`: Confirmation of report delivery

## Outputs

- `parent-feedback-log`: Log of parent questions, comments, and any follow-up actions needed
- `next-day-notes`: Notes to carry forward to the next day based on parent input

## Process

1. Monitor for parent responses to the daily reports.
2. Answer questions about the child's day (meals, naps, activities).
3. Log any parent requests or instructions for the following day.
4. Escalate any concerns that require a director or lead teacher conversation.
