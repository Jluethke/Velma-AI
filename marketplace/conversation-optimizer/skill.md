# Conversation Optimizer

Analyze the data and recommend optimizations.

## Inputs

- `analytics-dashboard`: Performance data to analyze
- `alert-rules`: Triggered alerts and trends

## Outputs

- `optimization-recommendations`: Prioritized list of changes to improve performance
- `conversational-analytics-report`: Complete report with metrics, trends, and action items

## Process

1. Identify the lowest-performing intents by resolution rate and volume.
2. Analyze the most common escalation paths and failure points.
3. Recommend dialog changes, training data additions, and routing adjustments.
4. Compile the report with metrics, trends, and prioritized recommendations.
