# Spending Category Inventory

List every spending category and the current allocation to each.

## Inputs

- `budget-data`: Current spending by category (marketing, R&D, operations, sales, admin, personal categories, etc.)
- `time-period`: The period being analyzed (monthly or quarterly)

## Outputs

- `spending-table`: Each category with its current spending and the primary return metric (revenue generated, time saved, risk reduced)
- `total-spend`: Total spending across all categories

## Process

1. List every spending category. Include both obvious categories (marketing, sales) and hidden ones (time spent on admin, opportunity cost of activities).
2. For each category, record the current spending per period.
3. For each category, identify the primary return metric. Marketing returns revenue. Training returns skill. Insurance returns risk reduction. Choose one metric per category.
4. If you are doing this for personal finances, the categories might be: housing, food, transportation, education, health, entertainment, savings. The return metric for each is the value it adds to your life per dollar spent.
