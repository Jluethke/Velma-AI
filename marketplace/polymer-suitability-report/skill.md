# Polymer Suitability Report

Compile all characterization data into a suitability report evaluating the polymer against the original application requirements.

## Inputs

- `mechanical-data`: Baseline mechanical properties
- `thermal-properties`: Thermal transition and stability data
- `aging-curves`: Property retention under accelerated aging

## Outputs

- `suitability-report`: Pass/fail assessment per requirement with supporting data and recommendations
- `scale-up-notes`: Process adjustments needed for pilot or production scale

## Process

1. Tabulate each application requirement against measured property values
2. Score pass/marginal/fail for each requirement with the supporting data reference
3. Identify any property gaps and propose formulation or compounding modifications
4. Outline scale-up considerations: reactor size, mixing, cooling, and quality control points
