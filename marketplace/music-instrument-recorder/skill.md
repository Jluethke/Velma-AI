# Music Instrument Recorder

Record or program the instruments for each part.

## Inputs

- `arrangement-chart`: Song structure and chord progressions
- `instrument-plan`: Instruments and parts to record

## Outputs

- `raw-tracks`: Individual audio tracks for each instrument
- `session-notes`: Notes on takes, tuning, and mic positions

## Process

1. Set up microphones and signal chain for each instrument
2. Record each instrument part with multiple takes
3. Program MIDI parts for synthesizers and virtual instruments
4. Log the best takes and any comping notes
