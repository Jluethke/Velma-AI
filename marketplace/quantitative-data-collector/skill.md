# Quantitative Data Collector

Collect and compile quantitative output and outcome data.

## Inputs

- `outcome-framework`: Outcomes and indicators
- `data-collection-plan`: Data sources and methods

## Outputs

- `quantitative-results`: Numbers for each indicator
- `data-quality-notes`: Notes on data completeness and limitations

## Process

1. Pull data from program databases, surveys, and administrative records
2. Calculate values for each indicator
3. Check for data quality issues (missing data, outliers)
4. Document any limitations or caveats
