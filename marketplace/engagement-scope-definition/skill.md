# Engagement Scope Definition

Define the network penetration test scope, rules of engagement, target IP ranges, and obtain authorization.

## Inputs

- `target-network`: IP ranges and network segments to test
- `authorization-document`: Written permission for the engagement

## Outputs

- `network-scope`: In-scope and out-of-scope IP ranges and systems
- `engagement-rules`: Testing constraints, escalation contacts, and test windows

## Process

1. Review authorization to confirm all target ranges are explicitly permitted.
2. Define testing windows and notification procedures.
3. Identify critical systems that require extra caution.
4. Set escalation procedures for unexpected findings (e.g., active compromise).
