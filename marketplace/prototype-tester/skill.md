# Prototype Tester

Test the prototype with sample users and document findings.

## Inputs

- `built-prototype`: The working prototype
- `prototype-url`: Where to access it

## Outputs

- `test-findings`: Usability issues and feedback from testers
- `prototype-documentation`: Documentation of the prototype's features, data model, and known limitations

## Process

1. Have 3 to 5 people walk through the main user flows.
2. Observe where they get stuck or confused.
3. Record the issues and prioritize fixes.
4. Document the prototype's current state, limitations, and next steps.
