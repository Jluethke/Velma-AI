# Replication Designer

Design the replication study with pre-registration, specifying exact procedures, sample size based on original effect, and decision criteria.

## Inputs

- `extracted-protocol`: Original protocol with ambiguities noted
- `validity-assessment`: Identified methodological concerns from the critique
- `replication-type`: Direct (exact), close (minor adaptations), or conceptual replication

## Outputs

- `replication-protocol`: Complete protocol for the replication with all decisions documented
- `pre-registration`: Pre-registration document for OSF or equivalent registry
- `power-analysis`: Sample size calculation using the original effect size with safeguard power

## Process

1. Resolve each ambiguity in the original protocol with a documented decision and justification
2. Calculate required sample size using the original effect size at 95% power (safeguard approach)
3. Write the pre-registration specifying hypotheses, methods, and analysis plan
4. Define replication success criteria (significance, effect size within CI, equivalence test)
5. Submit pre-registration to OSF before any data collection
