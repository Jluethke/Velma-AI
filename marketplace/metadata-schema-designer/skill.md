# Metadata Schema Designer

Define the metadata schema with technical, business, and operational dimensions.

## Inputs

- `asset-inventory`: Inventory of data assets
- `governance-requirements`: Governance and compliance requirements

## Outputs

- `metadata-schema`: Defined metadata schema for the catalog
- `classification-taxonomy`: Taxonomy for classifying data assets

## Process

1. Define technical metadata fields (schema, type, format, size, freshness).
2. Define business metadata fields (description, owner, domain, use cases).
3. Define operational metadata (SLAs, quality scores, access frequency).
4. Create the classification taxonomy (domain, sensitivity, criticality).
