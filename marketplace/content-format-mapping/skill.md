# Content Format Mapping

Map each answer to the format and channel where buyers actually look for it.

## Inputs

- `proof-backed-answers`: Answers with evidence
- `priority-questions`: The five questions

## Outputs

- `content-plan`: Each answer mapped to a format and channel
- `publishing-schedule`: The order and dates to publish, starting with the highest-impact answers

## Process

1. For each answer, choose the format the buyer prefers, such as an article, a comparison page, or a short video.
2. Match the channel to where buyers search, since the best answer in the wrong place goes unread.
3. Schedule publishing to lead with the answers that remove the biggest purchase blockers.
4. Plan to update each piece as the evidence gaps close, so the content stays true.
