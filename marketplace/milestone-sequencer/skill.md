# Milestone Sequencer

Break the scoped project into milestones that each produce something working.

## Inputs

- `scoped-project`: The smallest version that still proves the skill
- `deadline-plan`: A deadline short enough to force progress

## Outputs

- `milestone-plan`: Milestones that each end in a working piece
- `first-build-step`: The very first step to start today

## Process

1. Split the project into milestones that each end in a working piece.
2. Order milestones so you build the hardest risky part early.
3. Define the very first build step you can start today.
4. Set a rough time estimate for each milestone.
