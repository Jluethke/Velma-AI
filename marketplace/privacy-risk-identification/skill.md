# Privacy Risk Identification

Identify the privacy risks in the planned processing.

## Inputs

- `processing-summary`: Summary of planned data processing
- `data-subjects`: Categories of data subjects

## Outputs

- `risk-register`: List of identified privacy risks with likelihood and impact assessment
- `high-risk-flags`: Processing activities that may trigger a DPIA requirement

## Process

1. Assess each processing activity against the privacy principles (minimization, purpose limitation, accuracy, storage limitation, integrity, confidentiality).
2. Identify risks to data subjects (unauthorized access, data breach, function creep, profiling, discrimination).
3. Rate each risk by likelihood and impact.
4. Flag any processing that meets the criteria for a mandatory Data Protection Impact Assessment.
