# Curriculum Review Adapter

Review the curriculum effectiveness and adapt for the next planning cycle.

## Inputs

- `outcome-observations`: Documented learning outcomes from the executed plan
- `parent-curriculum-update`: Parent feedback on curriculum updates

## Outputs

- `curriculum-evaluation`: Assessment of which activities worked, which need modification, and what to repeat
- `curriculum-plan`: Updated curriculum plan incorporating lessons learned for the next cycle

## Process

1. Review the outcome observations against the developmental goals set for the period.
2. Identify activities that produced strong engagement and learning versus those that fell flat.
3. Incorporate parent feedback and suggestions.
4. Adjust the next cycle's plan based on what worked, children's evolving interests, and remaining goal gaps.
