# Difficulty Calibration

Test each challenge for solvability and calibrate difficulty against the tier definitions.

## Inputs

- `challenge-environments`: Running challenges
- `difficulty-tiers`: Tier criteria
- `solution-guides`: Intended solutions

## Outputs

- `calibration-results`: Actual difficulty vs intended tier for each challenge
- `adjustment-notes`: Changes needed to match intended difficulty

## Process

1. Have testers at each skill level attempt the challenges
2. Measure solve time and compare against tier expectations
3. Adjust difficulty up or down: add or remove distractors, change complexity
