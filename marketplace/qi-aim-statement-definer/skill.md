# Qi Aim Statement Definer

Define the aim statement and quality measures.

## Inputs

- `quality-problem`: The quality issue to address
- `baseline-data`: Current performance data

## Outputs

- `aim-statement`: Specific, measurable aim with timeline
- `quality-measures`: Process, outcome, and balancing measures

## Process

1. Write the aim statement: what, how much, by when.
2. Define process measures (adherence to the intervention).
3. Define outcome measures and balancing measures.
