# Impact Report Designer

Design and produce the impact report for stakeholder distribution.

## Inputs

- `impact-narrative`: Written findings
- `results-summary`: Key metrics summary

## Outputs

- `impact-report`: Designed report ready for distribution
- `distribution-plan`: Who receives the report and how

## Process

1. Design the report layout with charts, photos, and infographics
2. Include the executive summary, detailed findings, and financial overview
3. Plan distribution by audience (donors, board, public, funders)
4. Prepare print and digital versions
