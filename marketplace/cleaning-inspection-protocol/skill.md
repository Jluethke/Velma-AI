# Cleaning Inspection Protocol

Define cleaning standards and the inspection protocol.

## Inputs

- `room-assignments`: Current room assignments
- `property-room-count`: Property details

## Outputs

- `cleaning-checklist`: Room cleaning checklist by room type
- `inspection-rate`: Target inspection rate and method

## Process

1. Define the cleaning checklist for each room type.
2. Set the inspection sampling rate (percentage of rooms).
3. Define the scoring criteria for inspections.
4. Document the process for failed inspections.
