# Concept Scoper

Choose the concept to learn and write down what you already know about it.

## Inputs

- `concept-name`: The concept or topic you want to understand
- `current-understanding`: What you already believe you know about it

## Outputs

- `concept-scope`: The concept framed as a clear question to answer
- `prior-knowledge-notes`: What you can state about it from memory

## Process

1. State the concept as a single clear question you want to answer.
2. Write everything you already know about it from memory.
3. Mark the boundary of what the explanation needs to cover.
4. List the parts you are least sure about.
