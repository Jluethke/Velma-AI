# Bot Persona Definer

Define the persona and tone of voice for the conversational agent.

## Inputs

- `brand-guidelines`: Brand voice and tone guidelines
- `target-audience`: Description of the users who will interact with the agent

## Outputs

- `bot-persona`: Persona document: name, personality traits, tone, vocabulary, things it says and does not say
- `tone-examples`: Example responses showing the persona in different contexts (greeting, error, success, empathy)

## Process

1. Define the persona's personality traits (helpful, direct, warm, professional).
2. Set the vocabulary level and formality for the target audience.
3. Write examples of what the persona says and does not say.
4. Create tone examples for different emotional contexts (neutral, frustrated user, success).
