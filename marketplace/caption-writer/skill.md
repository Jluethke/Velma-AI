# Caption Writer

Write the figure caption: title line, description of what is shown, definition of error bars and statistical annotations, and sample sizes.

## Inputs

- `draft-figure`: The figure
- `annotation-list`: Statistical annotations to explain

## Outputs

- `figure-caption`: The complete caption text
- `caption-checklist`: Whether the caption covers all required elements (n, error bar definition, significance threshold)

## Process

1. Write a title line that states what the figure shows, not what the reader should conclude.
2. Describe the data: what each axis, color, and symbol represents.
3. Define the error bars (SEM, 95% CI, SD) and the significance threshold for any annotations.
4. State the sample size for each group or condition.
