# Narrative Dry Run

Present the story (situation, complication, resolution) to a test audience of one. Time it. If it takes longer than 3 minutes to tell the story before questions, it is too long.

## Inputs

- `main-presentation-contents`: The 3-part presentation
- `complication-chart`: The chart specification

## Outputs

- `dry-run-notes`: Where the story lost attention, felt unclear, or provoked the wrong questions
- `final-narrative-package`: The revised story, chart, and appendix ready for the real audience

## Process

1. Tell the story to one person who knows nothing about the data. Situation, complication, resolution. Time it.
2. If they ask a question during the story, the story is missing something. If they ask a question after, the story worked.
3. If any question is answered by the appendix, good. If any question is not answered by the appendix, add it.
4. The final package: main story (under 3 minutes), one chart, appendix for reference. Nothing else.
