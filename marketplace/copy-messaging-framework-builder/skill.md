# Copy Messaging Framework Builder

Define the messaging framework with headline, subhead, body, and CTA.

## Inputs

- `audience-insight`: Audience pain points and language
- `positioning-brief`: Product positioning statement

## Outputs

- `messaging-framework`: Headline, subhead, body copy, and CTA hierarchy
- `value-propositions`: Top 3 value propositions with supporting proof points

## Process

1. Write the primary headline options (benefit-led, problem-led, curiosity)
2. Develop supporting subheads for each headline
3. Draft the body copy framework with proof points
4. Write CTA options with urgency and clarity
