# Chaos Findings Documenter

Document the experiment findings, system weaknesses discovered, and improvement recommendations.

## Inputs

- `hypothesis-verdict`: Whether the hypothesis held
- `deviation-details`: Details of any deviations observed

## Outputs

- `improvement-actions`: Recommended improvements based on findings
- `chaos-experiment-report`: Complete experiment report with all details

## Process

1. Summarize the experiment setup, execution, and observations
2. Document each weakness or unexpected behavior discovered
3. Recommend specific improvements (retry logic, timeouts, fallbacks, redundancy)
4. Compile the full chaos experiment report
