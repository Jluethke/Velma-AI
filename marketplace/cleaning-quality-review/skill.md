# Cleaning Quality Review

Run quality checks on completed jobs and handle client feedback.

## Inputs

- `crew-schedule`: Completed job records
- `service-packages`: Package standards for quality comparison

## Outputs

- `quality-scores`: Quality scores per crew and per job with identified issues
- `cleaning-operations-plan`: Complete cleaning service operations plan

## Process

1. Send the post-service feedback request to the client (rating, comments, photos).
2. Conduct random spot checks on completed jobs using the quality checklist.
3. Track quality scores per crew and identify patterns in complaints.
4. Address quality issues through retraining or re-cleaning as needed.
