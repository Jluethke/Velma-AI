# Note Format Definer

Define the standard note format and templates.

## Inputs

- `pkm-method`: Selected PKM method
- `pkm-tool`: Selected tool

## Outputs

- `note-templates`: Templates for each note type (fleeting, literature, permanent)
- `naming-convention`: File naming and tagging convention

## Process

1. Create a template for fleeting notes (quick captures, no structure required).
2. Create a template for literature notes (source, key points, your reaction).
3. Create a template for permanent notes (one idea, your own words, linked).
4. Define the naming and tagging convention.
