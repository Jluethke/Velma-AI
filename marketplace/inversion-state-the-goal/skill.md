# Inversion State The Goal

Define the problem and the outcome you want in plain terms before you flip it.

## Inputs

- `problem-statement`: The problem you are trying to solve.
- `desired-outcome`: The result you want to reach.

## Outputs

- `goal-definition`: The goal written as a single clear sentence.
- `success-markers`: The signs that would tell you the outcome was reached.

## Process

1. Write the problem as a single sentence that names what you are trying to achieve.
2. List the markers that would tell you the outcome was reached.
3. Set aside any proposed solution so the inversion starts from the goal, not a plan.
