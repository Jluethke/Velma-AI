# Tos Scope Definer

Define the service scope, user eligibility, and account terms.

## Inputs

- `product-description`: Description of the product or service
- `target-audience`: Intended user base and any age or geographic restrictions

## Outputs

- `service-scope`: Defined service scope and eligibility criteria
- `account-terms`: Account creation, suspension, and termination terms

## Process

1. Describe the services covered by the ToS
2. Set eligibility requirements (age, geography, entity type)
3. Define account registration and termination terms
