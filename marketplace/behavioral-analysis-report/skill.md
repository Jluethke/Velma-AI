# Behavioral Analysis Report

Produce the behavioral experiment analysis report with statistics, figures, and interpretation.

## Inputs

- `model-results`: Statistical results
- `contrast-figures`: Key visualizations
- `effect-sizes`: Effect size estimates with CIs

## Outputs

- `analysis-report`: The full behavioral analysis report
- `statistical-supplement`: Complete ANOVA tables, assumption checks, and individual subject data

## Process

1. Report the sample (N, demographics, exclusions) and procedure.
2. Present each hypothesis with the corresponding statistical test, effect size, and figure.
3. Discuss whether results support, partially support, or fail to support each hypothesis.
4. Note limitations: sample size, generalizability, and any assumption violations.
