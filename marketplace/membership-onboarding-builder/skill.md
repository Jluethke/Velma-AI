# Membership Onboarding Builder

Create the onboarding experience for new members.

## Inputs

- `tier-structure`: The membership tiers and benefits
- `platform-selection`: The chosen platform

## Outputs

- `onboarding-sequence`: The welcome flow for new members (emails, messages, orientation)
- `member-guide`: A guide explaining how to access benefits and participate

## Process

1. Write the welcome message that introduces the community and sets expectations.
2. Design the onboarding sequence (welcome email, orientation tour, first exclusive content).
3. Create the member guide with instructions for accessing each benefit.
4. Set up automated delivery so new members receive the onboarding immediately.
