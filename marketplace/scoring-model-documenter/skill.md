# Scoring Model Documenter

Document the scoring model and produce the calibration plan.

## Inputs

- `scoring-matrix`: Final scoring rules
- `score-thresholds`: Classification boundaries
- `threshold-validation`: Backtest results

## Outputs

- `scoring-model-document`: Full documentation of the scoring model
- `calibration-plan`: Schedule and criteria for quarterly recalibration

## Process

1. Document every signal, its point value, and the rationale.
2. Document the thresholds and their backtest performance.
3. Define the quarterly calibration process.
4. Specify the data pulls and metrics for each calibration cycle.
