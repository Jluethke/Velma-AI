# Incident Remediation Planning

Define remediation actions with owners, priorities, and deadlines.

## Inputs

- `root-cause-finding`: Identified root cause
- `contributing-factors`: Contributing factors to address

## Outputs

- `remediation-actions`: Prioritized list of remediation actions with owners and deadlines
- `success-criteria`: Measurable criteria to verify each remediation is effective

## Process

1. Define specific actions to address the root cause
2. Define actions to address each contributing factor
3. Assign an owner and deadline to each action
4. Define measurable success criteria for each action
