# Criteria Definition Before Options

Define the evaluation criteria BEFORE looking at the options. If you define criteria after seeing the options, you will unconsciously choose criteria that favor the option you already prefer (criteria-gerrymandering). The criteria should reflect what you actually need, not what any particular option is good at.

## Inputs

- `decision-description`: What you are deciding
- `must-haves`: Non-negotiable requirements (any option that fails these is eliminated regardless of score)

## Outputs

- `evaluation-criteria`: The criteria for evaluation, defined before examining any specific option
- `must-have-filters`: Non-negotiable requirements that eliminate options before scoring

## Process

1. Before looking at any option, ask: what matters in this decision? List every criterion.
2. Check for completeness: have you included cost, time, risk, fit, opportunity cost, and reversibility?
3. Remove any criterion that is really a proxy for 'this is what option X is good at'.
4. Define the must-have filters: non-negotiable requirements. Options that fail a must-have are eliminated before scoring.
