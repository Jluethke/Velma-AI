# Chromatography Report Writer

Compile the chromatographic analysis report: method summary, chromatogram figure, peak table, identification, quantification, and system suitability.

## Inputs

- `concentration-table`: Quantification results
- `separation-metrics`: Separation quality assessment
- `identified-peaks`: Compound identifications

## Outputs

- `chromatography-report`: Structured analytical report
- `results-certificate`: Summary table suitable for a certificate of analysis

## Process

1. Present the annotated chromatogram with identified peaks labeled.
2. Include the peak table with retention time, area, identification, and concentration.
3. Report system suitability results and whether criteria were met.
4. Summarize the analytical findings in a format suitable for the intended audience.
