# Database Monitoring Setup

Set up database monitoring for slow queries, replication lag, connection counts, and disk usage.

## Inputs

- `pooling-config`: Connection pooling setup
- `replication-config`: Replication configuration

## Outputs

- `database-dashboards`: Monitoring dashboards for database health
- `database-reliability-plan`: Complete database reliability plan document

## Process

1. Configure metrics collection for query performance and resource usage
2. Set up alerts for replication lag, connection exhaustion, and disk pressure
3. Build dashboards showing database health and trends
4. Compile the complete database reliability plan
