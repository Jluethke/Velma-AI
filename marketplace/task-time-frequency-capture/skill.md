# Task Time Frequency Capture

Measure how long the task takes per occurrence and how often it occurs. Both numbers should be measured on the real task, because remembered times are usually shorter than observed ones.

## Inputs

- `task-description`: The repetitive task under consideration
- `measurement-window`: The period over which time and frequency are measured

## Outputs

- `time-per-occurrence`: Measured time the task takes each time it is done
- `occurrence-frequency`: How often the task occurs over the window

## Process

1. Time the task on several real occurrences rather than estimating from memory.
2. Count how often the task occurs over a representative window.
3. Include the setup and cleanup time around the task, not only the core minutes.
4. Record ranges where occurrences vary so later math can show a best and worst case.
