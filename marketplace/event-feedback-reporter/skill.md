# Event Feedback Reporter

Produce the post-event feedback report with scores, themes, and recommendations.

## Inputs

- `event-scores`: Average scores by question
- `comment-themes`: Top themes from comments
- `event-response-rate`: Response and completion rates

## Outputs

- `post-event-feedback-report`: Report with scores, NPS, themes, strengths, improvement areas, and recommendations

## Process

1. Summarize the overall event rating and NPS with comparison to prior events if available.
2. Present the top 3 strengths and top 3 improvement areas with supporting quotes.
3. List specific recommendations for the next event based on the findings.
4. Produce the post-event feedback report for the organizing team and stakeholders.
