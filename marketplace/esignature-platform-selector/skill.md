# Esignature Platform Selector

Select and configure the e-signature platform based on requirements.

## Inputs

- `signature-requirements`: Volume, compliance needs, integration requirements, and budget
- `document-types`: Types of documents that will use e-signatures

## Outputs

- `platform-selection`: Selected platform with rationale
- `platform-config`: Configuration settings: branding, templates, notification rules

## Process

1. Evaluate platforms against requirements (compliance, volume, integrations).
2. Select the platform that fits the use case.
3. Configure branding, notification templates, and default settings.
4. Set up integrations with existing document and contract systems.
