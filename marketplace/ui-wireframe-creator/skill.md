# Ui Wireframe Creator

Create wireframes for key screens.

## Inputs

- `user-flows`: Task flows showing screen sequence
- `ui-requirements`: Functional requirements per screen

## Outputs

- `wireframes`: Low-fidelity wireframes for each screen
- `interaction-notes`: Notes on transitions, gestures, and states

## Process

1. Sketch layout options for each screen type
2. Define the information hierarchy and content placement
3. Annotate interactions (taps, swipes, form submissions)
4. Review wireframes against user flows for completeness
