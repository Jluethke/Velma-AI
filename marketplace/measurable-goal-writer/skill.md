# Measurable Goal Writer

Write goals that are specific and measurable.

## Inputs

- `focus-areas`: Selected life areas
- `area-assessments`: Current state per area

## Outputs

- `goal-statements`: Specific, measurable goal statements
- `success-criteria`: How to know each goal is achieved

## Process

1. Write one goal per focus area with a number and deadline.
2. Define the success criteria (what does done look like).
3. Confirm each goal is within your control to achieve.
