# Ai Approval Gate Designer

Define approval gates and controls for each risk tier.

## Inputs

- `risk-classification`: Systems by risk tier
- `organization-scope`: Organizational structure

## Outputs

- `approval-gates`: Required approvals and reviews per risk tier
- `control-requirements`: Technical and process controls per tier

## Process

1. Define the approval process for each risk tier.
2. Set the technical controls (monitoring, logging, access).
3. Assign review responsibilities.
4. Document the gate criteria for passing.
