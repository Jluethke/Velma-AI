# Win Loss Report Writer

Produce the win-loss report with findings and recommendations.

## Inputs

- `win-loss-patterns`: Categorized findings
- `segment-differences`: Segment-level analysis

## Outputs

- `win-loss-report`: Analysis report with findings and recommendations
- `improvement-actions`: Prioritized actions to improve win rate

## Process

1. Summarize the top reasons for wins and losses.
2. Highlight the most actionable findings.
3. Recommend process, messaging, or product changes.
4. Prioritize actions by expected impact on win rate.
