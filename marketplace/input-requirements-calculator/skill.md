# Input Requirements Calculator

Calculate seed, fertilizer, and chemical input requirements for the season.

## Inputs

- `planting-schedule`: Planting dates and acreage by crop
- `soil-amendment-needs`: Required soil amendments

## Outputs

- `input-list`: Quantities and timing for all inputs
- `input-cost-estimate`: Estimated cost for all inputs

## Process

1. Calculate seed quantities by crop, variety, and seeding rate.
2. Determine fertilizer application rates from soil test recommendations.
3. List herbicide and pesticide needs based on field history.
4. Estimate total input costs and identify bulk purchase opportunities.
