# File Upload Endpoint Id

Identify all file upload endpoints and their validation mechanisms.

## Inputs

- `target-application`: Target application URL
- `test-credentials`: Test credentials for upload access

## Outputs

- `upload-endpoints`: List of all file upload endpoints
- `validation-mechanisms`: Validation checks applied at each endpoint

## Process

1. Enumerate all endpoints that accept file uploads
2. Identify client-side and server-side validation checks
3. Document allowed file types, size limits, and naming rules
