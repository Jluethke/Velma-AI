# Knowledge Item Extraction

Extract discrete, testable knowledge items from the material you need to retain.

## Inputs

- `source-material`: The content you need to learn and retain (textbook, notes, course material, procedures)
- `retention-goal`: What you need to be able to do with this knowledge (recall facts, apply procedures, recognize patterns)

## Outputs

- `knowledge-items`: A list of discrete, testable items: each one is a single fact, concept, procedure step, or association
- `item-format-map`: For each item, the test format that best measures retention (recall, recognition, application, explanation)

## Process

1. Read through the source material and identify each discrete piece of knowledge that you need to retain. A discrete item is one that can be tested with a single question.
2. Avoid items that are too broad ('explain cardiac physiology') or too trivial ('the heart has chambers'). Aim for items you could test in 10-30 seconds.
3. For each item, choose the test format that matches your retention goal. If you need to recall under pressure, use free recall. If you need to recognize patterns, use recognition. If you need to apply, use scenario-based questions.
4. Group related items so you can review them in clusters, but test each item independently.
