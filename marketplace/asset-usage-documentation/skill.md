# Asset Usage Documentation

Document the usage guidelines for each asset category.

## Inputs

- `organized-library`: The organized asset library
- `brand-guidelines`: Brand guidelines to reference

## Outputs

- `asset-usage-guide`: Usage rules for each asset category (clear space, minimum size, color versions, do/don't)
- `brand-asset-library-document`: The complete brand asset library setup document

## Process

1. For each asset category, write the usage rules (where to use, how to use, restrictions).
2. Include do/don't examples showing correct and incorrect usage.
3. Compile everything into the brand asset library setup document.
4. Produce the usage guide and complete library document.
