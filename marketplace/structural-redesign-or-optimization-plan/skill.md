# Structural Redesign Or Optimization Plan

Build the plan for the chosen path: an optimization plan that moves the system toward its ceiling, or structural options that raise the ceiling by changing the game. Each path produces a different kind of work and should not be confused.

## Inputs

- `chosen-path`: Optimize or change the structure
- `path-rationale`: Why that path was chosen

## Outputs

- `action-plan`: The optimization plan or the structural-change plan for the chosen path
- `game-change-options`: Structural options that raise the ceiling, when a change is needed

## Process

1. On the optimize path, plan the moves that close the gap between current output and the ceiling.
2. On the change path, generate structural options that lift the ceiling itself rather than tuning within it.
3. For a structural change, name what new ceiling each option would create.
4. Keep the two kinds of work distinct so a redesign is never mistaken for an optimization.
