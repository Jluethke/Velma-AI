# Quality Level Descriptor Writer

Write quality level descriptors for each performance dimension.

## Inputs

- `performance-dimensions`: List of dimensions to evaluate
- `dimension-definitions`: Clear definition of each dimension

## Outputs

- `rubric-draft`: Draft rubric with all levels described
- `level-scale`: The scale used (e.g., exemplary, proficient, developing, beginning)

## Process

1. Define the scale levels (typically 3-5 levels)
2. Write descriptors for the highest level first
3. Write descriptors for the lowest level
4. Fill in intermediate levels with clear distinctions between adjacent levels
