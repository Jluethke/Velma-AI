# Lesson Opener Designer

Design the opening activity to activate prior knowledge and engage learners.

## Inputs

- `lesson-objectives`: Specific, measurable objectives for this lesson
- `prior-knowledge`: What learners already know coming into this lesson

## Outputs

- `opening-activity`: Description of the hook and prior knowledge activation
- `opening-materials`: Materials needed for the opening activity

## Process

1. Design a hook to capture attention (question, scenario, demonstration)
2. Plan an activity to activate relevant prior knowledge
3. Estimate timing (5-10 minutes)
4. List required materials
