# Account Plan Documenter

Produce the account plan and set the QBR schedule.

## Inputs

- `org-map`: Account org chart
- `account-objectives`: Goals and metrics
- `engagement-plan`: Activity plan

## Outputs

- `account-plan`: Full strategic account plan
- `qbr-schedule`: Quarterly business review dates and agenda framework

## Process

1. Compile the org map, objectives, and engagement plan into the account plan.
2. Set the QBR cadence and standard agenda.
3. Distribute the plan to the account team.
4. Set the first QBR date.
