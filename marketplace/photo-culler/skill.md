# Photo Culler

Cull and select the best images from the shoot.

## Inputs

- `cataloged-library`: Full image library from the shoot
- `shoot-brief`: Client requirements and shot list

## Outputs

- `selected-images`: Curated set of images flagged for processing
- `cull-statistics`: Number of images shot vs selected

## Process

1. Review all images at screen size for technical quality
2. Flag the best images based on composition, expression, and sharpness
3. Compare similar shots and select the strongest from each group
4. Verify the selection covers all required shots from the brief
