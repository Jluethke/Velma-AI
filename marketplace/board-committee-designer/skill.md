# Board Committee Designer

Establish the committee structure with charters and assignments.

## Inputs

- `role-descriptions`: Board positions and duties
- `organization-bylaws`: Bylaw requirements for committees

## Outputs

- `committee-charters`: Charter for each committee
- `committee-assignments`: Board members assigned to committees

## Process

1. Define standing committees (executive, finance, governance, fundraising, program)
2. Write a charter for each committee (purpose, membership, meeting frequency)
3. Assign board members to committees based on skills
4. Set the committee reporting schedule to the full board
