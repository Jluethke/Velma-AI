# Climate Analysis Reporter

Compile the climate analysis into a final report with comparisons to model projections.

## Inputs

- `trend-results`: Trend analysis results
- `attribution-results`: Attribution analysis results
- `anomaly-series`: Full anomaly time series

## Outputs

- `climate-report`: Full climate analysis report with methods, results, and context
- `projection-comparison`: How the observed trend compares to CMIP model projections for the same period

## Process

1. Overlay the observed trend on the CMIP model ensemble range for context
2. Summarize the analysis: data, methods, trend, attribution, and projection comparison
3. State the key findings and their implications
4. Document limitations, data gaps, and recommendations for follow-up
