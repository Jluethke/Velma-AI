# Environmental Data Configurator

Configure the data collection and transmission from the sensor network.

## Inputs

- `placement-map`: Sensor locations
- `installation-plan`: Installation details

## Outputs

- `data-config`: Data collection and transmission configuration
- `dashboard-and-alerts`: Dashboard and alerting configuration for the network

## Process

1. Configure each sensor's data transmission (frequency, protocol, destination).
2. Set up the central dashboard with panels for each parameter and location.
3. Define the alert thresholds (air quality index levels, temperature extremes, noise limits).
