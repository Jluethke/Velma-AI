# Newsletter Writer Designer

Write the newsletter copy and assemble the design.

## Inputs

- `curated-content`: The curated and organized content
- `content-brief`: Briefs for original content sections

## Outputs

- `newsletter-draft`: The complete newsletter draft ready for review
- `design-assets`: Images, headers, and layout elements used

## Process

1. Write the original content sections from the briefs.
2. Write the intros, transitions, and CTAs for curated sections.
3. Assemble the content into the email template.
4. Add images, headers, and design elements.
