# Recurring Block Setter

Block recurring commitments and protect deep work windows.

## Inputs

- `weekly-template`: Ideal weekly template
- `deep-work-windows`: Deep work blocks to protect

## Outputs

- `calendar-blocks`: Recurring calendar events set
- `protection-rules`: Rules for protecting deep work time

## Process

1. Create recurring calendar events for each block type.
2. Mark deep work blocks as busy and decline conflicting meetings.
3. Set notification rules (off during deep work, on during admin).
