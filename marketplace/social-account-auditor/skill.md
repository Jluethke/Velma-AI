# Social Account Auditor

Audit existing social media accounts across platforms.

## Inputs

- `business-name`: The business or brand name
- `target-platforms`: Platforms to set up or audit (Instagram, Twitter/X, LinkedIn, Facebook, TikTok, YouTube)

## Outputs

- `account-inventory`: Inventory of existing accounts with status (active, inactive, unclaimed, duplicate)
- `gap-list`: Platforms where accounts are missing or incomplete

## Process

1. Search each target platform for existing accounts using the business name and variations.
2. Document each account found (URL, status, follower count, last activity date).
3. Identify duplicate or unauthorized accounts.
4. List the platforms where accounts need to be created or claimed.
