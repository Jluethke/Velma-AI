# Environmental Impact Reporter

Compile monitoring findings, trends, anomalies, and compliance status into an environmental impact report with maps, charts, and recommendations.

## Inputs

- `trend-results`: Long-term trend analysis from the trend step
- `source-attribution`: Anomaly source attribution results
- `compliance-summary`: Regulatory compliance status summary

## Outputs

- `impact-report`: Complete environmental impact report with executive summary and technical appendices
- `spatial-maps`: Interpolated concentration maps showing spatial patterns across the monitoring network
- `action-recommendations`: Prioritized recommendations for source reduction or further investigation

## Process

1. Assemble all analytical results into a consistent report framework
2. Create spatial maps showing pollutant distributions across the monitoring domain
3. Write the executive summary highlighting key trends, exceedances, and attributions
4. Present compliance status and discuss implications for continued monitoring
5. Develop prioritized action recommendations based on health significance and attribution confidence
