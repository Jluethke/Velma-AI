# Honest Answer Drafting

Draft honest answers to the chosen questions, including the parts that are not flattering.

## Inputs

- `priority-questions`: The five questions to answer
- `avoidance-reasons`: Why each has gone unanswered

## Outputs

- `draft-answers`: Direct answers that tell the buyer the truth, including limits
- `honesty-checks`: A pass confirming each answer would survive a skeptical buyer reading it

## Process

1. Answer each question the way you would tell a friend, including the cases where you are not the right choice.
2. State real price ranges and real tradeoffs, since dodging them is why buyers distrust vendor content.
3. Name the buyers you are not for, which paradoxically earns trust with the buyers you are for.
4. Run an honesty check: would this answer hold up if the buyer tested it against reality?
