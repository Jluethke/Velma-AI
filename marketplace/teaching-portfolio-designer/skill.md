# Teaching Portfolio Designer

Design the teaching portfolio process for faculty to document and reflect on their practice.

## Inputs

- `observation-protocol`: Structured peer observation form
- `institutional-priorities`: Teaching priorities

## Outputs

- `portfolio-template`: Template for the teaching portfolio
- `portfolio-guidelines`: Instructions and examples for building the portfolio

## Process

1. Define the portfolio components (philosophy, evidence, reflections, goals)
2. Create the template with sections and prompts
3. Provide annotated examples of strong portfolios
4. Establish the review and feedback cycle
