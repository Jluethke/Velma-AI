# Ip Portfolio Inventory

Inventory all intellectual property assets held by the target.

## Inputs

- `target-name`: Name of the target entity
- `ip-disclosures`: IP schedules and disclosures provided by the target

## Outputs

- `ip-inventory`: Complete inventory of patents, trademarks, copyrights, and trade secrets
- `registration-status`: Filing and registration status for each asset

## Process

1. Catalog all patents and patent applications with filing dates and jurisdictions
2. List all trademark registrations and applications
3. Inventory copyrights, trade secrets, and domain names
