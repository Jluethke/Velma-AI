# Iac Tool Selector

Select the IaC tool based on cloud provider, team expertise, and project requirements.

## Inputs

- `resource-inventory`: Inventory of resources to manage
- `team-expertise`: Team's existing IaC experience and preferences

## Outputs

- `selected-iac-tool`: The chosen IaC tool with rationale
- `module-structure`: Proposed module and directory structure

## Process

1. Evaluate Terraform, Pulumi, CloudFormation, and Bicep against requirements
2. Consider multi-cloud needs, language preferences, and state management
3. Select the tool and define the module structure
4. Set up the repository and directory layout
