# Event Schedule Publication

Finalize and publish the event schedule, then handle last-minute changes.

## Inputs

- `draft-event-schedule`: The draft event schedule
- `assignment-conflicts`: Any remaining conflicts

## Outputs

- `published-event-schedule`: The published event schedule (web, app, printed program)
- `event-schedule-record`: Complete event scheduling record including change log

## Process

1. Review the draft with speakers and stakeholders for final corrections.
2. Publish the schedule to the event website, mobile app, and printed program.
3. Set up a change protocol for last-minute issues (speaker cancellation, room change, time swap).
4. When a change occurs, update all published channels and notify affected attendees.
5. After the event, compile the scheduling record with lessons learned for next time.
