# Network Effect Type Mapping

Map which type of network effect applies: direct, indirect, data, or social. The type decides how the effect scales, how defensible it is, and where it can be attacked by a rival.

## Inputs

- `core-interaction`: The single interaction that drives the network effect
- `value-mechanism`: How that interaction turns more users into more value per user

## Outputs

- `network-effect-type`: The type of network effect at work
- `defensibility-note`: How defensible that type is and its weak points

## Process

1. Classify the effect: direct same-side, indirect cross-side, data-driven, or social.
2. Note how the effect scales for that type and whether it stays local or goes global.
3. Name the weak points of that type, such as multi-homing or local networks a rival can beat city by city.
4. Record how defensible the effect is once it takes hold.
