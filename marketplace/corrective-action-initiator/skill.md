# Corrective Action Initiator

Initiate the corrective action with problem description and containment.

## Inputs

- `nonconformance-report`: NCR or customer complaint triggering the action
- `affected-product`: Product, lot, and quantity affected

## Outputs

- `ca-record`: Corrective action record with problem description (D1-D3)
- `containment-status`: Interim containment actions in place

## Process

1. Open the corrective action record and assign a unique number
2. Form the team with relevant expertise (D1)
3. Describe the problem in specific, quantified terms (D2)
4. Implement interim containment actions to protect the customer (D3)
