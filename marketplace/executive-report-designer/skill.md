# Executive Report Designer

Design the report format and select the metrics.

## Inputs

- `audience-needs`: What executives need
- `report-inventory`: Existing reports and gaps

## Outputs

- `report-designs`: Format and metrics for each report (one-page summary, dashboard, or deck)
- `production-schedule`: When each report is produced and delivered

## Process

1. For each gap, design the report format: one-page summary, dashboard, or slide deck.
2. Select the metrics for each report from the metrics dictionary.
3. Set the production schedule: who produces it, when, and how it is delivered.
