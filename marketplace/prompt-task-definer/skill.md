# Prompt Task Definer

Define the task, success criteria, and evaluation rubric for the prompt.

## Inputs

- `task-description`: What the LLM must accomplish
- `success-criteria`: Measurable criteria for a correct output

## Outputs

- `task-spec`: Formalized task specification
- `evaluation-rubric`: Scoring rubric for prompt outputs

## Process

1. State the task in precise terms with input and output format.
2. List the success criteria with pass/fail thresholds.
3. Write the evaluation rubric with scoring dimensions.
4. Compile example inputs and their expected outputs.
