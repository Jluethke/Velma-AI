# Note Linker

Link each note to related notes so ideas connect rather than sit in isolation.

## Inputs

- `atomic-notes`: Self-contained notes, one idea each
- `source-references`: The source recorded for each note

## Outputs

- `linked-notes`: Notes connected to their related notes
- `link-map`: A map of how the notes connect

## Process

1. For each new note, find existing notes it relates to.
2. Add two-way links and a short phrase describing the relationship.
3. Create entry notes that gather links to a cluster of ideas.
4. Review links so connections reflect real relationships.
