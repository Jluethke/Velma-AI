# Wcs Numbered Actions List

When the message asks for more than one action, number them and attach an owner and a deadline to each. A numbered list is easy to reply to point by point and hard to half-answer. Unnumbered asks buried in prose get partially done at best.

## Inputs

- `action-sentence`: The primary action from the first sentence
- `scannable-layout`: The scannable structure the actions will live in

## Outputs

- `numbered-actions`: Each requested action as a numbered item written as an imperative
- `owner-deadline-map`: For each numbered action, the single owner and the due date

## Process

1. Write each action as a numbered imperative: '1. Send the revised figures. 2. Confirm the vendor date.'
2. Attach one owner to each action. Two names on one action means neither will move first.
3. Attach a deadline to each action. Actions without dates sort to the bottom of everyone's list.
4. Keep the list short. More than five actions in one message is a project, and a project needs a plan, not an email.
