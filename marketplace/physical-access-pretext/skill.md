# Physical Access Pretext

Attempt authorized physical access through social engineering and pretexting.

## Inputs

- `pretext-scenarios`: Prepared social engineering scenarios
- `red-team-scope`: Physical access testing authorization and safety protocols

## Outputs

- `physical-access-results`: Results of physical access attempts with evidence
- `physical-security-gaps`: Identified weaknesses in physical security controls

## Process

1. Attempt tailgating through controlled entry points
2. Test badge-based access controls for bypass techniques
3. Attempt to access server rooms or restricted areas using pretexts
4. Document all attempts with timestamps, locations, and outcomes
