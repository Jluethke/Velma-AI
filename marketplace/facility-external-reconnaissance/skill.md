# Facility External Reconnaissance

Perform external reconnaissance of the target facility to map entry points, schedules, and security patterns.

## Inputs

- `facility-address`: Target facility location
- `authorization-scope`: Written authorization and emergency contacts
- `facility-hours`: Known operating hours and shift schedules

## Outputs

- `entry-point-map`: Map of all entry and exit points with security observations
- `security-pattern-notes`: Observed security guard patterns and camera locations

## Process

1. Observe and map all doors, gates, loading docks, and emergency exits
2. Note security camera positions, angles, and apparent blind spots
3. Document guard patrol patterns and shift change timing
4. Identify the most promising entry points for each test scenario
