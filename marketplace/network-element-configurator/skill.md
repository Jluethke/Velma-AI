# Network Element Configurator

Configure the network elements to deliver the service.

## Inputs

- `provisioning-plan`: Technical provisioning plan
- `feasibility-result`: Feasibility assessment

## Outputs

- `configuration-record`: Record of all network element configurations applied
- `activation-checklist`: Checklist for service activation

## Process

1. Configure routers, switches, and access equipment per the provisioning plan.
2. Set up VLANs, IP addressing, QoS policies, and routing.
3. Configure monitoring and alerting for the new service.
4. Document all configurations in the network management system.
