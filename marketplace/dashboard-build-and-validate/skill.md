# Dashboard Build And Validate

Build the dashboard and validate it against the original requirements.

## Inputs

- `tool-selection`: Chosen platform
- `layout-wireframe`: Dashboard layout
- `refresh-schedule`: Data refresh cadence

## Outputs

- `dashboard-artifact`: The built dashboard ready for use
- `dashboard-design-doc`: Documentation of the dashboard design decisions and maintenance plan

## Process

1. Build the dashboard in the chosen tool following the wireframe.
2. Connect the data sources and verify the refresh schedule.
3. Walk through the dashboard with a sample user from each audience group.
4. Document the design decisions and set a review schedule.
