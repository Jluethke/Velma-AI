# Anxiety Routine Optimizer

Adjust daily routines to reduce anxiety: sleep, caffeine, exercise, screen time, and social connection.

## Inputs

- `current_routine`: Typical daily schedule
- `pattern_analysis`: When anxiety peaks
- `constraints`: Work schedule, family obligations, etc.

## Outputs

- `optimized_routine`: Adjusted daily schedule
- `habit_changes`: Specific habits to start, stop, or modify
- `implementation_plan`: Phased rollout of changes

## Process

1. Audit sleep, caffeine, exercise, and screen patterns
2. Cross-reference with anxiety peak times
3. Identify low-hanging-fruit changes
4. Design phased implementation (one change per week)
5. Build accountability checkpoints
