# Subscription Audience Definer

Define the target audience and value proposition for the subscription box.

## Inputs

- `product-category`: Product category for the subscription
- `market-research`: Market research on the target segment

## Outputs

- `audience-profile`: Target audience profile and personas
- `value-proposition`: Subscription value proposition and positioning

## Process

1. Define the target customer persona (demographics, interests, pain points).
2. Identify the unmet need the subscription solves.
3. Articulate the value proposition (surprise, convenience, savings, curation).
4. Define the competitive positioning against alternatives.
