# Course Sequencer

Sequence courses and modules into a logical progression from foundational to advanced.

## Inputs

- `learning-outcomes-list`: List of measurable learning outcomes
- `learner-profile`: Composite profile of the target learner

## Outputs

- `course-sequence`: Ordered list of courses and modules with prerequisites
- `prerequisite-map`: Dependency graph of course prerequisites

## Process

1. Group outcomes by topic and complexity level
2. Order modules from foundational to advanced
3. Define prerequisite relationships between courses
4. Produce the course sequence and prerequisite map
