# Sox Control Tester

Test controls for design and operating effectiveness.

## Inputs

- `control-documentation`: Control descriptions and objectives
- `testing-plan`: Testing procedures and sample sizes

## Outputs

- `test-results`: Results of design and operating effectiveness tests
- `deficiency-list`: List of control deficiencies identified

## Process

1. Test design effectiveness by evaluating whether the control is designed to prevent or detect the risk.
2. Test operating effectiveness by selecting samples and executing the testing procedure.
3. Document each test result with evidence.
4. Classify deficiencies (deficiency, significant deficiency, material weakness).
