# First Experiment Planner

Plan the lab's first experiment to validate equipment, methods, and team readiness using a known system before tackling novel questions.

## Inputs

- `research-program`: Primary research questions the lab will address
- `sop-collection`: Validated SOPs for the methods involved
- `benchmark-data`: Published results on a well-characterized system for comparison

## Outputs

- `experiment-protocol`: Detailed protocol for the validation experiment
- `expected-results`: Quantitative benchmarks the first experiment should reproduce
- `go-no-go-criteria`: Criteria for declaring the lab ready to proceed to novel experiments

## Process

1. Select a well-characterized system where expected results are published
2. Write the experiment protocol using the lab's SOPs
3. Define quantitative success criteria based on published benchmarks
4. Run the experiment with the full team following normal procedures
5. Compare results to benchmarks and document any discrepancies for SOP revision
