# Password Pattern Analysis

Analyze cracked passwords for patterns revealing organizational habits.

## Inputs

- `cracked-passwords`: Successfully cracked passwords
- `cracking-statistics`: Cracking metrics

## Outputs

- `pattern-report`: Common patterns, lengths, character classes, and reuse findings
- `risk-distribution`: Distribution of passwords by strength category

## Process

1. Analyze length distribution and character class usage
2. Identify common base words and mutation patterns
3. Detect password reuse across systems
4. Categorize passwords by cracking resistance: seconds, minutes, hours, not cracked
