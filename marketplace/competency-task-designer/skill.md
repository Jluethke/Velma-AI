# Competency Task Designer

Create assessment tasks that allow learners to demonstrate each competency.

## Inputs

- `competency-framework`: List of competencies with indicators
- `proficiency-levels`: Defined levels of proficiency

## Outputs

- `assessment-tasks`: Tasks aligned to each competency with instructions
- `task-rubrics`: Scoring rubrics for each task

## Process

1. Design authentic tasks that mirror real performance contexts
2. Align each task to one or more competencies
3. Write scoring rubrics mapping task performance to proficiency levels
4. Review tasks for fairness and accessibility
