# Door Bypass Technique Test

Test locked door bypass methods including under-door tools, request-to-exit sensor abuse, and hinge removal.

## Inputs

- `entry-point-map`: Doors to test for bypass
- `authorization-scope`: Approved bypass techniques and limitations

## Outputs

- `door-bypass-findings`: Successful door bypass methods and locations
- `lock-assessment`: Assessment of lock types and their resistance

## Process

1. Test for under-door tool access to interior door handles
2. Check request-to-exit sensors for activation from outside (paper, balloon)
3. Assess door gap and frame for shimming potential
4. Document each bypass attempt with timing and detection observations
