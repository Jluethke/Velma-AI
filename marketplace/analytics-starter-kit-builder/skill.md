# Analytics Starter Kit Builder

Build starter dashboards and train users.

## Inputs

- `platform-selection`: Chosen platform
- `data-layer-spec`: Prepared data layer

## Outputs

- `starter-dashboards`: Pre-built dashboards and templates for each user group
- `training-plan`: Training materials and schedule

## Process

1. Build starter dashboards addressing the top questions for each user group.
2. Create templates users can copy and modify.
3. Write training materials matched to each skill level.
4. Schedule training sessions and set up a support channel.
