# Call Metrics Definer

Define the call center metrics and KPIs to track.

## Inputs

- `business-goals`: What the call center is trying to achieve (cost efficiency, customer satisfaction, revenue, compliance)
- `data-sources`: Available data sources (ACD, CRM, quality system, IVR, workforce management)

## Outputs

- `metric-definitions`: Defined metrics with formula, data source, update frequency, and target value
- `metric-hierarchy`: Metrics organized by category (volume, efficiency, quality, revenue, compliance)

## Process

1. Define the volume metrics: calls offered, calls handled, calls abandoned, abandon rate.
2. Define the efficiency metrics: average handle time, average speed of answer, first call resolution, transfer rate.
3. Define the quality metrics: quality score, customer satisfaction, net promoter score.
4. Define the revenue metrics: revenue per call, upsell rate, conversion rate.
5. Set the target value and alerting threshold for each metric.
