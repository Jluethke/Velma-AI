# Hints Solution Authoring

Write hints and full solution guides for each challenge.

## Inputs

- `challenge-specs`: Challenge specifications
- `flag-inventory`: Correct flags

## Outputs

- `hint-sets`: Progressive hints for each challenge: subtle to direct
- `solution-guides`: Complete walkthroughs for event organizers

## Process

1. Write three progressive hints per challenge: nudge, direction, near-solution
2. Write complete solution guides documenting the intended solve path
3. Document alternative valid solve approaches where they exist
