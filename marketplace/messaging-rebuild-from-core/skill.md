# Messaging Rebuild From Core

Rebuild all messaging from the irreducible core outward. The core is the headline. The derivatives are supporting points. The removed claims stay removed.

## Inputs

- `irreducible-core`: The 1-2 fundamental claims
- `derivative-claims`: Claims that support the core
- `removable-claims`: Claims that were removed

## Outputs

- `rebuilt-messaging`: New messaging framework: core statement (headline), supporting claims (subheads), and the explicit list of things you no longer say
- `channel-specific-versions`: The core statement adapted for each channel (website, ads, social, email, sales conversations)

## Process

1. Write the core statement as a headline. It should be one sentence. It should be specific enough that a competitor cannot copy it word for word.
2. Arrange the derivative claims as supporting points beneath the core. They exist to prove the core, not to compete with it.
3. For each channel, adapt the length but not the message. The website gets the core plus derivatives. The ad gets the core only. The sales conversation gets the core as the opening line.
4. Create a 'do not say' list from the removable claims. This list prevents drift back toward generic messaging.
