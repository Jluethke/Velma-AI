# Email Component Builder

Build the reusable email components (header, footer, CTA buttons, content blocks).

## Inputs

- `email-brand-spec`: The email brand standards
- `email-types`: The email types to support

## Outputs

- `component-library`: Library of reusable email components (header, footer, hero, text block, image block, CTA button, divider, social links)
- `component-usage-guide`: Guide showing when and how to use each component

## Process

1. Build the header component (logo, navigation links if any).
2. Build the footer component (unsubscribe link, address, social links, legal text).
3. Build content components: text block, image-left/image-right, hero image, CTA button, divider.
4. Test each component across email clients (Gmail, Outlook, Apple Mail, mobile) for rendering.
