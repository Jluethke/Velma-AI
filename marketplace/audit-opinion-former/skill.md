# Audit Opinion Former

Form the audit opinion and issue the audit report.

## Inputs

- `misstatement-assessment`: Final misstatement assessment
- `management-letter-items`: Deficiencies to communicate

## Outputs

- `audit-report`: Issued audit report with opinion
- `management-letter`: Letter to management with deficiency recommendations

## Process

1. Determine the appropriate opinion type (unqualified, qualified, adverse, disclaimer).
2. Draft the audit report with the required elements.
3. Issue the management letter with control deficiency recommendations.
4. Complete the audit file documentation and archive.
