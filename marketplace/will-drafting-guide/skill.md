# Will Drafting Guide

Guide through will creation decisions: executor, guardians, specific bequests, and residuary estate.

## Inputs

- `asset_inventory`: Assets to distribute
- `family_situation`: Spouse, children, dependents
- `state_of_residence`: State for legal requirements

## Outputs

- `will_decisions`: All key decisions documented
- `executor_selection`: Primary and backup executor
- `guardian_selection`: Guardian for minor children if applicable

## Process

1. Choose executor and backup
2. Designate guardians for minors
3. Decide specific bequests
4. Determine residuary estate distribution
5. Note state-specific requirements
