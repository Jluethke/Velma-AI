# Recovery Execution Plan

Plan exactly how the recovery version is executed when the counter hits one, so recovery is automatic rather than a decision.

## Inputs

- `scaled-down-version`: The tiny recovery version
- `consecutive-miss-counter`: The running consecutive-miss count

## Outputs

- `recovery-action-plan`: The concrete steps to perform the recovery version the day after a miss
- `identity-preservation-note`: A reminder that completing the recovery version keeps the identity intact despite the miss

## Process

1. Write the recovery as a concrete sequence for the day after a miss, so when the counter reads one you execute rather than deliberate.
2. Lower the bar to the recovery version, not the full habit. Trying to make up for a miss with a double session usually produces another skip.
3. Attach the recovery to a fixed moment the next day, so it has a reliable slot rather than waiting for motivation that may not come.
4. Write the identity note: a person who recovers the next day is still that kind of person. The recovery day is proof the identity survived the miss.
