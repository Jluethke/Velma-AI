# Design Concept Developer

Develop initial design concepts in the approved direction.

## Inputs

- `mood-boards`: Approved style direction
- `clarified-brief`: Project requirements and constraints

## Outputs

- `design-concepts`: 3 initial design concepts
- `concept-rationale`: Explanation of each concept's approach

## Process

1. Sketch rough layouts for each concept direction
2. Develop 3 distinct concepts to presentation quality
3. Write a rationale connecting each concept to the brief
4. Prepare the concepts for client review
