# Csat Program Reporter

Produce the CSAT program report with scores, trends, alerts, and recommendations.

## Inputs

- `csat-scorecard`: Aggregated scores
- `triggered-alerts`: Alerts that fired during the period

## Outputs

- `csat-program-report`: Full program report with scores, trends, response rates, alerts, and recommendations

## Process

1. Summarize scores by touchpoint with trend arrows and period comparison.
2. List the alerts that fired and their resolution status.
3. Highlight the top and bottom performing touchpoints and teams.
4. Recommend actions for underperforming touchpoints and produce the program report.
