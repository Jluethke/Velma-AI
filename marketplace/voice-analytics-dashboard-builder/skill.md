# Voice Analytics Dashboard Builder

Build the voice analytics dashboard and produce the setup document.

## Inputs

- `analysis-pipeline`: Configured analysis pipeline
- `alert-rules`: Alert rules for anomalous calls

## Outputs

- `analytics-dashboard`: Dashboard layout with metric trends, agent comparisons, and alert feed
- `voice-analytics-setup-doc`: Complete voice analytics setup document covering metrics, pipeline, alerts, and dashboard

## Process

1. Design the dashboard with metric trend charts, agent-level comparisons, and a recent alerts feed.
2. Set the refresh frequency and data aggregation periods (hourly, daily, weekly).
3. Configure drill-down from dashboard metrics to individual call recordings.
4. Compile the setup document with metrics, pipeline config, alert rules, and dashboard spec.
