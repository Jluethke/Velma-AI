# Review Exercise Designer

Design hands-on review exercises built from seeded vulnerable code samples tied to the pattern library.

## Inputs

- `vulnerability-pattern-library`: Catalog of weakness patterns from the pattern step
- `secure-coding-standards`: Standard rules that prevent each cataloged pattern

## Outputs

- `hands-on-exercises`: Review exercises with learning goals and expected findings
- `vulnerable-code-samples`: Seeded code containing known planted weaknesses

## Process

1. Plant a known weakness from the library into a realistic code sample
2. Define the expected findings and the standard rule each exercise exercises
3. Grade exercises by difficulty from single obvious flaw to subtle chained flaws
4. Write an answer key that maps each planted flaw to its fix
