# Review Question Definer

Define the systematic review question using PICO (population, intervention, comparator, outcome) or a domain-appropriate framework.

## Inputs

- `research-topic`: broad topic area for the review
- `preliminary-readings`: key papers or prior knowledge informing the question

## Outputs

- `structured-question`: PICO-formatted review question
- `inclusion-criteria`: explicit criteria for study inclusion and exclusion
- `review-scope`: boundaries on date range, languages, study types

## Process

1. Decompose the topic into population, intervention, comparator, and outcome components
2. Draft inclusion and exclusion criteria tied to each PICO element
3. Set date range, language, and study design boundaries
4. Document the structured question and scope for protocol registration
