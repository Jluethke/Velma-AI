# Rubric Finalizer

Finalize the rubric document with instructions for use and scoring procedures.

## Inputs

- `calibrated-rubric`: Revised rubric after calibration
- `reliability-score`: Inter-rater reliability metric

## Outputs

- `final-rubric`: Validated rubric document ready for use
- `rubric-guide`: Instructions for raters on applying the rubric

## Process

1. Incorporate all revisions from calibration
2. Write clear instructions for raters
3. Format the rubric for distribution
4. Document the validation process and reliability results
