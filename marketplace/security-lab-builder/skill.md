# Security Lab Builder

Build hands-on labs using intentionally vulnerable applications and CTF-style challenges for each vulnerability class.

## Inputs

- `training-modules`: Selected training modules mapped to vulnerability classes
- `vuln-examples`: Concrete examples of each vulnerability class from the codebase

## Outputs

- `lab-exercises`: Set of hands-on exercises with instructions and solutions
- `lab-infrastructure`: Configuration for the lab environment (containers, VMs, or cloud)

## Process

1. Design exercises that replicate each vulnerability class in a safe environment.
2. Build or configure vulnerable applications (DVWA, WebGoat, or custom) for each exercise.
3. Write step-by-step instructions and solution guides for each lab.
