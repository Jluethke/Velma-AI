# Change Order Approval

Get client approval on the change order and update the project plan.

## Inputs

- `change-order`: The change order document
- `revised-schedule`: Updated schedule

## Outputs

- `approved-change`: The signed change order
- `updated-project-plan`: The project plan updated with the approved change

## Process

1. Present the change order to the client with the impact analysis.
2. Answer questions and negotiate if needed.
3. Get the client's written approval (signature, email confirmation, or platform approval).
4. Update the project plan, budget tracker, and timeline with the approved changes.
5. Communicate the updated plan to anyone else on the project team.
