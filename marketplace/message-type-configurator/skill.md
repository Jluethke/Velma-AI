# Message Type Configurator

Configure the message types, templates, and automation rules.

## Inputs

- `platform-selection`: The selected communication platform
- `channel-structure`: Defined communication channels

## Outputs

- `message-templates`: Templates for recurring messages (daily reports, weekly newsletters, billing reminders, closures, emergencies)
- `automation-rules`: Automated message triggers (daily report distribution, payment reminders, birthday greetings)

## Process

1. Create templates for each recurring message type (daily report, weekly newsletter, monthly billing, closure notice).
2. Set up the emergency communication protocol (severe weather, facility issue, health advisory).
3. Configure automation rules for routine messages (daily report at 4 PM, billing reminder on the 1st).
4. Define the response expectations (staff response time for parent messages, escalation for urgent issues).
