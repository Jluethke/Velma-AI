# Session Prep Delivery

Send session preparation materials and reminders to the client before each session.

## Inputs

- `reschedule-record`: Reschedule history
- `session-log`: Previous session notes

## Outputs

- `prep-materials`: Pre-session materials sent to the client (homework review, agenda, reading)
- `session-management-record`: Complete session management record for this client

## Process

1. 24-48 hours before the session, send a reminder with date, time, and modality.
2. Include any prep materials: homework to complete, questions to think about, documents to review.
3. Include a brief summary of the last session's action items so the client can report on progress.
4. Compile the complete session management record: cadence, history, attendance, package status, and notes.
