# Paper Form Auditor

Audit current paper forms in use and prioritize for digitization.

## Inputs

- `form-inventory`: List of paper forms currently in use across the organization
- `digitization-criteria`: Criteria for prioritization (volume, error rate, processing time)

## Outputs

- `prioritized-forms`: Forms ranked by digitization priority with rationale
- `form-analysis`: Each form's fields, logic, dependencies, and current pain points

## Process

1. Collect all paper forms in active use.
2. Analyze each form's volume, error rate, and processing cost.
3. Rank forms by digitization impact.
4. Document each form's fields, rules, and dependencies.
