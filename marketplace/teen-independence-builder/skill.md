# Teen Independence Builder

Gradually build teen independence with life skills, decision-making practice, and safe risk-taking.

## Inputs

- `teen_age`: Age and current capability
- `independence_goals`: Skills to develop before leaving home

## Outputs

- `skill_roadmap`: Life skills by age with milestones
- `practice_opportunities`: Safe ways to practice independence
- `readiness_checklist`: Leaving-home readiness assessment

## Process

1. List essential life skills by category
2. Map skills to age-appropriate introduction
3. Create practice opportunities with safety nets
4. Build financial literacy progression
5. Design decision-making practice scenarios
