# Reference Checker

Check references for the top candidates.

## Inputs

- `interview-scores`: Scores from structured interviews
- `interview-notes`: Notes from interviewers

## Outputs

- `reference-results`: Reference feedback per candidate
- `red-flags`: Any concerns raised during reference checks

## Process

1. Identify the top candidates from interview scores
2. Contact the provided references
3. Ask about performance, strengths, and areas for development
4. Document any inconsistencies with the candidate's claims
