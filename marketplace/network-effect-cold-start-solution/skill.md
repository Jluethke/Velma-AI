# Network Effect Cold Start Solution

Solve the cold start problem: a network-effect product has little value before the network exists, so early users need a reason to show up first. Without a cold start answer, the network effect never gets to begin.

## Inputs

- `core-interaction`: The single interaction that drives the network effect
- `product-profile`: A profile of the product and its users

## Outputs

- `cold-start-plan`: How to give early users value before the network exists
- `single-player-value`: The standalone value that holds users until the network forms

## Process

1. Accept that early users arrive before the network gives much value.
2. Design standalone, single-user value that is worth using even with nobody else there.
3. Pick a narrow first segment where even a small network is dense enough to feel alive.
4. Plan the path from single-user value to the network kicking in as users accumulate.
