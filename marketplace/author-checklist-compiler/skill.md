# Author Checklist Compiler

Complete the journal's author checklist covering ethics, data sharing, formatting, and reporting standards.

## Inputs

- `manuscript-draft`: Near-final manuscript
- `journal-checklist`: The target journal's submission checklist or reporting guideline (CONSORT, STROBE, PRISMA)

## Outputs

- `completed-checklist`: Filled-in author checklist with page/section references
- `compliance-gaps`: Any checklist items not yet addressed in the manuscript

## Process

1. Map each checklist item to the corresponding section of the manuscript.
2. Fill in page numbers or section references for each item.
3. Flag any items that cannot be satisfied and note the reason.
4. List compliance gaps that need to be fixed before submission.
