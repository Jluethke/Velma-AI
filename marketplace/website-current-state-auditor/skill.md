# Website Current State Auditor

Audit the current site using analytics, heatmaps, and user feedback.

## Inputs

- `site-url`: The current website URL
- `redesign-motivation`: Why the redesign is happening (low conversions, outdated design, rebrand)

## Outputs

- `current-state-audit`: Summary of current performance, usability issues, and user feedback
- `redesign-opportunities`: Specific areas where the redesign can improve outcomes

## Process

1. Review analytics for traffic patterns, bounce rates, and conversion data.
2. Analyze heatmaps and session recordings for user behavior.
3. Collect user feedback from surveys, support tickets, or interviews.
4. Identify the top problems and opportunities for improvement.
