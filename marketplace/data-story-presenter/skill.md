# Data Story Presenter

Design the visuals and produce the data story presentation.

## Inputs

- `narrative-outline`: Story structure
- `visual-plan`: Charts needed

## Outputs

- `data-story-presentation`: Finished presentation or document with the data story
- `executive-summary`: One-paragraph summary of the insight and recommended action

## Process

1. Build each visual following the narrative order.
2. Add annotations that guide the reader to the insight.
3. Write the executive summary: insight, evidence, recommended action.
4. Review the story end to end: does it answer the core question?
