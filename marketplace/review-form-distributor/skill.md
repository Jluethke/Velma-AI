# Review Form Distributor

Distribute the 360 review forms and track completion.

## Inputs

- `reviewer-assignments`: Reviewer-to-participant assignments
- `reviewer-guidelines`: Instructions for reviewers

## Outputs

- `collected-reviews`: All completed review forms with ratings and comments
- `completion-rates`: Completion rate by reviewer type (self, manager, peer, direct report)

## Process

1. Distribute unique review forms to each reviewer with the participant's name and competencies.
2. Set the review window (typically 2 to 3 weeks) and send the deadline with the form.
3. Send reminders at the midpoint and 3 days before close to non-completers.
4. Close collection and verify minimum reviewer thresholds are met for each participant.
