# Bottleneck Intervention Plan

Build an intervention aimed squarely at the bottleneck, and set a trigger to re-diagnose once it is relieved.

## Inputs

- `lowest-component`: The bottleneck component
- `bottleneck-rationale`: Why that component is the constraint

## Outputs

- `intervention-plan`: A plan whose actions all target the bottleneck component directly
- `reassessment-trigger`: The condition under which you re-score all three components to find the new bottleneck

## Process

1. Match the intervention to the bottleneck. A capability bottleneck needs instruction and practice. An opportunity bottleneck needs environment and schedule changes. A motivation bottleneck needs cue and habit work or a stronger reason.
2. Direct every action in the plan at the bottleneck. Adding unrelated improvements dilutes the effort and obscures whether the fix worked.
3. Set the reassessment trigger, such as once capability reaches a six, re-score all three. Relieving one bottleneck usually reveals a new one.
4. Plan to run the whole diagnostic again after the trigger fires, because the constraint moves as the behavior develops.
