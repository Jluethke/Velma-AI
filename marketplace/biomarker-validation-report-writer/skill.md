# Biomarker Validation Report Writer

Compile the biomarker validation study into a STARD-compliant report.

## Inputs

- `validation-performance`: Performance metrics from the validation cohort
- `roc-curve-data`: ROC analysis from the discovery cohort
- `cohort-characteristics`: Baseline characteristics of both cohorts

## Outputs

- `biomarker-report`: Complete validation report following STARD guidelines
- `clinical-recommendation`: Recommendation on clinical adoption readiness

## Process

1. Structure the report following STARD (Standards for Reporting of Diagnostic Accuracy Studies)
2. Include the flow diagram of participant enrollment
3. Present discovery and validation results side by side
4. State the clinical recommendation with confidence level
