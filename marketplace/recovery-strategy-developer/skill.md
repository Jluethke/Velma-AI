# Recovery Strategy Developer

Develop recovery strategies for each disruption scenario.

## Inputs

- `recovery-objectives`: RTO and RPO targets
- `dependency-map`: Dependencies to recover

## Outputs

- `recovery-strategies`: Strategies per scenario (site loss, system failure, pandemic, vendor failure)
- `resource-requirements`: Resources needed for each recovery strategy

## Process

1. Define recovery strategies for each scenario type
2. Identify alternate sites, systems, and personnel for each strategy
3. Estimate the cost and resource requirements
4. Select the primary and alternate strategy for each scenario
