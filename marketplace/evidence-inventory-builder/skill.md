# Evidence Inventory Builder

Catalog all available evidence sources, classify them by type (experiment, observational study, simulation, expert opinion, case report), and note their methodological characteristics.

## Inputs

- `evidence-sources`: list of studies, reports, simulations, and expert inputs to synthesize
- `synthesis-question`: the question the synthesis must answer

## Outputs

- `evidence-inventory`: cataloged sources with type classification, sample size, and key methodological features
- `evidence-typology`: count and distribution of evidence by type and quality tier

## Process

1. List every source with citation, type, year, sample size, and setting
2. Classify each source into a methodological tier (RCT, quasi-experiment, cohort, cross-section, case study, simulation, expert opinion)
3. Note key design features: blinding, randomization, measurement validity, generalizability
4. Produce a summary table and visual of the evidence landscape
