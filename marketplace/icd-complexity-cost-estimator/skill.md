# Icd Complexity Cost Estimator

Estimate the cost of cognitive load and complexity.

## Inputs

- `option-set`: The options under comparison
- `running-cost-with-opportunity`: The running total to add complexity cost onto

## Outputs

- `running-cost-with-complexity`: The running total including complexity cost
- `complexity-cost-detail`: The attention and decisions each option adds

## Process

1. Rate the ongoing attention and decisions each option adds.
2. Translate the load into a rough monthly cost.
3. Add the complexity cost to the running total and note where it compounds.
