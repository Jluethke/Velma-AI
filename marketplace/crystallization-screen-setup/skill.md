# Crystallization Screen Setup

Set up the initial crystallization screen matrix using vapor diffusion or batch methods.

## Inputs

- `concentrated-sample`: Sample at target concentration
- `screen-selection`: Commercial or custom screen kits to use

## Outputs

- `screen-plates`: Set of crystallization plates with documented conditions per well
- `setup-log`: Date, volumes, temperature, and method for each plate

## Process

1. Select the screening format (sitting drop, hanging drop, or microbatch under oil)
2. Dispense reservoir solutions and protein drops using a robot or manually
3. Seal plates and place at the target temperature (4C or 20C or both)
4. Record setup date, drop ratios, and reservoir volumes for each condition
