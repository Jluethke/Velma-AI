# Volunteer Training Builder

Create training materials including video tutorials, practice exercises, and competency checks for citizen science volunteers.

## Inputs

- `field-protocol`: The observation protocol volunteers will follow
- `common-errors`: Errors observed during protocol testing to address in training
- `delivery-format`: Online self-paced, in-person workshop, or hybrid training model

## Outputs

- `training-curriculum`: Complete training module sequence with learning objectives per module
- `practice-exercises`: Hands-on exercises with known correct answers for skill verification
- `competency-quiz`: Assessment that volunteers must pass before contributing data

## Process

1. Break the protocol into teachable modules aligned with each observation step
2. Create visual examples showing correct and incorrect observations
3. Design practice exercises using real-world examples with known answers
4. Build a competency quiz covering common error scenarios from pilot testing
5. Set the pass threshold for quiz completion before data collection access
