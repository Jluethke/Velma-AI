# Check In Checkout Procedure Writer

Define the standard check-in and check-out procedures.

## Inputs

- `property-type`: Type of property and its PMS system
- `service-level`: Target service level and brand standards

## Outputs

- `check-in-procedure`: Step-by-step check-in procedure
- `check-out-procedure`: Step-by-step check-out procedure

## Process

1. Write the check-in steps from greeting through key issuance.
2. Write the check-out steps from folio review through departure.
3. Include the express and mobile check-in alternatives.
4. Set the time target for each procedure.
