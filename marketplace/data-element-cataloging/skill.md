# Data Element Cataloging

Catalog the data elements, purposes, legal bases, and retention periods for each processing activity.

## Inputs

- `processing-activities`: List of processing activities
- `system-inventory`: Systems involved in processing

## Outputs

- `data-catalog`: Catalog of data elements per activity (categories, sensitivity, purpose, legal basis, retention)
- `third-party-recipients`: List of third parties receiving personal data and the purpose of each transfer

## Process

1. For each processing activity, list the personal data categories collected (name, email, financial, health, biometric).
2. Document the purpose for each data category and the legal basis (consent, contract, legitimate interest, legal obligation).
3. Set the retention period for each data category based on legal requirements and business need.
4. Identify all third-party recipients and document the transfer mechanism (DPA, SCCs, adequacy decision).
