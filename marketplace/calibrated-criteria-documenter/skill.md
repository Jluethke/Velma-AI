# Calibrated Criteria Documenter

Document the calibrated criteria with the anchor examples the group agreed on. Written criteria with concrete examples let the next cycle start calibrated instead of relitigating every level.

## Inputs

- `discussion-record`: The reasoning from the discussion
- `resolved-ratings`: The agreed ratings

## Outputs

- `calibrated-criteria`: What each rating level means in observable terms, drawn from the discussion
- `anchor-examples`: A concrete anonymized example attached to each level

## Process

1. For each rating level, write what it means in observable terms, drawn from the discussion.
2. Attach an anchor example to each level: a concrete anonymized case the group agreed represents it.
3. Capture the distinctions that caused the most disagreement, since those are where raters drift.
4. Distribute the calibrated criteria and anchors to all managers before the next rating cycle.
