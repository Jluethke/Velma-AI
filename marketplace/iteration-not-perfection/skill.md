# Iteration Not Perfection

Run the system for 30 days, then iterate. The goal is consistency, not perfection. An 80% hit rate on default meals is excellent.

## Inputs

- `default-meals`: The meal system
- `environment-changes`: Environment redesign

## Outputs

- `system-review`: 30-day review: how many days did you use default meals, how do you feel (energy, satiety, digestion), and what meals need adjustment
- `iteration-changes`: Swap out meals that did not work, adjust portions, add variety to the rotation

## Process

1. Track simply: did you eat a default meal today? Yes or no. 80% (24 of 30 days) is excellent. 60% needs troubleshooting. Below 50% means the defaults are not convenient enough or not enjoyable enough.
2. After 30 days, assess: do you have more energy? Are you less hungry between meals? Are you spending less time deciding what to eat? These are the metrics that matter, not the scale.
3. Swap out any default meal that you skipped more than twice. It is not sustainable for you. Replace it with something you will actually eat.
4. Add one new default meal per month. Over 6 months, you build a rotation of 10+ meals. Variety prevents boredom without requiring daily decision-making.
