# Network Forensics Report Writer

Produce the network forensics report with traffic analysis findings.

## Inputs

- `activity-map`: Attacker network activity map
- `exfiltration-findings`: Data exfiltration analysis
- `network-iocs`: Extracted network indicators of compromise

## Outputs

- `network-forensics-report`: The complete network forensics report
- `ioc-feed`: Machine-readable IOC feed for detection systems

## Process

1. Write the network activity narrative with packet-level evidence
2. Document data exfiltration findings and volume estimates
3. Include the network IOC list in both human and machine-readable formats
4. Provide recommendations for network monitoring improvements
