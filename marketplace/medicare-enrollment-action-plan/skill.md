# Medicare Enrollment Action Plan

Build a step-by-step enrollment action plan with deadlines, documents needed, and follow-up.

## Inputs

- `plan_choice`: Chosen Medicare path
- `enrollment_windows`: Applicable enrollment dates
- `current_insurance`: Transitioning from what coverage

## Outputs

- `enrollment_timeline`: Step-by-step with dates
- `documents_needed`: What to have ready
- `follow_up_checklist`: Post-enrollment verification steps

## Process

1. Set calendar reminders for enrollment dates
2. Gather required documents
3. Complete enrollment applications
4. Verify enrollment confirmation
5. Schedule first appointments with new coverage
