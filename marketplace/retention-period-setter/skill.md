# Retention Period Setter

Set and document retention periods for each data type.

## Inputs

- `data-inventory`: Data inventory
- `purpose-register`: Purpose and legal basis register

## Outputs

- `retention-schedule`: Retention period for each data type with justification
- `deletion-procedures`: Procedures for data deletion at the end of retention

## Process

1. Set retention periods based on purpose, legal requirements, and business need
2. Document the justification for each retention period
3. Define the deletion or anonymization procedure at expiration
