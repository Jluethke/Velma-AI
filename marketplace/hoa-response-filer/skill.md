# Hoa Response Filer

Respond to the HOA and produce the violation resolution record.

## Inputs

- `correction-record`: Documentation of corrections
- `remediation-cost`: Actual remediation cost

## Outputs

- `hoa-response`: Response filed with the HOA including photos
- `violation-resolution-record`: Complete file for the violation from notice through resolution

## Process

1. Draft the response to the HOA with before and after photos.
2. Submit the response before the deadline.
3. File the complete record: notice, assessment, corrections, response, and resolution confirmation.
