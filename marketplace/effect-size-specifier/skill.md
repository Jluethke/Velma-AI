# Effect Size Specifier

Define the minimum effect size of interest: how large a difference or association must be to matter practically or theoretically.

## Inputs

- `research-question`: The question the study addresses
- `prior-evidence`: Previous studies or pilot data estimating the expected effect

## Outputs

- `target-effect-size`: The minimum effect size (e.g., Cohen's d, odds ratio, R-squared)
- `effect-size-justification`: Why this effect size matters and how it was determined

## Process

1. Review prior studies for observed effect sizes in similar questions.
2. Determine the smallest effect that would be practically or clinically meaningful.
3. If no prior data exists, use the field's conventional small/medium/large benchmarks with justification.
4. Document the chosen effect size, its metric, and the reasoning.
