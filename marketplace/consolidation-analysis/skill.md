# Consolidation Analysis

Evaluate debt consolidation options: balance transfer, personal loan, and home equity.

## Inputs

- `debt_summary`: Current debt details
- `credit_score`: Approximate credit score
- `home_equity`: Available home equity if any

## Outputs

- `consolidation_options`: Available consolidation paths
- `savings_comparison`: Interest saved per option
- `consolidation_recommendation`: Whether to consolidate and how

## Process

1. Check balance transfer card eligibility
2. Compare personal loan rates at current credit score
3. Evaluate home equity options if applicable
4. Calculate interest savings per option
5. Assess risks of each approach
