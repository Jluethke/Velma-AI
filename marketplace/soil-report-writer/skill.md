# Soil Report Writer

Produce the soil analysis report with all measurements, interpretations, and recommendations.

## Inputs

- `suitability-assessment`: Land use suitability ratings
- `amendment-recommendations`: Recommended soil amendments

## Outputs

- `soil-report`: The full soil analysis report
- `data-tables`: Summary tables of all measured properties

## Process

1. Compile all measurements into summary tables with units and reference ranges.
2. Write the interpretation section explaining what each result means for the site.
3. Present amendment recommendations with expected outcomes and costs.
4. Include methods, lab accreditation, and quality control results.
