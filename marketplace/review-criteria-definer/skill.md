# Review Criteria Definer

Define the review criteria and timeline for the performance cycle.

## Inputs

- `review-period`: The time period being reviewed
- `company-values`: Values and competencies to assess

## Outputs

- `review-criteria`: Criteria and rating scale for the cycle
- `review-timeline`: Key dates and deadlines for the cycle

## Process

1. Define the performance dimensions (results, competencies, values)
2. Set the rating scale with behavioral anchors
3. Establish the timeline (self-assessment, feedback, calibration, delivery)
4. Communicate the process to all participants
