# Evaluation Data Collector

Collect data from participants, staff, and program records.

## Inputs

- `evaluation-design`: Methodology and sampling plan
- `data-collection-instruments`: Instruments to use

## Outputs

- `collected-data`: Raw data from all sources
- `collection-log`: Record of data collection activities and response rates

## Process

1. Administer surveys to participants and stakeholders
2. Conduct interviews and focus groups
3. Review program records and administrative data
4. Document response rates and any collection issues
