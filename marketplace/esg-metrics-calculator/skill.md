# Esg Metrics Calculator

Calculate the ESG metrics and indicators required by the selected frameworks.

## Inputs

- `esg-data-package`: Collected data by pillar
- `data-quality-notes`: Data quality documentation

## Outputs

- `esg-metrics`: Calculated metrics and indicators mapped to each framework requirement
- `performance-summary`: Summary of performance against targets and prior year

## Process

1. Calculate each metric per the framework's methodology (intensity ratios, percentages, absolute figures).
2. Compare each metric to the prior year and any stated targets.
3. Flag metrics where performance declined or targets were missed.
4. Map each calculated metric to the specific framework disclosure it satisfies.
