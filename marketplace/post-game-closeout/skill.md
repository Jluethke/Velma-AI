# Post Game Closeout

Handle post-game tasks: results reporting, incident documentation, and venue breakdown.

## Inputs

- `game-result`: Final score and key events
- `game-log`: Detailed event log

## Outputs

- `results-submission`: Official result submitted to the league or tournament
- `incident-reports`: Any incident reports filed (injuries, ejections, protests)

## Process

1. Submit the official result to the league or tournament system.
2. File incident reports for any injuries, ejections, or protests.
3. Break down the venue and secure equipment.
4. Produce the game day record.
