# Analysis Intake Designer

Define the intake process for ad-hoc analysis requests.

## Inputs

- `analyst-team`: Who handles analysis requests
- `common-requestors`: Who typically submits requests

## Outputs

- `intake-form`: Standardized request form with required fields
- `triage-criteria`: How to classify requests by urgency and complexity

## Process

1. Define who can submit requests and through what channel.
2. Design the intake form: question, context, deadline, decisions it supports.
3. Set triage criteria: urgent (same day), standard (this week), research (this month).
