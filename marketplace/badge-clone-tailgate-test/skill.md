# Badge Clone Tailgate Test

Attempt badge cloning and tailgating through controlled access points.

## Inputs

- `entry-point-map`: Doors with badge readers to test
- `security-pattern-notes`: Guard patterns for timing tailgate attempts

## Outputs

- `badge-clone-results`: Results of badge cloning attempts
- `tailgate-results`: Results of tailgating attempts with success rates

## Process

1. Attempt to capture badge credentials from authorized personnel (long-range readers)
2. Clone captured credentials to a test card
3. Test cloned credentials at badge reader entry points
4. Attempt tailgating by following authorized personnel through doors
