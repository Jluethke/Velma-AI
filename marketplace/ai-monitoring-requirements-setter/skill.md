# Ai Monitoring Requirements Setter

Set monitoring and alerting requirements for AI systems.

## Inputs

- `risk-classification`: Systems by risk tier
- `control-requirements`: Required controls

## Outputs

- `monitoring-requirements`: What to monitor per system and how
- `alerting-rules`: Alerting thresholds and escalation paths

## Process

1. Define the monitoring metrics per system type.
2. Set alerting thresholds for drift, bias, and errors.
3. Define the escalation path for each alert type.
4. Document the monitoring cadence and reporting.
