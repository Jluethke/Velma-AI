# Proposal Document Writer

Write the proposal document.

## Inputs

- `pricing-model`: Pricing structure
- `value-justification`: Value and ROI justification

## Outputs

- `proposal-document`: The complete proposal document ready for presentation
- `executive-summary`: One-page executive summary for decision-makers

## Process

1. Write the executive summary: problem, approach, expected outcome, investment.
2. Write the full proposal sections: background, objectives, approach, team, timeline, deliverables, pricing, terms.
3. Add the firm's credentials and relevant case studies.
4. Design the document for readability (headers, white space, visual timeline).
5. Have a second set of eyes review for errors, tone, and completeness.
