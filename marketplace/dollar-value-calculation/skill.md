# Dollar Value Calculation

Convert each pain point into a dollar amount per year using the prospect's own numbers.

## Inputs

- `pain-points`: The identified pain points
- `pain-evidence`: Frequency, time, error rates, missed opportunities

## Outputs

- `pain-in-dollars`: Each pain point converted to an annual dollar cost using a transparent formula
- `total-annual-pain`: Sum of all pain points in dollars per year

## Process

1. For time-based pain: hours per week x fully loaded hourly rate x 52 weeks. Use the prospect's stated hours and their approximate salary level (or ask). Example: 8 hours/week x $50/hour x 52 = $20,800/year.
2. For error-based pain: error rate x number of transactions x average cost per error. Example: 5% error rate x 200 transactions/month x $150/error x 12 months = $18,000/year.
3. For opportunity-based pain: number of missed opportunities x average value per opportunity. Example: 2 missed deals/month x $5,000 average deal x 12 months = $120,000/year.
4. Show your math transparently. The prospect should be able to verify every number. If they adjust a number, recalculate in real time. Their corrections make the final number more credible, not less.
