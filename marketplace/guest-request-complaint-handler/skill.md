# Guest Request Complaint Handler

Handle guest requests and complaints at the front desk.

## Inputs

- `reservation-workflow`: Reservation procedures
- `service-level`: Service standards

## Outputs

- `request-handling-guide`: Standard responses for common requests
- `complaint-escalation-matrix`: When and how to escalate complaints

## Process

1. Catalog the most common guest requests and their standard responses.
2. Define the escalation path for complaints by severity.
3. Set the resolution authority at each level.
4. Document the logging requirement for each interaction.
