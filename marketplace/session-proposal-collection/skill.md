# Session Proposal Collection

Collect session proposals and speaker availability for the event.

## Inputs

- `event-details`: Event name, dates, venue, expected attendance, and theme
- `call-for-proposals`: The criteria and format for session proposals

## Outputs

- `session-proposals`: All submitted proposals with title, speaker, duration, topic, AV needs, and speaker availability
- `speaker-availability`: Each speaker's available and unavailable time slots during the event

## Process

1. Publish the call for proposals with the submission format, topics, and deadline.
2. Collect proposals: title, abstract, speaker name and bio, session format (talk, panel, workshop), requested duration, AV/room requirements.
3. Collect each speaker's availability across the event dates (travel constraints, other commitments, preferred time of day).
4. Review and accept proposals based on the evaluation criteria. Notify accepted and declined speakers.
