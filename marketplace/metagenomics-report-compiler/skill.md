# Metagenomics Report Compiler

Compile the metagenomics analysis into a structured report with taxonomy, diversity, differential abundance, and functional results.

## Inputs

- `alpha-diversity`: Alpha diversity metrics per sample
- `differential-taxa-list`: Significant taxa with statistics
- `functional-summary`: Key functional findings

## Outputs

- `metagenomics-report`: The complete analysis report with methods, results, and figures
- `supplementary-tables`: Full taxonomy, diversity, and pathway tables for archival

## Process

1. Structure the report: methods, QC summary, taxonomy, diversity, differential abundance, function
2. Embed key figures (bar plots, ordination, heatmaps, forest plots)
3. Write interpretive text for each section
4. Package supplementary tables for data archival
