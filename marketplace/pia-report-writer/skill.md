# Pia Report Writer

Document the assessment for regulatory compliance and organizational record-keeping.

## Inputs

- `legal-basis-determination`: Legal basis analysis
- `control-recommendations`: Recommended mitigations

## Outputs

- `pia-report`: Complete privacy impact assessment report
- `action-items`: Required actions before processing can proceed

## Process

1. Compile all assessment components into the standard PIA format
2. List required actions and their owners
3. Include the sign-off section for the data protection officer
4. Archive the report for regulatory inspection readiness
