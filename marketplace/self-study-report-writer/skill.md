# Self Study Report Writer

Write the self-study report compiling findings, evidence, and remediation for submission.

## Inputs

- `self-study-findings`: Compliance status and evidence for each standard
- `new-evidence`: Newly collected evidence for gap standards

## Outputs

- `self-study-report`: Complete self-study report document
- `evidence-appendix`: Organized evidence appendix referenced by the report

## Process

1. Organize findings by standard in the required format
2. Integrate evidence references throughout the narrative
3. Compile the evidence appendix
4. Review for completeness and accuracy
