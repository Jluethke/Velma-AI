# Filing Document Drafter

Draft the filing in the prescribed format with all required content.

## Inputs

- `collected-data`: Collected data and documents
- `requirements-checklist`: Filing requirements

## Outputs

- `draft-filing`: Draft filing document in the required format
- `exhibits-package`: Supporting exhibits and attachments

## Process

1. Draft the filing narrative in the required format
2. Populate all required data fields and tables
3. Compile exhibits and supporting attachments
