# Annotation Tool Configurator

Select and configure the annotation tool for the project.

## Inputs

- `annotation-schema`: Label taxonomy
- `data-samples`: Sample data to configure the tool

## Outputs

- `tool-config`: Configured annotation tool setup
- `tool-documentation`: How to use the tool for this project

## Process

1. Select the annotation tool based on data type and schema.
2. Configure the label set and input format.
3. Set up the review and adjudication workflow.
4. Test the configuration with sample data.
