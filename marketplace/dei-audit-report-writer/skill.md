# Dei Audit Report Writer

Produce the final DEI audit report.

## Inputs

- `representation-report`: Representation data
- `pay-equity-results`: Pay equity results
- `dei-roadmap`: Roadmap

## Outputs

- `dei-audit-report`: Final DEI audit report
- `dei-dashboard`: Dashboard for ongoing tracking

## Process

1. Compile the full report with data, findings, and roadmap
2. Create the dashboard for leadership to track progress
3. Draft the employee communication summarizing the findings and commitments
4. Set the cadence for the next audit
