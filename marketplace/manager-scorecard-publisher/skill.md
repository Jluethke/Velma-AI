# Manager Scorecard Publisher

Create a recurring manager scorecard that presents the leading and lagging indicators in a single view. Publish it quarterly. The scorecard is not punitive. It is diagnostic. Managers who see their own data in context are more likely to self-correct than managers who receive only verbal feedback.

## Inputs

- `intervention-plans`: Interventions for flagged managers
- `escalation-criteria`: When coaching escalates to role change

## Outputs

- `scorecard-template`: The template for the quarterly manager scorecard, showing leading and lagging indicators with company quartile benchmarks
- `delivery-process`: How the scorecard is delivered to each manager (private, with their manager, with context and coaching resources)

## Process

1. Design the scorecard: one page, each indicator shown as a value with the company median and quartile boundaries. Green, yellow, red coloring based on quartile.
2. Deliver privately: each manager sees only their own data, not other managers'. The scorecard is shared with their manager for coaching purposes.
3. Include context: if a manager's turnover rate is high but all departures were low performers, note that. Context prevents misinterpretation.
4. Publish quarterly. Over time, managers learn to self-monitor and correct before the scorecard arrives.
