# Awareness Channel Selector

Select the channels and tactics for the awareness campaign.

## Inputs

- `audience-definition`: Target audience
- `key-message`: Core message

## Outputs

- `channel-plan`: Selected channels with roles and budget
- `media-timeline`: Timeline for each channel activation

## Process

1. Evaluate channels by audience reach and cost
2. Select the channel mix (PR, social, events, partnerships, display)
3. Build the media timeline
