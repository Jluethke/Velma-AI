# Oncall Handoff Protocol

Define handoff procedures for shift transitions including status updates, open incidents, and context transfer.

## Inputs

- `oncall-handbook`: The on-call handbook document
- `rotation-schedule`: The on-call rotation calendar

## Outputs

- `handoff-checklist`: Checklist for each shift transition
- `handoff-template`: Template for the handoff status update

## Process

1. Define the handoff meeting format and duration
2. Create the checklist of items to cover during handoff
3. Build the template for documenting open issues and context
4. Establish the handoff communication channel
