# Tabletop Scenario Designer

Design each scenario with injects, decision points, and facilitator notes.

## Inputs

- `complexity-schedule`: Ordered scenarios with difficulty level
- `learning-objectives-per-exercise`: What each exercise should achieve

## Outputs

- `scenario-packages`: Complete scenario for each exercise with situation brief, injects, decision points, and facilitator guide
- `participant-materials`: Handouts, reference cards, and role assignments for each exercise

## Process

1. Write the situation brief (what happened, what is known, what is unknown)
2. Design 5 to 8 injects per exercise (new information that changes the situation)
3. Define decision points: what should the team decide and what are the consequences of each option
4. Write facilitator notes: timing, expected discussion topics, correct and incorrect responses
