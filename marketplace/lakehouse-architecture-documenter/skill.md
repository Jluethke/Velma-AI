# Lakehouse Architecture Documenter

Produce the lakehouse architecture document.

## Inputs

- `governance-config`: Governance and access control setup
- `performance-benchmarks`: Query performance baselines

## Outputs

- `architecture-document`: Complete lakehouse architecture document
- `operations-runbook`: Runbook for lakehouse operations

## Process

1. Compile the architecture design with layer descriptions and data flows.
2. Document the governance model and access control policies.
3. Write the operations runbook (compaction, optimization, troubleshooting).
4. Include cost estimates and capacity planning guidance.
