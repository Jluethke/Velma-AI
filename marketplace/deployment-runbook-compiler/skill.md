# Deployment Runbook Compiler

Document the deployment runbook and compile the complete deployment strategy document.

## Inputs

- `pipeline-test-results`: End-to-end test results
- `rollback-procedure`: The rollback procedure

## Outputs

- `deployment-runbook`: Step-by-step deployment runbook
- `deployment-strategy-document`: Complete deployment strategy documentation

## Process

1. Write the step-by-step deployment runbook for operators
2. Include pre-deployment checks, deployment steps, and post-deployment validation
3. Document the rollback procedure with decision criteria
4. Compile the full deployment strategy document
