# Lms Course Builder

Build the course in the learning management system, uploading content and configuring navigation.

## Inputs

- `content-assets`: All produced content files
- `course-storyboard`: Module-by-module outline

## Outputs

- `lms-course`: Course configured in the LMS and ready for testing
- `navigation-map`: Map of course structure and navigation paths

## Process

1. Create the course shell in the LMS
2. Upload and organize content by module
3. Configure navigation, prerequisites, and completion tracking
4. Set up the discussion forums and communication tools
