# Buyer Journey Content Mapper

Map content types and topics to the buyer journey stages.

## Inputs

- `persona-profiles`: Target personas
- `question-bank`: Persona questions by stage

## Outputs

- `journey-content-map`: Content types and topics assigned to each journey stage
- `format-recommendations`: Recommended format for each content piece

## Process

1. Match content types to each journey stage (blog, guide, case study, comparison)
2. Assign topics from the question bank
3. Recommend the format based on the topic and stage
