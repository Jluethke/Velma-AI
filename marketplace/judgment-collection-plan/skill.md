# Judgment Collection Plan

Plan for collecting a judgment if won: payment demand, garnishment, and liens.

## Inputs

- `judgment_amount`: Amount awarded
- `defendant_info`: Defendant's known assets and employment

## Outputs

- `collection_steps`: Step-by-step collection process
- `enforcement_options`: Garnishment, lien, and levy options
- `timeline_expectations`: Realistic collection timeline

## Process

1. Send formal demand letter with judgment
2. File for wage garnishment if employed
3. Place lien on property if applicable
4. Consider bank levy for known accounts
5. Know when to use a collection agency
