# Learning Objective Definition

Define learning objectives and skill levels for the CTF event.

## Inputs

- `target-audience`: Who will participate: skill levels and roles
- `training-goals`: Security skills to develop or assess

## Outputs

- `learning-objectives`: Specific skills each challenge should teach or test
- `difficulty-tiers`: Tier definitions: beginner, intermediate, advanced, expert

## Process

1. Map training goals to specific technical skills
2. Define difficulty tiers with clear criteria for each level
3. Allocate challenges across categories and difficulty tiers
