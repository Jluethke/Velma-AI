# Cleaning Package Designer

Define the cleaning service packages with scope, pricing model, and add-on options.

## Inputs

- `target-market`: Target market (residential, commercial, or both)
- `service-area`: Geographic service area and travel radius

## Outputs

- `service-packages`: Defined packages (standard, deep, move-in/move-out) with scope, pricing, and duration estimates
- `pricing-model`: Pricing structure (per hour, per square foot, flat rate) with add-on pricing

## Process

1. Define the base packages: standard recurring, deep clean, and move-in/move-out.
2. For each package, list the included tasks and the expected duration by property size.
3. Set the pricing model (hourly, per square foot, or flat rate) and minimum charge.
4. Define add-on services (inside oven, inside fridge, windows, laundry) with separate pricing.
