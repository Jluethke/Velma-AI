# End Of Day Report Compiler

Compile the daily report for each child and distribute to parents.

## Inputs

- `activity-log`: The day's activity log
- `concern-flags`: Any flagged concerns
- `positive-highlights`: Positive moments to share

## Outputs

- `daily-reports`: Individual daily reports for each child ready for distribution
- `distribution-confirmation`: Confirmation that all reports were sent to parents

## Process

1. Compile each child's activity log, highlights, and any concerns into the daily report format.
2. Attach any photos taken during the day (with consent).
3. Send the reports to parents via the communication app before pickup time.
4. Log the distribution confirmation.
