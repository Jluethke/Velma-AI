# Narrative Structurer

Structure the narrative using situation, complication, resolution.

## Inputs

- `key-insight`: The main finding
- `supporting-evidence`: Data backing the finding

## Outputs

- `narrative-outline`: Story arc: situation, complication, resolution
- `visual-plan`: Which charts and visuals support each part of the narrative

## Process

1. Write the situation: what the audience expects or assumes.
2. Write the complication: what the data shows that challenges or confirms the assumption.
3. Write the resolution: what action the insight suggests.
4. Plan the visuals: one chart per key point, no more.
