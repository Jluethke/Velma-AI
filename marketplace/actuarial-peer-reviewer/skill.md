# Actuarial Peer Reviewer

Peer review the actuarial analysis for accuracy, reasonableness, and compliance.

## Inputs

- `method-results`: Results from each actuarial method
- `selected-estimate`: The selected estimate and rationale

## Outputs

- `peer-review-findings`: Findings from the peer review (data checks, method validation, reasonableness tests)
- `actuarial-report`: Final actuarial report with the selected estimate, supporting analysis, and peer review sign-off

## Process

1. Verify the data sources and reconcile totals against the source systems.
2. Check the calculations for arithmetic accuracy.
3. Test the reasonableness of the selected estimate against benchmarks and prior analyses.
4. Document the review findings and sign off on the final report.
