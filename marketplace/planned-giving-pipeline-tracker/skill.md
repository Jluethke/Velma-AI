# Planned Giving Pipeline Tracker

Track the planned giving pipeline and produce the program plan.

## Inputs

- `prospect-list`: Planned giving prospects
- `cultivation-plan`: Outreach strategies

## Outputs

- `pipeline-report`: Status of each prospect in the pipeline
- `planned-giving-plan`: Complete planned giving program document

## Process

1. Track each prospect through cultivation stages (awareness, interest, commitment, documented)
2. Record confirmed expectancies and their estimated values
3. Report on pipeline status and matured gifts
4. Compile the program plan with goals, strategies, and metrics
