# Evaluation Plan Writer

Write the evaluation plan with indicators, data collection, and analysis methods.

## Inputs

- `logic-model`: Logic model with outcomes
- `program-narrative`: Program description

## Outputs

- `evaluation-plan`: Complete evaluation methodology
- `data-collection-tools`: Instruments and schedules for data collection

## Process

1. Define process and outcome evaluation questions
2. Select indicators for each outcome in the logic model
3. Describe data collection methods, frequency, and responsible staff
4. Explain the analysis approach and how results will inform the program
