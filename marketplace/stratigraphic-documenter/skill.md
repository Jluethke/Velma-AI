# Stratigraphic Documenter

Document the site stratigraphy by recording layer sequences, interfaces, and depositional contexts.

## Inputs

- `excavation-records`: Field notes, section drawings, and photographs from the excavation
- `site-grid`: Site grid coordinates and unit designations

## Outputs

- `harris-matrix`: Stratigraphic sequence diagram showing the temporal relationships between contexts
- `context-register`: Register of all contexts with descriptions, elevations, and soil characteristics

## Process

1. Assign context numbers to each distinct stratigraphic unit
2. Record the physical characteristics (color, texture, inclusions) of each context
3. Determine the stratigraphic relationships (above, below, cuts, fill) between contexts
4. Construct the Harris matrix from the observed relationships
