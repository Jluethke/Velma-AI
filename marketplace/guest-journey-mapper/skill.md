# Guest Journey Mapper

Map the guest journey across all touchpoints.

## Inputs

- `property-type`: Type of property (hotel, resort, B&B)
- `target-guest-profile`: Primary guest segments and their expectations

## Outputs

- `journey-map`: Guest journey map with all touchpoints by phase
- `pain-points`: Current friction points in the guest experience

## Process

1. Define journey phases (pre-arrival, arrival, stay, departure, post-stay).
2. List every touchpoint within each phase.
3. Identify the current pain points at each touchpoint.
4. Map emotional highs and lows across the journey.
