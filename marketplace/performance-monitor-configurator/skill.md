# Performance Monitor Configurator

Set up page speed and Core Web Vitals monitoring.

## Inputs

- `uptime-config`: Uptime monitoring already in place
- `site-endpoints`: Pages to monitor for performance

## Outputs

- `performance-monitors`: Configured speed and vitals checks
- `performance-baselines`: Baseline scores to detect regressions

## Process

1. Set up scheduled page speed tests on key pages.
2. Configure Core Web Vitals monitoring (LCP, INP, CLS).
3. Record baseline scores for each page.
4. Set alert thresholds for performance regressions.
