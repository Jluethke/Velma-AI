# Test Build And Launch

Build the test in 1-3 days, drive traffic to it, and collect data.

## Inputs

- `test-format`: The type of test to build
- `target-audience`: Who to show the test to

## Outputs

- `test-live-url`: The live test (landing page, signup form, or pre-sale page)
- `traffic-plan`: How to drive 50-200 people from the target audience to the test in 1-2 weeks

## Process

1. Build the test with one clear call to action. No feature tours, no long explanations. One headline, one paragraph, one action button.
2. Drive traffic from the actual target audience, not from friends or general internet traffic. If the target audience is small business owners, post in communities where small business owners are.
3. Set a time limit: the test runs for 1-2 weeks. After that, you have enough data to decide, or you do not have enough traffic (which is itself a signal about the idea's market).
4. Do not optimize the test page during the run. Changing the headline or the offer mid-test invalidates the data. Run it as built, collect data, then analyze.
