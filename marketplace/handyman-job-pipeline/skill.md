# Handyman Job Pipeline

Manage the job pipeline from inquiry through estimate, scheduling, completion, and invoicing.

## Inputs

- `service-categories`: Services offered and pricing
- `minimum-charge-policy`: Minimum charges and estimate fees

## Outputs

- `job-pipeline`: Pipeline of jobs at each stage (inquiry, estimated, scheduled, in-progress, complete, invoiced)
- `estimate-process`: Standardized estimate process with templates and approval workflow

## Process

1. Set up the inquiry intake (phone, web form, referral) with required details.
2. Define the estimating process (phone estimate, on-site visit, photo-based).
3. Create the scheduling workflow from estimate acceptance to job date.
4. Build the completion-to-invoice workflow with payment collection.
