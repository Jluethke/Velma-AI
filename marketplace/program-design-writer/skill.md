# Program Design Writer

Describe the program design, logic model, and implementation plan.

## Inputs

- `needs-statement`: Statement of the problem
- `alignment-assessment`: Funder alignment notes

## Outputs

- `program-narrative`: Description of the program and its theory of change
- `logic-model`: Inputs, activities, outputs, outcomes diagram

## Process

1. Describe the program activities and how they address the need
2. Build the logic model linking inputs to outcomes
3. Include the implementation timeline with milestones
4. Explain the staffing plan and key personnel qualifications
