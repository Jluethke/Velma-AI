# Reliability Assessment Report

Produce the final reliability assessment: the coefficient, the disagreement analysis, the revised codebook, and the recommendation for proceeding.

## Inputs

- `agreement-coefficient`: Reliability statistic
- `disagreement-patterns`: Pattern analysis
- `codebook-revised`: Final codebook

## Outputs

- `reliability-report`: Structured report suitable for a methods section
- `proceed-recommendation`: Whether reliability is sufficient to proceed with full coding

## Process

1. Summarize the reliability coefficient and its interpretation.
2. Describe the main disagreement patterns and how the codebook was revised.
3. State whether reliability meets the field's accepted threshold.
4. Recommend proceeding, re-training, or redesigning the coding scheme.
