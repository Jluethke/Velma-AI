# Control Evidence Mapper

Map each question to existing controls and available evidence.

## Inputs

- `parsed-questions`: Categorized questions
- `evidence-repository`: Existing evidence from prior audits or reviews

## Outputs

- `mapped-questions`: Questions linked to controls and evidence
- `evidence-gaps`: Questions where evidence is missing

## Process

1. Match each question to the corresponding internal control
2. Link available evidence to each mapped question
3. Identify questions with no matching control or evidence
4. Prioritize gap remediation by question criticality
