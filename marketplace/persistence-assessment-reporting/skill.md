# Persistence Assessment Reporting

Compile the persistence and detection assessment into a report for both red and blue teams.

## Inputs

- `detection-timeline`: Detection timing for each technique
- `detection-gap-analysis`: Undetected techniques and actions
- `persistence-log`: All deployed persistence mechanisms

## Outputs

- `persistence-report`: Complete persistence and stealth assessment report
- `detection-improvement-plan`: Specific detection rules and procedures to close identified gaps

## Process

1. Map all red team actions to the MITRE ATT&CK framework
2. Document detection successes and failures with timing
3. Write specific detection rule recommendations for each gap
4. Produce the combined red/blue team improvement plan
