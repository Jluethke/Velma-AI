# Referral Routing

Define how a referral is received, routed, and acknowledged, so no introduction falls through the cracks.

## Inputs

- `forwardable-asset`: The ready-to-send asset
- `intro-template`: The introduction template

## Outputs

- `routing-process`: The path a referral takes from arrival to first contact
- `acknowledgment-plan`: How and when the referrer is thanked and updated

## Process

1. Define where a referral lands and who owns the first response, with a target response time.
2. Make sure the referred person gets a warm, context-aware first contact, not a generic sales touch.
3. Plan how the referrer is thanked quickly, since a slow or silent thank-you ends future referrals.
4. Decide what the referrer hears about the outcome, within the bounds of the referred person's privacy.
