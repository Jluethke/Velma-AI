# Conversation Principles Definer

Define the conversational design principles for the organization.

## Inputs

- `brand-voice`: The brand voice and tone guidelines
- `channel-list`: Channels where conversations happen (voice, chat, SMS, email)

## Outputs

- `design-principles`: Conversational design principles (clarity, brevity, natural language, error recovery, personality consistency)
- `channel-guidelines`: How the principles adapt to each channel (voice vs chat vs SMS)

## Process

1. Define the core principles: be clear, be brief, sound natural, recover from errors gracefully, stay in character.
2. Set the response length guidelines per channel (voice: under 20 seconds, chat: under 3 sentences, SMS: under 160 characters).
3. Define the personality consistency rules (same persona across channels, adapted for medium).
4. Set the accessibility requirements (reading level, language support, accommodations).
