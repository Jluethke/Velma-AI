# System Goal And Current Output

State the system's goal in measurable terms and its current output on the same measure. Without a goal expressed as a number, there is no way to tell whether optimization could ever be enough.

## Inputs

- `system-description`: The system or process under review
- `current-metric`: The metric that defines success for the system

## Outputs

- `system-goal`: The target output stated as a number on the metric
- `current-output`: The system's current output on that metric

## Process

1. State the system's goal as a number on a single clear metric.
2. Measure the system's current output on the same metric.
3. Confirm the metric captures what the system actually exists to produce.
4. Record the gap between current output and goal as the problem to be closed.
