# Strategic Retreat Trigger Definition

Define retreat triggers in advance, while you can still think clearly. A trigger is a specific, observable condition that, once met, means it is time to pull back. Defining them now beats deciding under sunk-cost pressure later.

## Inputs

- `commitment-profile`: The commitment and its goal stated clearly
- `resource-ledger`: The resources tied up and their rough value

## Outputs

- `retreat-triggers`: The named conditions that would signal retreat
- `trigger-thresholds`: The measurable threshold for each trigger

## Process

1. Decide the conditions, set now, under which you would pull back from this commitment.
2. Make each trigger specific and observable, not a vague feeling that things are going badly.
3. Set a measurable threshold for each trigger so there is no arguing later about whether it fired.
4. Write them down now. Triggers defined under pressure get bent to protect the commitment.
