# Quality Report Submission

Submit the quality reports to the applicable programs and archive the documentation.

## Inputs

- `performance-rates`: Calculated measure performance
- `applicable-programs`: Programs and submission requirements

## Outputs

- `submission-confirmation`: Confirmation of successful submission to each program with reference numbers
- `quality-reporting-record`: Complete quality reporting record for the year including data, calculations, and submissions

## Process

1. Format the data according to each program's submission specifications (QRDA, flat file, portal entry).
2. Submit the reports before the deadline for each program.
3. Verify the submission was accepted and record the confirmation.
4. Archive the complete reporting package for audit purposes.
