# Cutover Planner

Plan the cutover window and produce the migration plan document.

## Inputs

- `migration-strategy`: The migration strategy
- `validation-results`: Validation results from test runs

## Outputs

- `cutover-plan`: Detailed cutover timeline and checklist
- `migration-plan-doc`: Complete migration plan document

## Process

1. Schedule the cutover window with stakeholder agreement.
2. Build the minute-by-minute cutover checklist.
3. Define the go/no-go criteria at each checkpoint.
4. Compile the complete migration plan document.
