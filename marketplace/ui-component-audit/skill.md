# Ui Component Audit

Audit the existing UI components and patterns to identify inconsistencies, duplicates, and gaps.

## Inputs

- `product-screens`: Screenshots or URLs of the current product screens
- `existing-component-list`: Any existing list of UI components in use

## Outputs

- `component-inventory`: Full inventory of UI components with usage frequency and inconsistencies
- `gap-analysis`: List of missing or inconsistent components that need standardization

## Process

1. Walk through each product screen and catalog every distinct UI component (buttons, inputs, cards, modals, navigation, typography).
2. Note where the same component appears in different styles or sizes across screens.
3. Identify components that are missing from the current set but needed based on the product's patterns.
4. Produce the component inventory with usage counts and the gap analysis.
