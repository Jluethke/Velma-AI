# Coupon And Deals Strategy

Build a sustainable coupon and deals strategy that saves money without consuming excessive time.

## Inputs

- `store_strategy`: Stores being shopped
- `time_budget`: Minutes per week for deal hunting
- `tech_comfort`: Comfort with apps and digital coupons

## Outputs

- `coupon_system`: Streamlined coupon workflow
- `app_recommendations`: Cashback and coupon apps to use
- `weekly_routine`: Weekly deal-checking routine

## Process

1. Set up store loyalty programs
2. Install relevant cashback apps
3. Build 10-minute weekly deal check routine
4. Focus coupons on items already being bought
5. Track actual savings to validate effort
