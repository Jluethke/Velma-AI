# Capture Protocol Builder

Set up the capture protocol for getting information into the system.

## Inputs

- `note-templates`: Note templates
- `pkm-tool`: PKM tool in use

## Outputs

- `capture-protocol`: Step-by-step process for capturing notes from any source
- `inbox-setup`: Inbox or capture zone for unprocessed notes

## Process

1. Set up a capture inbox (a single place for all unprocessed notes).
2. Define the capture flow: encounter an idea, open the tool, write a fleeting note.
3. Set up mobile capture for on-the-go notes.
