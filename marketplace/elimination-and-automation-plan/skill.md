# Elimination And Automation Plan

For each low-importance decision, design a rule, default, or automation that eliminates the need to decide.

## Inputs

- `classified-decisions`: Decisions in four quadrants
- `quadrant-counts`: How many in each category

## Outputs

- `elimination-rules`: Rules and defaults that remove the need to make low-importance decisions (e.g., 'always eat the same breakfast,' 'process email only at 10am and 3pm,' 'say no to all meetings without an agenda')
- `automation-list`: Low-importance decisions that can be automated through tools, templates, or delegation

## Process

1. For each low-importance/reversible decision, create a default rule. 'What should I wear?' becomes 'I wear the same 5 outfits on rotation.' 'Which email should I answer first?' becomes 'I answer in the order they arrived.'
2. For each low-importance/irreversible decision, create a standard. 'Which vendor for office supplies?' becomes 'Always use vendor X unless they are more than 15% more expensive.'
3. For recurring decisions, look for automation: can a tool, template, or delegation handle this? If you make the same decision every day, it should not require your brain.
4. Estimate how many decisions per day the rules and automation will eliminate. The target is to remove 50% or more of daily decisions.
