# Final Readability Check

Final check: read the piece aloud. If you stumble on a sentence, the reader will stumble too. If a sentence needs to be read twice, rewrite it.

## Inputs

- `final-draft`: The restructured message

## Outputs

- `published-message`: The final, checked message ready to send
- `word-count-reduction`: Percentage reduction from first draft to final draft

## Process

1. Read the piece aloud. Mark every sentence where you stumble, pause, or need to re-read.
2. Rewrite marked sentences. If a sentence is longer than 25 words, split it. If it has more than one comma, simplify.
3. Check the word count against the first draft. A good revision cuts 30-50%. If you cut less than 20%, you were not ruthless enough.
4. Send it.
