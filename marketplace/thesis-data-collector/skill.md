# Thesis Data Collector

Execute data collection following the approved methodology, with progress tracking, quality checks, and secure storage.

## Inputs

- `methodology-chapter`: Approved methods specifying what data to collect and how
- `ethics-approval`: IRB or ethics approval documentation if applicable
- `data-management-plan`: Storage, backup, and security plan for collected data

## Outputs

- `raw-dataset`: Complete raw data in structured format with codebook
- `collection-log`: Chronological log of data collection activities, issues, and deviations
- `quality-summary`: Data completeness, missing values, and quality check results

## Process

1. Set up data collection instruments, databases, and storage following the management plan
2. Collect data following the approved protocol with regular progress logging
3. Run quality checks at predetermined intervals to catch problems early
4. Document any deviations from the protocol with justification
5. Compile the final dataset with a codebook explaining all variables
