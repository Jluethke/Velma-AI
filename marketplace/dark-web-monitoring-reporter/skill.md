# Dark Web Monitoring Reporter

Produce the dark web monitoring report with findings, impact assessment, and trend analysis.

## Inputs

- `impact-assessment`: Impact ratings for each finding
- `response-actions`: Recommended response actions
- `false-positive-log`: Dismissed alerts for tuning analysis

## Outputs

- `monitoring-report`: Dark web monitoring report with executive summary, findings, and response actions
- `tuning-recommendations`: Suggested changes to alerting rules based on false positive patterns

## Process

1. Summarize key findings and their business impact
2. Document response actions taken and their outcomes
3. Analyze false positive rates and recommend rule tuning
4. Identify trends in threat actor activity targeting the organization
