# Service Standard Definer

Define the service standard for each touchpoint in the guest journey.

## Inputs

- `journey-map`: Guest journey map
- `pain-points`: Current pain points

## Outputs

- `service-standards`: Defined standard for each touchpoint
- `measurement-criteria`: How to measure compliance with each standard

## Process

1. Write the expected behavior for each touchpoint.
2. Define the timing standard (check-in under 3 minutes, etc.).
3. Set the measurement method for each standard.
4. Prioritize standards by guest impact.
