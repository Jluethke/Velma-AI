# Youtube Metadata Optimizer

Optimize the video metadata for search and discovery.

## Inputs

- `video-file`: The finished video
- `content-pillars`: The content category for keyword context

## Outputs

- `optimized-metadata`: Title, description, tags, and end screen configuration
- `seo-keywords`: The target keywords and their search volume estimates

## Process

1. Research keywords related to the video topic using search suggest and analytics.
2. Write the title with the primary keyword placed early.
3. Write the description with keywords, timestamps, and links.
4. Select tags and configure end screens and cards.
