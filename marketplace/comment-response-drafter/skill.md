# Comment Response Drafter

Analyze comments and draft responses for the final rule preamble.

## Inputs

- `public-comments`: Categorized comments
- `proposed-rule-text`: Original proposed text for reference

## Outputs

- `comment-responses`: Written response to each comment theme explaining agreement, disagreement, or change made
- `rule-changes`: Changes to the proposed rule based on comments, with rationale

## Process

1. Address each significant comment theme with a substantive response.
2. Identify where comments warrant changes to the proposed rule.
3. Draft the revised rule text incorporating the changes.
4. Document the rationale for accepting or rejecting each suggested change.
