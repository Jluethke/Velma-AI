# Tax Return Reviewer

Review the draft return for accuracy, optimization opportunities, and common errors.

## Inputs

- `draft-return`: Completed draft tax return
- `tax-liability-summary`: Tax liability calculation

## Outputs

- `reviewed-return`: Reviewed tax return with corrections
- `review-notes`: Notes on optimization opportunities and risk areas

## Process

1. Cross-check all amounts against source documents.
2. Verify calculations and form carryovers between schedules.
3. Check for missed deductions or credits.
4. Flag any positions that could trigger audit scrutiny.
