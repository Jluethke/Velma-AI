# Paleoenvironment Reconstruction

Reconstruct the paleoenvironment of the fossil locality by integrating sedimentology, paleoecology, and geochemical proxies.

## Inputs

- `taphonomic-report`: Taphonomic signatures and depositional interpretation
- `taxonomic-assignments`: Faunal and floral list with abundance data
- `dating-plan`: Age constraints for the assemblage

## Outputs

- `paleoenvironment-model`: Reconstructed habitat, climate, and paleogeographic setting
- `site-summary-report`: Integrated report combining taxonomy, taphonomy, dating, and environment for publication

## Process

1. Identify paleoenvironmental indicator taxa and assess community structure
2. Integrate sedimentary facies analysis with stable isotope data where available
3. Compare the reconstructed environment with coeval localities in the region
4. Write the integrated site summary combining all analytical threads
