# Ui Prototype Builder

Build an interactive prototype for usability testing.

## Inputs

- `ui-designs`: High-fidelity screen designs
- `interaction-notes`: Transition and interaction specifications

## Outputs

- `interactive-prototype`: Clickable prototype covering key flows
- `prototype-script`: Test script with tasks for usability testing

## Process

1. Link screens into the primary user flows
2. Add micro-interactions and transition animations
3. Verify all paths through the prototype work
4. Write the usability test script with task scenarios
