# Servicing System Configurator

Set up the loan servicing system for payments, statements, and collections.

## Inputs

- `decision-engine-config`: Decisioning configuration for loan booking
- `product-catalog`: Products with payment terms

## Outputs

- `servicing-config`: Configured servicing for payment processing, statements, and escrow
- `platform-setup-document`: Complete platform documentation for operations and compliance

## Process

1. Configure the payment processing (ACH, autopay, one-time).
2. Set up the statement generation and delivery.
3. Configure the delinquency management and collection workflows.
4. Compile the platform setup documentation.
