# Reservation Management Workflow

Set up the reservation management workflow.

## Inputs

- `check-in-procedure`: Check-in procedure
- `property-type`: Property and system details

## Outputs

- `reservation-workflow`: Reservation handling from booking through arrival
- `overbooking-policy`: Overbooking thresholds and walk procedures

## Process

1. Define the reservation confirmation and pre-arrival communication.
2. Set the overbooking threshold by room type.
3. Write the walk procedure for overbooked guests.
4. Document the cancellation and no-show policies.
