# Ransomware Ir Report Writer

Produce the final ransomware incident response report with timeline, impact, and lessons learned.

## Inputs

- `recovery-log`: Record of all restoration actions
- `data-impact-assessment`: Classification of impacted data

## Outputs

- `ransomware-ir-report`: Complete incident response report
- `remediation-actions`: List of follow-up actions to prevent recurrence

## Process

1. Compile the full timeline from detection through recovery
2. Summarize the business impact (downtime, data loss, financial cost)
3. Document root cause and initial access vector
4. List remediation actions to prevent recurrence with owners and deadlines
