# Binary Assessment Report

Produce the binary exploitation assessment report with findings and remediation.

## Inputs

- `attack-chains`: Documented attack chains
- `exploitability-rating`: Ratings per finding
- `impact-assessment`: Impact descriptions

## Outputs

- `assessment-report`: Complete binary exploitation assessment report
- `remediation-guidance`: Specific fixes for each vulnerability

## Process

1. Organize findings by severity and exploitability
2. Include attack chain diagrams and proof-of-concept descriptions
3. Write specific remediation guidance: code fixes, compiler flags, deployment changes
4. Summarize overall binary security posture
