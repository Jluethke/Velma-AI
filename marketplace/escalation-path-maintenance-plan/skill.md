# Escalation Path Maintenance Plan

Set up ongoing maintenance for the escalation path. Contact info changes, people leave, authority shifts. An escalation path that is not maintained decays within months.

## Inputs

- `drill-results`: Results from the initial drill
- `path-revisions`: Changes identified during testing

## Outputs

- `maintenance-schedule`: When and how the escalation path is reviewed and updated
- `final-escalation-path-document`: The complete, tested, and maintained escalation path

## Process

1. Set a quarterly review: verify all contact info, confirm all receivers still have the required authority, and update the org chart mapping.
2. Set a semi-annual drill: run a Level 2 drill every 6 months. Run a Level 1 skip-level drill annually.
3. Assign an owner for the escalation path document. If no one owns it, no one maintains it.
4. Store the document where it can be accessed during an outage. If the document lives in a system that can go down, print a copy.
