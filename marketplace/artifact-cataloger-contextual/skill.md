# Artifact Cataloger Contextual

Catalog excavated artifacts by context, recording material, type, dimensions, and condition.

## Inputs

- `excavated-artifacts`: Artifacts recovered from each context with find numbers
- `context-register`: Register of stratigraphic contexts

## Outputs

- `artifact-catalog`: Database of artifacts with context, type, material, dimensions, and condition
- `type-frequency-table`: Counts of artifact types per context and phase

## Process

1. Wash, label, and photograph each artifact
2. Classify by material (ceramic, lithic, bone, metal, glass) and type
3. Record dimensions, weight, condition, and any diagnostic features
4. Compile the catalog and compute type frequencies by context
