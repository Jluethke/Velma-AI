# Trademark Application Preparer

Prepare the trademark application for filing.

## Inputs

- `proposed-mark`: The proposed mark
- `selected-classes`: Selected classes
- `gs-description`: Goods and services description

## Outputs

- `application-draft`: Complete trademark application ready for filing
- `specimen-package`: Specimens showing use of the mark in commerce

## Process

1. Complete the TEAS application form with applicant information
2. Upload the mark drawing and any design elements
3. Prepare and attach specimens of use (or declare intent to use)
