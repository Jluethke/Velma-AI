# Tracking Method Designer

Define the tracking method for each habit (streak, frequency, or time-based).

## Inputs

- `priority-habits`: Habits selected for tracking
- `habit-list`: Full ranked habit list

## Outputs

- `tracking-schema`: Tracking method and metric for each habit
- `tracking-tools`: Tools or templates to use for tracking

## Process

1. Match each habit to a tracking type: streak, frequency count, or duration.
2. Define the minimum threshold for a successful day.
3. Select the tracking tool (spreadsheet, app, paper).
