# Catalog Search Builder

Implement search and discovery functionality.

## Inputs

- `populated-catalog`: Catalog with metadata
- `classification-taxonomy`: Classification taxonomy

## Outputs

- `search-interface`: Search and discovery interface
- `discovery-features`: Faceted search, recommendations, and popular assets

## Process

1. Index all metadata for full-text and faceted search.
2. Implement filtering by domain, owner, classification, and quality score.
3. Add recommendations (related assets, frequently used together).
4. Build the browse interface organized by domain and taxonomy.
