# Financial Analysis Reporter

Produce the financial analysis report with findings and recommendations.

## Inputs

- `benchmark-comparison`: Peer comparison results
- `strengths-weaknesses`: Identified strengths and weaknesses

## Outputs

- `financial-analysis-report`: Complete financial ratio analysis report
- `action-items`: Recommended actions to improve financial health

## Process

1. Summarize the overall financial health assessment.
2. Present key findings by ratio category with visualizations.
3. Highlight areas requiring management attention.
4. Recommend specific actions to improve weak ratios.
