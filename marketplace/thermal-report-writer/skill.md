# Thermal Report Writer

Write the thermal analysis report: all transitions identified, mass losses quantified, kinetics characterized, and composition determined.

## Inputs

- `transition-table`: DSC transitions
- `mass-loss-table`: TGA results
- `composition-table`: Composition analysis

## Outputs

- `thermal-report`: Structured characterization report
- `comparison-data`: Parameters formatted for comparison with specifications or literature

## Process

1. Present the DSC and TGA curves with all transitions and mass loss steps annotated.
2. Tabulate all thermal parameters: Tg, Tm, Tc, decomposition onset, residue.
3. Report the composition analysis and crystallinity.
4. Compare to specifications or literature values if applicable.
