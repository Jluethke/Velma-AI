# Product Strategy Application

Apply the job statements to product, marketing, and sales strategy.

## Inputs

- `job-statements`: The synthesized jobs
- `job-priorities`: Which jobs matter most

## Outputs

- `strategy-implications`: Specific changes to: product roadmap (features that do the job better), marketing (messages that speak to the job), onboarding (reduce the anxiety forces), and competitive positioning (address the habit forces)
- `anti-roadmap`: Features currently planned that do NOT serve the core job and should be deprioritized

## Process

1. Product: reorder the roadmap so features that serve the core job get priority. Features that do not serve any identified job move to the bottom or are cut.
2. Marketing: rewrite the primary messaging to describe the job, not the features. 'Get your reports done in minutes instead of hours' is a job. 'Advanced reporting with 50+ templates' is a feature.
3. Onboarding: address the anxiety forces directly in the onboarding flow. If customers feared data loss, show the backup feature on day 1. If they feared complexity, start with the simplest workflow.
4. Competitive positioning: address the habit forces that keep people with competitors. If the habit is 'my team knows how to use it,' offer migration support and team training.
