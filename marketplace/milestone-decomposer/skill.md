# Milestone Decomposer

Break each goal into milestones and identify leading indicators.

## Inputs

- `goal-statements`: Goals to decompose
- `success-criteria`: Success criteria per goal

## Outputs

- `milestone-map`: Milestones per goal with dates
- `leading-indicators`: Early signals that progress is on track

## Process

1. Break each goal into 3-5 milestones with target dates.
2. Identify one leading indicator per goal (an early metric that predicts success).
3. Set the first milestone close enough to build momentum.
