# Voice Use Case Definer

Define the use cases and user personas for a voice agent.

## Inputs

- `business-context`: Description of the business and its customers
- `target-interactions`: Types of interactions the voice agent should handle

## Outputs

- `use-case-catalog`: List of use cases with priority, volume estimate, and complexity rating
- `user-personas`: Personas describing the target callers and their goals

## Process

1. Inventory the interactions the voice agent should handle, ranked by volume and value.
2. Define user personas with their goals, technical comfort, and common frustrations.
3. Rate each use case by complexity (simple lookup, multi-turn, requires authentication).
4. Select the use cases for the initial launch versus later phases.
