# Application Tracker

Track every application component: transcripts, recommendations, tests, essays, and submission status.

## Inputs

- `school_list`: Final school list
- `deadlines`: Application deadlines per school

## Outputs

- `tracking_sheet`: Status tracker for all components
- `deadline_calendar`: Calendar of all deadlines
- `missing_items`: Outstanding items needing action

## Process

1. List all required components per school
2. Map deadlines to a calendar
3. Track submission status for each item
4. Flag missing or late items
5. Send reminder schedule for recommenders
