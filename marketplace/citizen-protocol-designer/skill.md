# Citizen Protocol Designer

Design a field data collection protocol that non-experts can follow accurately, with clear decision trees and visual guides.

## Inputs

- `research-question`: The scientific question the citizen data will address
- `target-observations`: What participants need to observe, measure, or photograph
- `participant-profile`: Expected skill level, age range, and available equipment

## Outputs

- `field-protocol`: Step-by-step observation protocol with decision trees and visual aids
- `data-form`: Standardized data entry form with required fields and allowed values
- `equipment-list`: Equipment each participant needs, with consumer-grade alternatives for lab instruments

## Process

1. Translate the research question into specific observable data points
2. Write step-by-step instructions at a middle-school reading level
3. Create visual decision trees for identification or classification tasks
4. Design the data form with constrained response options to minimize free-text errors
5. Test the protocol with three non-scientist volunteers and revise based on errors
