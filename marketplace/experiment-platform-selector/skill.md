# Experiment Platform Selector

Select the experiment tracking platform based on team needs.

## Inputs

- `team-requirements`: Team size, workflow, and integration needs
- `existing-stack`: Current ML infrastructure

## Outputs

- `platform-selection`: Selected platform with justification
- `integration-plan`: How the platform fits the existing stack

## Process

1. Evaluate candidate platforms (MLflow, W&B, Neptune, ClearML).
2. Score by features, integrations, cost, and team fit.
3. Select the platform and document the rationale.
4. Plan the integration with existing infrastructure.
