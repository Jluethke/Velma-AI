# Promotional Pricing Designer

Set promotional pricing rules for sales, bundles, and volume discounts.

## Inputs

- `optimal-prices`: Optimal price points
- `pricing-constraints`: Margin floors and MAP rules

## Outputs

- `promo-pricing-rules`: Promotional pricing rules and calendar
- `bundle-offers`: Bundle and volume discount structures

## Process

1. Define promotional discount tiers (10%, 20%, clearance).
2. Set rules for which products can be promoted and how often.
3. Design bundle offers and volume discount thresholds.
4. Build the promotional pricing calendar.
