# Dropship Operations Manager

Set up customer service processes and track supplier performance.

## Inputs

- `product-listings`: Active product listings
- `supplier-integration`: Supplier order routing

## Outputs

- `operations-playbook`: Customer service and operations procedures
- `dropshipping-operations-plan`: Complete dropshipping operations plan

## Process

1. Define the customer service process for order inquiries and returns.
2. Set up tracking notification forwarding from supplier to customer.
3. Establish supplier performance metrics (ship time, defect rate, stockouts).
4. Produce the dropshipping operations plan with margin tracking.
