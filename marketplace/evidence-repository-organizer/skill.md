# Evidence Repository Organizer

Organize the evidence repository into a structure matching the audit framework.

## Inputs

- `evidence-repository`: Collected evidence
- `updated-evidence`: Evidence from remediation

## Outputs

- `organized-repository`: Evidence organized by control with index
- `evidence-index`: Table of contents mapping each control to its evidence

## Process

1. Merge original and remediation evidence
2. Organize by control number matching the framework
3. Create an index linking each control to its evidence files
4. Verify all controls have evidence before the mock audit
