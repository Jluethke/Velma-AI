# Isotope Ecology Report

Produce the stable isotope ecology report with the food web, niche analyses, and interpretation.

## Inputs

- `food-web-diagram`: Mapped food web
- `isotopic-niches`: Species niche metrics
- `trophic-positions`: Trophic level estimates
- `dietary-overlap-analysis`: Competition and resource partitioning analysis

## Outputs

- `isotope-ecology-report`: Complete report covering sampling, analytical methods, food web, niche analysis, and ecological interpretation
- `isotope-data-archive`: Raw isotope data formatted for repository submission

## Process

1. Write the methods covering sampling design, laboratory procedures, and statistical analyses
2. Present the food web, niche plots, trophic position estimates, and overlap analysis
3. Discuss the ecological implications: energy flow, resource partitioning, food chain length, keystone roles
4. Format the raw data for archival in a public data repository
