# Treatment Plan Documenter

Document the treatment plan with measurable objectives.

## Inputs

- `agreed-plan`: Mutually agreed treatment approach
- `evidence-citations`: Guideline references

## Outputs

- `treatment-plan-document`: Formal treatment plan with objectives and timelines
- `order-set`: Orders for medications, labs, and referrals

## Process

1. Write the treatment plan with SMART objectives.
2. Include the medication regimen, therapy schedule, and monitoring plan.
3. Generate the order set for implementation.
