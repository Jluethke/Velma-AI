# Procedure Scope Definer

Define the scope of the procedure: what it covers, what it does not, when to use it, and what outcome it produces.

## Inputs

- `procedure-name`: Name of the procedure to document
- `procedure-owner`: Who is responsible for this procedure's accuracy and currency

## Outputs

- `scope-statement`: One paragraph: what this procedure covers, when to use it, and what it produces
- `prerequisites`: What must be true before starting (access, tools, materials, approvals)

## Process

1. State in one sentence what this procedure accomplishes when executed correctly.
2. State when to use it: the trigger event or condition that starts the procedure.
3. State what it does NOT cover. Procedures without explicit boundaries get bloated with exceptions.
4. List every prerequisite: access permissions, tools, materials, prior approvals, training. If a prerequisite is missing, the procedure cannot start.
