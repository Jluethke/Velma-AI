# Copy Channel Adapter

Write copy variations for each marketing channel.

## Inputs

- `messaging-framework`: Core messaging hierarchy
- `campaign-objectives`: Channels and format specifications

## Outputs

- `channel-copy-set`: Copy for web, email, social, and print
- `character-count-log`: Compliance with each platform's limits

## Process

1. Adapt the messaging for the landing page (headline, body, CTA)
2. Write email subject lines and body copy
3. Write social media post copy per platform and character limits
4. Write print ad or direct mail copy
