# Design Brief Clarifier

Receive and clarify the design brief with the client.

## Inputs

- `client-request`: Initial design request or project description
- `brand-guidelines`: Existing brand guidelines if available

## Outputs

- `clarified-brief`: Detailed brief with objectives, audience, and constraints
- `project-timeline`: Milestones and review dates

## Process

1. Identify the deliverable types and specifications
2. Clarify the target audience and context of use
3. Confirm the brand constraints and creative freedom
4. Set the timeline with concept, revision, and delivery milestones
