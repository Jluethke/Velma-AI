# Onboarding Milestone Definer

Define the onboarding milestones and success criteria.

## Inputs

- `product-features`: Key product features and activation points
- `customer-segments`: Customer types and their goals

## Outputs

- `milestone-map`: Onboarding milestones with completion criteria
- `activation-definition`: What counts as a successfully activated customer

## Process

1. Identify the key actions a new customer must complete.
2. Sequence the milestones from signup to activation.
3. Define success criteria for each milestone.
4. Set the target timeline for reaching activation.
