# Dmaic Analyze Phase

Analyze data to identify root causes.

## Inputs

- `baseline-performance`: Current performance data
- `measurement-plan`: Data collection plan

## Outputs

- `root-causes`: Verified root causes with statistical evidence
- `analysis-report`: Statistical analysis results

## Process

1. Generate hypotheses using fishbone diagrams and process mapping
2. Test hypotheses with data (hypothesis tests, regression, ANOVA)
3. Run designed experiments (DOE) if needed to confirm factors
4. Document verified root causes with statistical evidence
