# Email Forensics Report Writer

Produce the email forensics report with authentication analysis and evidence references.

## Inputs

- `spoofing-assessment`: Spoofing analysis results
- `attachment-analysis`: Attachment examination findings
- `server-correlation`: Server log correlation results

## Outputs

- `email-forensics-report`: The complete email forensics report
- `email-evidence-index`: Index of all email evidence with hashes and references

## Process

1. Write the analysis narrative addressing the investigation questions
2. Include authentication verification results for each key message
3. Document attachment findings and malicious indicators
4. Compile the evidence index with message hashes and server log references
