# Perimeter Barrier Test

Test perimeter barriers including fences, gates, and loading dock access controls.

## Inputs

- `entry-point-map`: Entry points to test
- `authorization-scope`: Physical testing boundaries and limitations

## Outputs

- `perimeter-findings`: Perimeter barrier weaknesses and bypass results
- `gate-access-results`: Vehicle and pedestrian gate access test results

## Process

1. Test fence integrity and check for gaps or damage allowing bypass
2. Attempt vehicle gate access by tailgating authorized vehicles
3. Test loading dock access procedures and credential verification
4. Check for unlocked or propped-open emergency exits
