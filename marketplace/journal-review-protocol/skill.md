# Journal Review Protocol

Review journal entries weekly for themes and action items.

## Inputs

- `prompt-library`: Journaling prompts in use
- `journal-schedule`: Current journaling schedule

## Outputs

- `review-protocol`: Weekly review steps for journal entries
- `action-extraction-method`: How to pull action items from entries

## Process

1. Set the weekly review day and time.
2. Read the week's entries and highlight recurring themes.
3. Extract any action items or decisions that surfaced.
4. Note patterns to explore in the next week's prompts.
