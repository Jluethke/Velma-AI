# Monitoring Scenario Definer

Define the monitoring scenarios and detection logic for AML.

## Inputs

- `regulatory-requirements`: Applicable AML regulations and examination findings
- `product-channels`: Products and channels to monitor (deposits, wires, ACH, cards)

## Outputs

- `monitoring-scenarios`: Defined scenarios (structuring, rapid movement, high-risk geography, round-tripping)
- `scenario-logic`: Detection logic and parameters for each scenario

## Process

1. Identify the required scenarios from regulatory guidance and risk assessment.
2. Define the detection logic for each scenario (thresholds, time windows, aggregation rules).
3. Document the rationale for each scenario and its parameters.
