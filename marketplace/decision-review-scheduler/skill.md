# Decision Review Scheduler

Set up periodic review of past decisions and their outcomes.

## Inputs

- `logging-protocol`: The logging rules
- `storage-format`: Where the log lives

## Outputs

- `review-schedule`: When and how past decisions get reviewed
- `review-template`: Template for the review session

## Process

1. Set the review cadence (monthly, quarterly, at project close).
2. Define the review agenda (which decisions, what outcomes, what lessons).
3. Create the review session template.
4. Assign the review facilitator.
