# Practice Task Designer

Design a focused task that isolates the target sub-skill and repeats it many times.

## Inputs

- `target-sub-skill`: One specific sub-skill stated as an observable behavior
- `ability-edge-note`: A note on where this sits at the edge of your ability

## Outputs

- `practice-task`: A task stripped down to the single sub-skill
- `repetition-plan`: How many focused repetitions fit one session

## Process

1. Strip the task down to the single sub-skill, removing unrelated steps.
2. Set the difficulty so success is uncertain but reachable.
3. Plan how many focused repetitions fit into one session.
4. Define what one clean repetition looks like start to finish.
