# Vsm Future State Designer

Design the future state value stream map.

## Inputs

- `waste-catalog`: Identified wastes
- `improvement-opportunities`: Proposed changes

## Outputs

- `future-state-map`: Designed future state VSM
- `target-metrics`: Target lead time, VA ratio, inventory levels

## Process

1. Apply lean principles: produce to takt, implement flow where possible, use pull where flow is not possible
2. Design supermarket and kanban systems for remaining batch processes
3. Identify the pacemaker process
4. Draw the future state map with target metrics
