# Literature Collector

Collect and categorize papers from a defined search: databases, keywords, date range, inclusion and exclusion criteria.

## Inputs

- `research-question`: The question or topic to map
- `search-parameters`: Databases, keywords, date range, inclusion/exclusion criteria

## Outputs

- `paper-corpus`: Collected papers with metadata (title, authors, year, abstract, DOI)
- `search-log`: Record of queries run, databases searched, and papers excluded with reasons

## Process

1. Run the defined search queries across specified databases.
2. Apply inclusion and exclusion criteria to screen results.
3. Extract metadata and abstracts for all included papers.
4. Log the search process for reproducibility.
