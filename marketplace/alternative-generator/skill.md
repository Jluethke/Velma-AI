# Alternative Generator

Generate every alternative you have if this negotiation fails. Be specific: what exactly will you do?

## Inputs

- `negotiation-context`: What you are negotiating for and with whom
- `what-you-need`: The underlying need the negotiation serves (not just the position)

## Outputs

- `alternatives-list`: Every realistic alternative if this negotiation produces no agreement, with the specific actions and outcomes for each
- `alternative-costs`: The cost (time, money, effort, opportunity) of each alternative

## Process

1. List every alternative: other suppliers, other buyers, other employers, other candidates, self-provision, delay, or doing nothing. Include alternatives that require effort to create.
2. Be honest about each alternative: is it real or hypothetical? Can you execute it tomorrow, or does it require months of preparation?
3. Estimate the value of each alternative: what outcome does it produce, and at what cost?
4. Include the status quo: what happens if you negotiate nothing and do nothing differently? The status quo is always an alternative.
