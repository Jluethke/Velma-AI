# Send Rule Configurator

Configure send rules, suppression lists, and frequency caps.

## Inputs

- `sequence-map`: Email sequence with triggers
- `segment-criteria`: Audience targeting rules

## Outputs

- `send-rules`: Trigger logic, suppression, and frequency caps
- `suppression-list`: Contacts excluded from the campaign

## Process

1. Define the send trigger logic for each email
2. Set frequency caps to prevent over-sending
3. Build the suppression list from opt-outs and prior recipients
