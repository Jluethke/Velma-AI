# Agenda And Metrics Setter

Set the agenda and metrics for each review level.

## Inputs

- `review-levels`: The review levels
- `level-purposes`: Purpose of each level

## Outputs

- `agendas`: Standard agenda for each review level
- `metrics-per-level`: Which metrics are reviewed at which level

## Process

1. Write the standard agenda for each level (time-boxed, with roles: facilitator, note-taker, decision-maker).
2. Assign metrics to each level (daily: blockers and WIP; weekly: throughput and risks; monthly: P&L and pipeline; quarterly: OKRs and strategy).
3. Set time limits for each agenda item.
4. Produce the agendas and metrics assignments.
