# Dropship Storefront Builder

List products on the storefront with supplier integration.

## Inputs

- `selected-niche`: Chosen product niche
- `supplier-shortlist`: Selected suppliers

## Outputs

- `product-listings`: Published product listings
- `supplier-integration`: Automated order routing configuration

## Process

1. Import product data from supplier catalogs.
2. Write unique product titles and descriptions (not supplier defaults).
3. Set retail prices with target margin above supplier cost plus shipping.
4. Configure automated order routing to the supplier on purchase.
