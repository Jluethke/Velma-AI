# Chain Poc Builder

Build proof-of-concept demonstrations for each viable attack chain.

## Inputs

- `viable-chains`: Attack chains to demonstrate
- `chain-prerequisites`: Required conditions for each chain

## Outputs

- `chain-pocs`: Working proof-of-concept for each chain
- `success-criteria`: What constitutes successful exploitation of each chain

## Process

1. Execute each chain step by step in the authorized test environment
2. Document the exact commands, payloads, and transitions between steps
3. Record evidence of successful exploitation at each stage
