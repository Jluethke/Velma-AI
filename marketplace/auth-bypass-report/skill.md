# Auth Bypass Report

Produce the authentication bypass assessment report with all findings and remediation.

## Inputs

- `password-reset-findings`: Password reset findings
- `token-security-assessment`: Token security assessment

## Outputs

- `auth-bypass-report`: Complete authentication bypass report
- `remediation-plan`: Prioritized remediation plan

## Process

1. Compile all findings with exploitation evidence
2. Rate each finding by severity and exploitability
3. Recommend specific authentication hardening measures for each issue
