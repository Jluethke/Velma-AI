# Qualification Criteria Definer

Define the criteria for supplier qualification.

## Inputs

- `material-requirements`: Specifications for the material or component to be supplied
- `quality-standards`: Required certifications and quality system standards

## Outputs

- `qualification-criteria`: Weighted scoring criteria (quality, delivery, cost, capacity, certifications)
- `evaluation-scorecard`: Blank scorecard template for assessment

## Process

1. Define the quality requirements (specifications, defect limits, process capability)
2. Define delivery requirements (lead time, on-time rate, flexibility)
3. Define capacity and financial stability requirements
4. Weight the criteria by importance and create the scoring template
