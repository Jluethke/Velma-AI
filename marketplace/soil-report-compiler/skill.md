# Soil Report Compiler

Compile the soil analysis report: test results, interpretations, health score, contamination status, and management recommendations.

## Inputs

- `nutrient-ratings`: Nutrient assessment
- `contamination-assessment`: Contamination evaluation
- `soil-health-score`: Overall health assessment

## Outputs

- `soil-report`: Structured report for the landowner, agronomist, or regulator
- `action-plan`: Prioritized list of management actions with expected outcomes

## Process

1. Present all test results in a clear table with interpretations.
2. Summarize the texture, nutrient, contamination, and health assessments.
3. Prioritize management actions by impact: address limiting factors first.
4. Include a timeline for expected improvement if recommendations are followed.
