# Followup Habit Installer

Install follow-up as a durable habit by reducing friction at every step and anchoring the behavior to existing routines, because the system only delivers its compounding return if it runs automatically, and a follow-up practice that depends on willpower eventually lapses.

## Inputs

- `roi-review-method`: The method for reviewing what follow-up produces
- `follow-through-metrics`: The numbers that indicate follow-up health

## Outputs

- `habit-install-plan`: A plan to make follow-up automatic: triggers, routines, and an initial period of deliberate practice
- `friction-reduction-steps`: Specific changes that lower the effort of capturing, scheduling, and completing follow-ups

## Process

1. Anchor each part of the system to an existing routine. Capture anchors to ending an interaction, scheduling anchors to capture, and working the due list anchors to a fixed daily moment (such as the start of the workday) so none of it depends on remembering to begin.
2. Reduce friction everywhere. Pre-set templates for common follow-ups, a capture tool already open, a one-tap way to mark done. Every bit of friction is a point where the habit can break, so removing friction is how the habit survives.
3. Run a deliberate practice period of a few weeks where you consciously enforce the loop, because a habit needs repetition to become automatic, and the early period is where it is most fragile and most worth protecting.
4. Use the metrics from the review as the feedback that keeps the habit honest. A completion rate you check regularly is a gentle accountability that catches the slip before the practice quietly dies, and once the return is visible the habit largely sustains itself.
