# Geological Mapper

Produce a geological map from field observations: plot contacts, faults, fold axes, and sample locations on a topographic base.

## Inputs

- `site-list`: Field sites and coordinates
- `core-log`: Subsurface data to project to the map
- `rock-classification`: Rock types to map as units

## Outputs

- `geological-map`: Map with formation boundaries, structural symbols, sample locations, and cross-section lines
- `cross-sections`: Vertical profiles showing subsurface structure
- `structural-data-table`: Strike, dip, and structural measurements with locations

## Process

1. Plot field stations, contacts, and structural measurements on the base map
2. Trace formation boundaries between observation points
3. Add fault traces, fold axes, and unconformities
4. Draw cross-sections to show subsurface geometry
5. Add legend, scale, and coordinate grid
