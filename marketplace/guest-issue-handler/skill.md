# Guest Issue Handler

Manage guest-reported maintenance issues.

## Inputs

- `active-work-orders`: Current workload
- `completion-metrics`: Current performance data

## Outputs

- `issue-resolution-log`: Guest issues logged with resolution times
- `maintenance-program-report`: Final maintenance program report with metrics and recommendations

## Process

1. Log each guest-reported issue with priority.
2. Dispatch the appropriate technician.
3. Track resolution time against the SLA.
4. Produce the monthly maintenance report.
