# Subcontractor Progress Tracker

Track subcontractor progress against the project schedule.

## Inputs

- `scope-matrix`: Subcontractor scope matrix
- `conflict-resolutions`: Resolved schedule conflicts

## Outputs

- `progress-report`: Subcontractor progress report by trade
- `schedule-variance`: Variance between planned and actual progress

## Process

1. Collect percent complete from each subcontractor weekly.
2. Compare actual progress against the baseline schedule.
3. Identify subcontractors falling behind and the cause.
4. Escalate schedule risks to the project manager.
