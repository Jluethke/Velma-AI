# Mdp Options Framer

Lay out the options under consideration, each with its trade-off in one line. A decision with one option is an announcement. Naming the real alternatives, including the option to do nothing, is what makes the meeting a decision rather than a rubber stamp.

## Inputs

- `decision-statement`: The decision to be made

## Outputs

- `options-set`: The two to four real options on the table, including the status-quo option where relevant
- `option-tradeoffs`: For each option, the gain and the cost stated in one line each

## Process

1. List the genuine options, capped at four. Beyond four, the meeting debates the list instead of the decision.
2. Include the do-nothing or status-quo option when it is real, so the room is comparing against the true alternative.
3. For each option, write the gain and the cost in one line each. An option with only gains listed is not being described honestly.
4. Cut any option that is a straw man placed only to make another look good. The room will see through it and trust the process less.
