# Application Flow Builder

Configure the online application flow for borrowers.

## Inputs

- `product-catalog`: Available loan products
- `pricing-model`: Pricing tiers for rate quoting

## Outputs

- `application-flow`: Configured online application with fields, document upload, and e-signature
- `disclosure-templates`: Regulatory disclosures for each product (TILA, ECOA, state-specific)

## Process

1. Design the application steps (product selection, personal info, income, consent).
2. Configure the document upload requirements by product.
3. Set up the e-signature workflow and regulatory disclosures.
