# Loss Remediation Plan

Turn the validated objection into specific changes to messaging, qualification, and sales process, with metrics to prove they worked.

## Inputs

- `validated-objection`: The tested dominant objection
- `loss-patterns`: Named loss clusters

## Outputs

- `remediation-plan`: Concrete changes to messaging, qualification, and process tied to each pattern
- `tracking-metrics`: Metrics and a review date to confirm the changes reduced losses

## Process

1. For the validated objection, write one change to messaging, one to qualification criteria, and one to the sales process.
2. Assign each change an owner and a start date so the plan does not die as a document.
3. Define the metric that will move if the change works, such as win rate at the stage where the objection kills deals.
4. Set a review date one quarter out to compare the metric against the baseline from this study.
