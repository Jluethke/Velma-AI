# Pollen Diagram Construction

Build the pollen diagram showing taxon percentages or concentrations plotted against depth or age.

## Inputs

- `pollen-percentages`: Percentage data for all taxa and samples
- `core-samples`: Depth information for each sample

## Outputs

- `pollen-diagram`: Standard pollen diagram with taxa grouped by vegetation type (trees, shrubs, herbs)
- `pollen-zones`: Statistically or visually defined pollen zones marking assemblage changes

## Process

1. Order taxa by ecological group: trees and shrubs (AP), herbs (NAP), aquatics, spores
2. Plot each taxon as a silhouette or bar against the depth/age axis
3. Apply zonation (CONISS or visual) to identify boundaries between distinct assemblages
4. Add the total pollen concentration and charcoal curves as summary tracks
