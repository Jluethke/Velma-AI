# Parental Leave Planner

Plan parental leave logistics: work handoff, benefits, return-to-work timeline, and backup care.

## Inputs

- `employer_policy`: Company leave policy details
- `state_benefits`: State paid family leave availability
- `partner_leave`: Partner leave availability if applicable
- `financial_runway`: Savings available for unpaid leave

## Outputs

- `leave_timeline`: Week-by-week leave plan
- `work_handoff`: Handoff checklist for work responsibilities
- `return_plan`: Return-to-work transition plan

## Process

1. Map all available leave benefits and stack them
2. Build week-by-week timeline with partner coverage
3. Create work handoff document
4. Plan return-to-work ramp including childcare
