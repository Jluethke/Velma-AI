# Abstract Distiller

Distill the entire paper into a structured abstract: background, objective, methods, results, and conclusion in the word limit.

## Inputs

- `results-draft`: Results section for key findings
- `discussion-draft`: Discussion section for the main conclusion

## Outputs

- `abstract-text`: The abstract within the specified word limit
- `keyword-list`: Keywords for indexing

## Process

1. Write one sentence of background establishing why the question matters.
2. State the objective in one sentence.
3. Summarize the methods in one to two sentences (design, sample, main analysis).
4. State the primary result with its key statistic.
5. Close with the main conclusion and its implication.
