# Phone Prompt Scripter

Write the audio prompts for each menu node.

## Inputs

- `menu-tree`: Menu structure with options
- `routing-rules`: Routing for context (hours, hold messages)

## Outputs

- `prompt-scripts`: Word-for-word scripts for each greeting, menu, hold, and error prompt
- `recording-plan`: List of all prompts to record, with talent and session requirements

## Process

1. Write the main greeting, after-hours greeting, and holiday greeting.
2. Write each menu prompt with clear options and timing.
3. Write hold messages, transfer announcements, and voicemail greetings.
4. Compile the recording plan with all scripts, estimated duration, and talent notes.
