# Geotechnical Interpretation And Report

Interpret all investigation data into a final ground model, design parameters, and geotechnical baseline report.

## Inputs

- `field-data`: All field investigation results
- `design-parameters`: Laboratory-derived parameters by stratum
- `preliminary-ground-model`: Pre-investigation expectations for comparison

## Outputs

- `final-ground-model`: Interpreted stratigraphic model with design parameters, groundwater regime, and geotechnical hazards
- `geotechnical-baseline-report`: GBR for construction: anticipated ground conditions, baseline parameters for contractual risk allocation

## Process

1. Cross-correlate all data sources. Plot borehole logs alongside CPT profiles. Use CPT Ic classification to bridge between boreholes. Correlate SPT N-values with CPT qt for consistency check. Identify layers by engineering behavior, not just geological origin.
2. Build cross-sections. Longitudinal and transverse sections through the site showing interpreted layer boundaries. Contour surfaces of key interfaces (top of rock, top of bearing stratum, base of soft clay). Show groundwater levels with seasonal range if known.
3. Assign design parameters to each stratum. Tabulate characteristic values of: unit weight, undrained shear strength (or friction angle and cohesion for drained), compression index, permeability, and stiffness. Provide ranges and recommended values. Note any spatial trends (increasing strength with depth in a clay unit).
4. Write the geotechnical baseline report (GBR) if for tunneling or complex construction. The GBR states the baseline conditions that the contractor prices against. Quantify: percentage of each ground type along alignment, groundwater inflows, abrasivity values for cutter life, boulders or obstructions, and any ground treatment required. Deviations from baseline during construction trigger contractual mechanisms.
5. Identify residual risks and recommend further investigation if needed. Flag areas where borehole spacing is wider than ideal, where unexpected conditions were found, or where parameter scatter is high. Provide recommendations for construction monitoring to verify design assumptions.
