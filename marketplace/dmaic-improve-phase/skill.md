# Dmaic Improve Phase

Develop and implement solutions for verified root causes.

## Inputs

- `root-causes`: Verified root causes
- `project-charter`: Project scope and goals

## Outputs

- `implemented-solutions`: Solutions implemented with verification data
- `improved-performance`: Post-improvement process capability

## Process

1. Generate solution alternatives for each root cause
2. Evaluate and select solutions (impact, feasibility, cost)
3. Pilot the solutions and verify improvement with data
4. Implement the full-scale solutions
