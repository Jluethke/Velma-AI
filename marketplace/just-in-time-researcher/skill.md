# Just In Time Researcher

Research only when a build step blocks you, then return to building.

## Inputs

- `milestone-plan`: Milestones that each end in a working piece
- `first-build-step`: The very first step to start today

## Outputs

- `research-log`: A log of what you researched and learned
- `unblocked-steps`: The build steps you unblocked

## Process

1. Start building and work until you hit a specific block.
2. Research the narrow question that unblocks the current step.
3. Return to building and log what you learned.
4. Resist studying topics you are not yet blocked on.
