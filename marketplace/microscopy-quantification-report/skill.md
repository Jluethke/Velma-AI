# Microscopy Quantification Report

Compile the microscopy quantification into a report with methods, representative images, measurements, and conclusions.

## Inputs

- `summary-statistics`: Statistical summary of all measurements
- `distribution-plots`: Visualization of distributions
- `segmentation-parameters`: Segmentation method details for reproducibility

## Outputs

- `quantification-report`: Complete microscopy quantification report
- `analysis-archive`: Images, masks, measurement tables, and scripts for reproducibility

## Process

1. Write methods: specimen preparation, imaging parameters, segmentation approach, measurement definitions.
2. Include representative images with overlaid segmentation for quality verification.
3. Present summary statistics and distributions in tables and figures.
4. State conclusions about the specimen's microstructure and note any limitations.
