# Reading Note Taker

Take structured notes and highlights while reading.

## Inputs

- `next-reads`: Items currently being read
- `reading-targets`: Reading pace targets

## Outputs

- `reading-notes`: Structured notes and highlights per item
- `key-takeaways`: Top insights from each item

## Process

1. Highlight key passages while reading.
2. Write a one-paragraph summary after each chapter or article.
3. List the top 3 takeaways per item.
