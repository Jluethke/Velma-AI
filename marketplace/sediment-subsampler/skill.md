# Sediment Subsampler

Subsample the core at defined intervals for destructive analyses.

## Inputs

- `core-log`: Visual log with identified boundaries
- `sampling-plan`: Depth intervals and volume required for each analysis

## Outputs

- `subsamples`: Labeled samples at each depth with recorded wet weight
- `sampling-log`: Exact depths, volumes, and any gaps or disturbance noted

## Process

1. Mark sampling positions at the planned interval (typically 1cm or 0.5cm).
2. Extract each subsample using a clean spatula or syringe cutter.
3. Record wet weight and split into aliquots for LOI, grain size, microfossils, and dating.
4. Store dating aliquots separately to avoid contamination.
