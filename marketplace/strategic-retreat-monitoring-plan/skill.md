# Strategic Retreat Monitoring Plan

Set up monitoring so a triggered condition is actually noticed and acted on. A trigger nobody watches is useless, and sunk-cost pressure is strongest exactly when a trigger quietly fires.

## Inputs

- `opportunity-cost-trigger`: The threshold where continuing costs more than it returns
- `permanent-change-trigger`: The condition signaling a permanent shift against the commitment
- `reallocation-trigger`: The multiple at which moving resources is clearly worth it

## Outputs

- `monitoring-plan`: How and how often each trigger is checked
- `review-cadence`: The schedule and owner for trigger reviews

## Process

1. For each trigger, define the signal to watch and where it is measured.
2. Set a review cadence frequent enough to catch a trigger before heavy new losses pile up.
3. Assign an owner for each review, since an unwatched trigger never fires in practice.
4. Plan to pre-commit the response so the review is about facts, not relitigating the decision.
