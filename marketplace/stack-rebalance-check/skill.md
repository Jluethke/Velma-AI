# Stack Rebalance Check

After the 90-day practice period, reassess all three skills and determine whether the stack is balanced or needs another round.

## Inputs

- `practice-plan`: The plan that was executed
- `progress-milestones`: The checkpoints and whether they were met

## Outputs

- `updated-percentiles`: New percentile estimates for all three skills after practice
- `next-action`: Either the stack is balanced (all 3 at 75th+) or a new weakest skill needs a practice round

## Process

1. Reassess the practiced skill using the same evidence-based method: recent output quality, peer comparison, test results.
2. Reassess the other two skills as well. Sometimes neglecting them for 90 days causes slippage.
3. If all three are at or above the 75th percentile, the stack is balanced. Shift to maintenance mode: practice each skill at least once per week to prevent decay.
4. If one skill is still below 75th, it becomes the next practice target. Repeat the cycle.
