# Dpa Instructions Drafter

Draft the processing instructions and purpose limitations.

## Inputs

- `role-assignment`: Controller/processor roles
- `processing-scope`: Processing scope

## Outputs

- `processing-instructions`: Documented processing instructions from controller
- `purpose-limitations`: Restrictions on processing beyond documented instructions

## Process

1. Document the specific processing instructions from the controller
2. Specify that processing must not exceed documented instructions
3. Define the process for the controller to issue new or revised instructions
