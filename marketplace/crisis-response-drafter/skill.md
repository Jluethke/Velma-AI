# Crisis Response Drafter

Draft the response messaging and activate the response team.

## Inputs

- `crisis-assessment`: The severity and scope assessment
- `affected-channels`: Where the crisis is active

## Outputs

- `response-messages`: Approved response messages for each channel
- `response-team-assignments`: Who is handling which channel and responsibility

## Process

1. Assemble the response team (social, PR, legal, product as needed).
2. Draft the initial response (acknowledge, empathize, state next steps).
3. Adapt the message for each affected channel's format and tone.
4. Get approval from the necessary stakeholders before publishing.
