# Workout Programmer

Program the specific workouts for each training phase.

## Inputs

- `training-plan`: Periodized plan with phase goals
- `phase-calendar`: Dates and phase structure

## Outputs

- `workout-library`: Programmed workouts for each day in each phase
- `exercise-database`: Exercise descriptions, progressions, and alternatives

## Process

1. Select exercises for each phase based on the training focus (strength, power, endurance, sport-specific).
2. Set the sets, reps, load, and rest for each exercise.
3. Include warm-up, cool-down, and mobility work.
4. Produce the workout library.
