# Improvement Trend Analyzer

Measure improvement trends over time and produce the retro action report.

## Inputs

- `completion-status`: Status of actions
- `carry-over-list`: Unfinished actions
- `theme-tags`: Themes from retros

## Outputs

- `improvement-trends`: Trends in action completion rate, recurring themes, and carry-over rate
- `retro-action-report`: Complete retrospective action report

## Process

1. Calculate the completion rate per sprint.
2. Identify themes with the most carry-over (systemic issues).
3. Track improvement trends over the last N sprints.
4. Produce the complete retro action report.
