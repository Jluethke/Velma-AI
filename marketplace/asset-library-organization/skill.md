# Asset Library Organization

Organize the assets into a structured library with categories and metadata.

## Inputs

- `asset-catalog`: The complete catalog of brand assets
- `asset-issues`: Issues to resolve during organization

## Outputs

- `library-structure`: The folder structure, naming convention, and metadata schema
- `organized-library`: The assets organized into the library structure

## Process

1. Define the category structure (logos, photography, icons, templates, fonts, color palettes).
2. Set the naming convention and metadata fields (usage context, format, size, last updated).
3. Resolve the flagged issues (remove duplicates, archive outdated versions, flag unauthorized assets).
4. Produce the library structure and organized asset library.
