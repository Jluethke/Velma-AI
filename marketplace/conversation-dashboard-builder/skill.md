# Conversation Dashboard Builder

Build the analytics dashboard for monitoring conversational AI performance.

## Inputs

- `metric-catalog`: Metrics to display
- `data-collection-plan`: Data sources to connect

## Outputs

- `analytics-dashboard`: Dashboard configuration with charts, filters, and drill-downs
- `alert-rules`: Alerts for metric thresholds that need attention

## Process

1. Design the dashboard layout: summary at top, channel breakdowns, intent-level detail.
2. Configure the data connections and refresh intervals.
3. Set alert thresholds for metric degradation (drop in containment, spike in escalation).
