# Co Parenting Expense Tracker

Split and track shared child expenses: medical, education, activities, clothing, and extras.

## Inputs

- `income_ratio`: Approximate income ratio between parents
- `expense_categories`: Categories of shared expenses
- `existing_agreements`: Any existing financial agreements

## Outputs

- `expense_split`: How to split each category
- `tracking_method`: System for tracking and settling expenses
- `dispute_process`: How to resolve expense disagreements

## Process

1. Categorize all child-related expenses
2. Agree on split ratios per category
3. Choose tracking tool or method
4. Set monthly settlement cadence
5. Define dispute resolution process
