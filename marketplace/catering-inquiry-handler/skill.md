# Catering Inquiry Handler

Receive and qualify catering event inquiries.

## Inputs

- `event-details`: Event type, date, location, estimated guest count, and dietary requirements
- `service-capabilities`: Catering capacity, cuisine types, and service area

## Outputs

- `qualified-inquiry`: Qualified inquiry with feasibility assessment and initial cost range
- `site-visit-plan`: Plan for the site visit or virtual walkthrough if needed

## Process

1. Collect the event details (date, time, location, guest count, event type).
2. Check availability and capacity for the requested date.
3. Identify dietary requirements and special requests.
4. Provide an initial cost range and schedule the detailed consultation.
