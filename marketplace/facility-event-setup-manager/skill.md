# Facility Event Setup Manager

Manage the setup, access, and teardown for each booked event.

## Inputs

- `booking-record`: The confirmed booking details
- `booking-calendar`: Master facility calendar

## Outputs

- `setup-instructions`: Room layout, equipment placement, and access details for the event
- `post-event-inspection`: Condition report after the event noting any damage or issues

## Process

1. Provide the room layout diagram and equipment placement instructions to the setup team or renter.
2. Arrange building access: keys, codes, or a host to open and close.
3. After the event, inspect the space: cleanliness, equipment returned, and any damage.
4. Document the inspection results and process any damage charges against the deposit.
