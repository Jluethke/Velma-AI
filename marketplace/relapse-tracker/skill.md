# Relapse Tracker

Run the practice and track relapses into the old pattern as data, not failure.

## Inputs

- `practice-settings`: Low-stakes settings where a slip costs little
- `cue-plan`: Cues that trigger the new pattern

## Outputs

- `relapse-log`: A judgment-free log of relapses
- `relapse-triggers`: The triggers around each relapse

## Process

1. Practice the new pattern in the chosen settings.
2. Log each relapse into the old pattern without judgment.
3. Record the trigger and situation around each relapse.
4. Treat the log as data that guides the next adjustment.
