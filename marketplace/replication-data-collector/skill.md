# Replication Data Collector

Execute the replication protocol, collecting data according to the pre-registered plan with fidelity checks.

## Inputs

- `replication-protocol`: Finalized protocol from the design step
- `materials-list`: All required materials, instruments, and software
- `participant-pool`: Available participants or samples meeting inclusion criteria

## Outputs

- `replication-data`: Complete dataset from the replication study
- `fidelity-log`: Documentation of protocol adherence and any deviations
- `participant-demographics`: Demographic characteristics of the replication sample for comparison

## Process

1. Set up all materials and calibrate instruments following the protocol exactly
2. Recruit and screen participants according to pre-registered inclusion criteria
3. Conduct the study following the protocol with a fidelity checklist for each session
4. Record any deviations from protocol with the reason and time of occurrence
5. Compile the complete dataset and verify data integrity before analysis
