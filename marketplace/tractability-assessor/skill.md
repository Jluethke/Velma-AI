# Tractability Assessor

Assess which gaps are tractable: could a new study feasibly address this gap given current methods, data availability, and ethical constraints?

## Inputs

- `gap-list`: List of identified gaps
- `domain-constraints`: Available methods, data sources, ethical and logistical constraints

## Outputs

- `tractability-ratings`: Each gap rated as tractable, partially tractable, or currently intractable
- `feasibility-notes`: What would be needed to address each gap

## Process

1. For each gap, identify what kind of study would fill it.
2. Check whether the required methods, instruments, and populations are available.
3. Check for ethical, legal, or logistical barriers.
4. Rate tractability and note what would need to change for intractable gaps.
