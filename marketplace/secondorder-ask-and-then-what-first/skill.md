# Secondorder Ask And Then What First

Ask 'and then what?' once: for each first-order effect, name what it causes next.

## Inputs

- `first-order-effects`: The direct, near-term effects of the decision.
- `first-order-notes`: Which first-order effects are good and which are bad.

## Outputs

- `second-order-effects`: What each first-order effect sets off in turn.
- `second-order-notes`: Where a good first-order effect starts to turn bad.

## Process

1. For each first-order effect, ask what it leads to in turn.
2. Write the second-order effects that each first-order effect sets off.
3. Note where a good first-order effect starts to turn bad.
