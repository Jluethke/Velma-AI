# Immunogenicity Assay Design

Design the immunogenicity assay panel to measure humoral and cellular immune responses in preclinical and clinical samples.

## Inputs

- `optimized-formulation`: Final vaccine formulation with expected immune targets
- `target-immune-response`: Desired immune profile guiding assay selection

## Outputs

- `assay-panel`: List of assays (ELISA, neutralization, ELISpot, flow cytometry) with SOPs and acceptance criteria
- `reagent-requirements`: Reagent sourcing, reference standards, and positive controls needed

## Process

1. Select binding antibody assays (ELISA) and functional assays (neutralization, opsonophagocytosis) for humoral response
2. Select T-cell assays (ELISpot, intracellular cytokine staining) for cellular response
3. Define assay acceptance criteria, positive/negative controls, and reportable range
4. Write SOPs with plate layouts, reagent concentrations, and data analysis methods
