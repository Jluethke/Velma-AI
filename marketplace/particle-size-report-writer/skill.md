# Particle Size Report Writer

Compile the particle size analysis into a report with methods, distributions, model fits, and conclusions.

## Inputs

- `comparison-results`: Batch comparison and specification compliance
- `fitted-model`: Distribution model and parameters
- `cumulative-distribution`: Distribution curves and metrics

## Outputs

- `particle-size-report`: Complete particle size analysis report
- `data-package`: Raw and processed data files for archival

## Process

1. Structure the report: objective, technique, sample prep, results, comparison, conclusions
2. Include distribution plots, model overlays, and trend charts
3. State whether samples meet specification and flag any concerns
4. Package the raw and processed data for archival
