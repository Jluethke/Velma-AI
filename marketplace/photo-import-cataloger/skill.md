# Photo Import Cataloger

Import and catalog the raw image files.

## Inputs

- `memory-cards`: Camera memory cards or transferred files
- `shoot-brief`: Description of the shoot and client requirements

## Outputs

- `cataloged-library`: Imported and organized image library with metadata
- `backup-confirmation`: Verification that backups are complete

## Process

1. Import raw files to the catalog application
2. Apply metadata (keywords, shoot name, date, location)
3. Verify file integrity and create a backup copy
4. Organize into collections by scene or subject
