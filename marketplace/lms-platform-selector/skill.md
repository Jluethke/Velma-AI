# Lms Platform Selector

Evaluate and select the LMS platform that best fits the requirements.

## Inputs

- `lms-requirements`: Prioritized list of requirements
- `integration-needs`: Required integrations

## Outputs

- `platform-selection`: Selected LMS platform with justification
- `comparison-matrix`: Feature comparison across evaluated platforms

## Process

1. Identify 3-5 candidate platforms
2. Score each against the requirements matrix
3. Evaluate cost (license, hosting, support)
4. Select the best fit and document the rationale
