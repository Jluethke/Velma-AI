# Content Asset Auditor

Audit existing content assets for repurposing potential.

## Inputs

- `content-inventory`: List of existing content assets (blog posts, videos, podcasts, webinars, whitepapers)
- `target-platforms`: The social platforms to repurpose content for

## Outputs

- `repurposing-candidates`: Ranked list of content assets with the highest repurposing potential
- `format-matrix`: Matrix mapping each candidate to the formats it can become on each platform

## Process

1. Score each content asset on performance (traffic, engagement, shares), evergreen value, and adaptability.
2. Rank assets by repurposing potential.
3. For each top candidate, identify the formats it can become (carousel, short video, thread, infographic, quote card, story).
4. Produce the format matrix mapping content to platform-specific formats.
