# Incident Root Cause Analysis

Determine the root cause and contributing factors of the incident.

## Inputs

- `incident-narrative`: What happened during the incident
- `improvement-areas`: Identified areas for improvement

## Outputs

- `root-cause-finding`: Identified root cause with supporting evidence
- `contributing-factors`: List of factors that contributed to the incident or its severity

## Process

1. Apply root cause analysis techniques (5 Whys, fishbone diagram, fault tree)
2. Distinguish between the root cause and contributing factors
3. Identify systemic issues that allowed the incident to occur or worsen
4. Document the analysis with evidence supporting each finding
