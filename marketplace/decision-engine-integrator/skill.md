# Decision Engine Integrator

Integrate the credit decision engine with the application flow.

## Inputs

- `application-flow`: Configured application intake
- `product-catalog`: Products and eligibility criteria

## Outputs

- `decision-engine-config`: Integrated decisioning with automated approval, decline, and manual review rules
- `decision-audit-trail`: Logging and audit trail configuration for adverse action compliance

## Process

1. Connect the credit bureau pull to the application flow.
2. Configure the automated decision rules (approve, decline, refer to manual review).
3. Set up adverse action notice generation for declines.
4. Configure the audit trail for fair lending compliance.
