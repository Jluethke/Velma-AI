# Activity Data Collector

Collect activity data for all emission sources within the reporting boundary.

## Inputs

- `reporting-boundary`: The defined boundary and scopes
- `data-collection-plan`: Plan listing data sources and responsibilities

## Outputs

- `activity-data-set`: Collected activity data organized by scope and category (fuel, electricity, travel, supply chain)
- `data-gaps`: List of any data gaps or estimates used

## Process

1. Collect Scope 1 data: fuel consumption, refrigerant leaks, process emissions.
2. Collect Scope 2 data: purchased electricity, steam, heating, and cooling.
3. Collect Scope 3 data: business travel, employee commuting, purchased goods, waste, upstream transportation.
4. Document any data gaps and the estimation methods used to fill them.
