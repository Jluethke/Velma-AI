# Audit Scope Definer

Define the audit scope, identify applicable controls, and build the control matrix.

## Inputs

- `audit-standard`: The audit framework (SOC2, ISO 27001, PCI DSS)
- `system-inventory`: Inventory of in-scope systems and processes

## Outputs

- `control-matrix`: Matrix of applicable controls mapped to systems
- `evidence-requirements`: List of evidence needed per control

## Process

1. Map the audit standard's controls to in-scope systems
2. Identify the evidence type required for each control
3. Build the control matrix with owners and evidence sources
4. Estimate the effort to collect each piece of evidence
