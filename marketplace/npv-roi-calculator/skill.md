# Npv Roi Calculator

Compute NPV, ROI, payback period, and IRR for each alternative.

## Inputs

- `cost-estimates`: Cost estimates by period
- `benefit-estimates`: Benefit estimates by period

## Outputs

- `financial-metrics`: NPV, ROI, payback period, and IRR for each alternative
- `comparison-table`: Side-by-side comparison of all alternatives

## Process

1. Calculate net cash flows per period (benefits minus costs) for each alternative.
2. Compute NPV using the established discount rate.
3. Calculate ROI, payback period, and IRR.
4. Build a comparison table ranking alternatives by each metric.
