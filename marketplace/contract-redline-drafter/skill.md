# Contract Redline Drafter

Prepare a redline with proposed changes and alternative language.

## Inputs

- `deviation-list`: Deviations from standard terms
- `negotiation-priorities`: Ranked negotiation items

## Outputs

- `redline-document`: Marked-up contract with proposed changes
- `change-rationale`: Explanation for each proposed change

## Process

1. Draft alternative language for each deviation
2. Mark deletions, additions, and modifications clearly
3. Write a brief rationale for each proposed change
