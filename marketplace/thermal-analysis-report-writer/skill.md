# Thermal Analysis Report Writer

Compile all thermal measurements into a structured report with methods, data, interpretation, and conclusions.

## Inputs

- `thermal-profile`: Unified thermal property summary
- `reference-comparison-table`: Measured vs literature comparison
- `discrepancy-notes`: Any instrument conflicts or unexpected findings

## Outputs

- `thermal-analysis-report`: Complete report with figures, tables, methods, and conclusions
- `data-archive-package`: Raw data files, processed curves, and metadata for archival

## Process

1. Write the methods section covering instrument models, calibration dates, sample preparation, and measurement parameters.
2. Include annotated thermograms, TGA curves, and DMA plots as figures.
3. Present the reference comparison table and discuss any discrepancies.
4. State conclusions about the material's thermal suitability for its intended application.
