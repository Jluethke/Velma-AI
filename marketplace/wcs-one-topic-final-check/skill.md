# Wcs One Topic Final Check

Run the final check before sending: one message, one topic, action visible, length earned. This last pass catches the message that drifted into a second subject or swelled past what the ask requires. The question is simple: can the reader act from the top without reading to the bottom?

## Inputs

- `executive-summary`: The stand-alone summary, if the piece is long
- `numbered-actions`: The actions the reader must take
- `summary-sufficiency-test`: Whether the summary alone was enough to act

## Outputs

- `final-message`: The message cleared to send, one topic, action first, no unearned length
- `send-readiness`: A short checklist result confirming topic, action placement, owners, and deadlines are all set

## Process

1. Confirm the message holds one topic. If a second topic crept in, split it into its own message now.
2. Confirm the reader can act from the first sentence or the summary alone, without hunting through the body.
3. Confirm every action has an owner and a date, and that no action hides in the prose instead of the list.
4. Read it once as the recipient. If any part makes you ask 'so what do you want from me,' fix that part, then send.
