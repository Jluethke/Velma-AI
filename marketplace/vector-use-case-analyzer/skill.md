# Vector Use Case Analyzer

Analyze the use case and define query patterns for the vector database.

## Inputs

- `use-case`: What the vector database will be used for
- `data-profile`: Description of the data to store

## Outputs

- `query-patterns`: Expected query types, volumes, and latency needs
- `requirements-doc`: Functional and non-functional requirements

## Process

1. Document the primary query patterns.
2. Estimate query volume and latency requirements.
3. Define the data size and growth projections.
4. List the filtering and metadata needs.
