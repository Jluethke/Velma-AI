# Ui Usability Tester

Conduct usability testing on the prototype.

## Inputs

- `interactive-prototype`: Clickable prototype to test
- `prototype-script`: Test tasks and questions

## Outputs

- `usability-findings`: Issues found with severity ratings
- `task-completion-rates`: Success and error rates for each task

## Process

1. Recruit 5 to 8 participants matching the user persona
2. Run each session with think-aloud protocol
3. Record task success, errors, and time on task
4. Compile findings and rate severity
