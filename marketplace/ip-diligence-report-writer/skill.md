# Ip Diligence Report Writer

Produce the final IP due diligence report with findings and recommendations.

## Inputs

- `ip-inventory`: IP inventory
- `title-issues`: Title defects
- `fto-risks`: FTO risks

## Outputs

- `ip-diligence-report`: Complete IP due diligence report
- `deal-impact-summary`: Summary of IP findings that affect deal terms

## Process

1. Summarize the IP portfolio value and key assets
2. List all identified risks with severity ratings
3. Recommend deal terms, representations, and indemnities to address IP risks
