# Lidar Analysis Report

Compile the lidar processing results into a final analysis report.

## Inputs

- `validation-results`: Accuracy assessment statistics
- `extracted-features`: Final feature datasets
- `classification-statistics`: Point classification summary

## Outputs

- `lidar-report`: Complete lidar analysis report with methods, products, accuracy, and deliverables
- `deliverable-package`: All output rasters, vectors, and point clouds for the client or collaborator

## Process

1. Write the methods section covering data acquisition, registration, classification, and feature extraction
2. Present the products with maps, cross-sections, and summary statistics
3. Include the accuracy assessment with error statistics and spatial error maps
4. Package all deliverables with metadata and coordinate system documentation
