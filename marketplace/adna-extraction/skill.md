# Adna Extraction

Extract DNA from ancient specimens (bone, tooth, sediment) using protocols optimized for short, damaged fragments.

## Inputs

- `ancient-specimen`: Bone powder, tooth root, or sediment sample prepared under clean-room conditions
- `extraction-protocol`: Selected protocol (silica column, magnetic bead) with blank controls

## Outputs

- `dna-extract`: Purified DNA extract ready for library preparation
- `extraction-log`: Weights, volumes, incubation times, and blank control results

## Process

1. Process the specimen in a dedicated ancient DNA clean room with UV-sterilized equipment
2. Run the lysis, binding, and elution steps per the selected protocol
3. Process extraction blanks alongside every batch to monitor contamination
4. Quantify the extract with a fluorometric assay (Qubit or equivalent)
