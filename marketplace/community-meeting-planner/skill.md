# Community Meeting Planner

Plan and run a neighborhood meeting: venue, agenda, facilitation, and documentation.

## Inputs

- `interested_neighbors`: People who want to attend
- `top_concerns`: Priority topics to discuss
- `available_venues`: Possible meeting locations

## Outputs

- `meeting_plan`: Logistics and agenda
- `facilitation_guide`: How to run the meeting
- `meeting_notes`: Template for documenting decisions

## Process

1. Select venue and date
2. Create focused agenda
3. Send invitations with agenda
4. Prepare facilitation materials
5. Assign note-taker and timekeeper
