# Maintenance Technician Trainer

Train maintenance technicians on procedures and the scheduling system.

## Inputs

- `work-order-templates`: Work order templates
- `pm-task-list`: Task descriptions and procedures

## Outputs

- `training-records`: Completed training documentation
- `procedure-manual`: Maintenance procedure manual

## Process

1. Write step-by-step procedures for each maintenance task
2. Train technicians on procedures, safety, and the CMMS system
3. Assess competency through practical demonstrations
4. Document training completion for each technician
