# Permit Technical Reviewer

Conduct the technical review of the permit application against applicable codes and standards.

## Inputs

- `verified-application`: The complete application package
- `review-routing`: Reviewer assignment and review type

## Outputs

- `review-findings`: Technical findings, code citations, and any required corrections
- `review-recommendation`: Recommendation to approve, approve with conditions, or deny

## Process

1. Review the application against the applicable building codes, zoning ordinances, or regulations.
2. Document any non-compliance items with specific code citations.
3. Determine whether the application can be approved, needs corrections, or must be denied.
4. Write the recommendation with conditions if applicable.
