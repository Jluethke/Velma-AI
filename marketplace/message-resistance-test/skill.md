# Message Resistance Test

Test the message against the most likely resistance points. For each point of resistance, check whether the message already addresses it. If not, revise before sending.

## Inputs

- `message-sequence`: The full message in delivery order
- `belief-map`: The audience's existing beliefs, including ones that conflict with your message

## Outputs

- `resistance-points`: The top 3-5 points where the audience will push back, with the real concern underneath each
- `revised-message`: The message after incorporating pre-emptive responses to the top resistance points

## Process

1. Read the message as the audience would. At each sentence, ask: where would they stop agreeing?
2. For each resistance point, name the stated objection and the real concern underneath it. 'Too expensive' usually means 'I am not sure of the return.'
3. Check whether the message already addresses the real concern. If yes, verify the address is in the audience's vocabulary.
4. If not addressed, insert a pre-emptive sentence that acknowledges the concern and provides evidence. Pre-emption is stronger than rebuttal.
5. Cut any pre-emption that makes the message longer than the audience's attention span. Prioritize the top 3 concerns.
