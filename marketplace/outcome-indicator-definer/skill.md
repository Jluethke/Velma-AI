# Outcome Indicator Definer

Define the outcomes and indicators to measure for the impact report.

## Inputs

- `program-description`: Description of the program or initiative
- `reporting-period`: Time period for the report

## Outputs

- `outcome-framework`: Outcomes with measurable indicators
- `data-collection-plan`: What data to collect and how

## Process

1. List the intended outcomes of the program
2. Define one or more measurable indicators per outcome
3. Specify data sources, collection methods, and responsible staff
4. Set targets or benchmarks for each indicator
