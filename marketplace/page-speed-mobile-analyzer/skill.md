# Page Speed Mobile Analyzer

Analyze page load speed and mobile usability.

## Inputs

- `storefront-url`: Storefront URL
- `funnel-analysis`: Funnel analysis results

## Outputs

- `performance-scores`: Core Web Vitals and mobile usability scores
- `speed-recommendations`: Prioritized speed improvement recommendations

## Process

1. Measure Core Web Vitals (LCP, FID, CLS) for key pages.
2. Test mobile responsiveness on common device sizes.
3. Identify the largest render-blocking resources.
4. Prioritize fixes by impact on the conversion funnel.
