# Derivative Format Definer

Define the derivative formats and production workflow for each.

## Inputs

- `pillar-content-list`: The selected pillar content pieces
- `repurpose-opportunity-map`: Which derivatives each piece can produce

## Outputs

- `derivative-specs`: Format specs for each derivative type (clips, quotes, carousels, threads, audiograms)
- `production-workflow`: Step-by-step workflow for producing each derivative type

## Process

1. For each derivative format, define the specs (duration, dimensions, text limits).
2. Document the production steps for each format (extract, edit, caption, design).
3. Identify which steps can be templated or automated.
4. Estimate the time per derivative by format.
