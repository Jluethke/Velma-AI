# Website Performance Checker

Check page speed, mobile responsiveness, and Core Web Vitals.

## Inputs

- `functional-signoff`: All interactive elements verified
- `site-url`: The site URL

## Outputs

- `performance-report`: Page speed scores, Core Web Vitals, and mobile test results
- `performance-fixes`: List of performance issues to address before launch

## Process

1. Run page speed tests on key pages (homepage, landing pages, forms).
2. Check Core Web Vitals (LCP, FID/INP, CLS) against thresholds.
3. Test responsive layout on phone, tablet, and desktop viewports.
4. Identify and prioritize any performance issues.
