# Ir Tabletop Report

Compile the tabletop exercise results into a final report for leadership and the security team.

## Inputs

- `gap-list`: Prioritized gap list
- `improvement-actions`: Improvement actions with owners

## Outputs

- `tabletop-report`: Complete tabletop exercise report with findings and recommendations
- `action-tracker`: Trackable list of improvement actions for follow-up

## Process

1. Write the exercise summary including scenario, participants, and timeline
2. Document key decisions made and their outcomes
3. Present gaps and improvement actions organized by priority
4. Produce the final report with both executive and technical sections
