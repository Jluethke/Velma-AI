# Dsr Response Delivery

Prepare and send the formal response to the data subject.

## Inputs

- `fulfillment-log`: Record of actions taken
- `exceptions`: Data that could not be processed and reasons

## Outputs

- `response-letter`: The formal response sent to the data subject
- `dsr-record`: The complete DSR record for audit purposes

## Process

1. Draft the response letter summarizing the actions taken and any exceptions.
2. For access or portability requests, package the exported data securely for delivery.
3. Send the response to the data subject through a secure channel.
4. File the complete DSR record (request, verification, actions, response) for audit retention.
