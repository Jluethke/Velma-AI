# Mdp Agenda Sequencer

Sequence the time in the room: brief advocacy for each option, then focused objections, then the decision. Advocacy before objections keeps the room from killing an option before it has been heard. A time box on each phase keeps the meeting from pooling in debate.

## Inputs

- `options-set`: The options to be advocated and challenged
- `decision-owner`: The person who will make the final call

## Outputs

- `meeting-agenda`: The in-room sequence: advocacy, objections, decision, with a purpose for each phase
- `timebox-plan`: Minutes allocated to each phase so the decision phase is never squeezed out

## Process

1. Open with brief advocacy: a short case for each option, ideally from someone who favors it, so every option gets a fair hearing.
2. Move to objections: invite disagreement with the recommendation and surface the risks. Silence here is treated as agreement, not as consent extracted by rushing.
3. Reserve a protected block for the decision itself. If objections run long, cut advocacy time, never the decision.
4. Set the time box per phase and name a facilitator to hold it, separate from the decision owner.
