# Archaeological Dating Selector

Select and apply dating methods appropriate to the site and materials, combining absolute and relative techniques.

## Inputs

- `harris-matrix`: Stratigraphic sequence of the site
- `datable-materials`: Charcoal, bone, ceramic, or other datable samples from each context

## Outputs

- `chronology-table`: Absolute and relative dates for each phase or context
- `dating-method-notes`: Methods used, lab IDs, and calibration details for each date

## Process

1. Identify datable materials from each major context
2. Select appropriate methods (radiocarbon, thermoluminescence, typological seriation)
3. Submit samples and calibrate results (IntCal for radiocarbon)
4. Integrate absolute dates with the stratigraphic sequence to build the site chronology
