# Athlete Progress Monitor

Track athlete progress through the training program and adjust based on performance data.

## Inputs

- `workout-library`: Programmed workouts for reference
- `exercise-database`: Exercise catalog for substitutions

## Outputs

- `progress-report`: Performance tracking data showing improvement, plateaus, and regressions
- `program-adjustments`: Modifications made to the plan based on monitoring data

## Process

1. Log training loads and performance markers for each session.
2. Compare current performance to baseline and phase targets.
3. Identify athletes who are ahead, on track, or behind, and adjust the plan accordingly.
4. Produce the progress report with adjustment notes.
