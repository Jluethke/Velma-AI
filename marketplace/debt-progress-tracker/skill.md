# Debt Progress Tracker

Track payoff progress with milestone celebrations, projected vs actual timeline, and motivation tools.

## Inputs

- `payment_calendar`: Original payment plan
- `debt_summary`: Original debt totals

## Outputs

- `progress_dashboard`: Current balances vs original
- `milestone_map`: Upcoming milestones and rewards
- `timeline_update`: Revised payoff date based on actual payments

## Process

1. Calculate percentage paid off per debt
2. Compare actual vs projected timeline
3. Set milestone rewards at 25/50/75/100%
4. Identify debts close to payoff for motivation
5. Adjust plan if income or expenses changed
