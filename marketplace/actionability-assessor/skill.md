# Actionability Assessor

Assess which lessons are actionable and assign follow-up.

## Inputs

- `category-taxonomy`: Lesson categories
- `capture-protocol`: How lessons are captured

## Outputs

- `action-plan`: Actionable lessons with owners, deadlines, and expected outcomes
- `non-actionable-archive`: Lessons noted but not requiring action (context for future reference)

## Process

1. For each lesson, assess whether it is actionable (can a specific change prevent recurrence?).
2. For actionable lessons, assign an owner, deadline, and expected outcome.
3. Archive non-actionable lessons for reference.
4. Produce the action plan.
