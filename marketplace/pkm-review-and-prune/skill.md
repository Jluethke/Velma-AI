# Pkm Review And Prune

Set up the review and pruning schedule and compile the PKM setup plan.

## Inputs

- `linking-rules`: Linking protocol
- `promotion-criteria`: Promotion criteria

## Outputs

- `review-schedule`: Schedule for reviewing and pruning the knowledge base
- `pkm-setup-plan`: Complete PKM setup document

## Process

1. Set a weekly review to process the inbox and link new notes.
2. Set a monthly review to prune outdated or low-value notes.
3. Compile the full PKM setup plan with method, tool, templates, protocols, and schedule.
