# Lifecycle Automation Documenter

Document the full lifecycle automation and produce the implementation plan.

## Inputs

- `welcome-sequence`: The welcome sequence
- `re-engagement-sequence`: The re-engagement sequence
- `lifecycle-stages`: All stages and transitions

## Outputs

- `automation-map`: Visual map of all automations, triggers, and email sequences
- `lifecycle-plan`: The complete lifecycle management plan with implementation steps and success metrics

## Process

1. Map every automation: trigger event, email sequence, branching logic, exit conditions.
2. Document the data requirements for each trigger (what fields, what tracking).
3. Set the success metrics for each automation (conversion rate, engagement lift, churn reduction).
4. Compile the implementation plan with build order, testing, and launch timeline.
