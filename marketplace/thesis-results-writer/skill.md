# Thesis Results Writer

Analyze the collected data and write the results chapter with tables, figures, and statistical output organized by research question.

## Inputs

- `raw-dataset`: Clean dataset ready for analysis
- `analysis-plan`: Pre-specified analytical plan from the methodology chapter
- `research-question`: Research questions and sub-questions structuring the results

## Outputs

- `results-chapter`: Complete results chapter with narrative, tables, and figures
- `statistical-output`: Complete statistical output files for appendix or supplementary materials
- `analysis-code`: Reproducible analysis scripts with comments

## Process

1. Run descriptive statistics and assess distributional assumptions
2. Execute the pre-specified analyses for each research question in order
3. Create tables and figures that communicate each finding clearly
4. Write the results narrative reporting test statistics, effect sizes, and confidence intervals
5. Document all analysis code for reproducibility
