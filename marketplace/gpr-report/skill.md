# Gpr Report

Compile the GPR survey results into an interpretation report with annotated profiles, plan-view maps, and conclusions.

## Inputs

- `interpretation-maps`: Plan-view feature maps
- `feature-catalog`: Interpreted features with depths and classifications
- `validation-results`: Ground truth comparison results

## Outputs

- `gpr-report`: Full GPR survey report with annotated profiles, maps, and recommendations
- `gpr-data-archive`: All raw and processed data packaged for reproducibility

## Process

1. Annotate representative profile sections with feature picks and depth labels
2. Compile plan-view maps showing all interpreted features
3. Write the interpretation narrative addressing the survey objectives
4. Package all data files and processing parameters for archival
