# Bias Pattern Documenter

Document the patterns of bias revealed during calibration. Which managers consistently over-rate or under-rate? Which managers rate based on recency (the last month of performance rather than the full cycle)? Which managers rate based on effort rather than output? These patterns are coaching opportunities.

## Inputs

- `calibrated-ratings`: Final ratings after calibration
- `calibration-notes`: Key discussions and adjustments

## Outputs

- `bias-pattern-report`: Documented patterns of rating bias by manager, including the type of bias (leniency, severity, recency, effort-based, halo effect) and specific examples
- `coaching-recommendations`: Specific coaching points for each manager with identified bias patterns

## Process

1. Review the calibration adjustments. Group them by manager. If a manager's ratings were adjusted multiple times in the same direction, there is a systematic bias.
2. Classify the bias: leniency (rates everyone high), severity (rates everyone low), recency (bases ratings on recent events), effort-based (rates hard workers high regardless of output), halo effect (one strong trait inflates all ratings).
3. Write the coaching recommendation for each manager: what specific bias to watch for, with the examples from this calibration as evidence.
4. Note: bias patterns are private feedback to the manager, not public. The goal is to help them rate more accurately, not to shame them.
