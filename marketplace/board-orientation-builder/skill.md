# Board Orientation Builder

Build the board orientation program for new members.

## Inputs

- `role-descriptions`: Board positions and duties
- `committee-charters`: Committee structure

## Outputs

- `orientation-materials`: Board binder with all governance documents
- `orientation-schedule`: Agenda for the orientation session

## Process

1. Compile the board binder (bylaws, financials, strategic plan, roster, calendar)
2. Design the orientation session (mission overview, fiduciary duties, key programs)
3. Schedule meetings with the executive director and committee chairs
4. Set up the mentor pairing for each new member
