# Digital Form Designer

Design the digital version of the form with fields, validation, and conditional logic.

## Inputs

- `form-analysis`: The paper form's fields, rules, and dependencies

## Outputs

- `form-design`: Digital form specification with fields, types, validation rules, and conditional logic
- `user-experience-notes`: Notes on layout, mobile compatibility, and accessibility

## Process

1. Map each paper field to a digital field type (text, dropdown, date, checkbox, file upload).
2. Add validation rules (required fields, format checks, range constraints).
3. Design conditional logic (show/hide fields based on other answers).
4. Plan the layout for desktop and mobile use.
