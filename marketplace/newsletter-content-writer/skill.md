# Newsletter Content Writer

Write the newsletter content from the issue plan.

## Inputs

- `issue-plan`: The issue plan with topic and sections
- `audience-profile`: The audience context

## Outputs

- `newsletter-draft`: The written newsletter content ready for design
- `preview-text`: The email preview text (first 90 characters visible in inbox)

## Process

1. Write the lead section: hook the reader in the first two sentences.
2. Write each supporting section with clear value and a link or takeaway.
3. Write the call to action (reply, click, share, buy).
4. Write the preview text that complements the subject line.
