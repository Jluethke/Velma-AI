# Response Accuracy Reviewer

Review responses for accuracy and completeness before submission.

## Inputs

- `draft-responses`: Draft responses to review
- `evidence-attachments`: Evidence referenced in responses

## Outputs

- `reviewed-responses`: Responses verified for accuracy
- `review-notes`: Corrections and improvements made

## Process

1. Verify each response accurately reflects the actual control state
2. Check that evidence supports the claims in each response
3. Correct inaccuracies and strengthen weak responses
4. Verify no confidential information is disclosed unnecessarily
