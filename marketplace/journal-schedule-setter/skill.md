# Journal Schedule Setter

Set the daily journaling time, duration, and environment.

## Inputs

- `journal-format`: Selected journaling format
- `time-available`: Minutes per day available

## Outputs

- `journal-schedule`: Daily time, duration, and location for journaling
- `environment-setup`: Physical or digital setup needed

## Process

1. Pick the time of day that aligns with the format (morning for intention setting, evening for reflection).
2. Set the duration (minimum 5 minutes, maximum matches available time).
3. Prepare the environment (notebook, app, quiet space).
