# Food Storage Plan

Plan storage for prepped meals: containers, labeling, freezer vs fridge, and reheating instructions.

## Inputs

- `weekly_menu`: All prepared meals
- `storage_containers`: Available container types and sizes

## Outputs

- `storage_assignments`: Which container for each meal
- `label_guide`: Labels with contents, date, and reheat method
- `consumption_order`: Which meals to eat first based on freshness

## Process

1. Assign each meal to appropriate container size
2. Determine fridge vs freezer for each item
3. Create labeling system with date and contents
4. Order consumption by perishability
5. Write reheating instructions per meal
