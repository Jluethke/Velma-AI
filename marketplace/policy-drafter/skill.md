# Policy Drafter

Draft the security policy with clear roles, responsibilities, and control statements.

## Inputs

- `policy-scope-document`: Defined scope from prior step
- `regulatory-requirements-map`: Regulation-to-requirement mapping

## Outputs

- `draft-policy`: Complete policy draft with sections, roles, and control statements
- `responsibility-matrix`: RACI matrix for policy controls

## Process

1. Structure the policy with purpose, scope, definitions, and control sections
2. Write control statements for each requirement
3. Assign roles and responsibilities using a RACI matrix
4. Include enforcement and exception procedures
