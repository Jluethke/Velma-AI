# Summative Usability Validation

Conduct the summative human factors validation study to demonstrate that the final device can be used safely and effectively by the intended users in the intended environment.

## Inputs

- `formative-findings`: History of usability problems found and resolved
- `design-iterations`: Final interface design incorporating formative learnings
- `use-related-risk-analysis`: Final risk analysis with critical tasks identified

## Outputs

- `summative-validation-report`: Task completion data, use error data, root cause analysis for any residual use errors, and overall pass/fail determination
- `usability-engineering-file`: Complete human factors file for regulatory submission

## Process

1. Design the summative study: 15 representative users per user group (minimum per FDA guidance). Use the final or production-equivalent device in a simulated use environment that replicates the clinical setting. Include the final labeling (IFU, quick start guide).
2. Define critical tasks from the risk analysis: tasks where a use error could cause serious harm. Each critical task must be tested. Define the success criteria before testing: what constitutes a successful completion, a use error, and a close call.
3. Conduct simulated-use sessions: present participants with clinical scenarios requiring them to perform each critical task. Do not train beyond what the intended user would receive. Observe and record task performance, errors, and difficulties. Do not intervene during the task.
4. After each session, conduct a knowledge-task interview: ask the participant to explain the meaning of displays, symbols, and labels. This tests whether the user understands the information the interface presents, not just whether they can operate the device mechanically.
5. Analyze results: for each critical task, report the number of successful completions, use errors, and close calls. For each use error, perform root cause analysis (perception, cognition, action). If use errors on critical tasks occurred, assess whether the residual risk is acceptable. No use errors on critical tasks that could cause serious harm is the FDA expectation for summative validation.
