# Value Communication Materials

Create the materials that communicate the value case to the customer: the ROI calculation, the value comparison, and the proof points.

## Inputs

- `price-as-value-share`: The price and value share
- `annual-value-per-customer`: The value delivered

## Outputs

- `roi-calculator`: A simple calculator the customer can use to estimate their specific value (input their numbers, see their ROI)
- `value-proof-points`: 3-5 customer examples showing the actual value delivered (with permission)

## Process

1. Build a simple ROI calculator: the customer inputs their specific numbers (team size, hourly rate, error rate, etc.) and sees the estimated annual value and payback period. This makes the value tangible and specific to their situation.
2. Collect value proof points from existing customers: 'Customer X saved $47,000 in the first year.' Real numbers from real customers are more convincing than your own estimates.
3. Create a one-page value summary that shows: the problem, the cost of the problem, how your product solves it, the expected value, the price, and the net value retained by the customer.
4. Train anyone involved in selling to lead with the value conversation, not the feature list. Features describe what the product does. Value describes what the customer gets.
