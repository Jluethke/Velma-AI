# Course Content Producer

Produce the course content: video lectures, readings, and interactive elements.

## Inputs

- `course-storyboard`: Module-by-module outline
- `media-plan`: List of media assets needed

## Outputs

- `content-assets`: All produced content files (videos, documents, interactives)
- `content-inventory`: Inventory of all assets with metadata

## Process

1. Script and record video lectures
2. Write or curate reading materials
3. Build interactive activities and simulations
4. Catalog all assets in the content inventory
