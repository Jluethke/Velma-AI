# Order Sync Configurator

Configure order sync and inventory management across channels.

## Inputs

- `active-accounts`: Marketplace accounts with API access
- `optimized-listings`: Published listings

## Outputs

- `sync-configuration`: Order and inventory sync setup
- `marketplace-setup-plan`: Complete marketplace setup plan

## Process

1. Connect order management to each marketplace via API.
2. Configure inventory sync to prevent overselling.
3. Set up automated order import and status updates.
4. Test the end-to-end flow (order placed, imported, fulfilled, status updated).
