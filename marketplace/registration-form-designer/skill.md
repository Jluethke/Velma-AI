# Registration Form Designer

Design the registration form with all required fields, waivers, and document uploads.

## Inputs

- `program-details`: The program being registered for (sport, divisions, dates, costs)
- `data-requirements`: Required participant information, waivers, and supporting documents

## Outputs

- `form-design`: Registration form layout with all fields, validation rules, and conditional logic
- `waiver-templates`: Liability waiver and media release templates

## Process

1. Define the required fields (participant info, emergency contact, medical, allergies).
2. Add the waiver and media release with digital signature.
3. Set conditional fields (e.g., medical details only if a condition is indicated).
4. Produce the form design.
