# Merge Template Builder

Create the document template with merge field placeholders.

## Inputs

- `merge-fields`: The fields available for insertion
- `document-purpose`: What the merged document is for (letter, label, certificate, notice)

## Outputs

- `merge-template`: The document template with placeholders for each merge field
- `template-preview`: Preview of the template with sample data inserted

## Process

1. Design the document layout for the stated purpose.
2. Insert merge field placeholders at the correct positions.
3. Preview the template with sample data from the data source.
4. Verify formatting holds across different data lengths.
