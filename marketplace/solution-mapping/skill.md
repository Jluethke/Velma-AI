# Solution Mapping

Map your solution only to the problems the buyer actually named, and leave the rest unsaid.

## Inputs

- `problem-list`: The problems the buyer named
- `cost-estimates`: The cost of each problem

## Outputs

- `mapped-solution`: The parts of your solution tied to each stated problem
- `unaddressed-gaps`: Problems you cannot solve, named honestly

## Process

1. Present only the parts of your solution that answer a problem the buyer stated, and skip the rest.
2. Tie each capability back to the exact problem and cost the buyer described, in their words.
3. Name the problems you cannot solve, since honesty here protects the deal from unraveling later.
4. Keep this short, since the buyer has already sold themselves if the discovery was done well.
