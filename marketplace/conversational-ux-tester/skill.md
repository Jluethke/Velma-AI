# Conversational Ux Tester

Test the conversational UX with user walkthroughs and produce the design document.

## Inputs

- `conversation-scripts`: Conversation scripts
- `multimodal-elements`: Multimodal element designs

## Outputs

- `ux-test-results`: Results from user walkthrough testing including task completion, confusion points, and satisfaction
- `conversational-ux-design-doc`: Complete conversational UX design document

## Process

1. Run user walkthroughs for each conversation type with representative users.
2. Note confusion points, abandoned conversations, and unexpected user inputs.
3. Measure task completion rate and user satisfaction.
4. Compile the design document with persona, flows, scripts, multimodal elements, and test results.
