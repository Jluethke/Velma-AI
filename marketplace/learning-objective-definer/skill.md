# Learning Objective Definer

Define learning objectives for each priority skill area.

## Inputs

- `skill-gap-map`: Skill gaps
- `priority-skills`: Prioritized skills

## Outputs

- `learning-objectives`: Specific, measurable learning objectives
- `target-audiences`: Who needs each training by role and level

## Process

1. Write measurable learning objectives for each priority skill
2. Define the target audience for each training
3. Set the proficiency level expected after completion
4. Align objectives with business outcomes
