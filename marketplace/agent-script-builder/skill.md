# Agent Script Builder

Build the agent scripts for common call types.

## Inputs

- `routing-logic`: Call routing rules
- `service-level-targets`: Service level targets

## Outputs

- `agent-scripts`: Scripts for each call type: opening, verification, troubleshooting, closing
- `knowledge-base-links`: Links to relevant knowledge base articles for each call type

## Process

1. Write the standard opening (greeting, identification, verification).
2. Write the resolution scripts for each common call type.
3. Write the escalation script for when the agent cannot resolve the issue.
4. Write the closing script (summary, next steps, satisfaction check).
