# Loss Analysis Cadence

Set up ongoing loss analysis as a quarterly practice, not a one-time exercise.

## Inputs

- `action-plan`: The changes implemented
- `loss-patterns`: The baseline patterns

## Outputs

- `quarterly-schedule`: The ongoing schedule for loss interviews (5 interviews per quarter, 15 minutes each)
- `pattern-tracking`: A simple tracker showing how loss patterns change over time as interventions take effect

## Process

1. Schedule 5 loss interviews per quarter. This is enough to detect patterns without being burdensome.
2. Track the loss patterns quarter over quarter. The patterns you fixed should decrease in frequency. New patterns may emerge.
3. Share the loss analysis findings with the entire team quarterly. Sales teams that understand why they lose outperform teams that only celebrate wins.
4. Close the loop: when a pattern is fixed and the loss rate drops, connect the improvement to the specific intervention. This builds the habit of learning from losses.
