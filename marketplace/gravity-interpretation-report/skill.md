# Gravity Interpretation Report

Synthesize all gravity analysis products into an interpretation report with figures, depth estimates, and geological conclusions.

## Inputs

- `inverted-density-model`: Final subsurface density model from inversion
- `misfit-report`: Data misfit and residual analysis
- `bouguer-anomaly-map`: Original Bouguer anomaly map for reference

## Outputs

- `gravity-report`: Interpretation report with figures, cross-sections, depth estimates, and conclusions
- `data-archive`: Packaged data, models, and processing logs for reproducibility

## Process

1. Compile cross-sections through the density model at key profiles
2. Annotate with depth estimates and geological unit assignments
3. Write the interpretation narrative linking the gravity results to the geological question
4. Package all data, scripts, and intermediate products for archival
