# Portal Content Creator

Write the help content, FAQs, and community forum structure.

## Inputs

- `portal-architecture`: Portal structure and navigation
- `content-requirements`: Content specifications per section

## Outputs

- `portal-content`: Written help articles, FAQs, and guides
- `forum-structure`: Community forum categories and moderation rules

## Process

1. Write help articles for each self-service feature.
2. Build the FAQ section from the most common questions.
3. Define the community forum categories and posting guidelines.
4. Set up the moderation rules and response commitments.
