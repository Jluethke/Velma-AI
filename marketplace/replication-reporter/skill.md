# Replication Reporter

Write the replication report following Registered Report or standard format, documenting all outcomes regardless of direction.

## Inputs

- `comparison-analysis`: Statistical comparison between original and replication
- `fidelity-log`: Protocol adherence documentation
- `pre-registration`: The pre-registered plan for comparison to actual analysis

## Outputs

- `replication-report`: Complete manuscript following replication reporting standards
- `data-and-code-archive`: Reproducible analysis archive (data, code, environment) for repository deposit
- `comparison-table`: Summary table comparing original and replication on all key metrics

## Process

1. Structure the report following the journal's Registered Report or replication guidelines
2. Present both original and replication results side by side with all pre-registered analyses
3. Discuss protocol fidelity, deviations, and their potential impact on results
4. Address whether the replication supports, partially supports, or fails to support the original
5. Prepare the data and code archive for open repository deposit
