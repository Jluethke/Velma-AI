# Course Pilot Evaluator

Pilot the course with a test group and evaluate for usability and learning effectiveness.

## Inputs

- `lms-course`: Course configured in the LMS
- `assessment-setup`: All assessments configured

## Outputs

- `pilot-feedback`: Feedback from pilot participants on usability and content
- `course-package`: Final course package with revisions from pilot

## Process

1. Recruit a small pilot group (5-15 learners)
2. Run the pilot over a compressed timeline
3. Collect feedback on usability, clarity, engagement, and technical issues
4. Revise the course based on pilot results and finalize
