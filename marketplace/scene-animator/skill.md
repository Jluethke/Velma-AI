# Scene Animator

Animate the scenes using the approved animatic timing.

## Inputs

- `character-designs`: Rigged or prepared character assets
- `timing-sheet`: Frame timing for each scene

## Outputs

- `animated-scenes`: Rendered animation frames for each scene
- `animation-notes`: Notes on motion quality and revision needs

## Process

1. Block out the key poses for each scene
2. Add breakdowns and in-between frames
3. Refine the motion curves and secondary action
4. Render the animated scenes for review
