# Employment Review Memo Writer

Produce the employment agreement review memo with findings and recommendations.

## Inputs

- `comp-analysis`: Compensation analysis
- `restrictive-covenant-analysis`: Non-compete analysis
- `termination-analysis`: Termination analysis

## Outputs

- `review-memo`: Employment agreement review memo
- `negotiation-points`: Recommended negotiation points

## Process

1. Summarize all findings organized by topic
2. Highlight the highest-risk provisions
3. List recommended negotiation points in priority order
