# Threat Dev Report Compiler

Compile the threat-driven development report covering threats, mitigations, test results, and residual risk.

## Inputs

- `test-results`: Pass/fail result for each security test case
- `remaining-risks`: Threats where mitigations are incomplete

## Outputs

- `tdd-report`: Threat-driven development report with threats, mitigations, test evidence, and residual risk
- `residual-risk-acceptance`: Documented acceptance or escalation of any remaining risks

## Process

1. Compile all threats, mitigations, and test results into the report.
2. Document residual risks and their acceptance or escalation.
3. Produce the final threat-driven development report.
