# Template Designer

Create the standard templates with branding, placeholder fields, and instructions.

## Inputs

- `template-inventory`: Document types to templatize
- `brand-guidelines`: Branding standards

## Outputs

- `template-files`: The actual template files (DOCX, PPTX, XLSX, or platform-native)
- `usage-instructions`: Instructions for filling out each template correctly

## Process

1. For each template, set the page layout, header/footer, and branding elements (logo, colors, fonts).
2. Add placeholder fields with clear labels (e.g., [Client Name], [Project Start Date], [Deliverable Description]).
3. Write brief inline instructions where the user needs guidance (e.g., 'Summarize the scope in 2-3 sentences').
4. Save each template in the appropriate format.
