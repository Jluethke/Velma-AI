# Change Idea Developer

Develop the change idea to address the root causes.

## Inputs

- `root-causes`: Identified root causes
- `aim-statement`: QI aim and measures

## Outputs

- `change-concept`: Description of the proposed change
- `implementation-plan`: Steps, timeline, and resources for the change

## Process

1. Generate change ideas based on the root causes.
2. Select the most feasible and impactful change.
3. Plan the implementation with responsible parties and timeline.
