# Decision Context Definer

Define the decision the data must support. If the data is not aimed at a decision, it is decoration. Start with: what will the audience do differently after seeing this data?

## Inputs

- `dataset-description`: What data you have and what it covers
- `audience-and-decision`: Who will see this data and what decision they need to make

## Outputs

- `decision-statement`: The specific decision this data must inform, stated in one sentence
- `data-relevance-filter`: Which parts of the dataset matter for this decision and which are noise

## Process

1. Write the decision in one sentence: 'Should we expand into market X?' or 'Should we continue funding project Y?'
2. For each data element, ask: does this change the decision? If removing it would not change what the audience decides, cut it.
3. Note what data is missing that would change the decision. Missing data is more important than present data.
4. If the data does not point toward a decision, say so. Presenting inconclusive data as conclusive is worse than presenting nothing.
