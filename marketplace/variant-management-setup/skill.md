# Variant Management Setup

Set up variant management for products with multiple options (size, color, style).

## Inputs

- `categorized-catalog`: Categorized product catalog
- `product-schema`: Product data schema

## Outputs

- `variant-catalog`: Catalog with variant relationships configured
- `variant-rules`: Rules for variant creation and pricing

## Process

1. Identify which products need variants and which option types apply.
2. Define variant-level fields (SKU suffix, price differential, inventory tracking).
3. Configure parent-child relationships between base products and variants.
4. Set rules for variant images, descriptions, and pricing overrides.
