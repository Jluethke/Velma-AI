# Sla Compliance Reporter

Report on SLA compliance and recommend adjustments.

## Inputs

- `tracking-configuration`: Active SLA tracking setup
- `alert-configuration`: Alert thresholds and escalation actions

## Outputs

- `sla-framework`: Complete SLA management framework document
- `compliance-report-template`: Template for weekly compliance reporting

## Process

1. Define the compliance metrics (% met, average response time, average resolution time).
2. Build the weekly compliance report template.
3. Set the quarterly review cadence for target adjustments.
4. Produce the SLA framework document.
