# Palynological Report

Write the complete palynological report with the diagram, interpretation, and data tables.

## Inputs

- `pollen-diagram`: Final diagram
- `vegetation-reconstruction`: Zone-by-zone vegetation description
- `climate-inference`: Climate interpretations

## Outputs

- `palynology-report`: Complete report including methods, diagram, interpretation, and raw data appendix
- `pollen-data-archive`: Raw and processed pollen data in a standard format for repository submission

## Process

1. Write the methods covering sampling, preparation, counting, and statistical procedures
2. Present the pollen diagram with zone descriptions and photomicrographs of key taxa
3. Discuss the vegetation and climate history in the context of regional records
4. Format the raw data for archival in a palynological database (European Pollen Database, Neotoma)
