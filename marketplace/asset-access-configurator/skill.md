# Asset Access Configurator

Configure the search interface, access permissions, and download tracking.

## Inputs

- `tagged-asset-count`: Number of uploaded and tagged assets
- `tagging-guidelines`: How assets are organized

## Outputs

- `access-config`: Who can search, view, download, and edit assets
- `asset-management-document`: Complete setup document for the media asset management system

## Process

1. Configure the search: full-text search on metadata fields, filter by category, type, date, and rights status.
2. Set access permissions by role: viewers can browse and download, editors can upload and tag, admins can delete and manage schema.
3. Enable download tracking so you know which assets are used and by whom.
4. Compile the asset management setup document.
