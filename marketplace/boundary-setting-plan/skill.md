# Boundary Setting Plan

Define and communicate boundaries for work hours, availability, and obligations.

## Inputs

- `drain_ranking`: Top energy drains
- `current_commitments`: All current obligations
- `non_negotiables`: Things that cannot change

## Outputs

- `boundary_list`: Specific boundaries to set
- `communication_scripts`: How to communicate each boundary
- `commitment_audit`: Commitments to drop, delegate, or renegotiate

## Process

1. List all current commitments and obligations
2. Categorize: keep, drop, delegate, renegotiate
3. Define specific boundary for each drain
4. Write communication scripts for each boundary
5. Identify who needs to hear each boundary first
