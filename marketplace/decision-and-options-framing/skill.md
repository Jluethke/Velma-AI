# Decision And Options Framing

State the decision clearly and list the realistic options (including doing nothing).

## Inputs

- `decision-description`: The decision you are facing
- `options`: The options you are considering (if known)

## Outputs

- `framed-decision`: The decision stated as a specific choice between specific options
- `option-list`: All options including the default (do nothing / status quo), each described in one sentence

## Process

1. State the decision as: 'I am choosing between [option A], [option B], and [option C].' If you cannot state it this way, the decision is not yet clear enough to analyze.
2. Always include the 'do nothing' option. Doing nothing is a choice with its own consequences. Ignoring it biases the analysis toward action.
3. Limit to 3-4 options. More than 4 creates analysis paralysis. If you have more, eliminate the weakest before proceeding.
4. For each option, write a one-sentence description of what it involves. This ensures everyone analyzing the decision has the same understanding of each option.
