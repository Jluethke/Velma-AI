# Incident Template Writer

Write the communication templates used during status page incidents.

## Inputs

- `check-configuration`: Health check setup for each component
- `component-list`: Status page components

## Outputs

- `incident-templates`: Templates for initial notice, update, and resolution communications
- `communication-guidelines`: Guidelines for tone, frequency, and content of status updates

## Process

1. Write the initial incident template: what is affected, what the impact is, when the next update will be.
2. Write the update template: what has changed, what the team is doing, when the next update will be.
3. Write the resolution template: what was affected, what the root cause was, what the team did to fix it.
4. Document the guidelines: update every 30 minutes during an active incident, use plain language, state facts not guesses.
