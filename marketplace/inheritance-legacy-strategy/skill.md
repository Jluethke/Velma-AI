# Inheritance Legacy Strategy

Build a long-term strategy honoring the inheritance: estate plan updates, charitable giving, and family discussions.

## Inputs

- `inheritance_amount`: Total inherited
- `family_situation`: Spouse, children, etc.
- `donor_wishes`: Any known wishes of the deceased

## Outputs

- `estate_plan_updates`: Changes to make to own estate plan
- `charitable_plan`: Giving strategy if desired
- `family_communication`: How to discuss with family if needed

## Process

1. Update own estate plan with new assets
2. Consider charitable giving that honors the deceased
3. Discuss with spouse or family if appropriate
4. Set up separate tracking for inherited assets
5. Review plan annually
