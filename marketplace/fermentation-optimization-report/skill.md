# Fermentation Optimization Report

Compile the optimization study into a report with screening results, response surface analysis, optimal conditions, and validation.

## Inputs

- `response-surface-model`: Model results and surface plots
- `predicted-optimum`: Recommended conditions
- `fermentation-time-courses`: Process data for representative runs

## Outputs

- `optimization-report`: Complete fermentation optimization report
- `recommended-protocol`: Optimized media and process conditions ready for scale-up evaluation

## Process

1. Summarize the screening phase: which components mattered and which did not.
2. Present the response surface model, contour plots, and ANOVA table.
3. State the optimized conditions and the improvement over baseline.
4. Recommend validation runs and note considerations for scaling up.
