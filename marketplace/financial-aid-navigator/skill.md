# Financial Aid Navigator

Navigate financial aid: FAFSA, CSS Profile, merit scholarships, and appeal strategies.

## Inputs

- `family_income`: Household income range
- `assets`: Savings and asset summary
- `school_list`: Schools being applied to

## Outputs

- `aid_timeline`: Filing deadlines and steps
- `scholarship_list`: Merit and need-based opportunities
- `efc_estimate`: Expected family contribution estimate

## Process

1. Calculate estimated family contribution
2. Map FAFSA and CSS Profile deadlines
3. Identify merit scholarships per school
4. Research external scholarship opportunities
5. Prepare appeal letter template if needed
