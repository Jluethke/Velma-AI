# Identity Proving Action List

List the small actions that would prove the identity, then find the smallest one you could not plausibly skip.

## Inputs

- `identity-statement`: The present-tense identity
- `identity-evidence-gap`: The gap between identity and current actions

## Outputs

- `proving-actions`: A set of small actions, each of which an observer would read as evidence of the identity
- `smallest-vote-action`: The smallest single action from the set that still clearly counts as a vote for the identity

## Process

1. List actions a person with this identity would take, from small to large. A reader keeps a book nearby, reads one page, reads a chapter, finishes a book a week.
2. Mark which actions an outside observer would read as proof of the identity. Private intentions are not votes. Visible actions are.
3. Find the smallest action that still counts as a vote, such as reading a single page. The size must survive a tired, busy day.
4. Confirm the smallest action needs no motivation to complete. If it still feels like a decision on a bad day, make it smaller.
