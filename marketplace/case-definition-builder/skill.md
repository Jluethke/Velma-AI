# Case Definition Builder

Establish the case definition specifying the clinical, temporal, and geographic criteria for inclusion.

## Inputs

- `initial-reports`: Early reports of illness including symptoms, timing, and location
- `clinical-presentation`: Description of the illness (symptoms, lab findings, severity)

## Outputs

- `case-definition`: Confirmed, probable, and suspect case criteria
- `case-classification-guide`: Decision tree for classifying each reported case

## Process

1. Review initial clinical presentations to identify the syndrome
2. Define confirmed cases (lab-confirmed), probable (clinical + epidemiologic link), and suspect (clinical only)
3. Set the time and place boundaries for the investigation
4. Document the classification guide for field use
