# Email Ab Test Designer

Design A/B tests for subject lines, CTAs, or send times.

## Inputs

- `email-drafts`: Draft emails to test
- `campaign-brief`: Campaign goals and KPIs

## Outputs

- `test-plan`: A/B test variants and success criteria
- `test-variants`: Alternative subject lines, CTAs, or send times

## Process

1. Select the variable to test for each email
2. Write the variant copy or define the variant timing
3. Set the sample size and success threshold
