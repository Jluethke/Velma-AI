# Cleaning Estimate Workflow

Create estimates for prospective clients based on property details and selected services.

## Inputs

- `service-packages`: Available packages and pricing
- `pricing-model`: Pricing structure and rates

## Outputs

- `estimate-template`: Reusable estimate template with line items, terms, and acceptance signature
- `walkthrough-checklist`: Property walkthrough checklist for accurate estimating

## Process

1. Create the property assessment checklist (rooms, square footage, condition, pets, access).
2. Build the estimate template with line items that pull from the pricing model.
3. Include the terms of service, cancellation policy, and payment terms.
4. Set up the estimate-to-booking conversion workflow.
