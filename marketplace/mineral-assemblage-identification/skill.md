# Mineral Assemblage Identification

Confirm the mineral assemblage by integrating PPL and XPL observations with diagnostic criteria.

## Inputs

- `ppl-observations`: Plane-polarized light data
- `xpl-observations`: Cross-polarized light data
- `mineral-candidates`: Preliminary identifications to confirm

## Outputs

- `confirmed-minerals`: Final mineral list with volume percentages estimated by point counting or visual estimate
- `modal-composition`: Quantitative or semi-quantitative mineral proportions

## Process

1. Compare each candidate mineral's properties against determinative tables
2. Resolve ambiguities using distinguishing criteria (e.g., feldspar twinning, pyroxene cleavage angles)
3. Estimate modal proportions by visual comparison charts or point counting
4. List the mineral assemblage in order of abundance
