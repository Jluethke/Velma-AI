# Note Linking Protocol

Define the protocol for linking notes by topic and promoting to permanent notes.

## Inputs

- `capture-protocol`: Capture process
- `note-templates`: Note templates

## Outputs

- `linking-rules`: Rules for when and how to link notes
- `promotion-criteria`: Criteria for promoting a fleeting note to permanent

## Process

1. Define linking rules: every permanent note links to at least one other note.
2. Set promotion criteria: a fleeting note becomes permanent when you can state the idea in your own words.
3. Schedule a weekly processing session to promote and link notes.
