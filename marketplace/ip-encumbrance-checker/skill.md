# Ip Encumbrance Checker

Check for encumbrances, licenses, liens, and litigation on IP assets.

## Inputs

- `ip-inventory`: IP inventory
- `ownership-report`: Ownership verification results

## Outputs

- `encumbrance-list`: All licenses, liens, pledges, and security interests
- `litigation-history`: Past and pending IP litigation

## Process

1. Search for existing license agreements (exclusive and non-exclusive)
2. Check for UCC filings and security interests in IP
3. Search court records for past and pending IP disputes
