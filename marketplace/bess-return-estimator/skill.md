# Bess Return Estimator

Estimate the monthly incremental revenue or savings.

## Inputs

- `investment-definition`: The investment and its target outcome

## Outputs

- `monthly-return-estimate`: The steady monthly revenue added or cost removed
- `return-assumptions`: The assumptions and the ramp-up before the return is steady

## Process

1. Estimate the added revenue the investment produces each month.
2. Estimate the costs it removes each month.
3. State the assumptions and the ramp-up before the return is steady.
