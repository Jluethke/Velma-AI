# Teen Communication Framework

Build a communication approach that works with teenagers: active listening, non-judgmental questions, and conversation starters.

## Inputs

- `teen_age`: Age of teenager
- `current_dynamic`: Current parent-teen relationship quality
- `communication_issues`: Specific communication breakdowns

## Outputs

- `conversation_starters`: Age-appropriate conversation openers
- `listening_techniques`: Active listening methods for parents
- `conflict_scripts`: Scripts for common conflict scenarios

## Process

1. Assess current communication patterns
2. Identify conversation shut-down triggers
3. Build library of open-ended questions by topic
4. Practice reflective listening techniques
5. Create conflict de-escalation scripts
