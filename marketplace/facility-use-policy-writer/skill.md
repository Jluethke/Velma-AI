# Facility Use Policy Writer

Set the policies and fees for facility use by internal and external groups.

## Inputs

- `space-catalog`: Available spaces and their features
- `equipment-catalog`: Available equipment

## Outputs

- `use-policies`: Rules for facility use: who can book, fees, deposits, cancellation, cleanup, and prohibited uses
- `fee-schedule`: Rental fees by space, hours, and user type (member, nonprofit, commercial)

## Process

1. Define who can use the facility: members (free or reduced), nonprofits, community groups, commercial renters.
2. Set fees by space and user type, including the security deposit and cleaning fee.
3. Write the use agreement covering: liability, insurance requirements, setup and cleanup expectations, damage policy, and prohibited activities.
4. Define the cancellation policy and refund terms.
