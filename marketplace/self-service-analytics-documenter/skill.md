# Self Service Analytics Documenter

Produce the self-service analytics plan and adoption tracking.

## Inputs

- `starter-dashboards`: Pre-built assets
- `training-plan`: Training schedule and materials

## Outputs

- `self-service-plan`: Complete plan for self-service analytics rollout
- `adoption-metrics`: How to measure whether users are adopting self-service analytics

## Process

1. Document the rollout plan: timeline, user groups, milestones.
2. Define adoption metrics: active users, queries run, dashboards created.
3. Set a review cadence to track adoption and adjust.
