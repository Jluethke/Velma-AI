# Forecast Report Writer

Produce the forecast report with scenarios and recommendations.

## Inputs

- `weighted-forecast`: Revenue forecast by period
- `scenario-models`: Best/likely/worst scenarios
- `trend-analysis`: Conversion rate trends

## Outputs

- `forecast-report`: Sales forecast document
- `gap-analysis`: Shortfall to quota and pipeline needed to close the gap

## Process

1. Compare the forecast to quota.
2. Calculate the pipeline gap (additional pipeline needed).
3. Highlight the top deals driving the forecast.
4. Recommend actions to close any gap.
