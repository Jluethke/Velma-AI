# Scenario Modeler

Model base, upside, and downside scenarios for the budget.

## Inputs

- `revenue-forecast`: Base case revenue forecast
- `expense-forecast`: Base case expense forecast

## Outputs

- `scenario-models`: Three-scenario model (base, upside, downside)
- `sensitivity-results`: Sensitivity analysis on key variables

## Process

1. Define the key variables that drive the upside and downside cases.
2. Build the upside scenario (higher revenue, lower costs, faster growth).
3. Build the downside scenario (lower revenue, higher costs, slower growth).
4. Run sensitivity analysis on the top 5 variables to quantify impact.
