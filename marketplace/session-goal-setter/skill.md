# Session Goal Setter

Define the specific goal for each focus session.

## Inputs

- `distraction-checklist`: Pre-session distraction elimination steps
- `session-format`: Session structure

## Outputs

- `goal-template`: Template for setting the session goal
- `completion-criteria`: How to know the session goal is met

## Process

1. Write one sentence stating what will be done by the end of the session.
2. Define the completion criteria (deliverable, word count, problem solved).
3. Confirm the goal is achievable in the session length.
