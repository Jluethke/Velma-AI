# Loss Response Action Plan

For each fixable pattern, design a specific change to the sales process, messaging, or product that addresses it.

## Inputs

- `loss-patterns`: Recurring themes from loss analysis
- `fixable-vs-structural`: Which patterns can be addressed

## Outputs

- `action-plan`: For each fixable pattern: the specific change, who owns it, and the deadline
- `expected-win-rate-impact`: Estimated improvement in win rate if the top pattern is fixed

## Process

1. For each fixable pattern, design the intervention. If the pattern is 'could not justify price to CFO,' the intervention might be: create a one-page ROI calculator that the champion can hand to the CFO.
2. Make each intervention specific and owned. 'Improve value messaging' is not an action. 'Rewrite the proposal executive summary to lead with the dollar impact, not the feature list, by November 1, owned by [name]' is an action.
3. Estimate the win rate impact: if this pattern explained 30% of losses and the fix addresses it fully, your win rate could improve by up to 30% of the loss rate.
4. Schedule a follow-up loss analysis in 6 months to see if the patterns have shifted.
