# Playbook Assembler

Assemble all components into the final sales playbook.

## Inputs

- `buyer-personas`: Persona profiles
- `talk-tracks`: Conversation guides
- `battle-cards`: Competitive cards
- `objection-responses`: Objection handling

## Outputs

- `sales-playbook`: Complete sales playbook document
- `quick-reference`: One-page cheat sheet for the field

## Process

1. Organize the playbook by sales stage.
2. Include personas, talk tracks, and battle cards in each section.
3. Create the one-page quick reference card.
4. Set the update cadence for the playbook.
