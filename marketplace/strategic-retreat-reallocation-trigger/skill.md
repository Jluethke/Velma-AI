# Strategic Retreat Reallocation Trigger

Define the reallocation trigger: the point where the resources would produce a clear multiple of their current return if moved to a specific better use. This reframes retreat as moving capital to where it works hardest.

## Inputs

- `resource-ledger`: The resources tied up and their rough value
- `alternative-use-estimate`: The best estimated return on the resources elsewhere

## Outputs

- `reallocation-trigger`: The multiple at which moving resources is clearly worth it
- `reallocation-targets`: The specific better uses the resources would move to

## Process

1. Identify specific alternative uses that would clearly outperform the current commitment.
2. Estimate the multiple each alternative would return versus staying the course.
3. Set the trigger at a multiple high enough to cover the cost and disruption of moving.
4. Name the concrete targets so retreat has somewhere to send the resources.
