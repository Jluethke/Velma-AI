# Quality Measure Calculation

Calculate the performance rates for each quality measure.

## Inputs

- `measure-data`: Clinical data organized by measure

## Outputs

- `performance-rates`: Calculated performance rate for each measure (numerator/denominator, percentage, benchmark comparison)
- `improvement-opportunities`: Measures where performance is below benchmark, with root cause notes

## Process

1. Calculate the performance rate for each measure (numerator divided by denominator).
2. Compare the rates against national benchmarks and prior year performance.
3. Identify measures below the benchmark and investigate the root causes.
4. Document improvement opportunities for the quality improvement team.
