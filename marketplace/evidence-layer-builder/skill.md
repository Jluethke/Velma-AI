# Evidence Layer Builder

Under each argument, place the evidence that supports it. Data, examples, and citations. The reader drills into the evidence only if they question the argument.

## Inputs

- `supporting-arguments`: The arguments to back with evidence
- `key-information`: The available data and analysis

## Outputs

- `evidence-structure`: Under each argument: the data points, examples, and citations that support it. Organized so the reader can scan or deep-dive.
- `complete-message-structure`: The full pyramid: conclusion, arguments, evidence, ready to draft into the final format

## Process

1. For each argument, list the evidence: data points, examples, precedents, expert opinions, test results. Each piece of evidence should directly support the argument it sits under.
2. Remove evidence that does not support any argument. Interesting but irrelevant data weakens the structure.
3. For each evidence item, assess its strength: primary data (strong), secondary analysis (moderate), anecdote (weak). Lead with the strongest evidence.
4. The reader should be able to read at three levels: conclusion only (10 seconds), conclusion plus arguments (1 minute), full document with evidence (5+ minutes). Each level is self-contained.
