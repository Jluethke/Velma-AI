# Literacy Level Setter

Define functional literacy for each adjacent area so breadth stays bounded.

## Inputs

- `adjacent-areas`: Five to seven areas that surround the core
- `adjacency-rationale`: Why each adjacent area matters

## Outputs

- `literacy-targets`: What functional literacy means for each area
- `stop-rules`: Rules that keep breadth from turning into endless study

## Process

1. Define what functional literacy means for each adjacent area.
2. Set a stop rule so breadth does not turn into endless study.
3. Describe the conversations each literacy level should enable.
4. Keep the bar at useful understanding, not mastery.
