# Network Effect Engagement Metric Design

Design the metric that proves the network effect is real: engagement per user should rise as the total user count grows. If each user engages the same or less as the network grows, there is no real network effect, only growth.

## Inputs

- `core-interaction`: The single interaction that drives the network effect
- `network-effect-type`: The type of network effect at work

## Outputs

- `engagement-metric`: The metric linking engagement per user to total user count
- `measurement-plan`: How and when the metric is tracked

## Process

1. Define engagement per user in terms of the core interaction, not vanity activity.
2. Set the key test: does engagement per user rise as the total user count grows?
3. Plan to track the metric over time and across cohorts of different network sizes.
4. Decide the reading that would disprove the network effect, so the metric can fail honestly.
