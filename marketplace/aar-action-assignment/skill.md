# Aar Action Assignment

Convert the discussion into assigned actions. Every action has an owner, a deadline, and a definition of done. Actions without owners do not get done.

## Inputs

- `aar-discussion-record`: Record of the four-question discussion
- `gap-analysis`: Gaps with root causes

## Outputs

- `action-register`: List of specific actions with owner, deadline, and definition of done
- `lesson-archive-entries`: Lessons formatted for the organizational lesson archive (situation, gap, root cause, action, outcome)

## Process

1. For each 'what will we do differently' answer, assign an owner. The owner is the person who can actually make the change, not the person who suggested it.
2. Set a deadline. If the action has no natural deadline, set one within 30 days. Actions with distant or no deadlines do not get done.
3. Define 'done.' How will we know this action is complete? 'Set up a weekly status update' is done when the first update is sent and the recurring calendar event exists.
4. Separate the actions into two categories: process changes (permanent changes to how we work) and one-time fixes (something that needs to happen once). Process changes need a verification step to confirm they stuck.
