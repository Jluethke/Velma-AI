# Soil Practice Selector

Select soil health practices for each field.

## Inputs

- `improvement-targets`: Target values for soil health indicators
- `priority-fields`: Fields ranked by need

## Outputs

- `practice-plan`: Practices assigned to each field with implementation timeline
- `cost-estimate`: Estimated cost per field for the selected practices

## Process

1. Evaluate cover crop species and mixes for each field's needs.
2. Assess tillage reduction options compatible with the cropping system.
3. Select organic matter additions (compost, manure, crop residue management).
4. Estimate costs and timeline for each practice per field.
