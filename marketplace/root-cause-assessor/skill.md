# Root Cause Assessor

Assess the root causes of academic risk for each flagged student.

## Inputs

- `at-risk-list`: List of students flagged with their risk indicators
- `student-data`: Enrollment, attendance, grade, and engagement data

## Outputs

- `cause-analysis`: Root cause assessment per student (academic, financial, personal, health)
- `support-needs`: Matched support services needed per student

## Process

1. Review each student's academic history and current performance
2. Identify patterns (specific courses, attendance drops, engagement changes)
3. Categorize causes: academic skill gaps, financial stress, personal issues, health
4. Match each student to relevant support services
