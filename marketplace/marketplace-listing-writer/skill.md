# Marketplace Listing Writer

Write the marketplace listing content.

## Inputs

- `package-bundle`: Packaged integration
- `marketplace-requirements-checklist`: What the listing needs

## Outputs

- `listing-content`: Title, description, screenshots, category, and tags for the listing
- `setup-documentation`: End-user setup guide for the integration

## Process

1. Write the listing title and description focused on what the integration does for the user.
2. Create screenshots or diagrams showing the integration in action.
3. Choose the correct category and tags.
4. Write the setup documentation: prerequisites, installation steps, configuration, first use.
