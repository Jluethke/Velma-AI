# Journal Quarterly Review

Run the quarterly review of the decision journal. Update all outcome comparisons, refresh the calibration analysis, adjust the correction rules, and identify the single highest-impact lesson from the quarter. The quarterly review is the payoff: it is where the journal converts raw data into improved judgment.

## Inputs

- `correction-rules`: Current correction rules
- `calibration-report`: Current calibration data

## Outputs

- `quarterly-review`: The quarterly summary: entries reviewed, calibration update, correction rule adjustments, and the single most important lesson
- `highest-impact-lesson`: The one insight from this quarter that most changes how you will make decisions going forward

## Process

1. Review all entries from the quarter. Update outcomes for entries that have reached their check date.
2. Re-run the calibration analysis with the new data.
3. Adjust correction rules: are they helping? Over-correcting? Under-correcting?
4. Identify the single highest-impact lesson: the one thing you learned about your own decision-making that you did not know before this quarter.
