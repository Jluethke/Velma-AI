# Donor Management Plan Writer

Produce the donor management plan summarizing the system, segments, and workflows.

## Inputs

- `donor-data-model`: Field definitions
- `segment-definitions`: Named segments
- `acknowledgment-plan`: Acknowledgment workflow rules

## Outputs

- `donor-management-plan`: Complete plan document
- `training-guide`: Staff guide for using the donor system

## Process

1. Summarize the data model and system selection rationale
2. Document each segment and its communication strategy
3. Describe the acknowledgment workflows and timing standards
4. Write the staff training guide for daily operations
