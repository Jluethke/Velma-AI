# Photo Media Organizer

Organize photos and media files into a consistent structure.

## Inputs

- `file-inventory`: Current file organization state
- `storage-locations`: Where photos and media live

## Outputs

- `media-library`: Organized photo and media library
- `backup-status`: Backup verification for all media

## Process

1. Consolidate photos from all devices into one library.
2. Organize by date and event.
3. Delete blurry, duplicate, or unwanted photos.
4. Verify the backup covers all media.
