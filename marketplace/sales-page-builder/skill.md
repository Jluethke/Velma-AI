# Sales Page Builder

Build the sales page and set up the payment and delivery system.

## Inputs

- `finished-product`: The completed product
- `product-assets`: Preview and sample materials

## Outputs

- `sales-page`: The live sales page with payment integration
- `delivery-system`: The automated delivery system (email, platform access, download link)

## Process

1. Write the sales page copy (headline, problem, solution, benefits, testimonials, CTA).
2. Set up the payment processor and pricing (one-time, payment plan, early bird).
3. Configure the automated delivery (access email, login credentials, download).
4. Test the full purchase flow from landing to delivery.
