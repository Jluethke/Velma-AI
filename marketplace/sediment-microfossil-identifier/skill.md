# Sediment Microfossil Identifier

Identify and count microfossils (pollen, diatoms, foraminifera, or ostracods) at selected depths.

## Inputs

- `subsamples`: Subsamples prepared for microfossil analysis
- `reference-collection`: Identification keys or atlas for the target microfossil group

## Outputs

- `microfossil-counts`: Counts of each taxon per depth with total counted
- `assemblage-diagram`: Percentage or concentration diagram of key taxa through the core

## Process

1. Process subsamples using the appropriate chemical preparation (acetolysis for pollen, acid cleaning for diatoms).
2. Mount on slides and count a minimum of 300 specimens per sample (or equivalent counting sum).
3. Identify to the lowest practical taxonomic level using the reference collection.
4. Calculate percentages or concentrations and plot the assemblage diagram.
