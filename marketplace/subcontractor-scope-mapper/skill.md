# Subcontractor Scope Mapper

Maintain the subcontractor contact list and scope matrix.

## Inputs

- `project-name`: Name of the construction project
- `subcontractor-list`: List of subcontractors on the project

## Outputs

- `scope-matrix`: Matrix mapping each sub to their scope of work
- `contact-directory`: Contact directory for all subcontractors

## Process

1. List each subcontractor with their contract scope.
2. Map overlapping areas of work and interface points between subs.
3. Build the contact directory with project manager, superintendent, and emergency contacts.
4. Identify the subcontractors on the critical path.
