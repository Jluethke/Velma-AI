# Rca Effectiveness Verifier

Verify that corrective actions are effective and the problem does not recur.

## Inputs

- `corrective-actions`: Implemented actions
- `verification-data`: Baseline data for comparison

## Outputs

- `effectiveness-check`: Verification that the problem has not recurred
- `rca-report`: Complete root cause analysis report

## Process

1. Monitor the process for a defined period after implementation
2. Compare defect rates before and after corrective action
3. Verify the problem has not recurred and no new problems were created
4. Compile the complete RCA report and close the investigation
