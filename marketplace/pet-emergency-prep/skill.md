# Pet Emergency Prep

Prepare for pet emergencies: vet contacts, first aid, disaster kit, and pet-sitter instructions.

## Inputs

- `pet_type`: Species
- `health_history`: Known conditions and medications
- `location`: Home location for emergency vet lookup

## Outputs

- `emergency_contacts`: Emergency vet and poison control numbers
- `first_aid_kit`: Pet first aid supplies
- `pet_sitter_packet`: Complete care instructions for sitters

## Process

1. Locate nearest emergency vet
2. Build pet-specific first aid kit
3. Create pet sitter instruction document
4. Include medications and feeding details
5. Plan for disaster evacuation with pet
