# Expression Workflow Design

Design the expression step: using captured and distilled knowledge to produce something (a document, a decision, a plan, a conversation, a presentation). The system pays off here. Every expression draws from the accumulated knowledge base.

## Inputs

- `search-configuration`: Working search across all knowledge
- `findability-test-results`: Verified findability of stored items

## Outputs

- `expression-workflow`: The workflow for producing outputs from the knowledge base: gather, arrange, draft, refine
- `second-brain-system-doc`: Complete documentation of the second brain system: capture, organize, distill, express

## Process

1. The expression workflow: when you start a new output (writing, presentation, decision, plan), begin by searching your knowledge base. Pull every relevant item into a working set.
2. Arrange the working set: group related items, identify gaps (what do you need that you do not have?), and sequence the ideas into a rough outline.
3. Draft from the working set. You are remixing and connecting existing knowledge, not starting from scratch. The value of the system is that you never start from zero.
4. After expression, capture any new insights that emerged during the creation process. The output feeds back into the system.
