# Animation Asset Designer

Design characters, props, and environments.

## Inputs

- `storyboard-panels`: Storyboard for reference
- `style-guide`: Visual style direction

## Outputs

- `character-designs`: Character model sheets with poses and expressions
- `environment-designs`: Background and prop artwork

## Process

1. Design each character with turnaround and expression sheets
2. Design the environments and backgrounds for each scene
3. Create props and secondary elements
4. Prepare assets for rigging or frame-by-frame animation
