# Community Event Scoping

Define the event purpose, target audience, and success criteria.

## Inputs

- `event-idea`: The proposed event (festival, fundraiser, outreach, celebration)
- `available-budget`: The budget available for the event

## Outputs

- `event-brief`: Purpose, target audience, date, estimated attendance, and success metrics
- `budget-allocation`: How the budget is divided across venue, food, supplies, promotion, and contingency

## Process

1. Define the event purpose: fundraising, community building, outreach, celebration, or service.
2. Identify the target audience: members only, community open, families, youth, seniors.
3. Set the date, time, and estimated attendance based on past events and audience size.
4. Allocate the budget across categories and define the success metrics (attendance, funds raised, new contacts).
