# Design System Usage Guide

Write the usage guidelines that explain when and how to use each component and token.

## Inputs

- `component-library`: The standardized components
- `component-specs`: The specification sheets for each component

## Outputs

- `usage-guidelines`: Documentation explaining when to use each component, with do/don't examples
- `pattern-recipes`: Common UI patterns built from the component library (forms, lists, dashboards)

## Process

1. For each component, write a usage section: what it is, when to use it, when not to use it, and examples.
2. Include do/don't pairs showing correct and incorrect usage.
3. Build pattern recipes for common page layouts using the components.
4. Produce the usage guidelines and pattern recipe documentation.
