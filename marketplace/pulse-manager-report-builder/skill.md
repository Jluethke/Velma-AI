# Pulse Manager Report Builder

Build manager-level reports with team scores, trends, and action suggestions.

## Inputs

- `dimension-scores`: Scores by dimension and team
- `trend-analysis`: Score trends and flagged changes

## Outputs

- `manager-reports`: Team-level reports for each manager with scores, trends, and benchmarks
- `pulse-survey-report`: Organization-wide pulse survey report with all dimensions and trends

## Process

1. Generate each manager's report with their team's scores and organization benchmarks.
2. Highlight dimensions where the team is above or below the organization average.
3. Include suggested conversation starters for low-scoring dimensions.
4. Produce the organization-wide pulse survey report with executive summary.
