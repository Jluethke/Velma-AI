# Coordination Log Compiler

Produce the subcontractor coordination log.

## Inputs

- `progress-report`: Progress report by trade
- `schedule-variance`: Planned vs actual variance

## Outputs

- `coordination-log`: Complete coordination log with meeting notes, conflicts, and progress
- `coordination-metrics`: Metrics on meetings held, conflicts resolved, and schedule adherence

## Process

1. Compile meeting minutes, conflict resolutions, and progress data.
2. Calculate coordination metrics.
3. Identify recurring coordination issues for process improvement.
4. File the log in the project records.
