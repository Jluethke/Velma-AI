# Capacity Action Planner

Plan and implement the capacity changes.

## Inputs

- `capacity-gaps`: Identified shortfalls
- `optimization-opportunities`: Right-sizing opportunities

## Outputs

- `capacity-actions`: Planned procurement, scaling, or optimization actions
- `capacity-management-report`: Complete capacity management report with current state, forecast, and actions

## Process

1. Define the action for each gap (procure, scale, optimize, migrate).
2. Estimate the cost and timeline for each action.
3. Submit procurement or change requests as needed.
4. Document the complete capacity management report.
