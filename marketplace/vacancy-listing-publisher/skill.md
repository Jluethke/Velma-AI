# Vacancy Listing Publisher

List the vacant unit on rental platforms.

## Inputs

- `unit-details`: Unit specifications, photos, and rent amount
- `listing-platforms`: Target rental listing platforms

## Outputs

- `active-listings`: Published listings with URLs
- `listing-analytics`: Initial view and inquiry counts

## Process

1. Prepare the listing with photos, floor plan, rent, and move-in requirements.
2. Publish to each target platform.
3. Verify the listing is active and accurate on each platform.
