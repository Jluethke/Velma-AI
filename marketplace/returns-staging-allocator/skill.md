# Returns Staging Allocator

Allocate space for returns processing and staging areas.

## Inputs

- `zone-definitions`: Named zones with product assignments and capacity
- `zone-adjacency-map`: Map of zone relationships and flow direction

## Outputs

- `returns-layout`: Returns processing area layout and workflow
- `staging-plan`: Staging areas for inbound and outbound

## Process

1. Size the returns area based on historical return rates
2. Position returns adjacent to receiving and quality inspection
3. Define staging areas for inbound cross-dock and outbound consolidation
4. Document workflow from receipt to restock or disposal
