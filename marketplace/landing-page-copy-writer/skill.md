# Landing Page Copy Writer

Write the landing page headline, subhead, body copy, and call to action.

## Inputs

- `page-objective`: The single action the page should drive
- `audience-profile`: Who the page is for and what they care about

## Outputs

- `page-copy`: All text for the page: headline, subhead, benefits, social proof, CTA
- `cta-text`: The call-to-action button text and supporting microcopy

## Process

1. Write a headline that states the value proposition in the audience's language.
2. Write the subhead, benefit bullets, and social proof section.
3. Write the call-to-action text and any supporting microcopy.
4. Review for clarity and remove any filler.
