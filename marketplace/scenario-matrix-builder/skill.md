# Scenario Matrix Builder

Build the 2x2 scenario matrix from the two uncertainties. Each quadrant is a distinct, internally consistent future.

## Inputs

- `top-two-uncertainties`: The two uncertainties as spectrums
- `strategic-context`: The planning context

## Outputs

- `scenario-matrix`: The 2x2 matrix with four named scenarios, each described in one paragraph
- `scenario-narratives`: For each scenario: a one-paragraph narrative describing what the world looks like, who thrives, and who struggles

## Process

1. Draw the matrix: uncertainty 1 on the x-axis (pole A left, pole B right), uncertainty 2 on the y-axis (pole A bottom, pole B top). Each quadrant is a combination of the two poles.
2. Name each scenario with a memorable, descriptive name (not 'Scenario A'). The name should evoke the character of that future.
3. Write a one-paragraph narrative for each: what does the world look like? What has changed? Who thrives in this world and who struggles? What are the dominant dynamics?
4. Check for internal consistency: are the events in each narrative compatible with each other? Remove contradictions.
