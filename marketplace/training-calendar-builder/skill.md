# Training Calendar Builder

Build the training calendar for the program period.

## Inputs

- `delivery-plan`: Delivery methods and programs
- `target-audiences`: Who needs what

## Outputs

- `training-calendar`: Calendar of all training events and deadlines
- `enrollment-plan`: Enrollment targets and communication plan

## Process

1. Schedule each program accounting for business cycles and availability
2. Set enrollment windows and capacity limits
3. Plan the communication and enrollment process
4. Build in buffer for rescheduling
