# Provider Query Generator

Generate queries to the provider for clarification on documentation gaps.

## Inputs

- `gap-list`: Missing documentation elements
- `ambiguity-list`: Items needing clarification

## Outputs

- `query-set`: Formatted queries for the provider
- `query-tracking-log`: Log to track query status and responses

## Process

1. Draft each query as a specific, non-leading question.
2. Reference the relevant section and date of the documentation.
3. Route queries to the provider through the approved workflow.
