# Sem Report Writer

Produce the SEM report with path diagram, fit indices, parameter table, and interpretation.

## Inputs

- `best-model`: The final selected model
- `model-comparison-table`: Comparison results across models

## Outputs

- `sem-report`: The full SEM analysis report
- `path-diagram-final`: Annotated path diagram with standardized estimates

## Process

1. Draw the final path diagram with standardized estimates on each path.
2. Write the parameter table with estimates, standard errors, p-values, and standardized values.
3. Summarize which hypotheses were supported and which were not.
4. Note limitations: sample size adequacy, normality assumptions, cross-sectional design constraints.
