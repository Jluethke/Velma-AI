# Proposal Evaluator

Evaluate proposals against the stated criteria and select the best value.

## Inputs

- `published-solicitation`: Solicitation with evaluation criteria
- `qa-amendments`: Any amendments that changed requirements or criteria

## Outputs

- `evaluation-results`: Each proposal scored against the criteria with strengths, weaknesses, and risks
- `selection-recommendation`: Recommended awardee with documented rationale

## Process

1. Convene the evaluation panel and review the criteria.
2. Score each proposal independently on technical merit, past performance, and price.
3. Consolidate scores and document consensus strengths, weaknesses, and risks.
4. Identify the best value and document the selection rationale.
