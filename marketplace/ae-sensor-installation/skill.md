# Ae Sensor Installation

Install acoustic emission sensors on the structure and verify coupling quality.

## Inputs

- `structure-description`: Geometry, material, and loading conditions of the test article
- `monitoring-objectives`: What damage or defect types to detect and the coverage area

## Outputs

- `sensor-layout`: Sensor positions, types, coupling media, and preamplifier gains
- `coupling-verification`: Pencil lead break test results confirming adequate sensitivity at each sensor

## Process

1. Select sensor type and frequency range based on the material and expected source mechanisms
2. Determine sensor positions for source location coverage using the structure's wave velocity
3. Mount sensors with appropriate couplant and secure them against vibration
4. Perform pencil lead break tests at each sensor and at mid-points to verify sensitivity and wave speed
