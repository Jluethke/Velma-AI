# Warranty Manual Assembler

Gather warranties, guarantees, and operation manuals.

## Inputs

- `project-name`: Name of the construction project
- `as-built-drawings`: As-built drawing set

## Outputs

- `warranty-package`: All warranties and guarantees organized by system
- `om-manuals`: Operation and maintenance manuals for all systems

## Process

1. Collect warranties from each subcontractor and supplier.
2. Organize by building system (HVAC, electrical, plumbing, roofing, etc.).
3. Gather the operation and maintenance manuals for each system.
4. Verify that all required warranties match the specification requirements.
