# Vaccine Animal Model Protocol

Design the preclinical animal study protocol including species selection, group sizes, dosing schedule, sample collection, and endpoints.

## Inputs

- `optimized-formulation`: Final vaccine formulation to be tested
- `assay-panel`: Immunogenicity assays that will be run on collected samples

## Outputs

- `animal-protocol`: Complete study protocol with species, groups, schedule, and endpoints
- `ethics-submission`: IACUC or equivalent ethics committee submission package

## Process

1. Select animal model based on pathogen susceptibility, immune system relevance, and regulatory guidance
2. Calculate group sizes using power analysis for the primary immunogenicity endpoint
3. Design the dosing and sampling schedule with prime, boost, and challenge timepoints
4. Prepare the ethics submission with humane endpoints, housing, and veterinary oversight plan
