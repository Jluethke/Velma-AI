# Security Champion Program Audit

Assess the security champion program for participation, effectiveness, and organizational reach.

## Inputs

- `team-structure`: Team structure for champion coverage analysis
- `training-findings`: Training findings for cross-reference

## Outputs

- `champion-program-findings`: Gaps and strengths in the champion program
- `champion-coverage-map`: Which teams have active champions and which do not

## Process

1. Inventory active security champions and the teams they cover
2. Check whether champions receive additional training and dedicated time
3. Review champion-originated security findings and improvements
4. Identify teams without champion coverage
