# Dlp Assessment Report Writer

Produce the final DLP assessment report with findings and recommendations.

## Inputs

- `response-time-analysis`: Detection and response time statistics
- `coverage-gap-summary`: Channels with gaps
- `classification-matrix`: Data types and expected controls

## Outputs

- `dlp-assessment-report`: Complete DLP assessment report
- `remediation-priorities`: Ranked list of control improvements needed

## Process

1. Summarize test coverage across all channels and data types
2. Detail each gap with the test evidence and risk implication
3. Recommend specific control improvements for each gap
4. Estimate the cost and timeline for each remediation
