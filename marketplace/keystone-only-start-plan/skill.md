# Keystone Only Start Plan

Build a plan that starts the keystone habit and nothing else, so attention is not split across all five changes at once.

## Inputs

- `chosen-keystone`: The single keystone habit
- `keystone-pick-rationale`: The reason this habit was chosen

## Outputs

- `keystone-start-plan`: A thirty-day plan that establishes the keystone at a small, repeatable size
- `single-focus-guardrail`: A written rule to not add any of the other four changes until the keystone is stable

## Process

1. Define the smallest version of the keystone that still counts, such as a ten-minute walk rather than a planned workout. The size must be low enough that skipping it would feel absurd.
2. Set a fixed time and place for the habit and remove one friction point in advance, such as leaving shoes by the door the night before.
3. Write the single-focus guardrail in plain words: you will not start the other four changes until the keystone has held for the full thirty days. Splitting focus is what stalled past attempts.
4. Name the first downstream change you expect to shift on its own. This becomes the signal that the cascade has started.
