# Backlink Profile Reviewer

Review the backlink profile for quality, diversity, and toxic links.

## Inputs

- `site-url`: Site being audited
- `crawl-summary`: Crawl data for context

## Outputs

- `backlink-report`: Backlink count, quality distribution, and toxic links
- `link-opportunities`: Domains worth pursuing for new backlinks

## Process

1. Pull the backlink profile from available data sources
2. Classify links by quality (high, medium, low, toxic)
3. Identify link-building opportunities from competitor analysis
