# Privacy Measure Recommendation

Recommend privacy-enhancing measures to mitigate the identified risks.

## Inputs

- `risk-register`: The identified privacy risks
- `processing-summary`: The planned processing

## Outputs

- `recommended-measures`: Privacy-enhancing measures to mitigate each risk
- `design-changes`: Specific changes to the technical design to embed privacy

## Process

1. For each risk, identify the appropriate mitigation (data minimization, pseudonymization, encryption, access controls, retention limits, anonymization).
2. Recommend specific design changes (collect less data, shorter retention, user controls, audit logging).
3. Assess the residual risk after applying each measure.
4. Prioritize the measures by effectiveness and implementation effort.
