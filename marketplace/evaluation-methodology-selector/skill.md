# Evaluation Methodology Selector

Select the evaluation methodology and design.

## Inputs

- `evaluation-questions`: Questions to answer
- `evaluation-scope`: Scope and constraints

## Outputs

- `evaluation-design`: Methodology with rationale
- `data-collection-instruments`: Surveys, interview guides, and observation protocols

## Process

1. Select the evaluation type (formative, summative, developmental, empowerment)
2. Choose the design (pre-post, comparison group, case study, mixed methods)
3. Develop data collection instruments
4. Plan the sampling strategy and timeline
