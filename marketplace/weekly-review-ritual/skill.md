# Weekly Review Ritual

Set up a weekly review that processes the inbox and strengthens links.

## Inputs

- `storage-scheme`: A scheme for storing and naming notes
- `retrieval-rules`: How notes are found when needed

## Outputs

- `weekly-review-checklist`: A checklist for the weekly review
- `review-cadence`: The fixed time and rhythm for the review

## Process

1. Process every item left in the inbox into a note or discard it.
2. Revisit recent notes and add any missing links.
3. Set the fixed weekly time and checklist for the review.
4. Note any cluster that is growing and worth attention.
