# Survey Instrument Designer

Design a survey questionnaire with validated scales, demographic items, response formats, skip logic, and pilot testing plan.

## Inputs

- `construct-definitions`: Operational definitions and measurement plan from construct definition
- `target-population`: Description of the population to be surveyed
- `delivery-mode`: Online, paper, phone, or in-person administration method

## Outputs

- `survey-instrument`: Complete questionnaire with item text, response scales, and skip logic
- `pilot-plan`: Cognitive interview and pilot test protocol with sample size and criteria
- `psychometric-targets`: Expected reliability (Cronbach alpha) and validity benchmarks per scale

## Process

1. Assemble items from validated scales, adapting wording for the target population
2. Write new items for constructs without existing measures, balancing positive and negative framing
3. Organize the instrument with logical flow, attention checks, and skip logic
4. Design a cognitive interviewing protocol to test item clarity with 5-10 respondents
5. Plan the pilot study with target sample size for preliminary reliability analysis
