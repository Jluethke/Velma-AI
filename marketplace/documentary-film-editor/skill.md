# Documentary Film Editor

Edit the documentary following the paper edit through final cut.

## Inputs

- `paper-edit`: Narrative blueprint with timecodes
- `narration-script`: Voiceover script if applicable

## Outputs

- `finished-documentary`: Final edited documentary film
- `deliverable-package`: Master file and all required delivery formats

## Process

1. Build the assembly cut following the paper edit
2. Record and place the narration voiceover
3. Refine pacing, add music, and color grade
4. Export the final master and delivery formats
