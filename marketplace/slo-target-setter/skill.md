# Slo Target Setter

Set SLO targets for each SLI based on business requirements, historical performance, and user expectations.

## Inputs

- `sli-definitions`: The defined service level indicators
- `historical-performance`: Historical SLI data for baseline

## Outputs

- `slo-targets`: SLO targets for each SLI
- `target-rationale`: Justification for each target level

## Process

1. Review historical SLI performance to establish a baseline
2. Consult with product and business stakeholders on expectations
3. Set targets that are achievable but meaningful (not too loose or tight)
4. Document the rationale for each target
