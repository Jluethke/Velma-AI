# Report Structure Designer

Define the report structure: sections, metrics, and visualizations for each section.

## Inputs

- `report-purpose`: What question the report answers and who reads it
- `available-data-sources`: Data sources the report can pull from (databases, APIs, spreadsheets)

## Outputs

- `report-outline`: Ordered list of sections with the metrics and visual types for each
- `data-requirements`: Fields and aggregations needed from each data source

## Process

1. Identify the audience and the decisions the report informs.
2. List the metrics and KPIs the report must show.
3. Group the metrics into logical sections (summary, detail, trend, comparison).
4. For each section, choose the visual type (table, bar chart, line chart, single number, heatmap).
