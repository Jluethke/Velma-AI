# Keystone Adoption Plan

Build a focused plan to adopt the keystone habit using environment design and the minimum viable version.

## Inputs

- `top-keystone`: The chosen keystone habit
- `causal-map`: The behavior cascade it triggers

## Outputs

- `adoption-plan`: A 30-day plan to establish the keystone habit, starting with the minimum viable version and scaling up
- `environment-changes`: Specific physical and digital environment changes to make the keystone habit the default

## Process

1. Define the minimum viable version of the keystone habit. If the habit is 'exercise 4 times per week,' the minimum viable version is 'put on workout clothes and stand outside for 5 minutes, 4 times per week.' The barrier must be so low that not doing it feels ridiculous.
2. Make the environment changes that reduce friction to zero. Lay out the clothes. Set the alarm. Block the calendar. Remove competing cues.
3. Plan the 30-day ramp: week 1 is the minimum viable version only. Week 2 adds 50% of the target. Week 3 adds 75%. Week 4 is the full target. This ramp builds the habit before increasing the effort.
4. Identify the first downstream behavior you expect to see change without deliberate effort. This is your confirmation signal that the cascade is working.
