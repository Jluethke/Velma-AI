# Asset Access Permissions

Set up access permissions and the request process for brand assets.

## Inputs

- `library-structure`: The organized library structure
- `team-roles`: The roles that need access (marketing, sales, partners, agencies)

## Outputs

- `access-policy`: Who can view, download, and use which assets
- `request-workflow`: The process for requesting new assets or custom versions

## Process

1. Define access levels by role (view-only, download, edit, admin).
2. Assign each asset category to the appropriate access levels.
3. Design the request workflow for assets not in the library or needing customization.
4. Produce the access policy and request workflow.
