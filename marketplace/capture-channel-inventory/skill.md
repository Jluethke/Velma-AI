# Capture Channel Inventory

Inventory every channel where information enters your life (email, chat, meetings, reading, conversations, browsing, podcasts) and set up a frictionless capture path from each one into a single inbox.

## Inputs

- `current-information-sources`: List of all places where you currently encounter information worth keeping
- `current-note-tools`: Note-taking and storage tools you already use

## Outputs

- `capture-channel-map`: Map of each information source to its capture method (quick-add, forward-to-inbox, voice memo, screenshot, clip)
- `unified-inbox-config`: Configuration for the single inbox where all captured items land before processing

## Process

1. List every information channel: email, Slack or chat, meetings, web browsing, reading (books, articles, PDFs), conversations, podcasts, video, social media, and your own thoughts.
2. For each channel, define the fastest possible capture method. The capture method must take under 10 seconds or it will not be used. Examples: email forward, share-to-app, voice memo, screenshot, browser extension clip.
3. Configure all capture paths to deposit into a single inbox location. Do not create separate inboxes per source. One inbox, many entry points.
4. Test each capture path: send a test item through each channel and verify it arrives in the inbox.
