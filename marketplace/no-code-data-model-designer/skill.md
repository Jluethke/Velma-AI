# No Code Data Model Designer

Design the data model: tables, fields, relationships, and access rules.

## Inputs

- `platform-choice`: The chosen platform
- `app-requirements`: Feature requirements

## Outputs

- `data-model`: Tables, fields, types, and relationships
- `access-rules`: Who can read and write each data type

## Process

1. Define the tables or collections the app needs.
2. Specify the fields, data types, and relationships between tables.
3. Set up access rules (who can create, read, update, delete).
4. Add sample data for testing.
