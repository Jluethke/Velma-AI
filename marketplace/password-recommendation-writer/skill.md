# Password Recommendation Writer

Write specific policy change recommendations based on the audit findings.

## Inputs

- `policy-gaps`: Identified policy weaknesses
- `breach-exposure`: Breach exposure findings

## Outputs

- `policy-recommendations`: Specific password policy changes to implement
- `implementation-plan`: Steps to roll out the new policy

## Process

1. Draft specific policy changes addressing each identified gap
2. Recommend technical controls: password managers, banned password lists, MFA
3. Outline an implementation timeline with user communication plan
