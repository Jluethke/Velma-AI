# Edtech Evaluator

Evaluate candidate tools against features, accessibility, privacy, and cost criteria.

## Inputs

- `need-statement`: Clear statement of the pedagogical need
- `success-criteria`: Evaluation criteria

## Outputs

- `tool-shortlist`: Top 2-3 tools with evaluation scores
- `evaluation-matrix`: Detailed scoring matrix for all candidates

## Process

1. Identify 5-8 candidate tools through research and recommendations
2. Score each tool on functionality, accessibility (WCAG), privacy (FERPA/GDPR), and cost
3. Check vendor stability, support quality, and integration capabilities
4. Select the top 2-3 finalists
