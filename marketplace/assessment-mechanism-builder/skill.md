# Assessment Mechanism Builder

Build knowledge assessment and testing mechanisms for each module.

## Inputs

- `training-modules`: Content to assess
- `learning-objectives`: Objectives to measure against

## Outputs

- `assessment-bank`: Quiz questions and practical assessments per module
- `passing-criteria`: Minimum score and completion requirements

## Process

1. Write quiz questions aligned to each learning objective
2. Design practical assessments (simulated phishing, data handling exercises)
3. Set passing criteria and retake policies
4. Validate question quality and difficulty
