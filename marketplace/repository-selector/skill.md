# Repository Selector

Choose the appropriate data repository based on the domain, funder requirements, and data sensitivity.

## Inputs

- `inventory-summary`: Summary of data types, sizes, and sensitivity
- `funder-requirements`: Funder's data sharing policy and preferred repositories

## Outputs

- `selected-repository`: Chosen repository with deposit URL and submission guide link
- `repository-rationale`: Why this repository fits the data type, funder, and access needs

## Process

1. List candidate repositories (domain-specific like GenBank, Dryad, Zenodo, or institutional).
2. Check each against funder mandates and data type compatibility.
3. Verify size limits, embargo support, and access control options.
4. Select the best fit and document the rationale.
