# Fraud Report Filer

File suspicious activity reports and produce the investigation record.

## Inputs

- `investigation-findings`: Confirmed fraud cases
- `evidence-package`: Supporting evidence

## Outputs

- `sar-filings`: Suspicious activity reports filed with FinCEN
- `fraud-investigation-record`: Complete record of the investigation and outcomes

## Process

1. Prepare the SAR for each confirmed case per FinCEN requirements.
2. File the report within the regulatory deadline.
3. Update the fraud case management system with outcomes.
4. Produce the investigation summary for compliance records.
