# Sensor Placement Planner

Plan the physical placement of sensors in the monitoring area.

## Inputs

- `parameter-spec`: Parameter specifications
- `sensor-selection`: Selected sensors

## Outputs

- `placement-map`: Map showing sensor locations with rationale
- `installation-plan`: Installation instructions for each sensor site

## Process

1. Map the monitoring area and identify placement locations based on spatial coverage.
2. Account for environmental factors (airflow, shade, interference, power access).
3. Document the mounting method, power source, and connectivity for each site.
