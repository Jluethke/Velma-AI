# Client Database Setup

Set up the client database to track preferences, visit history, allergies, and notes.

## Inputs

- `booking-configuration`: Booking system configuration
- `service-menu`: Service menu for tagging visit types

## Outputs

- `client-database-schema`: Database structure for client records including required and optional fields
- `intake-form`: New client intake form with health, preference, and allergy questions

## Process

1. Define the client record fields (name, contact, preferences, allergies, notes, visit history).
2. Create the new client intake form with health and allergy screening questions.
3. Set up the tagging system to track service preferences and product purchases.
4. Configure automated reminders for follow-up appointments.
