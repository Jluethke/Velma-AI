# Buyer Persona Definer

Define the target buyer personas for the playbook.

## Inputs

- `product-description`: What the product does
- `customer-interviews`: Interviews or feedback from existing customers

## Outputs

- `buyer-personas`: Detailed persona profiles
- `pain-points`: Key problems each persona faces

## Process

1. Identify the distinct buyer roles involved in purchasing.
2. Define each persona's title, responsibilities, and goals.
3. Map the pain points each persona experiences.
4. Describe how each persona evaluates solutions.
