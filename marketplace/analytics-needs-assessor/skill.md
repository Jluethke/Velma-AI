# Analytics Needs Assessor

Assess business user needs and skill levels for self-service analytics.

## Inputs

- `user-groups`: Business teams that need analytics access
- `current-tools`: Analytics tools currently in use

## Outputs

- `needs-assessment`: What each user group needs to do with data
- `skill-levels`: Current data literacy by group (beginner, intermediate, advanced)

## Process

1. Survey each user group about their current data questions and how they answer them.
2. Assess the data literacy level of each group.
3. Identify the gap between what they need and what they can do today.
