# Internal Position Setup

Establish the authorized insider starting position and document the initial access level.

## Inputs

- `engagement-scope`: Authorized scope, network segments, and rules of engagement
- `starting-credentials`: Initial credentials or access level provided for the test

## Outputs

- `initial-position-report`: Documentation of the starting access level, network segment, and host
- `test-environment-baseline`: Baseline configuration of the test workstation

## Process

1. Connect to the authorized network segment from the designated starting position
2. Document the initial access level, IP address, and host configuration
3. Verify connectivity to in-scope network segments
4. Confirm communication with the client point of contact
