# Icd Time Cost Calculator

Convert the time each option consumes into dollars.

## Inputs

- `option-set`: The options under comparison
- `visible-cost-table`: The visible costs to add time onto
- `your-hourly-value`: The dollar value of an hour of your time

## Outputs

- `running-cost-with-time`: Visible cost plus the time cost per option
- `time-cost-detail`: The hours and dollar value behind the time cost

## Process

1. Estimate the hours each option consumes, such as commute, setup, and upkeep.
2. Multiply the hours by the hourly value of your time.
3. Add the time cost to the visible cost for a running total.
