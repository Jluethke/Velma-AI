# Listening Keyword Definer

Define the keywords and topics to monitor across social channels.

## Inputs

- `brand-name`: The brand or product name to monitor
- `competitor-names`: Key competitors to track
- `industry-terms`: Industry-specific keywords and hashtags

## Outputs

- `keyword-list`: Organized list of keywords by category (brand, competitor, industry)
- `boolean-queries`: Search queries formatted for monitoring tools

## Process

1. List all brand name variations, misspellings, and abbreviations.
2. List competitor brand names and product names.
3. Add industry terms, trending hashtags, and relevant phrases.
4. Format each group into boolean search queries for the monitoring tool.
