# Unintended Consequence Identifier

Identify unintended consequences from change data.

## Inputs

- `effect-tracking-method`: How effects are tracked
- `linkage-rules`: How changes link to effects

## Outputs

- `consequence-patterns`: Recurring unintended consequence patterns
- `prevention-recommendations`: How to prevent the identified patterns

## Process

1. Analyze linked effects to find negative outcomes not in the expected impact.
2. Categorize unintended consequences (performance, usability, cost, security).
3. Identify recurring patterns (same type of change producing the same type of consequence).
4. Produce prevention recommendations.
