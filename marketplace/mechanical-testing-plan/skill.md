# Mechanical Testing Plan

Plan and execute mechanical testing: tensile, hardness, impact, or fatigue tests matched to the application requirements.

## Inputs

- `material-description`: Material form and expected application
- `sample-inventory`: Available test specimens

## Outputs

- `mechanical-results`: Yield strength, UTS, elongation, hardness, and modulus with uncertainties
- `stress-strain-curves`: Recorded curves with labeled features (yield point, necking, fracture)
- `fracture-analysis`: Fracture surface description (ductile, brittle, mixed) from visual and SEM examination

## Process

1. Select test types based on application (tensile, compression, hardness, impact)
2. Machine specimens to standard dimensions (ASTM or ISO)
3. Run tests at controlled strain rate and temperature
4. Record and process stress-strain data, hardness indents, and impact energies
5. Examine fracture surfaces for failure mode
