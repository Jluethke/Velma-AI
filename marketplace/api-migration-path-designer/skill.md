# Api Migration Path Designer

Design the migration path for consumers moving between API versions.

## Inputs

- `versioning-scheme`: Chosen versioning approach
- `compatibility-rules`: Breaking vs non-breaking change definitions

## Outputs

- `migration-guide-template`: Template for consumer migration guides between versions
- `sunset-policy`: How long old versions are supported and how deprecation is communicated

## Process

1. Design the migration guide template: what changed, how to update, timeline.
2. Define the sunset policy: minimum support period, deprecation notices, shutdown timeline.
3. Define the communication plan: how consumers are notified of new versions and deprecations.
