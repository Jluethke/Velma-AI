# Skill Stack Roadmap

Produce an investment roadmap for building the chosen skill stack over time.

## Inputs

- `priority-skill`: The weakest skill in the chosen stack to improve first
- `improvement-targets`: Specific targets that define better for that skill

## Outputs

- `skill-stack-roadmap`: A sequenced plan for building the stack
- `review-schedule`: A schedule for re-rating percentiles and adjusting

## Process

1. Sequence the skills to develop, starting with the priority skill.
2. Set time allocations and milestones for each skill.
3. Schedule reviews to re-rate percentiles and adjust the stack.
4. Record the roadmap and the first action to take this week.
