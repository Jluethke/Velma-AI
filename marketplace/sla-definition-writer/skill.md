# Sla Definition Writer

Define SLAs for IT services.

## Inputs

- `service-catalog`: IT service catalog with service definitions
- `business-requirements`: Business expectations for each service

## Outputs

- `sla-drafts`: Draft SLAs for each service
- `measurement-criteria`: How each SLA metric will be measured

## Process

1. Identify the SLA metrics for each service (availability, response time, resolution time).
2. Set the target levels based on business requirements.
3. Define how each metric will be measured and reported.
4. Draft the SLA document for each service.
