# Evidence Layer

Under each supporting argument, place evidence: data, examples, analogies, or expert opinions.

## Inputs

- `argument-structure`: The 2-4 supporting arguments
- `topic`: What you are writing about

## Outputs

- `evidence-map`: Under each argument: 2-3 pieces of evidence that make the argument credible
- `evidence-gaps`: Arguments that lack strong evidence and need more research

## Process

1. For each argument, identify 2-3 pieces of evidence: data, examples, analogies, or authority.
2. Data is the strongest evidence. If data exists, use it. If not, say what you are relying on instead.
3. Flag evidence gaps. An argument without evidence is an assertion.
4. Two strong data points are better than five weak ones.
