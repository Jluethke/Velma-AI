# Ui Design Iterator

Iterate the design based on usability feedback and produce final files.

## Inputs

- `usability-findings`: Issues found in testing
- `ui-designs`: Current design files to update

## Outputs

- `final-ui-designs`: Updated and approved UI design files
- `design-handoff-specs`: Developer handoff with spacing, colors, and assets

## Process

1. Address each usability finding in order of severity
2. Update the component library with any new patterns
3. Prepare the design handoff with measurements and assets
4. Export all screens and components for development
