# Security Reporting Culture Assessor

Assess whether employees actively report security concerns and suspicious activity.

## Inputs

- `phishing-trend-analysis`: Phishing simulation trend data
- `completion-metrics`: Training completion data

## Outputs

- `reporting-culture-assessment`: Assessment of security reporting behavior across the organization
- `report-rate-vs-click-rate`: Comparison of phishing report rates against click rates

## Process

1. Calculate the phishing report rate: what percentage of simulated phishing emails are reported
2. Compare report rates against click rates (reporting should exceed clicking)
3. Review non-phishing security incident reports submitted by employees
4. Assess whether there are barriers to reporting (complex process, fear of blame, no feedback)
