# Awareness Audience Definer

Define the target audience and key message for the awareness campaign.

## Inputs

- `brand-positioning`: Current brand positioning and values
- `target-market`: Market segment to reach

## Outputs

- `audience-definition`: Target audience profile for the campaign
- `key-message`: Core message and supporting proof points

## Process

1. Define the audience demographics, interests, and media habits
2. Craft the key message aligned to brand positioning
3. Develop supporting proof points
