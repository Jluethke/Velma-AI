# Geochemical Analysis Plan

Plan geochemical analyses for selected samples: choose methods (XRF, ICP-MS, isotope ratios), define elements of interest, and set QA/QC procedures.

## Inputs

- `mineral-id-table`: Minerals present to guide element selection
- `research-objectives`: What geochemical questions to answer

## Outputs

- `geochemical-protocol`: Methods, elements, detection limits, and sample prep per batch
- `qaqc-plan`: Blanks, standards, duplicates, and acceptance criteria
- `element-suite`: Target analytes with expected ranges

## Process

1. Select analytical methods matched to target elements and detection limits
2. Define sample preparation (crushing, dissolution, fusion) per method
3. Design QA/QC with blanks, certified reference materials, and field duplicates
4. Set acceptance criteria for precision and accuracy
