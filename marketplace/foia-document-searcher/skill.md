# Foia Document Searcher

Search for and collect responsive documents from identified sources.

## Inputs

- `logged-request`: Request details and tracking number
- `scope-assessment`: Offices and systems to search

## Outputs

- `collected-documents`: All potentially responsive documents gathered from the identified sources
- `search-log`: Record of searches performed, systems queried, and date ranges covered

## Process

1. Send search taskers to each identified office with the request scope.
2. Search electronic systems (email, file shares, databases) for responsive records.
3. Collect the returned documents and log the search methodology.
