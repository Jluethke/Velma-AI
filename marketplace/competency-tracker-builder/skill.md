# Competency Tracker Builder

Build the competency tracking system to record and visualize learner progress.

## Inputs

- `competency-framework`: List of competencies
- `proficiency-levels`: Defined levels of proficiency

## Outputs

- `tracking-system`: Configured system for tracking competency progress
- `progress-dashboard`: Dashboard design showing learner progress across competencies

## Process

1. Configure the tracking tool (spreadsheet, LMS gradebook, or dedicated platform)
2. Set up the competency matrix with proficiency levels
3. Design the learner dashboard showing progress per competency
4. Test the tracking workflow end to end
