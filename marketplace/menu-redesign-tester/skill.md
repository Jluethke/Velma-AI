# Menu Redesign Tester

Redesign the menu and test with a pilot period.

## Inputs

- `action-plan`: Recommended actions per item
- `placement-recommendations`: New layout recommendations

## Outputs

- `new-menu-design`: Redesigned menu layout
- `menu-engineering-report`: Final menu engineering report with classification, actions, and test results

## Process

1. Apply the placement and pricing changes to the menu design.
2. Run the new menu for a test period.
3. Compare sales mix and margins against the prior period.
4. Produce the final report with before-and-after data.
