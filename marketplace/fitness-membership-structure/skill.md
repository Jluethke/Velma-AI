# Fitness Membership Structure

Set up the membership tiers and session package structure.

## Inputs

- `studio-format`: Type of studio (one-on-one, small group, classes, hybrid)
- `trainer-capacity`: Number of trainers and their available hours

## Outputs

- `membership-tiers`: Membership options with pricing, session counts, and included services
- `package-options`: Session packages with volume discounts and expiration rules

## Process

1. Define the membership tiers (basic, standard, premium) with included sessions per month.
2. Set package options for non-members (5-pack, 10-pack, 20-pack) with volume pricing.
3. Define what each tier includes beyond sessions (assessments, nutrition, app access).
4. Set the contract terms, freeze policy, and cancellation rules.
