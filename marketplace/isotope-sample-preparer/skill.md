# Isotope Sample Preparer

Prepare samples for isotope ratio measurement: dissolution, chemical separation, or combustion as needed.

## Inputs

- `sample-material`: Description of the material (rock, bone, water, organic tissue)
- `isotope-system`: Which isotope system (C, N, O, S, Sr, Pb, U-Th)

## Outputs

- `prepared-samples`: Samples ready for mass spectrometer loading
- `preparation-log`: Reagents, blanks, procedural losses, and contamination controls

## Process

1. Select the preparation protocol for the isotope system and sample type.
2. Process samples alongside procedural blanks and reference materials.
3. Quantify recovery and check for contamination at each step.
4. Log all reagent lots, temperatures, and timing.
