# Supporting Argument Builder

Build 2-4 supporting arguments that hold up the conclusion. Each argument is a reason to believe the conclusion.

## Inputs

- `conclusion-statement`: The conclusion to support
- `key-information`: The available information and analysis

## Outputs

- `supporting-arguments`: 2-4 arguments, each stated in one sentence, that support the conclusion. Together they are sufficient; individually they are necessary.
- `argument-order`: The order of arguments: strongest first if persuading, most important first if informing

## Process

1. Ask: why should the reader believe the conclusion? List every reason.
2. Group the reasons into 2-4 categories. Each category becomes a supporting argument. More than 4 arguments means the categories are too granular.
3. State each argument in one sentence. Like the conclusion, each argument should stand on its own as a claim.
4. Order the arguments: if the purpose is persuasion, lead with the strongest argument. If the purpose is information, lead with the most important argument. If the purpose is a decision, lead with the argument that addresses the reader's biggest concern.
