# Response Drafter

Draft responses for each question with supporting evidence references.

## Inputs

- `mapped-questions`: Questions with control and evidence mappings
- `evidence-gaps`: Gaps requiring workaround responses

## Outputs

- `draft-responses`: Complete draft responses for all questions
- `evidence-attachments`: List of evidence files to attach

## Process

1. Write a response for each question based on the mapped control
2. Reference specific evidence for questions requiring documentation
3. Note compensating controls for gap areas
4. Mark responses needing owner review
