# Outcome Tracking Setup

Track decision outcomes over time and identify patterns.

## Inputs

- `decision-schema`: The log entry schema
- `review-schedule`: When reviews happen

## Outputs

- `outcome-tracker`: System for recording actual outcomes against expected outcomes
- `decision-log-framework`: Complete decision log framework document

## Process

1. Add outcome fields to each entry (actual outcome, variance from expected, date assessed).
2. Define the scoring criteria for decision quality.
3. Set up trend tracking (decision quality over time, by domain, by maker).
4. Produce the complete decision log framework.
