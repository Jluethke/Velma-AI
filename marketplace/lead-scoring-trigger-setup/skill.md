# Lead Scoring Trigger Setup

Set up lead scoring rules and sales handoff triggers.

## Inputs

- `touchpoint-plan`: Nurture touchpoints and their sequence
- `segment-definitions`: Lead segments

## Outputs

- `scoring-model`: Point values for each behavior and attribute
- `handoff-threshold`: Score at which a lead is handed to sales

## Process

1. Assign point values to engagement behaviors (open, click, download, demo request)
2. Assign point values to demographic fit attributes
3. Set the threshold score that triggers sales handoff
