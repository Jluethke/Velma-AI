# Retrain Trigger Definer

Define the criteria and process for triggering model retraining.

## Inputs

- `drift-alerts`: Alert configuration
- `business-metrics`: Business impact thresholds

## Outputs

- `retrain-criteria`: Conditions that trigger retraining
- `drift-monitoring-plan`: Complete drift monitoring plan document

## Process

1. Define the retraining triggers (drift score thresholds, performance degradation, schedule).
2. Document the retraining pipeline (data refresh, training, evaluation, deployment).
3. Set the approval process for retraining (automatic vs manual review).
4. Write the complete drift monitoring plan.
