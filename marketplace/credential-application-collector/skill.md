# Credential Application Collector

Collect the credentialing application and supporting documents.

## Inputs

- `applicant-name`: Name of the provider applying for credentials
- `credential-type`: Initial appointment, reappointment, or privilege modification

## Outputs

- `application-package`: Completed application with all required documents
- `missing-items`: List of any documents not yet received

## Process

1. Send the application and document checklist to the provider.
2. Collect the completed application with CV, licenses, and references.
3. Identify and request any missing documents.
