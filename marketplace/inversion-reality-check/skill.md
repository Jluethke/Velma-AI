# Inversion Reality Check

Reality-check the inversion strategy by asking: are you currently doing any of the things on the failure path list? If yes, you have already started down a failure path. This is the most uncomfortable step because it often reveals that some failure behaviors are already in progress.

## Inputs

- `failure-paths`: The enumerated failure paths
- `inversion-strategy`: The derived strategy

## Outputs

- `current-failure-behaviors`: Failure path behaviors that are already happening right now
- `immediate-corrections`: Specific changes to make this week to stop current failure behaviors

## Process

1. Go through each failure path and honestly ask: am I doing this right now, even partially?
2. For each yes, write down exactly what you are doing that matches the failure path.
3. For each current failure behavior, define the specific correction to make this week.
4. Prioritize corrections by how far down the failure path you already are. Further along means more urgent.
