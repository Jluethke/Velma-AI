# Ein Obtainer

Obtain the Employer Identification Number from the IRS.

## Inputs

- `filing-confirmation`: State filing confirmation
- `entity-type`: Entity type

## Outputs

- `ein-number`: Assigned EIN
- `ein-confirmation`: IRS EIN assignment letter

## Process

1. Complete IRS Form SS-4 with entity information
2. Submit online through the IRS EIN application portal
3. Record and securely store the assigned EIN
