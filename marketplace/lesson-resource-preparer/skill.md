# Lesson Resource Preparer

Prepare all materials, handouts, slides, and technology resources for the lesson.

## Inputs

- `activity-sequence`: Ordered list of instructional activities with timing
- `activity-materials`: Materials and resources for each activity

## Outputs

- `resource-package`: All prepared materials ready for the lesson
- `technology-checklist`: Technology setup checklist

## Process

1. Prepare handouts, worksheets, and reference materials
2. Create or select presentation slides
3. Verify technology requirements (projector, software, internet)
4. Produce the resource package and tech checklist
