# Input Output Data Collection

Collect the data on inputs and outputs: what are you putting in, and what results are you getting?

## Inputs

- `system-to-audit`: What you are auditing (revenue by customer, time by activity, features by usage, marketing channels by conversion)
- `time-period`: The period to analyze (last quarter, last year, last month)

## Outputs

- `input-output-data`: A table of inputs and their corresponding outputs, sorted by output volume descending
- `total-output`: The total output across all inputs

## Process

1. Define the input and output clearly. For revenue: input = customer, output = revenue. For time: input = activity, output = value produced. For features: input = feature, output = user sessions involving that feature.
2. Collect the data for the specified period. Use actual numbers, not estimates. Estimates are biased toward the inputs you pay attention to.
3. Sort the data by output descending: highest-output inputs first.
4. Calculate the total output. This is the denominator for calculating percentages.
