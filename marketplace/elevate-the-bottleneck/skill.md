# Elevate The Bottleneck

If exploitation and subordination are not enough, invest in elevating the bottleneck: add capacity through spending.

## Inputs

- `capacity-after-exploitation`: The bottleneck capacity after free improvements
- `bottleneck-cost`: The cost of the remaining constraint

## Outputs

- `elevation-options`: Options for adding capacity to the bottleneck: hiring, equipment, automation, outsourcing, process redesign
- `elevation-roi`: For each option: cost to implement vs. value of the additional throughput it produces

## Process

1. List every option for adding capacity to the bottleneck. Common options: add a second instance (hire another person, buy another machine), automate part of the work, outsource part of the work, redesign the step to be faster.
2. For each option, calculate the ROI: the cost of the investment divided by the value of the additional throughput it produces. Because the bottleneck limits the entire system, even expensive investments at the bottleneck can have high ROI.
3. Implement the option with the highest ROI. Do not implement multiple options simultaneously; add capacity incrementally and measure the impact.
4. After elevating, re-measure the system. The former bottleneck may no longer be the constraint. A new step is now the bottleneck. Return to step 1 and repeat the cycle.
