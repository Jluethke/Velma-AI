# Prompt Rotation Designer

Design a rotating set of journaling prompts.

## Inputs

- `journal-format`: Selected journaling format
- `format-guidelines`: Format rules and structure

## Outputs

- `prompt-library`: Collection of journaling prompts organized by theme
- `rotation-schedule`: Which prompts to use on which days

## Process

1. Write 20-30 prompts organized by theme (gratitude, growth, planning, reflection).
2. Assign prompts to days of the week or rotate randomly.
3. Include at least one open-ended freewrite day per week.
