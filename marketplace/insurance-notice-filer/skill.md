# Insurance Notice Filer

Notify the insurance agent and file the notice of loss.

## Inputs

- `loss-documentation`: Description and evidence of the loss
- `policy-details`: Policy number, coverage type, and agent contact

## Outputs

- `notice-confirmation`: Confirmation that the notice was filed with date and reference number
- `adjuster-assignment`: Assigned adjuster name and expected inspection timeline

## Process

1. Contact the insurance agent within the required notification period.
2. Provide the loss documentation and policy details.
3. Confirm receipt and get the notice reference number.
4. Note the assigned adjuster and expected inspection date.
