# Reviewer Competency Assessment

Assess reviewer competency against the rubric and produce a targeted training improvement plan.

## Inputs

- `review-rubric`: Scoring rubric for reviewer accuracy and coverage
- `session-plan`: Timed agenda pairing exercises with checklist practice

## Outputs

- `competency-scorecard`: Per-reviewer scores for finding rate and accuracy
- `training-improvement-plan`: Follow-up practice targeted at each weak area

## Process

1. Score each reviewer against the rubric on finding rate and false positives
2. Identify weakness classes a reviewer repeatedly misses
3. Recommend targeted exercises for each identified gap
4. Set a re-assessment cadence to confirm the gaps close
