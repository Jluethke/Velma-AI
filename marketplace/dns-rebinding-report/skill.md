# Dns Rebinding Report

Produce the DNS rebinding test report with findings, proof-of-concept evidence, and remediation guidance.

## Inputs

- `sop-bypass-findings`: Same-origin policy bypass findings
- `impact-assessment`: Impact assessment of each finding

## Outputs

- `rebinding-report`: Complete DNS rebinding test report
- `remediation-plan`: Prioritized remediation recommendations

## Process

1. Compile all findings with proof-of-concept evidence
2. Rate each finding by severity using CVSS
3. Write remediation recommendations for each vulnerability
