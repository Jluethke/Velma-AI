# Test Report Assembler

Assemble all test and inspection reports.

## Inputs

- `project-name`: Name of the construction project

## Outputs

- `test-reports`: Complete set of test and inspection reports
- `test-gaps`: Any required tests not yet documented

## Process

1. Collect all test reports (concrete, steel, soil, air balance, fire alarm, etc.).
2. Verify that each required test was performed and documented.
3. Cross-reference against the specification requirements.
4. Flag any missing tests for immediate scheduling.
