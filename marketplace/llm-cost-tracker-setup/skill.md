# Llm Cost Tracker Setup

Set up ongoing cost tracking and produce the optimization report.

## Inputs

- `model-recommendations`: Recommended models per use case
- `cache-savings-estimate`: Projected savings

## Outputs

- `cost-dashboard`: Cost tracking dashboard configuration
- `optimization-report`: Full cost optimization report with action items

## Process

1. Set up cost-per-query tracking by application.
2. Configure budget alerts and anomaly detection.
3. Create the cost dashboard.
4. Compile the optimization report with projected savings.
