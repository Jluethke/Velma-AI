# Formation Documents Filer

Prepare and file the formation documents with the state.

## Inputs

- `entity-type`: Selected entity type
- `formation-state`: State of formation

## Outputs

- `filing-confirmation`: State filing confirmation and entity number
- `formation-documents`: Filed articles of incorporation or organization

## Process

1. Draft the articles of incorporation or organization
2. File with the Secretary of State and pay the filing fee
3. Obtain the filing confirmation and certified copies
