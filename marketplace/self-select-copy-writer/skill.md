# Self Select Copy Writer

Write copy that gives the wrong buyer a clear, early reason to leave before anyone spends time on a call.

## Inputs

- `worst-fit-profile`: The named worst-fit composite
- `disqualifier-list`: Observable disqualifiers

## Outputs

- `self-select-copy`: Copy that lets the wrong buyer recognize this is not for them
- `placement-recommendations`: Where the copy should sit to catch bad fit before a call

## Process

1. Write short copy in the buyer's words that states who this is not built for, drawn from the worst-fit profile.
2. Test each line against a good-fit buyer: if it would scare the right buyer off, soften or remove it.
3. Recommend placement where it catches bad fit early, such as the pricing page or a qualification form.
4. Note that this copy often raises conversion, because confidence and specificity reassure the right buyer.
