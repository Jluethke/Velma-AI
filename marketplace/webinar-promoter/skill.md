# Webinar Promoter

Promote the webinar to the target audience across channels.

## Inputs

- `registration-page`: Registration URL
- `webinar-plan`: Event details for promotion copy

## Outputs

- `promotion-plan`: Channels, timeline, and assets for promotion
- `registration-metrics`: Registration count and source data

## Process

1. Create promotion assets (emails, social posts, ads)
2. Schedule promotions across channels
3. Track registrations by source
