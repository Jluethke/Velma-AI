# Drop Off Hypothesis Builder

Hypothesize causes for the highest-impact drop-off points.

## Inputs

- `drop-off-rates`: Stage-by-stage drop-off data
- `product-context`: Product context for informed hypotheses

## Outputs

- `hypotheses`: Ranked hypotheses for each major drop-off
- `evidence-needed`: Data or research needed to validate each hypothesis

## Process

1. Review the highest-impact drop-off stages
2. Generate hypotheses for each based on common patterns
3. Rank hypotheses by plausibility and testability
