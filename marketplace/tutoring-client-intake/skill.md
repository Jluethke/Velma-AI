# Tutoring Client Intake

Onboard new clients with an intake assessment to identify their starting level and goals.

## Inputs

- `service-offerings`: Available services and formats
- `session-policies`: Policies the client must acknowledge

## Outputs

- `client-profile`: Client profile with goals, current level, learning style, and availability
- `initial-plan`: Preliminary lesson or coaching plan based on the intake assessment

## Process

1. Collect client information (name, contact, goals, timeline, prior experience).
2. Run the intake assessment to determine the starting skill level.
3. Identify the client's learning style and preferred session format.
4. Draft the initial lesson or coaching plan with milestones.
