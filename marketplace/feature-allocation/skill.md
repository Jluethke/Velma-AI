# Feature Allocation

Allocate features so the decoy sits close to premium but is missing the one capability the best buyers most want.

## Inputs

- `decoy-tier`: The middle tier definition
- `value-metric`: The metric buyers compare on

## Outputs

- `feature-allocation`: Which features sit in basic, decoy, and premium
- `premium-differentiator`: The single capability that pulls the right buyer up to premium

## Process

1. Give the decoy most of the premium value so it is clearly better than basic.
2. Hold back one capability that the highest-value buyers care about most, and place it only in premium.
3. Check the differentiator is something the right buyer will notice and the wrong buyer will not miss.
4. Avoid crippling the decoy on small, petty features, since that reads as manipulation rather than design.
