# Privacy Questionnaire Distribution

Send the privacy assessment questionnaire to the vendor.

## Inputs

- `vendor-name`: Name of the vendor being assessed
- `data-sharing-scope`: Description of what personal data will be shared and for what purpose

## Outputs

- `questionnaire-responses`: The vendor's completed privacy questionnaire
- `vendor-documentation`: Supporting documentation provided by the vendor (privacy policy, certifications, audit reports)

## Process

1. Select the appropriate questionnaire based on the data sensitivity and processing scope.
2. Send the questionnaire to the vendor with a deadline for completion.
3. Request supporting documentation (privacy policy, SOC 2 report, ISO 27001 certificate, data processing agreement template).
4. Follow up if responses are incomplete or unclear.
