# Security Program Charter Writer

Define the red/blue team program charter including objectives, scope, authority, and reporting structure.

## Inputs

- `organizational-context`: Industry, size, regulatory environment, and current security posture
- `executive-sponsor`: Executive sponsor and reporting chain for the program

## Outputs

- `program-charter`: Signed charter defining objectives, scope, authority, and boundaries
- `success-metrics`: Measurable criteria for program effectiveness

## Process

1. Define program objectives (detection improvement, response time reduction, vulnerability discovery)
2. Set the scope: which systems, networks, and personnel are in bounds
3. Define the authority: what the red team can and cannot do without additional approval
4. Establish the reporting structure and escalation path
