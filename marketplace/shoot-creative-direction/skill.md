# Shoot Creative Direction

Define the shot list and creative direction for the photo shoot.

## Inputs

- `shoot-brief`: The brief or purpose for the photo shoot
- `brand-guidelines`: Brand visual guidelines and mood references

## Outputs

- `shot-list`: Detailed list of shots with subject, composition, mood, and usage
- `creative-direction-doc`: Mood board, color palette, styling notes, and reference images

## Process

1. Define the purpose and usage of each photo (website, social, print, packaging).
2. Create the mood board with reference images, color palette, and styling direction.
3. Write the shot list with specifics for each shot (subject, angle, lighting, props).
4. Produce the shot list and creative direction document.
