# Account Provisioner

Set up the account in the core banking system.

## Inputs

- `kyc-result`: Passed KYC screening
- `account-preferences`: Account type and features selected

## Outputs

- `account-number`: Assigned account number and routing number
- `account-setup-record`: Account configuration in the core system

## Process

1. Create the account record in the core banking system.
2. Configure the selected features (overdraft, online access, alerts).
3. Generate the account number and routing details.
