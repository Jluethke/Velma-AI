# Alternative Use Brainstormer

For the resource being allocated, brainstorm every plausible alternative use. The opportunity cost is the value of the best alternative, not the average of all alternatives.

## Inputs

- `resource-description`: The resource being allocated (money, time, a person, a machine, attention)
- `proposed-use`: The use being considered for the resource
- `resource-amount`: The amount of the resource being allocated

## Outputs

- `alternative-uses`: Every plausible alternative use for the same resource, with a rough value estimate for each
- `best-alternative`: The single best alternative use: the one with the highest value

## Process

1. List every plausible alternative use for this resource. Include: doing nothing (keeping the resource in reserve), applying it to a different project, investing it, using it to reduce a different risk, using it to seize a different opportunity.
2. For each alternative, estimate the value it would produce. Use the same metric as the proposed use (dollars, time saved, risk reduced, skills gained).
3. Identify the best alternative: the one with the highest estimated value. This is the opportunity cost of the proposed use.
4. The proposed use is only worth it if its value exceeds the best alternative's value. If the best alternative is better, do that instead.
