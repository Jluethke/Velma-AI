# Course Objective Scoper

Define the learning objectives and target audience for the online course.

## Inputs

- `course-topic`: Subject and scope of the course
- `target-audience`: Description of the intended learners

## Outputs

- `course-objectives`: List of learning objectives for the course
- `audience-analysis`: Analysis of learner characteristics and prerequisites

## Process

1. Analyze the target audience (background, motivation, technical access)
2. Define 5-10 learning objectives for the course
3. Determine prerequisite knowledge and skills
4. Set the course scope and estimated duration
