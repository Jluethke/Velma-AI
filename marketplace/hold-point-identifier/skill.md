# Hold Point Identifier

Identify the inspection hold points from the project specifications.

## Inputs

- `project-specifications`: Project specifications and quality requirements
- `construction-schedule`: Schedule with upcoming activities

## Outputs

- `hold-point-schedule`: Schedule of upcoming inspection hold points
- `inspection-criteria`: Acceptance criteria for each hold point

## Process

1. Extract all inspection hold points from the specifications.
2. Map each hold point to the construction schedule.
3. Define the acceptance criteria for each inspection.
4. Notify the subcontractors of upcoming inspections.
