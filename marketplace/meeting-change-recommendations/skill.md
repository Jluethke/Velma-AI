# Meeting Change Recommendations

Recommend specific changes for each low-value recurring meeting.

## Inputs

- `meeting-scores`: Scored meetings
- `low-value-meetings`: Meetings flagged for change

## Outputs

- `change-recommendations`: Specific recommendation for each meeting (cancel, reduce frequency, shorten, combine, make async)
- `projected-time-savings`: Projected hours recovered per week if recommendations are adopted

## Process

1. For each low-value meeting, recommend one action: cancel entirely, reduce frequency (weekly to biweekly), shorten duration, combine with another meeting, or convert to async (written update, shared doc).
2. For meetings to keep, recommend attendee list trimming if some people are optional.
3. Calculate the projected time savings per week for each recommendation.
4. Present the recommendations to the meeting organizers for approval.
