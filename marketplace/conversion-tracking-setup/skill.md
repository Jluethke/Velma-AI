# Conversion Tracking Setup

Set up conversion tracking pixels, events, and attribution.

## Inputs

- `platform-plan`: Platforms in use
- `success-criteria`: KPIs to track

## Outputs

- `tracking-config`: Pixel and event configuration per platform
- `attribution-setup`: Attribution model and lookback window

## Process

1. Install or verify tracking pixels for each platform
2. Define conversion events aligned to the KPIs
3. Set the attribution model and lookback window
