# Bess Payback Calculator

Divide cost by monthly return to get the payback period.

## Inputs

- `total-cost`: The total cost to recover
- `monthly-return-estimate`: The steady monthly return

## Outputs

- `payback-months`: The number of months to recover the cost
- `cumulative-curve`: The cumulative return up to the break-even point

## Process

1. Divide the total cost by the steady monthly return.
2. Adjust for the ramp-up months at the start.
3. Build the cumulative return curve to the break-even point.
