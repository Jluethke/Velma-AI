# Meeting Execution Guide

Run the meeting: start on time, follow the agenda, make decisions, capture actions.

## Inputs

- `meeting-agenda`: The timeboxed agenda with decision owners
- `participants`: The attendees and their roles

## Outputs

- `meeting-execution-checklist`: The step-by-step protocol for running the meeting: open, discuss, decide, close, with timing
- `decision-capture-template`: The template for capturing decisions during the meeting: what was decided, by whom, and what actions follow

## Process

1. Start on time. Do not wait for latecomers. Do not recap for latecomers. This trains people to arrive on time.
2. For each agenda item: state the question to be decided, give the decision owner the floor, allow 80% of the time box for discussion, use the last 20% for the decision owner to make the call.
3. If a decision cannot be reached in the time box, the decision owner either extends (taking time from a later item) or moves the decision to async with a deadline.
4. Capture every decision and every action item in real time. An action item has: what, who, and by when. No action item is valid without all three.
