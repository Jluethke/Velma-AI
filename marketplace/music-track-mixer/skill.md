# Music Track Mixer

Mix the track with EQ, compression, reverb, and panning.

## Inputs

- `edited-tracks`: All edited instrument tracks
- `reference-tracks`: Reference songs for mix balance

## Outputs

- `stereo-mix`: The mixed stereo audio file
- `mix-notes`: Processing chain and settings for each track

## Process

1. Set levels and panning for each track in the stereo field
2. Apply EQ to carve frequency space for each instrument
3. Apply compression and dynamics processing
4. Add reverb, delay, and spatial effects
