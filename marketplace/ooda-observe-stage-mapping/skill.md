# Ooda Observe Stage Mapping

Map the Observe stage: how raw information about the situation reaches you and how long that takes. Stale or slow observation starts the whole loop behind.

## Inputs

- `loop-context`: The situation framed as a repeating decision loop
- `decision-inventory`: The specific recurring decisions in the loop

## Outputs

- `observe-map`: How information is gathered and from where
- `observe-latency`: The time from an event to you knowing about it

## Process

1. Trace how you learn what is happening: sensors, reports, dashboards, customer signals.
2. Measure the delay from an event occurring to you first seeing it.
3. Flag blind spots, the events you do not observe at all.
4. Record the observe latency as a number so stages can be compared later.
