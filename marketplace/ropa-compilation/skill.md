# Ropa Compilation

Compile the Record of Processing Activities (ROPA) and identify gaps.

## Inputs

- `data-flow-diagram`: The data flow diagrams
- `data-catalog`: The data element catalog

## Outputs

- `ropa-document`: The completed Record of Processing Activities
- `gap-report`: Gaps identified (missing legal basis, missing DPA, excessive retention, undocumented flows)

## Process

1. Compile the ROPA in the required format (controller name, purposes, data categories, recipients, transfers, retention, security measures).
2. Review each entry for completeness and flag gaps (missing legal basis, missing data processing agreement, no retention period set).
3. Prioritize the gaps by risk level.
4. Produce the ROPA document and the gap report with recommended remediation actions.
