# Catering Brief Collector

Gather the event details including guest count, dietary needs, budget, and theme.

## Inputs

- `event-brief`: Client description of the event
- `budget-range`: Budget parameters for the catering

## Outputs

- `event-requirements`: Structured requirements (count, dietary, theme, timing)
- `budget-allocation`: Budget split across food, beverage, staff, and rentals

## Process

1. Confirm guest count and dietary restrictions.
2. Define the event timeline and service style.
3. Allocate the budget across categories.
4. Document special requests and non-negotiables.
