# Video Concept Script Writer

Develop the video concept and write the script with scene breakdowns.

## Inputs

- `project-brief`: Description of the video's purpose and audience
- `key-messages`: Core messages or story beats to cover

## Outputs

- `script-document`: Completed script with scene descriptions and dialogue
- `shot-list`: List of required shots by scene

## Process

1. Identify the target audience and distribution platform
2. Outline the narrative arc or structure
3. Write the script with scene headings, action lines, and dialogue
4. Generate the shot list from the script
