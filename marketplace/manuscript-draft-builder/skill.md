# Manuscript Draft Builder

Structure a scientific manuscript with standard sections (introduction, methods, results, discussion), integrate figures and tables, and format citations.

## Inputs

- `results-narrative`: Interpreted results from the analysis
- `source-list`: Literature references
- `experiment-protocol`: Methods used

## Outputs

- `manuscript-draft`: Structured draft with all standard sections
- `figure-table-list`: Descriptions and captions for each figure and table
- `citation-list`: Formatted bibliography

## Process

1. Write the introduction from the literature context and knowledge gap
2. Describe methods in sufficient detail for replication
3. Present results with tables and figure placeholders
4. Write the discussion linking results to the hypothesis and prior work
5. Compile and format the reference list
