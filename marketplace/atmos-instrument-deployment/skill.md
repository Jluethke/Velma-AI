# Atmos Instrument Deployment

Plan the instrument suite and site layout for a field campaign, including power, data logging, and maintenance schedules.

## Inputs

- `campaign-objectives`: Scientific questions driving the measurement campaign
- `site-characteristics`: Geography, land use, elevation, and access at the field site
- `measurement-period`: Start date, end date, and intensive observation windows

## Outputs

- `instrument-plan`: Instrument list with specifications, placement coordinates, and data logging configuration
- `maintenance-schedule`: Calibration check and consumable replacement timeline

## Process

1. Map campaign objectives to required measurements (radiation, winds, temperature, humidity, trace gases, aerosols)
2. Select instruments and specify placement to minimize interference and maximize fetch
3. Design power supply (mains, solar, generator) and data acquisition system with backup logging
4. Schedule pre-deployment calibration, mid-campaign checks, and post-campaign calibration
