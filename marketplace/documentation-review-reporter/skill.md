# Documentation Review Reporter

Produce the documentation review report.

## Inputs

- `compliance-status`: Payer compliance results
- `query-tracking-log`: Status of provider queries

## Outputs

- `review-report`: Documentation review findings and recommendations
- `action-items`: Required corrections and their deadlines

## Process

1. Summarize findings by category (coding, evidence, compliance).
2. List action items with priority and responsible party.
3. Calculate the documentation quality score.
