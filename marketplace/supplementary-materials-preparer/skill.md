# Supplementary Materials Preparer

Compile supplementary materials: additional figures, extended tables, raw data summaries, and code availability statements.

## Inputs

- `raw-results`: Full set of results including those not in the main text
- `analysis-scripts`: Code used in the analysis

## Outputs

- `supplementary-package`: Organized supplementary files with index
- `data-availability-statement`: Statement describing where data and code can be accessed

## Process

1. Identify results that support the main findings but do not fit in the main text.
2. Format supplementary figures and tables with captions and numbering.
3. Prepare the code availability or repository link.
4. Write the data availability statement per the target journal's policy.
