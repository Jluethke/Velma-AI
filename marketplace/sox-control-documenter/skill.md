# Sox Control Documenter

Document control descriptions, objectives, and testing procedures.

## Inputs

- `control-inventory`: Inventory of controls
- `in-scope-processes`: Processes in scope

## Outputs

- `control-documentation`: Documented control descriptions with objectives and procedures
- `testing-plan`: Testing procedures and sample sizes for each control

## Process

1. Write the control description for each key control.
2. Define the control objective and what could go wrong.
3. Design the testing procedure (inquiry, observation, inspection, reperformance).
4. Set sample sizes based on control frequency.
