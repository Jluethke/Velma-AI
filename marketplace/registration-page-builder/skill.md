# Registration Page Builder

Set up the registration page with form fields and confirmation flow.

## Inputs

- `webinar-plan`: Topic, speakers, and date
- `business-goals`: Data to capture from registrants

## Outputs

- `registration-page`: Registration page URL and form configuration
- `confirmation-sequence`: Confirmation email and reminder sequence

## Process

1. Build the registration page with the event details
2. Define the form fields to capture
3. Set up confirmation and reminder emails
