# Neighborhood Project Selector

Select and scope a neighborhood project that has broad support and achievable impact.

## Inputs

- `survey_results`: What neighbors want
- `meeting_notes`: Discussion outcomes
- `available_resources`: Time, money, and skills available

## Outputs

- `selected_project`: Chosen project with scope
- `success_criteria`: How to measure success
- `resource_needs`: What the project requires

## Process

1. List candidate projects from survey and meeting
2. Score by impact, feasibility, and support level
3. Select project with broadest support
4. Define scope and success criteria
5. Identify resource requirements
