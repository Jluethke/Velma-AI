# Archive Access Setup

Set the access and retrieval procedures and compile the archive setup document.

## Inputs

- `archive-catalog`: Searchable catalog
- `finding-aid`: Guide to the archive

## Outputs

- `access-procedures`: Who can access the archive, how to request items, and the retrieval SLA
- `archive-setup-document`: Complete archive setup document covering scope, standards, catalog, and access

## Process

1. Define the access roles: public, internal, restricted, and the request process for each.
2. Set the retrieval SLA: how quickly requested items are delivered.
3. Schedule the periodic fixity checks (quarterly or annually) to verify file integrity.
4. Compile the archive setup document.
