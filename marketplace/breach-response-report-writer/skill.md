# Breach Response Report Writer

Produce the final data breach response report.

## Inputs

- `forensic-timeline`: Reconstructed timeline of the breach
- `notification-log`: Record of all notifications sent

## Outputs

- `breach-response-report`: Complete data breach response report
- `prevention-recommendations`: Recommendations to prevent similar breaches

## Process

1. Compile the complete timeline from initial access through notification
2. Summarize the total impact (individuals affected, data types, financial cost)
3. Document all response actions and their effectiveness
4. List recommendations to prevent recurrence
