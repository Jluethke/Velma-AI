# Redesign Build And Launcher

Build the new site, test it, and launch with redirects from the old pages.

## Inputs

- `visual-mockups`: Approved design mockups
- `content-plan`: Content decisions

## Outputs

- `new-site`: The built and tested new site
- `redesign-project-plan`: Complete project record including goals, design decisions, launch date, and post-launch measurement plan

## Process

1. Build the new site following the approved mockups.
2. Migrate and update content per the content plan.
3. Test thoroughly: content, functionality, performance, accessibility.
4. Set up redirects from old URLs, switch DNS, and monitor post-launch.
