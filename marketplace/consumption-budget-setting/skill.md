# Consumption Budget Setting

Set a time budget for information consumption. Without a budget, consumption expands to fill available time. The budget forces prioritization: you can only consume X minutes per day, so you must choose the highest-signal material.

## Inputs

- `eliminated-sources`: Sources that have been cut
- `retained-source-list`: Curated sources with signal ratios

## Outputs

- `daily-consumption-budget`: Time budget for information consumption: total minutes per day, allocated across retained sources
- `consumption-schedule`: When to consume each source (batched, not continuous) and the cutoff rule for stopping

## Process

1. Set the total daily budget. For most people, 30 to 60 minutes of deliberate information consumption is enough. Everything beyond that is usually low-signal browsing.
2. Allocate the budget across retained sources. Higher-signal sources get more time. The allocation is a rough guide, not a rigid schedule.
3. Batch consumption into 1 to 2 time blocks per day. Do not consume information continuously. Continuous consumption fragments attention. Batched consumption is focused.
4. Set a cutoff rule: when the time block ends, stop. Do not 'finish one more article.' The discipline of stopping is what prevents consumption from expanding.
