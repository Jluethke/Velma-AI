# Tenant Escalation Guide

Escalate unresolved issues: code enforcement, rent withholding, repair-and-deduct, and legal aid.

## Inputs

- `violation_log`: Documented violations
- `repair_request_history`: Prior repair requests and responses
- `state_of_residence`: State for legal reference

## Outputs

- `escalation_options`: Available legal remedies ranked
- `code_enforcement_filing`: How to file with code enforcement
- `legal_aid_resources`: Free and low-cost legal help

## Process

1. Review state-specific tenant remedies
2. File code enforcement complaint if applicable
3. Evaluate rent withholding legality in state
4. Research repair-and-deduct options
5. Locate legal aid organizations
