# Pillar Content Identifier

Identify the pillar content with the highest repurposing potential.

## Inputs

- `content-library`: The creator's existing content catalog (videos, podcasts, blog posts, presentations)
- `performance-data`: View counts, engagement, and evergreen scores for each piece

## Outputs

- `pillar-content-list`: Ranked list of content pieces with the highest repurposing potential
- `repurpose-opportunity-map`: Which derivative formats each pillar piece can generate

## Process

1. Review the content library for pieces that are evergreen, high-performing, or information-dense.
2. Score each piece on repurposing potential (length, density, visual appeal, topic breadth).
3. Map each pillar piece to the derivative formats it could produce.
4. Rank by expected reach and effort ratio.
