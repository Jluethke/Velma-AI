# jqwik Property Tests for the JVM

**One-line description:** Writes jqwik `@Property` tests for Java or Kotlin catalog rows with `@ForAll` parameters, constraint annotations and `@Provide` methods returning `Arbitrary<T>`, runs them on the JUnit 5 platform through Maven or Gradle, and replays failures with the printed seed.

**Execution Pattern:** Phase Pipeline

---

## Inputs

- `property_catalog` (object[], required): Rows from `pft-invariant-discovery`.
- `repo_path` (string, required): Maven or Gradle project root.

---

## Outputs

- `jvm_property_tests` (object[]): One row per property: catalog `id`, class, method, arbitraries, `tries` and its source, mutation used, and the shrunk sample plus seed from the failure report.

---

## Phase 1: Add jqwik

### Entry Criteria
- `mvn -q test` or `./gradlew test` passes before changes.

### Actions
1. Add the dependency with the current release number from the jqwik user guide:

| Build | Add |
|---|---|
| Maven | `<dependency><groupId>net.jqwik</groupId><artifactId>jqwik</artifactId><version>VERSION</version><scope>test</scope></dependency>` and Surefire 2.22 or later so JUnit Platform runs |
| Gradle | `testImplementation("net.jqwik:jqwik:VERSION")` and `tasks.test { useJUnitPlatform { includeEngines("jqwik", "junit-jupiter") } }` |

If the project already runs JUnit Jupiter, keep that engine in the include list or existing tests stop running.
2. Run the existing suite again and compare the test count with the count before the change. It must not drop.

### Output
jqwik on the test classpath.

### Quality Gate
- The build passes and the reported test count is unchanged (Surefire `Tests run:` line or Gradle test report).

---

## Phase 2: Arbitraries

### Entry Criteria
- jqwik resolves.

### Actions
1. Prefer annotations on `@ForAll` parameters for simple domains:

| Domain | Annotation or API |
|---|---|
| Bounded int or long | `@ForAll @IntRange(min = a, max = b) int n`, `@LongRange` |
| String with size and chars | `@ForAll @StringLength(min = 1, max = m) @AlphaChars String s` |
| Collection size | `@ForAll @Size(max = m) List<@IntRange(min = 0) Integer> xs` |
| Unique elements | `@UniqueElements` |
| Non-null, positive | `@Positive`, `@Negative`; null is not generated by default |
| Custom type | `@Provide Arbitrary<Order> orders() { return Combinators.combine(Arbitraries.integers(), Arbitraries.strings().alpha().ofMaxLength(m)).as(Order::new); }` then `@ForAll("orders") Order o` |
| Choices | `Arbitraries.of(...)`, `Arbitraries.oneOf(a, b)` |
| Transform | `.map(f)`, `.flatMap(f)` (flatMap shrinks less well) |
| Reject | `.filter(p)` or `Assume.that(cond)` sparingly |

2. Bounds come from the catalog domain; leave open questions open.

### Output
Arbitraries per catalog row.

### Quality Gate
- Every annotation and API used appears in the jqwik user guide for the installed version.

---

## Phase 3: Properties, Mutation-Check, Replay

### Entry Criteria
- Arbitraries chosen.

### Actions
1. Create `src/test/java/.../<Target>Properties.java`:

```java
class VarintProperties {
    @Property
    void p1Roundtrip(@ForAll @LongRange(min = 0) long n) {
        byte[] b = Varint.encode(n);
        assertThat(Varint.decode(b)).isEqualTo(new Decoded(n, b.length));
    }

    @Example
    void p1EdgeZero() { assertThat(Varint.decode(Varint.encode(0))).isEqualTo(new Decoded(0, 1)); }
}
```

2. The documented default is 1000 tries per property; set `@Property(tries = N)` only with a user-provided N.
3. Run one class: `mvn -q test -Dtest=VarintProperties` or `./gradlew test --tests VarintProperties`.
4. Apply one temporary mutation per property. The report shows:

```text
VarintProperties:p1Roundtrip =
  org.opentest4j.AssertionFailedError: expected: Decoded[value=128, length=2] but was: Decoded[value=0, length=1]
                              |-----------------------jqwik-----------------------
tries = 13                    | # of calls to property
checks = 13                   | # of not rejected calls
generation = RANDOMIZED       | parameters are randomly generated
after-failure = SAMPLE_FIRST  | try previously failed sample, then previous seed
seed = 4250918311536297413    | random seed to reproduce generated values
Shrunk Sample (7 steps)
-----------------------
  n: 128
```

The `after-failure` mode shown depends on the version and settings.
5. Replay with `@Property(seed = "4250918311536297413")` temporarily, confirm the same shrunk sample, then remove the seed attribute. jqwik also stores failures in `.jqwik-database` and retries them first by default; add `.jqwik-database` to `.gitignore`.
6. Revert the mutation (`git checkout -- <file>`), rerun green.

### Output
`jvm_property_tests`.

### Quality Gate
- The property class passes on the unmodified code.
- Every property has a recorded mutation, seed and shrunk sample.
- No `seed = ` attribute remains in committed code (`grep -rn 'seed = "' src/test` prints nothing).

## Worked Example

Illustrative. Row P3 (metamorphic): adding a filter term to a search never adds results.

```java
@Property
void p3MoreTermsNeverMoreHits(@ForAll("queries") String q, @ForAll @AlphaChars @StringLength(min = 1, max = 5) String extra) {
    assertThat(index.search(q + " AND " + extra)).isSubsetOf(index.search(q));
}
```

Mutation: `AND` parsed as `OR`. jqwik reports `Shrunk Sample (4 steps): q: "a", extra: "b"` with a seed; after revert the property passes 1000 tries.

---

## Exit Criteria

DONE when each JVM catalog row has a passing jqwik property, the existing test count is unchanged, each property was killed by a recorded mutation with a seed, and no replay seed is left in code.

---

## Error Handling

| Phase | Failure Mode | Response |
|---|---|---|
| Phase 1 | Existing JUnit tests stop running | **Adjust**: include both `jqwik` and `junit-jupiter` engines; rerun and compare counts. |
| Phase 2 | `CannotFindArbitraryException` | **Adjust**: add a `@Provide` method or register a default arbitrary provider; do not change the parameter type to dodge it. |
| Phase 3 | `TooManyFilterMissesException` | **Adjust**: replace filters with `Combinators` or `.map`. |
| Phase 3 | Real failure before mutation | **Return**: record sample and seed for `pft-shrinking-reproduction`. |
| Phase 3 | Mutation not detected | **Adjust**: strengthen the assertion and rerun. |
