# Dpa Breach Notification Drafter

Draft the breach notification obligations and timeline.

## Inputs

- `processing-scope`: Processing scope
- `role-assignment`: Role assignment

## Outputs

- `breach-clause`: Data breach notification provisions
- `notification-timeline`: Notification deadline and required information

## Process

1. Set the notification deadline (without undue delay, within X hours)
2. Specify the information that must be included in the notification
3. Define cooperation obligations for breach investigation and response
