# Psm Three Argument Builder

Build the three arguments that support the governing answer. Three is enough to be convincing and few enough to be remembered. The arguments should be distinct and together complete, so they cover the answer without overlapping each other.

## Inputs

- `governing-answer`: The answer the arguments must support
- `audience-question`: The question being resolved, to keep the arguments on point

## Outputs

- `supporting-arguments`: The three arguments that together justify the governing answer
- `mece-check`: A check that the arguments are distinct from each other and complete as a set

## Process

1. Ask what has to be true for the governing answer to hold. The answers to that are your arguments.
2. Reduce to three. If you have five, some are sub-points of others, so group them. If you have one, it is probably the answer restated, so break it down.
3. Check that the three do not overlap. Two arguments making the same point waste a slot and weaken the set.
4. Check that the three are complete: if the audience accepts all three, do they have to accept the answer? If not, an argument is missing.
