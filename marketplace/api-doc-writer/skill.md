# Api Doc Writer

Write the API documentation in a standard format.

## Inputs

- `endpoint-catalog`: Endpoint details
- `example-requests`: Sample requests
- `example-responses`: Sample responses

## Outputs

- `api-reference`: Complete API reference documentation
- `getting-started-guide`: Quick start guide for new API consumers

## Process

1. Group endpoints by resource or domain area.
2. Write each endpoint section: description, authentication, parameters, request body, response, examples, error codes.
3. Write the getting started guide: authentication, first request, common patterns.
4. Add a changelog section for tracking updates.
