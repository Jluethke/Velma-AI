# Violation Identifier

Identify and document a code violation.

## Inputs

- `complaint-or-observation`: The complaint received or inspector observation that triggered the case
- `applicable-codes`: The building, zoning, or property maintenance codes that apply

## Outputs

- `violation-documentation`: Documented violation with photos, location, and code citations
- `inspection-report`: Formal inspection report with findings

## Process

1. Conduct the site inspection and document the conditions with photos.
2. Identify the specific code sections being violated.
3. Record the violation details including location, severity, and responsible party.
4. Prepare the formal inspection report.
