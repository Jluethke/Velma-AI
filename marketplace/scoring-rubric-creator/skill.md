# Scoring Rubric Creator

Create a scoring rubric that defines what each rating level looks like for each competency.

## Inputs

- `competency-list`: Competencies to assess
- `question-bank`: Interview questions by competency

## Outputs

- `scoring-rubric`: Rating scale with behavioral anchors per competency
- `scoring-sheet`: Printable scoring sheet for interviewers

## Process

1. Define the rating scale (1 to 5 with behavioral anchors)
2. Write example responses for each rating level per competency
3. Create the scoring sheet template
4. Review for consistency across competencies
