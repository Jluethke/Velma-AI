# Landing Page Layout Designer

Design the page layout: hero section, benefits, social proof, and CTA placement.

## Inputs

- `page-copy`: All the written content for the page
- `cta-text`: Call-to-action text

## Outputs

- `page-wireframe`: Section-by-section layout of the page
- `design-specs`: Color palette, typography, and image direction

## Process

1. Lay out the hero section with headline, subhead, and primary CTA.
2. Arrange the benefits section and social proof below the fold.
3. Place a secondary CTA at the bottom of the page.
4. Specify the visual direction (colors, fonts, imagery style).
