# Return Receiver

Receive and log returned items.

## Inputs

- `return-authorization`: Return authorization number and expected items
- `return-reason-codes`: Standard reason codes for returns

## Outputs

- `received-returns`: Logged return receipts with item details
- `initial-inspection`: Initial condition assessment of each item

## Process

1. Verify the return against the authorization
2. Log each item with condition notes and photos
3. Assign the appropriate reason code
4. Produce the received returns log
