# Talk Track Writer

Write talk tracks and objection handling for each persona.

## Inputs

- `buyer-personas`: Persona profiles
- `pain-points`: Persona pain points

## Outputs

- `talk-tracks`: Conversation guides for each persona and stage
- `objection-responses`: Responses to common objections

## Process

1. Write the opening value statement for each persona.
2. Script discovery questions tied to each pain point.
3. Write responses to the top five objections.
4. Create the closing language for each deal stage.
