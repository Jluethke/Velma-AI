# Reinsurance Submission Preparer

Prepare the reinsurance submission package for marketing to reinsurers.

## Inputs

- `program-structure`: The designed program structure
- `risk-analysis`: Supporting risk and portfolio analysis

## Outputs

- `submission-package`: The reinsurance submission with company overview, portfolio data, loss history, and program structure
- `target-reinsurer-list`: Target reinsurers ranked by capacity, expertise, and relationship

## Process

1. Compile the submission with company financials, portfolio summary, and loss history.
2. Include the proposed program structure and pricing expectations.
3. Identify and rank target reinsurers by capacity and expertise.
4. Distribute the submission to the target reinsurers.
