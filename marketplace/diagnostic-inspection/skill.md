# Diagnostic Inspection

Perform a diagnostic inspection to identify the root cause of the customer complaint.

## Inputs

- `intake-record`: Vehicle information and customer complaint
- `work-order-number`: Work order number for this job

## Outputs

- `diagnostic-findings`: Root cause analysis with supporting evidence (codes, measurements, visual inspection)
- `recommended-repairs`: List of repairs needed to resolve the complaint

## Process

1. Pull diagnostic trouble codes if applicable.
2. Perform the relevant inspection (visual, road test, component test, fluid analysis).
3. Identify the root cause and any related issues discovered during inspection.
4. Document the findings with measurements, photos, or code data.
