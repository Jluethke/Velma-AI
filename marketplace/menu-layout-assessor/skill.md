# Menu Layout Assessor

Assess the current menu layout and its effect on item sales.

## Inputs

- `item-classification`: Item classifications
- `current-menu-layout`: Current menu design and item placement

## Outputs

- `layout-findings`: Which items get prime placement vs their classification
- `placement-recommendations`: Where to place each item for better results

## Process

1. Map item placement against the eye-tracking zones.
2. Compare placement with item classification.
3. Identify mismatches (dogs in prime spots, stars hidden).
4. Recommend placement changes.
