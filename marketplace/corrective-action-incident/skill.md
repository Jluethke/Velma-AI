# Corrective Action Incident

Investigate the root cause and implement corrective actions to prevent recurrence.

## Inputs

- `parent-notification-record`: Parent notification status
- `licensing-report-status`: Licensing report status

## Outputs

- `root-cause-finding`: Identified root cause or contributing factors
- `incident-report`: Final incident report with corrective actions, responsible parties, and implementation dates

## Process

1. Interview the staff and witnesses to understand what led to the incident.
2. Identify the root cause (supervision gap, environmental hazard, policy gap, individual behavior).
3. Develop corrective actions (policy change, environmental fix, additional training, schedule adjustment).
4. Assign responsible parties and implementation dates for each corrective action.
5. File the complete incident report in the child's record and the center's incident log.
