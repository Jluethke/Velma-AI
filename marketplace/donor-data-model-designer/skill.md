# Donor Data Model Designer

Define donor data fields including contact information, giving history, communication preferences, and relationships.

## Inputs

- `organization-profile`: Description of the nonprofit and its donor base
- `existing-data-sources`: Current systems and spreadsheets holding donor data

## Outputs

- `donor-data-model`: Field definitions for the donor record
- `data-migration-map`: Mapping from existing sources to the new model

## Process

1. List every field needed for donor records (name, address, email, phone, employer, relationships)
2. Define giving history fields (gift date, amount, campaign, fund, payment method)
3. Add communication preference and opt-in fields
4. Map existing data sources to the new field structure
