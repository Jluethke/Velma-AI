# Dpa Security Measures Specifier

Specify the technical and organizational security measures required.

## Inputs

- `processing-scope`: Processing scope
- `data-types`: Data types being processed

## Outputs

- `security-requirements`: Required security measures (encryption, access controls, testing)
- `security-annex`: Technical security measures annex

## Process

1. Define encryption requirements for data at rest and in transit
2. Specify access control, authentication, and logging requirements
3. Require regular security testing and vulnerability assessments
