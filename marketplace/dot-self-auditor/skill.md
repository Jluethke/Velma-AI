# Dot Self Auditor

Conduct self-audits and prepare for DOT compliance reviews.

## Inputs

- `dq-file-status`: Driver qualification file status
- `compliance-procedures`: Compliance procedures

## Outputs

- `self-audit-results`: Results of the self-audit by compliance area
- `dot-compliance-report`: Complete DOT compliance program report with readiness assessment

## Process

1. Conduct the self-audit using the FMCSA compliance review checklist.
2. Score each area (satisfactory, conditional, unsatisfactory).
3. Develop corrective action plans for any deficiencies.
4. Compile the compliance program report with current status and audit readiness.
