# No Code Platform Selector

Select the no-code platform based on the app requirements.

## Inputs

- `app-requirements`: Features and user stories
- `user-flows`: Main user paths

## Outputs

- `platform-choice`: The selected no-code platform with rationale
- `platform-constraints`: Limitations of the chosen platform to design around

## Process

1. Evaluate platform options against the feature requirements.
2. Consider data model complexity, integrations needed, and deployment options.
3. Note the platform's limitations and how they affect the design.
4. Select the platform and document the rationale.
