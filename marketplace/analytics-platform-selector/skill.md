# Analytics Platform Selector

Select the analytics platform and prepare the data layer.

## Inputs

- `needs-assessment`: What users need
- `skill-levels`: User capabilities

## Outputs

- `platform-selection`: Chosen analytics platform with rationale
- `data-layer-spec`: Semantic model and curated datasets for self-service use

## Process

1. Evaluate platforms against user needs and skill levels.
2. Select the platform and document the rationale.
3. Design the data layer: semantic model, curated datasets, pre-built dimensions and measures.
