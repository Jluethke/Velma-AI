# Eoc Structure Designer

Define the emergency operations center structure and roles.

## Inputs

- `hazard-inventory`: Identified hazards
- `risk-priorities`: Prioritized risk list

## Outputs

- `eoc-org-chart`: Organizational chart for the emergency operations center using ICS
- `role-assignments`: Roles and responsibilities for each EOC position

## Process

1. Design the EOC organizational structure using the Incident Command System.
2. Define the roles, responsibilities, and authority for each position.
3. Identify primary and backup personnel for each role.
4. Document the activation triggers and staffing levels for each emergency tier.
