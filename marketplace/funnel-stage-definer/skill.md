# Funnel Stage Definer

Define the funnel stages and the events that mark transitions between them.

## Inputs

- `product-context`: Product or service being analyzed
- `user-journey`: Expected user journey from first touch to conversion

## Outputs

- `funnel-stages`: Named stages with transition events
- `tracking-requirements`: Events that must be tracked for each transition

## Process

1. List the funnel stages (visit, signup, activation, purchase, retention)
2. Define the event that marks each stage transition
3. Verify tracking is in place for each event
