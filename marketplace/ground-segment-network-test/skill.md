# Ground Segment Network Test

Assess ground segment network security including segmentation between operations and administrative networks.

## Inputs

- `station-specifications`: Ground segment network architecture
- `authorization-scope`: Network testing boundaries

## Outputs

- `network-findings`: Ground segment network security findings
- `segmentation-assessment`: Assessment of network segmentation effectiveness

## Process

1. Map the ground segment network topology and segmentation boundaries
2. Test firewall rules between operations, administrative, and internet zones
3. Check for lateral movement paths from administrative to operations networks
4. Assess remote access security for ground station operations
