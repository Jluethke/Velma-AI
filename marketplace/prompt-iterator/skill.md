# Prompt Iterator

Revise the prompt to address failure cases and edge cases.

## Inputs

- `draft-prompt`: Current prompt
- `failure-cases`: Cases that failed

## Outputs

- `revised-prompt`: Updated prompt addressing failures
- `change-log`: What changed and why

## Process

1. Analyze each failure to find the root cause.
2. Revise the prompt to handle each failure pattern.
3. Add or update examples to cover edge cases.
4. Document every change and its justification.
