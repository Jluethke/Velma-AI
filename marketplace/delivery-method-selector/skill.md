# Delivery Method Selector

Select the delivery methods for each training program.

## Inputs

- `learning-objectives`: Learning objectives
- `target-audiences`: Target audiences

## Outputs

- `delivery-plan`: Delivery method for each program (classroom, e-learning, mentoring, rotation)
- `vendor-requirements`: Requirements for external training vendors if needed

## Process

1. Match the learning objective type to the best delivery method
2. Assess in-house capability vs external vendor needs
3. Consider learner preferences and accessibility
4. Estimate the cost per delivery method
