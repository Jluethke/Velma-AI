# Safety Test Designer

Design test cases for each safety category.

## Inputs

- `safety-taxonomy`: Categories and severity levels
- `system-description`: System under test

## Outputs

- `test-suite`: Test cases organized by category
- `adversarial-prompts`: Adversarial inputs designed to trigger failures

## Process

1. Write test cases for each category and severity level.
2. Design adversarial prompts for jailbreak and injection.
3. Include edge cases and ambiguous inputs.
4. Validate that test cases cover the full taxonomy.
