# Species Inventory Protocol

Design a species inventory method for a target area: define taxa of interest, choose survey methods (visual, trap, acoustic), and set sampling effort.

## Inputs

- `study-area`: Geographic location, coordinates, and habitat type
- `taxa-of-interest`: Which groups to survey (birds, insects, plants, etc.)

## Outputs

- `inventory-protocol`: Survey method, transect layout, trap types, and effort per session
- `species-checklist-template`: Recording form with expected species and identification keys
- `permits-needed`: Collection, access, or IACUC permits required

## Process

1. Review existing species records for the area
2. Select survey methods matched to each taxon (point counts, pitfall traps, quadrats, mist nets)
3. Design transect or plot layout for spatial coverage
4. Set sampling effort (sessions, duration, replicates) based on detection probability
5. Identify permitting requirements
