# Cross Client Template Tester

Test all templates across email clients and devices.

## Inputs

- `template-set`: The master templates to test

## Outputs

- `test-results`: Rendering results across clients (Gmail, Outlook, Apple Mail, Yahoo) on desktop and mobile
- `template-fixes`: Issues found and fixes applied

## Process

1. Test each template in Gmail (web and mobile), Outlook (desktop and web), Apple Mail, and Yahoo.
2. Check dark mode rendering in each client.
3. Verify responsive behavior on mobile screens.
4. Fix any rendering issues and retest.
