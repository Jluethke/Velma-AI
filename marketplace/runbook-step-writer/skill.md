# Runbook Step Writer

Write step-by-step instructions for each runbook including diagnostic commands and expected outputs.

## Inputs

- `runbook-inventory`: List of runbooks to write
- `template-structure`: Standard runbook template

## Outputs

- `draft-runbooks`: Draft runbooks with step-by-step procedures
- `command-reference`: Diagnostic commands and their expected outputs

## Process

1. Write the symptom identification section for each runbook
2. Document the diagnostic steps with exact commands to run
3. Include the expected output for each command at each decision point
4. Write the resolution steps with verification checks
