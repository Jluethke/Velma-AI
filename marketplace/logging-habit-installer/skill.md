# Logging Habit Installer

Install the logging habit by reducing friction to near zero and building accountability for the first 30 days.

## Inputs

- `prep-card-template`: The one-page prep card format
- `retrieval-triggers`: When prep cards should appear

## Outputs

- `friction-reduction-plan`: Specific changes to make logging take under 30 seconds per interaction (templates, quick-entry tools, voice-to-text)
- `accountability-system`: How to track logging compliance for the first 30 days and what to do when you skip a day

## Process

1. Reduce friction to the minimum. Pre-populate date and channel automatically. Use a contact picker instead of typing names. Offer topic templates for common interaction types ('caught up on their project,' 'discussed potential collaboration,' 'they asked for help with X'). Enable voice-to-text for the their-state field so you can dictate instead of type.
2. Set a 30-day compliance target: log at least 80% of substantive interactions. Track compliance as a simple ratio (entries created / interactions that should have been logged). Below 80%, the system is not producing enough data to be useful.
3. Build the recovery protocol for skipped days: at the end of each week, review your calendar and communication history for any interactions you forgot to log. Batch-enter them with whatever you can remember. A late entry with partial information is better than no entry.
4. Define the 30-day graduation: after 30 days, review the logs. Are the prep cards useful? Are you actually reading them before interactions? If yes, the habit is installed. If no, identify which fields are not providing value and remove them. A 4-field log you actually use beats a 7-field log you abandon.
