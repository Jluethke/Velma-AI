# Social Admin Configurator

Set up admin access, business tools, and analytics tracking.

## Inputs

- `optimized-profiles`: The optimized profiles across platforms
- `business-name`: The business name for verification

## Outputs

- `admin-configuration`: Admin roles, business manager setup, and security settings for each platform
- `analytics-configuration`: Analytics and tracking setup for each platform

## Process

1. Set up business manager or creator studio access on each platform.
2. Assign admin roles and permissions to team members.
3. Enable two-factor authentication and review security settings.
4. Configure native analytics and connect any third-party tracking tools.
