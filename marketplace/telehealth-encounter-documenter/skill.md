# Telehealth Encounter Documenter

Document the telemedicine encounter in the EHR.

## Inputs

- `assessment-findings`: Clinical findings from video exam
- `patient-reported-symptoms`: Patient-reported information

## Outputs

- `encounter-note`: Complete encounter documentation
- `billing-codes`: CPT and modifier codes for the telehealth visit

## Process

1. Write the encounter note with telehealth-specific documentation.
2. Apply the correct telehealth CPT codes and modifiers.
3. Note the technology platform used and any technical issues.
