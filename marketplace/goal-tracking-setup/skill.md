# Goal Tracking Setup

Set up weekly tracking and the review cadence.

## Inputs

- `milestone-map`: Milestones and dates
- `leading-indicators`: Leading indicators per goal

## Outputs

- `tracking-system`: Weekly tracking method and template
- `goal-framework`: Complete goal framework document

## Process

1. Set a weekly check-in to update leading indicators.
2. Design the tracking template (goal, milestone, indicator, status).
3. Set a monthly review to assess milestone progress.
4. Compile the full goal framework document.
