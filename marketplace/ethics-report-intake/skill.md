# Ethics Report Intake

Receive and log the ethics hotline report and assess severity.

## Inputs

- `report-details`: Details of the ethics report (allegation, parties involved, dates)
- `reporter-information`: Reporter contact information (if not anonymous)

## Outputs

- `case-record`: Logged case with case number and initial assessment
- `severity-rating`: Severity rating and recommended investigation scope

## Process

1. Log the report with a unique case number.
2. Assess the severity and urgency of the allegation.
3. Determine whether immediate protective action is needed.
4. Assign a priority and recommended investigation scope.
