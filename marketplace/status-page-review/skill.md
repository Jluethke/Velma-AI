# Status Page Review

Review the status page program and produce the management document.

## Inputs

- `published-incident-log`: Log of published incidents
- `subscriber-notification-record`: Notification delivery record

## Outputs

- `status-page-metrics`: Metrics on incidents published, update frequency, subscriber count
- `status-page-management-document`: Final management document with all configurations and processes

## Process

1. Review the last quarter's incidents for timeliness and accuracy of updates.
2. Measure the average time from detection to first status page post.
3. Check that the component list and health checks are still accurate.
4. Compile the management document with all configurations, templates, and review findings.
