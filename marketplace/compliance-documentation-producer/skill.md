# Compliance Documentation Producer

Produce the compliance documentation and ongoing audit schedule.

## Inputs

- `consent-framework`: The consent management framework
- `unsubscribe-spec`: The unsubscribe mechanism
- `compliance-gaps`: The original gaps for tracking fixes

## Outputs

- `compliance-documentation`: The complete compliance documentation (policies, procedures, consent records, unsubscribe process)
- `audit-schedule`: Schedule for periodic compliance audits (quarterly review, annual full audit)

## Process

1. Document the privacy policy sections covering email collection and use.
2. Document the consent record-keeping procedure and retention period.
3. Document the unsubscribe process with the processing timeline commitment.
4. Set the audit schedule: quarterly spot check, annual full audit, triggered audit on regulation changes.
