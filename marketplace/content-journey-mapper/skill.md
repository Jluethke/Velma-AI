# Content Journey Mapper

Map content to each stage of the buyer journey (awareness, consideration, decision).

## Inputs

- `segment-definitions`: Lead segments and their attributes
- `funnel-definition`: Funnel stages

## Outputs

- `content-map`: Content assigned to each funnel stage and segment
- `content-gaps`: Missing content that needs to be created

## Process

1. List existing content assets by type and topic
2. Assign content to each funnel stage
3. Identify gaps where new content is needed
