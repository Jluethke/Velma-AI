# Schedule Activity Updater

Update activity percent complete and dates in the schedule.

## Inputs

- `progress-data`: Percent complete and actual dates
- `field-notes`: Notes affecting progress

## Outputs

- `updated-schedule`: Schedule with current progress data
- `critical-path-changes`: Any changes to the critical path

## Process

1. Enter percent complete for each activity.
2. Record actual start and finish dates.
3. Recalculate the critical path.
4. Identify any new critical or near-critical activities.
