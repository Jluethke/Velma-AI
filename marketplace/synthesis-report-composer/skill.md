# Synthesis Report Composer

Write the evidence synthesis report presenting all conclusions, their evidence base, confidence ratings, and remaining gaps.

## Inputs

- `convergence-map`: synthesized findings
- `confidence-ratings`: confidence per conclusion
- `residual-contradictions`: unresolved disagreements

## Outputs

- `synthesis-report`: complete evidence synthesis report
- `research-gap-list`: prioritized questions where evidence is insufficient or contradictory

## Process

1. Present each conclusion with its supporting evidence, confidence rating, and key caveats
2. Address unresolved contradictions explicitly with what additional evidence would resolve them
3. Produce a summary of findings table for quick reference
4. List research gaps as prioritized questions for future investigation
