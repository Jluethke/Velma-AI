# Grooming Service Menu

Define the grooming service menu with pricing by pet size, breed, and coat type.

## Inputs

- `business-scope`: Types of pets served (dogs, cats, both) and service area
- `vehicle-capacity`: Mobile unit capabilities and limitations

## Outputs

- `grooming-menu`: Service menu with prices by pet size and coat type
- `time-estimates`: Average service duration per pet size and service combination

## Process

1. Define the base services (bath, haircut, nail trim, ear cleaning, teeth brushing).
2. Set pricing tiers by pet size (small, medium, large, extra-large) and coat type (short, long, double).
3. Add specialty services (de-shedding, flea treatment, creative grooming) with separate pricing.
4. Estimate service duration per combination for scheduling.
