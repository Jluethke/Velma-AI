# Call Reporting Automator

Automate the recurring reports generated from the dashboard.

## Inputs

- `dashboard-design`: The dashboard design
- `alert-configuration`: Alert rules

## Outputs

- `report-schedule`: Automated report schedule (daily ops report, weekly management report, monthly executive report)
- `call-analytics-system-document`: Complete call analytics system document covering metrics, pipeline, dashboard, and reporting

## Process

1. Configure the daily operations report (previous day summary, top issues, agent highlights).
2. Configure the weekly management report (trend analysis, staffing vs demand, quality trends).
3. Configure the monthly executive report (KPI summary, cost analysis, improvement recommendations).
4. Set the distribution lists and delivery method for each report.
5. Compile the full analytics system document.
