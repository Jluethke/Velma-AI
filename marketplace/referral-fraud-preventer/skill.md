# Referral Fraud Preventer

Set fraud prevention rules to block self-referral and abuse.

## Inputs

- `referral-flow`: Referral mechanics
- `tracking-requirements`: Tracking events

## Outputs

- `fraud-rules`: Rules to detect and block fraudulent referrals
- `review-process`: Manual review process for flagged referrals

## Process

1. Define rules for self-referral detection (same IP, device, payment method)
2. Set velocity limits on referral claims
3. Design the manual review process for flagged cases
