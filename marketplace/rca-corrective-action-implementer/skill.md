# Rca Corrective Action Implementer

Implement corrective actions addressing the root cause.

## Inputs

- `verified-root-cause`: Confirmed root cause
- `problem-definition`: Problem scope

## Outputs

- `corrective-actions`: Implemented permanent corrective actions
- `prevention-actions`: Systemic changes to prevent recurrence in similar processes

## Process

1. Develop corrective actions that address the root cause directly
2. Develop preventive actions that address the systemic gap that allowed the cause
3. Implement the actions with clear ownership and timelines
4. Update procedures, training, and error-proofing as needed
