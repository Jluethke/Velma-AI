# Critical Journey Identifier

Identify the critical user journeys that define the service's reliability from the user's perspective.

## Inputs

- `service-description`: Description of the service and its users
- `usage-analytics`: User traffic patterns and journey data

## Outputs

- `critical-journeys`: List of critical user journeys ranked by importance
- `journey-metrics-map`: Map of each journey to measurable metrics

## Process

1. List all user-facing journeys the service supports
2. Rank by business impact and user frequency
3. Select the top journeys that define service reliability
4. Map each journey to the technical metrics that measure its health
