# Welcome Sequence Builder

Create the welcome and onboarding communication sequence.

## Inputs

- `milestone-map`: Onboarding milestones
- `activation-definition`: Activation criteria

## Outputs

- `welcome-sequence`: Timed emails, in-app messages, and guides
- `getting-started-guide`: Step-by-step getting started guide

## Process

1. Write the welcome email with first steps.
2. Create in-app messages that trigger at each milestone.
3. Build the getting-started guide with screenshots.
4. Schedule check-in touchpoints at day 1, 7, 14, and 30.
