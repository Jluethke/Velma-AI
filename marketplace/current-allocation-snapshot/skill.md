# Current Allocation Snapshot

Capture the current allocation across all spending categories and the current return from each.

## Inputs

- `spending-categories`: All categories where money is currently allocated
- `return-metrics`: The measurable return from each category (revenue, savings, satisfaction, time recovered)

## Outputs

- `allocation-snapshot`: Each category with its current spend and current measured return
- `average-returns`: The average return per dollar for each category (total return divided by total spend)

## Process

1. List every spending category with the current period's allocation and the measured return.
2. Calculate the average return per dollar: total return from the category divided by total spend. This is the number most people use to allocate, and it is the wrong number.
3. Note the limitation: average return tells you what the existing dollars produce. It does not tell you what the next dollar would produce. A category with high average returns may have declining marginal returns.
4. Flag categories where you have no data on returns. These are blind spots that need measurement before marginal analysis can include them.
