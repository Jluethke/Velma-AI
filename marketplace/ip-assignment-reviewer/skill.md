# Ip Assignment Reviewer

Review intellectual property assignment and work-for-hire provisions.

## Inputs

- `agreement-text`: Employment agreement text
- `position-details`: Role details

## Outputs

- `ip-assignment-analysis`: Analysis of IP assignment scope and carve-outs
- `prior-inventions-note`: Prior inventions disclosure requirements

## Process

1. Review the scope of the IP assignment clause
2. Check for a prior inventions exclusion schedule
3. Assess whether the assignment is limited to job-related work
