# Daily Checkin Protocol

Design the daily check-in routine for logging habit completion.

## Inputs

- `tracking-schema`: Tracking method per habit
- `tracking-tools`: Selected tracking tools

## Outputs

- `checkin-protocol`: Step-by-step daily check-in routine
- `checkin-template`: Template for the daily log entry

## Process

1. Set the check-in time (morning, evening, or both).
2. Write the check-in steps: open tracker, log each habit, note any blockers.
3. Design the log entry template with fields for each habit.
