# Performance Decomposition

Break the target skill into its component sub-skills and measure your current performance in each one separately.

## Inputs

- `target-skill`: The skill you want to improve
- `current-performance-evidence`: Recent examples of your performance in this skill (recordings, work samples, scores, feedback)

## Outputs

- `sub-skill-map`: The target skill broken into 5-10 measurable sub-skills
- `sub-skill-scores`: Your current performance level in each sub-skill based on evidence, not self-assessment

## Process

1. Study how experts decompose this skill. Every complex skill is a bundle of smaller skills. A surgeon's skill includes hand steadiness, spatial reasoning, anatomical knowledge, decision-making under pressure, and communication with the team.
2. List 5-10 sub-skills for your target skill. Exclude any that are really the same skill described differently.
3. Score each sub-skill using your performance evidence. Watch recordings, review output, or ask someone who has observed you to rate each sub-skill independently.
4. Rank the sub-skills from weakest to strongest. The weakest one is your first practice target.
