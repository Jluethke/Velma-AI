# Culture Add Outcome Reviewer

After the hire, check whether the added perspective actually changed outcomes. The proof is in decisions: did the team decide differently, or catch a blind spot it would have missed? Track this for the first twelve months.

## Inputs

- `bias-checklist`: The bias checklist used
- `debrief-protocol`: The debrief protocol used

## Outputs

- `add-impact-log`: Specific instances where the added perspective changed a decision or caught a blind spot in the first twelve months
- `profile-adjustments`: Changes to the culture-add profile for the next hire based on the log

## Process

1. At monthly retrospectives, ask whether anyone's different perspective changed a decision this month.
2. Log each instance: the decision, what the team would have done without the input, and what the perspective added.
3. At twelve months, review the log; several logged instances mean the criteria were good.
4. If the log is empty, either the criteria missed or the team did not make room for the perspective, so adjust the profile for the next hire.
