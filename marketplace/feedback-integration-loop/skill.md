# Feedback Integration Loop

After each milestone, get feedback from someone who can evaluate the output and integrate it before starting the next milestone.

## Inputs

- `milestone-deliverables`: What each milestone produces
- `scoped-project`: The project context

## Outputs

- `feedback-plan`: Who will review each milestone, what you will ask them, and how you will integrate their feedback
- `quality-criteria`: For each milestone, the specific quality criteria that distinguish good output from adequate output

## Process

1. Identify one person for each milestone who can evaluate the output. This person should be better than you at the skill (they can spot errors you cannot see).
2. Ask specific questions, not 'what do you think?' Ask: 'Does this work correctly for edge case X?' or 'Where would a user get confused?' Specific questions produce specific feedback.
3. After receiving feedback, categorize it: critical (must fix before next milestone), important (should fix, improves quality), nice-to-have (optional). Fix all critical items. Address as many important items as time allows.
4. The feedback loop is the mechanism that converts building into learning. Without feedback, you practice your mistakes. With feedback, you correct them.
