# Maintenance Record Keeper

Set up a maintenance log to track all services, costs, and receipts for resale value and warranty.

## Inputs

- `vehicle_info`: Vehicle details
- `past_services`: Known past maintenance if any

## Outputs

- `log_template`: Maintenance log format
- `digitization_plan`: How to store receipts and records
- `resale_value_impact`: How records affect resale value

## Process

1. Create log template with date, mileage, service, cost, shop
2. Enter known past services
3. Set up receipt storage (photos, folder, app)
4. Link to service schedule for upcoming items
5. Note warranty-relevant services
