# Tribology Report Writer

Compile the tribology study into a report with test methods, friction curves, wear data, comparisons, and recommendations.

## Inputs

- `comparison-table`: Cross-material friction and wear comparison
- `ranking`: Material ranking
- `wear-morphology`: Wear mechanism images

## Outputs

- `tribology-report`: Complete tribology testing report with figures and recommendations
- `raw-data-archive`: Friction time series, profilometry files, and images

## Process

1. Write the methods section: test standard, geometry, parameters, specimen preparation, and instrumentation.
2. Include friction vs distance plots and representative wear track images.
3. Present the comparison table and material ranking.
4. Recommend the material pair that best meets the application's friction and wear requirements.
