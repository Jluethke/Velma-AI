# Password Audit Report

Produce the password security audit report with findings and recommendations.

## Inputs

- `pattern-report`: Password patterns found
- `policy-recommendations`: Recommended changes
- `stuffing-risk-score`: Credential stuffing risk

## Outputs

- `audit-report`: Complete password security audit report
- `executive-summary`: One-page summary for leadership

## Process

1. Compile all findings into the structured report
2. Include anonymized statistics (never expose individual passwords in the report)
3. Write the executive summary with key risk metrics
4. Prioritize recommendations by impact and implementation effort
