# Coping Toolkit Builder

Build a personalized coping toolkit with immediate, short-term, and long-term strategies.

## Inputs

- `trigger_inventory`: Known triggers
- `current_coping`: What currently helps or hurts
- `preferences`: Physical activity level, mindfulness experience, etc.

## Outputs

- `immediate_tools`: In-the-moment techniques (breathing, grounding)
- `daily_practices`: Daily prevention habits
- `weekly_practices`: Weekly maintenance activities

## Process

1. Assess current coping strategies for effectiveness
2. Match trigger types to evidence-based techniques
3. Build an immediate response toolkit (5-4-3-2-1, box breathing)
4. Design daily maintenance practices
5. Plan weekly deeper practices (exercise, journaling, social)
