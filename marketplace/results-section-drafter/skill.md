# Results Section Drafter

Draft the results section: present each claim in order with its supporting data, referencing figures and tables, without interpretation.

## Inputs

- `argument-outline`: Ordered claims with section assignments
- `claim-list`: Claims with full statistical details

## Outputs

- `results-draft`: Complete results section text with figure and table references
- `figure-table-callouts`: Ordered list of which figure/table is cited where

## Process

1. Write each claim as a topic sentence, followed by the supporting statistic.
2. Reference the appropriate figure or table in parentheses after the statistic.
3. Use transitional phrases to connect claims within each sub-question.
4. Avoid interpretation: save 'why' for the discussion, keep results to 'what'.
