# Technical Detail Writer

Write detailed technical sections with reproduction steps, affected components, and root cause analysis.

## Inputs

- `deduplicated-findings`: Findings to document in detail
- `root-cause-map`: Root cause relationships for context

## Outputs

- `technical-sections`: Detailed technical finding write-ups
- `reproduction-guides`: Step-by-step reproduction instructions per finding

## Process

1. Write each finding with description, affected component, and evidence
2. Include step-by-step reproduction instructions with tool commands
3. Document the root cause and why the vulnerability exists
4. Add references to CWE, OWASP, and vendor advisories where applicable
