# Lms Requirements Gatherer

Define the LMS requirements covering user roles, content types, integrations, and reporting.

## Inputs

- `organization-profile`: Size, structure, and learning needs of the organization
- `existing-systems`: Current systems the LMS must integrate with

## Outputs

- `lms-requirements`: Prioritized list of functional and technical requirements
- `integration-needs`: Required integrations (SIS, HR, SSO, content libraries)

## Process

1. Interview stakeholders (instructors, admins, learners, IT)
2. Document functional requirements (enrollment, grading, reporting, content types)
3. Document technical requirements (SSO, API, mobile, accessibility)
4. Prioritize requirements as must-have, should-have, nice-to-have
