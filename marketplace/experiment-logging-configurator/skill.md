# Experiment Logging Configurator

Configure metric, parameter, and artifact logging.

## Inputs

- `platform-selection`: Selected platform
- `metadata-schema`: Required metadata

## Outputs

- `logging-config`: Logging configuration and code templates
- `artifact-policy`: What artifacts to log and retention rules

## Process

1. Configure automatic metric logging.
2. Set up parameter logging for reproducibility.
3. Define which artifacts to save (models, datasets, plots).
4. Set retention and cleanup policies.
