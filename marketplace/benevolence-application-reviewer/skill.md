# Benevolence Application Reviewer

Receive and review benevolence applications.

## Inputs

- `program-policy`: Eligibility rules and limits
- `application-form`: The application template

## Outputs

- `application-decision`: Approved, denied, or referred with rationale and amount
- `verification-notes`: Documentation reviewed and need verification results

## Process

1. Receive the application and check completeness: contact info, description of need, supporting documents.
2. Verify eligibility against the program policy.
3. Review supporting documentation: bills, eviction notice, disconnect notice, medical statements.
4. Make the decision: approve (full or partial), deny with reason, or refer to an external resource.
