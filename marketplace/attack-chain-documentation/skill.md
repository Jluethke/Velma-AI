# Attack Chain Documentation

Document the full attack chain from initial access to impact for each exploit path.

## Inputs

- `poc-exploits`: Working exploits
- `exploitability-rating`: Exploitability assessments

## Outputs

- `attack-chains`: Documented attack chains with steps and prerequisites
- `impact-assessment`: What an attacker achieves at each stage

## Process

1. Map each exploit to a complete attack chain from entry to impact
2. Document prerequisites and attacker skill requirements
3. Describe the impact at each stage: code execution, data access, privilege level
