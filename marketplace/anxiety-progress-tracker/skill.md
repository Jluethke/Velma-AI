# Anxiety Progress Tracker

Track anxiety levels over time with journaling prompts, symptom logging, and progress visualization.

## Inputs

- `severity_baseline`: Starting severity level
- `coping_toolkit`: Tools being used
- `habit_changes`: Routine changes being implemented

## Outputs

- `tracking_template`: Daily check-in format
- `weekly_review_prompts`: Weekly reflection questions
- `escalation_criteria`: When to seek professional help

## Process

1. Design simple daily rating system
2. Create weekly reflection prompts
3. Define progress milestones
4. Set escalation criteria for professional referral
5. Plan 30/60/90 day reviews
