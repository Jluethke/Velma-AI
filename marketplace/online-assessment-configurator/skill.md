# Online Assessment Configurator

Set up assessments and grading in the LMS for the online course.

## Inputs

- `lms-course`: Course configured in the LMS
- `course-objectives`: List of learning objectives

## Outputs

- `assessment-setup`: All assessments configured in the LMS with rubrics
- `gradebook-config`: Gradebook configuration with weights and policies

## Process

1. Create quizzes, assignments, and discussion prompts in the LMS
2. Upload rubrics and scoring criteria
3. Configure the gradebook with weights and late policies
4. Set up automated feedback where possible
