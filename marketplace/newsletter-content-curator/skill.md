# Newsletter Content Curator

Gather and curate the content for a single newsletter issue.

## Inputs

- `editorial-calendar`: The editorial plan for this issue
- `content-sources`: Sources to draw content from

## Outputs

- `curated-content`: Selected and organized content for the issue
- `content-brief`: Brief for any original content that needs to be written

## Process

1. Collect content from each identified source.
2. Select the best items based on relevance, timeliness, and audience interest.
3. Write the brief for any original sections that need drafting.
4. Organize the content in the planned section order.
