# Core Model Definitions

Learn the precise definition of each of the 10 core mental models: first principles, inversion, second-order thinking, Pareto principle, opportunity cost, margin of safety, feedback loops, compounding, reversion to mean, map is not territory.

## Inputs

- `current-decision-domain`: The domain where you make most of your decisions (business, engineering, personal, investing, management)
- `known-models`: Mental models you already use, even informally

## Outputs

- `model-definitions`: Precise one-paragraph definition of each of the 10 core models, with the key question each one answers
- `model-trigger-conditions`: For each model, the situation type where it is most useful (e.g., inversion is most useful when you are stuck on 'how to succeed' and should instead ask 'how would I guarantee failure')

## Process

1. For each model, write a one-paragraph definition in your own words (not copied). If you cannot explain it simply, you do not understand it yet.
2. For each model, write the key question it answers. First principles: 'What is actually true here, independent of convention?' Inversion: 'What would guarantee failure, and am I doing any of those things?' Second-order: 'And then what?'
3. For each model, identify the trigger condition: the type of situation where this model produces the most insight.
4. Identify which models you already use informally. You probably use 2-3 without naming them. The goal is to add the other 7-8 deliberately.
