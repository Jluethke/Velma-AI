# Load Test Optimization Recommender

Recommend optimizations based on bottleneck findings and produce the load test report.

## Inputs

- `bottleneck-findings`: Identified bottlenecks
- `breaking-point`: The system's breaking point under load

## Outputs

- `optimization-recommendations`: Prioritized list of performance improvements
- `load-test-report`: Complete load testing campaign report

## Process

1. Prioritize bottlenecks by impact on user experience
2. Recommend specific optimizations for each bottleneck
3. Estimate the expected improvement from each optimization
4. Compile the full load test report with findings and recommendations
