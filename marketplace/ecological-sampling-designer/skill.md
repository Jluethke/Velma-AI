# Ecological Sampling Designer

Design a sampling scheme for population estimation: choose method (transects, quadrats, point counts, traps), set spatial layout, and determine replication.

## Inputs

- `target-species`: Species or species group to study
- `study-area`: Geographic extent, habitat types, and access

## Outputs

- `sampling-design`: Method, spatial layout (transect routes, plot coordinates), replication, and seasonal timing
- `detection-model`: Expected detection probability and factors affecting it
- `effort-schedule`: Number of visits, time per visit, and seasonal windows

## Process

1. Select a sampling method suited to the species' ecology and detectability
2. Lay out sampling units to cover habitat variation and minimize spatial bias
3. Estimate detection probability from pilot data or published values
4. Set replication to achieve the target precision for population estimates
