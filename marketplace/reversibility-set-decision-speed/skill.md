# Reversibility Set Decision Speed

Assign a timeline and owner to each decision so the pace matches its type.

## Inputs

- `corrected-labels`: Over-labeled decisions moved to the fast path.
- `speed-gains`: The time saved by not over-analyzing reversible choices.

## Outputs

- `decision-schedule`: A deadline and owner for each decision.
- `speed-rules`: A reusable rule for setting decision speed by type.

## Process

1. Set a deadline for each decision that fits its type.
2. Name the owner who will make each decision.
3. Write a short rule the team can reuse to set decision speed by type.
