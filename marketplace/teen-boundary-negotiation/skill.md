# Teen Boundary Negotiation

Set age-appropriate boundaries with teen input: curfews, screens, responsibilities, and consequences.

## Inputs

- `teen_age`: Age and maturity level
- `current_rules`: Existing household rules
- `problem_areas`: Areas where boundaries are needed

## Outputs

- `boundary_agreement`: Negotiated rules with teen input
- `consequence_matrix`: Clear consequences for violations
- `earned_privileges`: How to earn more freedom

## Process

1. List areas needing boundaries
2. Research age-appropriate expectations
3. Draft proposed boundaries
4. Build in teen negotiation room
5. Define consequences and earned privileges
