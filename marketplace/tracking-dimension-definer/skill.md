# Tracking Dimension Definer

Define the dimensions for tracking project status.

## Inputs

- `project-list`: Active projects or workstreams to track
- `stakeholder-needs`: What stakeholders need to know

## Outputs

- `tracking-dimensions`: Fields to track per workstream (milestone, owner, status, blockers, dependencies)
- `status-definitions`: What each status value means (on-track, at-risk, blocked, complete)

## Process

1. List the dimensions: milestone, owner, status, blockers, dependencies, next action, target date.
2. Define the status values and their criteria.
3. Map stakeholder needs to tracking dimensions.
4. Produce the tracking dimension definitions.
