# Vsm Implementation Planner

Create the implementation plan with kaizen events.

## Inputs

- `future-state-map`: Future state VSM
- `target-metrics`: Target metrics

## Outputs

- `implementation-plan`: Sequenced plan with kaizen events
- `value-stream-analysis`: Complete VSM analysis document

## Process

1. Break the future state into implementation loops (pacemaker loop first)
2. Define kaizen events for each loop with scope, team, and dates
3. Sequence the events to build on each other
4. Compile the complete value stream analysis with current state, future state, and implementation plan
