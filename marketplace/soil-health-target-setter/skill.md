# Soil Health Target Setter

Set improvement targets based on baseline data and production goals.

## Inputs

- `baseline-results`: Current soil health metrics
- `production-goals`: Yield and quality targets for the operation

## Outputs

- `improvement-targets`: Specific numeric targets for key soil health indicators
- `priority-fields`: Fields ranked by need for intervention

## Process

1. Compare baseline values to regional benchmarks and production requirements.
2. Set targets for organic matter, aggregate stability, water infiltration, and biology.
3. Rank fields by the gap between current values and targets.
4. Prioritize fields where improvement has the highest return.
