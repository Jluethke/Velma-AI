# Insider Access Pattern Analysis

Analyze the subject's data access patterns for anomalies.

## Inputs

- `preserved-logs`: Collected logs and access records
- `initial-risk-assessment`: Preliminary risk level and indicators to investigate

## Outputs

- `access-anomalies`: Identified anomalous access patterns with evidence
- `data-access-timeline`: Timeline of the subject's data access activity

## Process

1. Build a baseline of the subject's normal access patterns
2. Identify deviations from baseline (unusual hours, volumes, file types, systems)
3. Cross-reference with known indicators from the referral
4. Build a timeline of suspicious activity
