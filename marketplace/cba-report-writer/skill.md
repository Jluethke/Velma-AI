# Cba Report Writer

Produce the cost-benefit analysis report with recommendation.

## Inputs

- `comparison-table`: Side-by-side alternative comparison
- `sensitivity-results`: Sensitivity analysis results

## Outputs

- `cba-report`: Complete cost-benefit analysis report with recommendation
- `executive-summary`: One-page executive summary of the analysis

## Process

1. Write the executive summary with the recommended alternative and key rationale.
2. Present the detailed analysis with methodology, assumptions, and calculations.
3. Include sensitivity analysis results and risk factors.
4. State the recommendation with conditions and next steps.
