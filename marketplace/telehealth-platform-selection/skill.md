# Telehealth Platform Selection

Evaluate and select a telehealth platform based on practice requirements.

## Inputs

- `practice-requirements`: Practice size, specialties, EHR system, and telehealth use cases
- `compliance-requirements`: HIPAA, state licensing, and payer requirements for telehealth

## Outputs

- `platform-selection`: Selected telehealth platform with rationale
- `platform-comparison`: Comparison of evaluated platforms on key criteria (EHR integration, cost, features, compliance)

## Process

1. Define the must-have features (EHR integration, scheduling, patient portal, mobile access, recording).
2. Evaluate platforms against the requirements (video quality, HIPAA compliance, cost, ease of use).
3. Check EHR integration compatibility and implementation effort.
4. Select the platform and document the rationale.
