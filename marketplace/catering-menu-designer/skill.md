# Catering Menu Designer

Design the menu to match the event requirements and budget.

## Inputs

- `event-requirements`: Event requirements
- `budget-allocation`: Budget allocation

## Outputs

- `proposed-menu`: Menu with items, portions, and pricing
- `dietary-accommodation-plan`: Plan for each dietary restriction

## Process

1. Select menu items that fit the theme and budget.
2. Design options for each dietary restriction.
3. Calculate the per-person cost.
4. Produce the menu proposal for client review.
